## Description
Resolved. Completed the code-level decoupling of behavioral and system settings from `config.json` into the 3-Tier Configuration Cascade:

1. **Pure Disk Topology SSOT (`config.json`)**: Sanitized `config.json` to contain strictly physical disk mapping keys (`target_repos`, `sub_buckets`, `ignore_dirs`, `ignore_files`, `ignore_patterns`, `include_extensions`, `managed_dirs`, `workspace_root`). All non-topology keys are stripped on write via `sanitize_workspace_config()`.
2. **Daemon Settings Scoping (`system.json`)**: Global daemon settings (`port`, `enable_watchdog`, `preload_all_extensions`, `offline_cache_limit_mb`) are vaulted in `.insetu/system.json` under `daemon` scope.
3. **Workspace Settings Scoping (`workspace.settings.json`)**: Tenant-specific preferences (`instance_title`, `instance_emoji`, `extensions`, `export_shared_domains`, `shared_mounts`) are vaulted in `<control_dir>/workspace.settings.json` under `workspace` scope.
4. **Transparent In-Memory Hydration**: Deployed `@hooks.on('mutate_workspace_config', priority=1)` handler `hydrate_and_migrate_cascade_settings` to lazily migrate legacy `config.json` files and hydrate in-memory `cfg` maps for downstream consumers (`is_extension_enabled`, UI config endpoints) without polluting physical disk files.
5. **CLI Onboarding Alignment**: Refactored `handle_init` in `cli_commands.py` to scaffold pure topology `config.json` files by default and store settings into their respective cascade tiers.
