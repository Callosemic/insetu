## Description
* **Universal Selector-Scoped Store Subscription Migration (`ext_*.js`)**: Migrated all remaining coarse store subscriptions (`this.subscribe(Store, state => { ... })`) across all 11 Tier 3 domain extensions (`citations`, `cronic`, `dev`, `favorites`, `flow`, `freshdesk`, `git`, `hooks`, `ingest`, `research`, `skills`, `tracker`, `update`) to 3-argument selector-scoped subscriptions (`this.subscribe(Store, selector, listener)`), satisfying the `COARSE_STORE_SUBSCRIPTION_MANDATE` and eliminating render thrashing.
* **Repository Storage Containment & Migration (`.insetu-data/`)**:
  * **Issue Tracker (`engine_tracker.py`, `ext_tracker.js`)**: Migrated physical ticket storage from `<repo>/.tracker/` to `<repo>/.insetu-data/tracker/`. Implemented automatic Phase 1 boot migration (`move_tree_contents`) for legacy `.tracker/` directories, added dual-path fallback resolution, updated Cartographer `managed_dirs` / `ignore_exceptions`, and packaged `.insetu-data/tracker/prompts/ticket_authoring_guide.md` as an ADR 0064 virtual module template.
  * **Notes Library (`engine_notes.py`, `ext_notes.js`)**: Implemented dual-scope notes architecture supporting repository-scoped notes (`vfs://{repo}/.insetu-data/notes/{filename}`) alongside global workspace notes (`ctx://notes/{filename}`). Notes automatically relocate across `ctx://` and `vfs://` boundaries if frontmatter `repo` is modified, and `.insetu-data/notes/` sub-buckets (`notes_omitted`) are automatically excluded from Git diffs via `@hooks.on('mutate_workspace_config')`.
  * **Skills Tracker (`engine_skills.py`, `ext_skills.js`)**: Relocated localized skills markdown storage to `ctx.paths["data_dir"]` (`.insetu/data/skills`), with Phase 1 boot-time self-migration from legacy paths.
* **Akasa Kernel Background Job API Unification (`engine_*.py`)**: Standardized all extension background workers on `@bp.worker` decorators and `ctx.jobs` methods (`schedule`, `cancel`, `register_ephemeral`), purging legacy `submit_job`, `cancel_job`, `register_callback`, and direct SQLite mutations on `immediate_jobs`.
* **Bi-Directional State Hydration & JSON Persistence Sync**:
  * Implemented `_ensure_*_hydrated(ctx)` and `_flush_*_to_json(ctx)` across `citations` (`library.json`), `cronic` (`schedules.json`), `favorites` (`bookmarks.json`), and `hooks` (`rules.json`), ensuring SQLite ledgers survive ephemeral restarts and synchronize with JSON configurations.
* **Automation Hooks Cryptographic Command Approval Gate (`engine_hooks.py`)**: Implemented `_get_approved_hook_ids` and `_mark_hook_approved`, persisting cryptographic command SHA-256 signatures in `.insetu/system.json` under `approved_hooks`. Rules loaded from disk without matching approvals are initialized with `enabled: 0` to prevent unreviewed execution.
* **Freshdesk Thread Archival & Synchronous REST Gateway (`engine_freshdesk.py`, `ext_freshdesk.js`)**: Moved thread caching from `artifacts_base` to `cache_dir`, exposed `GET tickets/<id>/thread` for synchronous text fetching, and eliminated raw `.innerHTML` template assignment in favor of safe text interpolation.
* **AST Import Hygiene & Private Namespace Isolation**: Hoisted all standard library and core framework imports to top-level module scope across all backend engines, and aliased deferred inline imports (`import module as _module`) to satisfy the `UNALIASED_INLINE_IMPORT` AST rule.
* **Virtual Module Prompt Templates**: Added untracked prompt templates `insetu/extensions/research/prompts/batch_triage_filter.md` and `insetu/extensions/tracker/prompts/ticket_authoring_guide.md` for virtual projection under ADR 0064.
