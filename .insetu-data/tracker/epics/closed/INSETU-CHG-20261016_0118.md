## Description
* **Core Module Registration Alignment (`insetu/app.py`)**: Registered `prompts` as a trusted Tier 2 core module in `akasa.utils.register_core_module`, completing the Core Prompt Engine graduation from ADR 0064.
* **CLI Profile Scaffolding Modernization (`insetu/cli.py`)**: Purged obsolete `workflows.json` generation from `scaffold_profiles()`. Added automatic initialization for `.insetu/data/` and `.insetu/cache/db/` directories during profile setup.
* **Default Gitignore Cache & Credential Expansion (`insetu/defaults/gitignore.txt`)**: Replaced deprecated `data/` rule with explicit exclusions for ephemeral runtime directories (`cache/`, `ext/`, `contexts/`, `diffs/`, `workflows/`), SQLite transactions and corrupt databases (`*.db`, `*.db-wal`, `*.db-shm`, `*.db-journal`, `*.db.corrupt_*`), and sensitive credentials (`secrets.json`, `master_key.txt`, `*.env`), allowing `.insetu/data/` persistent state to be tracked.
* **Fallback Bridge AST Import Hygiene (`insetu/fallback_bridge.py`)**: Hoisted function-level inline imports (`redirect`, `datetime`, `zipfile`, `threading`, `time`) to the module top-level scope, eliminating `UNALIASED_INLINE_IMPORT` violations and ensuring full compliance with the AST fitness linter.
* **Service Worker Cache Invalidation Bump (`insetu/static/sw.js`)**: Incremented `self.OS_CACHE_VERSION = 'v5'` to invalidate stale browser caches and trigger immediate Service Worker client updates.
* **Vendor Manifest Offline CDN Ban Remediation (`insetu/static/vendor.json`)**: Replaced external unpkg CDN URL (`https://unpkg.com/lucide@latest`) with the local vendored path `vendor/lucide/icons.js` (version `1.0.0`, range `>=0.0.0`), resolving static analysis warnings under `VENDOR_MANIFEST_CDN_BAN` and enforcing ADR 0032 offline compliance.
