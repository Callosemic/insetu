## Description
* **Yomama Multi-Surface Shell Architecture (`bridge.js`, `agent.js`)**:
  * Unified the Yomama Sync Bridge, Autonomous Agent Chat, Routines Catalog, and Patch Receipts into an integrated multi-surface shell (`.yomama-shell`).
  * Implemented responsive drawer navigation (`.yomama-drawer`, `.yomama-stage`, `.yomama-drawer-backdrop`) discovering and rendering `slots:yomama-surface` (`bridge`, `chat`, `routines`, `receipts`) and `slots:yomama-drawer` (`agent-sessions`).
  * Standardized dynamic tab header synchronization via `ExtensionRegistry.setDynamicLayoutSlots('bridge', ...)`, updating tab intent and icon dynamically to match the active surface.
  * Added chunk navigation controls (`Prev` / `Next`) to `InSetuBridgeEditProjection` and enforced strict full-container viewport sizing (`min-height: 0; min-width: 0; height: 100%; width: 100%`).
* **Declarative Agent Orchestration Routines & Scratch Vaulting (`orchestrator.py`, `engine_agent.py`, `agent.js`, `routines/*.yaml`)**:
  * Implemented the declarative YAML routine execution engine (`execute_declarative_routine`, `load_routine_definition`, `list_available_routines`).
  * Bundled standard routine DAGs: `workspace_turn` (/auto router), `code` (/code patch generator), `plan` (/plan architectural planner), `ask` (/ask read-only Q&A), `yomama` (/yomama patch healer), `map_reduce_audit` (parallel per-file audit), and `symbol_refactor` (surgical AST refactor).
  * Built safe, zero-eval conditional expression evaluation (`evaluate_when_condition`) using Python standard library AST traversal.
  * Enforced automatic 256KB disk scratch vaulting (`SCRATCH_VAULT_THRESHOLD_BYTES = 256 * 1024`) via `ctx.jobs.write_scratch`, keeping RAM allocations flat during massive context operations.
  * Implemented unified slash command parsing (`_parse_slash_command`) mapping `/code`, `/plan`, `/ask`, `/yomama`, and `/undo`.
  * Added session turn cancellation (`POST agent/cancel`) and transactional rollback (`POST agent/undo` invoking `bridge.revert`).
  * Redesigned `InSetuCoreAgent` composer with two-tier input controls, pill differentiation for editable target files (`✏️`) vs read-only references (`🔒`), and raw patch paste interception.
* **Deferred Chunk Post-Valid Buffer Re-Evaluation & Fast-Tier Auto-Healing (`bridge_vfs.py`, `engine_bridge.py`, `bridge.js`)**:
  * Upgraded `_process_sync_transaction` with deferred chunk handling: when a multi-chunk patch contains an anchor mismatch or overlapping edit, the engine defers the failed chunk to the end of the patch list, applies prior valid non-overlapping chunks to the in-memory buffer, and re-evaluates the deferred chunk against the post-valid buffer.
  * Implemented the auto-heal background loop (`_background_bridge_sync`): when `auto_heal=True` and patches fail, captures post-valid in-memory buffers and submits only failed chunks to the fast LLM tier (`llm.complete` with `tier="fast"`, `output_schema="yomama_patch"`).
  * Added client-side auto-heal toggle (`Auto-Heal: ON (Fast Tier)`) in the `bridge.js` footer.
* **AST Refactoring Directives & Ledger Commit Message Synthesis (`bridge_ast.py`, `engine_bridge.py`, `prompts/yomama_patch_protocol.md`)**:
  * Extended `parse_blocks` with declarative `<<<<<<< RELOCATE` and `<<<<<<< RENAME` directives terminated by `>>>>>>> EXECUTE`.
  * Implemented `apply_ast_relocate_in_memory` providing byte-exact symbol relocation between source and target files with idempotency detection.
  * Implemented `apply_ast_rename_to_content` providing token-aware identifier renaming for Python (via `tokenize`) and JavaScript/TypeScript without modifying string literals or comments.
  * Exposed `POST bridge/ast_relocate`, `POST bridge/ast_rename`, and `GET bridge/commit_message` (synthesizing Conventional Commit messages and `Transaction-ID:` trailers from `bridge_ledger` comments).
  * Purged deprecated legacy stub `bridge_parser.py`.
* **Universal LLM Gateway Enhancements (`engine_llm.py`)**:
  * Added the `openai_compatible` inference provider supporting local and OpenAI-compatible endpoints (Ollama, LM Studio, vLLM, llama.cpp) via configurable `base_url`.
  * Added semantic tier model routing (`tier_fast_model`, `tier_thinking_model`, `tier_frontier_model`).
  * Implemented the Universal Output Schema Bouncer (`validate_output_schema`) supporting `yomama_patch`, `intent_classification`, `json`, and custom schemas with automated self-healing retry loops.
  * Hardened the Claude CLI subprocess adapter: pipes prompts over stdin, isolates stderr, strips ANSI escape sequences, and sets `NO_COLOR=1` and `TERM=dumb`.
  * Added aggregated completion endpoint `POST llm/complete` and push-to-talk audio transcription endpoint `POST llm/transcribe`.
