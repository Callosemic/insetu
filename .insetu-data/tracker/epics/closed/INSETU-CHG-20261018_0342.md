## Description
* **WSGI Request Context SQLite Connection Cleanup (`insetu/app.py`)**: Added `@app.teardown_appcontext` hook invoking `close_thread_connections()` from `akasa.db`, ensuring thread-local SQLite connection handles spawned by ephemeral WSGI request threads are deterministically closed to eliminate connection leaks and WAL lock contention.
* **File Descriptor Scaling (`insetu/app.py`)**: Integrated POSIX `resource.setrlimit` adjustment during application startup to raise soft file descriptor limits (`RLIMIT_NOFILE`) up to 65,536, protecting the daemon from socket and file descriptor exhaustion during high-concurrency compilation and VFS sweeps.
* **Daemon Scope Configuration Cascade Alignment (`insetu/app.py`)**: Migrated `preload_all_extensions` and `port` lookups in `load_workspace_extensions()` and `run_app()` to resolve values from Tier 1 Daemon Scope (`system.json`) via `SettingsManager('system', 'default')` with fallback to `cfg.get()`, aligning runtime execution with ADR 0040 and ADR 0066.
* **Boot Lifecycle & Reloader Guardrail Refinement (`insetu/app.py`)**: Refined the system boot ignition guardrail to evaluate `use_reloader = os.environ.get("INSETU_RELOADER", "0") == "1"`, ensuring `@hooks.emit('system_boot')` ignites reliably for single-process `insetu serve` and WSGI production environments while preventing duplicate thread execution under Werkzeug supervisor reloads.
* **Pure Disk Topology Default Configuration (`insetu/defaults/config_json.txt`)**: Stripped legacy daemon and workspace settings keys (`instance_title`, `instance_emoji`, `port`, `extensions`), fully populating default disk topology keys (`ignore_dirs`, `ignore_files`, `ignore_patterns`, `include_extensions`, `managed_dirs`, `target_repos`) in compliance with ADR 0066 and completing ticket `INS-QUEUE-20260812_1018`.
* **Extension Scaffolding Scope Mandate Compliance (`insetu/defaults/engine_template_py.txt`)**: Added `"scope": "workspace"` to the scaffolded `SETTINGS` schema in `engine_template_py.txt` to ensure newly scaffolded extensions pass the `SETTINGS_SCOPE_MANDATE` AST fitness linter.
