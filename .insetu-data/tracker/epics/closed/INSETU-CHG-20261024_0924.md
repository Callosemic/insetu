## Description
* **Pure-Stdlib Daemon Port Pre-Seeder (`insetu/app.py`)**:
  * Implemented `_preseed_daemon_port_env()`, which executes at module evaluation before application bootstrap or settings manager initialization.
  * Directly inspects `.insetu/host.json` using Python standard library modules (`pathlib.Path`, `json`, `os`), parsing and exporting `INSETU_PORT` into `os.environ`.
  * Guarantees that if an early kernel panic occurs, the Immutable Recovery OS (Lifeboat FS) binds to the operator's configured host port rather than defaulting to 5005.
* **System Index Path SSOT Alignment (`insetu/app.py`)**:
  * Replaced the hardcoded `.insetu/system.json` path calculation in `load_workspace_extensions()` with `get_system_index_path()`.
  * Ensures multi-tenant workspace extension sweeps query the authoritative `workspaces.json` registry in compliance with ADR 0040 and ADR 0066.
* **Pathlib Compliance & Lifecycle Shutdown Guards (`insetu/app.py`)**:
  * Migrated icon cache-busting timestamp evaluation in `manifest()` from `os.path.getmtime` to `Path(cfg_path).stat().st_mtime` and `Path(cfg_path).exists()`, fulfilling the `PATHLIB_MANDATE`.
  * Wrapped `run_app()` server execution in a `try...except` block dispatching `hooks.emit("system_shutdown")` upon unexpected crashes, ensuring thread pools, database locks, and sockets are cleanly torn down.
* **Resilient Zero-Dependency Profile Scaffolding (`insetu/cli.py`)**:
  * Enhanced `scaffold_profiles(cwd)` with in-memory fallback JSON structures for `host.json` (`{"port": 5005}`) and `workspaces.json` (`{"workspaces": {"default": {"config_path": "config.json"}}, "active_workspace": "default"}`).
  * Protects `insetu serve` from boot failures in minimal packaging or containerized environments where default template files may be missing or unreadable.
* **Extension Template API Client Modernization (`insetu/defaults/ext_template_js.txt`)**:
  * Updated `{{cap_name}}Store` in the starter extension template to call `window.inSetu.api.get('{{ext_name}}/list')` instead of the deprecated `window.inSetu.api.workspace.get()`.
  * Ensures newly scaffolded extensions comply out of the box with the semantic API routing contract (ADR 0016) and prevent `SEMANTIC_API_ROUTING_MANDATE` static analysis warnings.
* **Fallback Bridge Patch Protocol & Pathlib Hardening (`insetu/fallback_bridge.py`)**:
  * Added ignore handling for `<<<<<<< ID:` cell metadata lines in `parse_blocks()`, preventing cell ID headers generated by the Yomama Sync Bridge from corrupting patch parsing.
  * Added direct transition to `REPLACE` state when `=======` is encountered from `OUTSIDE` or `COMMENT` states, ensuring genesis patches are parsed reliably even when the search block header is omitted.
  * Replaced `os.path.splitext()` with `Path(bucket_name).stem` and `Path(bucket_name).suffix` in `api_emergency_dump()`, satisfying the `PATHLIB_MANDATE`.
