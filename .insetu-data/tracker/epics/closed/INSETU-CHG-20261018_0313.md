## Description
* **Canonical URI Standardization & Ingress Normalization (`InSetuURI`, `utils_core.py`)**:
  * Hardened `InSetuURI` to strictly mandate canonical `scheme://` prefixes (`vfs://`, `ctx://`, `ws://`) internally, raising `ValueError` on scheme-less strings and eliminating fragile path heuristics.
  * Isolated input normalization to `InSetuURI.from_external_input(raw, default_scheme="vfs")` at system ingress boundaries (Yomama search blocks, HTTP route parameters).
  * Deployed boot migrations across `topology_ledger`, `manifest_ledger`, and `file_preferences` to automatically upgrade legacy un-prefixed rows to canonical URIs.
  * Purged deprecated `coerce_naked_uri`, `coerce_gather_uris`, and `coerce_prompts_uris` hooks.
* **Inter-Workspace Virtual Mounts (`ws://`) & Mutual Authorization Handshake (`engine_system.py`, `engine_topology.py`)**:
  * Implemented `InterWorkspaceVFSDriver` and registered `_authorize_inter_workspace_mount` with the Akasa kernel, enabling tenant workspaces to mount assets from peer workspaces read-only via `ws://<workspace_id>/<domain>/...`.
  * Enforced mutual authorization handshake: subscriber declares `shared_mounts` in `workspace.settings.json`, and publisher declares `export_shared_domains` with tenant whitelists or wildcard `*`.
  * Implemented strict read-only VFS write barriers: attempts to save, move, delete, or bulk-mutate `ws://` targets are rejected with HTTP 403 Forbidden.
  * Configured cross-workspace event broadcasting (`broadcast_cross_workspace_mutations`): mutations on exported `ctx://` domains broadcast synthetic `ws://` mutations to subscribed workspaces, guarded against recursive reentrancy.
  * Built the "Virtual Mounts & Asset Sharing" management interface in `<insetu-system-settings>` to configure subscriptions and exports visually.
* **3-Tier Configuration Cascade Hardening & Pure Topology Sanitization (`engine_system.py`, `cli_commands.py`)**:
  * Sanitized `config.json` to be 100% pure physical disk topology (`target_repos`, `sub_buckets`, `ignore_dirs`, `include_extensions`, `managed_dirs`), resolving ticket `INS-QUEUE-20260812_1018`.
  * Migrated `port`, `enable_watchdog`, and `preload_all_extensions` to `system.json` (`daemon` scope), while `instance_title`, `instance_emoji`, and `extensions` reside in `workspace.settings.json` (`workspace` scope).
  * Deployed `hydrate_and_migrate_cascade_settings` hook to lazily migrate legacy `config.json` files and hydrate in-memory configs for runtime consumers.
  * Updated `insetu init` in `cli_commands.py` to scaffold pure topology configurations and initialize master key encryption for LLM credentials.
* **Terminal Mark-and-Sweep Garbage Collection & Atomic Cache Settlement (`engine_gather.py`)**:
  * Registered `vacuum_unaccounted_cache_on_complete` under the `@hooks.on('compilation_sequence_complete')` lifecycle event, deferring cache sweeping across `ctx://contexts`, `ctx://diffs`, and `ctx://workflows` until all compilation DAG steps settle and flush chunks to disk.
  * Refactored `compile_context_payload` to compute SHA-256 hashes incrementally across chunk streams, eliminating duplicate multi-megabyte string allocations in RAM.
* **Extension SDK Advancements & Web Component Ergonomics (`sdk/__init__.py`, `insetu_sdk.js`, `ui_file_tree.js`, `ui_editor.js`)**:
  * Added `ctx.create_entity_file()` to `ExtensionContext`, standardizing Markdown document creation with YAML frontmatter, slug generation, and atomic VFS commits.
  * Enhanced `InSetuElement` with `this.bindStore()` (featuring declarative `autoFetch`) and `this.filterItems()`.
  * Standardized tree hierarchy construction on `buildUriFileTree()` in `ui_file_tree.js`, parsing canonical URIs natively and displaying distinct visual iconography for shared mounts (`ws://`), module templates, and Git-modified files.
  * Created `<insetu-projection-window-controls>` and connected `InSetuFrontmatterEditor` to debounced auto-saving (2000ms delay), `beforeunload` keepalive emergency flushes, and focus-aware idle hot-swapping.
