## Description
* **Compiler-Grade Yomama Two-Phase Parser (`insetu/core/bridge/parser.py`)**:
  * Extracted Yomama block lexing and parsing out of `utils_core.py` into sovereign module `insetu/core/bridge/parser.py`.
  * Implemented fence-balanced lookahead separator disambiguation (`_select_optimal_separator_index`) to resolve ambiguous `=======` lines within code blocks.
  * Added web-chat artifact pre-cleaning (`_preclean_web_chat_artifacts`): expands anti-meltdown macros (`{{ymm:...}}`), strips zero-width invisible characters, and repairs blockquote chevron meltdowns (`> > > REPLACE` -> `>>>>>>> REPLACE`).
  * Hardened marker candidate detection to tolerate leading indentation and strip leaked citation tags.
  * Added deterministic diagnostic blocks (`malformed: True`) with line numbers for boundary synchronization failures.
  * Centralized `compute_block_signature`, `flatten_parsed_blocks`, and `get_base_step_and_diffs`.
* **Two-Tier Signature Memoization & In-Place $n-1$ Healing (`bridge_vfs.py`, `bridge_fuzzy.py`, `engine_bridge.py`)**:
  * Implemented Tier 1 per-file bundle cache (`_FILE_EVAL_CACHE` with `compute_file_eval_signature`), skipping AST syntax validation and block execution in $O(1)$ time for untouched files.
  * Implemented Tier 2 intra-file sequential chunk cache (`_PATCH_EVAL_CACHE` with `compute_patch_eval_signature`), memoizing state transitions ($H(B_{k-1}) \rightarrow H(B_k)$) so preceding valid chunks are not re-applied when healing chunk $n$.
  * Enforced canonical given order ($0 \dots n$): blocks preserve their creation `order`, evaluate in sequence, and are never reordered to the tail.
  * Enforced Patch Payload Immutability: eliminated in-place mutation of `block["search"]` and `block["replace"]` inside `apply_block_in_memory`.
  * Implemented Tier 2 deterministic overlap rebasing (`rebase_overlapping_block_in_memory`): context-edge shrinking and in-memory 3-way line merge (`three_way_merge_text(O, A, B)`).
  * Built parallel in-place $n-1$ fast-tier auto-healing (`_background_bridge_sync`): captures exact $B_{n-1}$ pre-buffers, extracts windowed line slices (`_extract_windowed_buffer_context`) for files > 400 lines, heals failed chunks via `ctx.jobs.map_parallel`, and substitutes repaired blocks in-place at index $n$.
  * Built $O(1)$ end-of-file AST syntax gate validating files once on clean batches, with fault-isolating rollback.
  * Enforced S8 guarded writes blocking agent-originated writes targeting `cli.py` or `fallback_bridge.py`.
* **Yomama Sync Bridge Client UI Modernization (`bridge.js`)**:
  * Migrated `InSetuExtBridge`, `InSetuBridgeDiffProjection`, `InSetuBridgeEditProjection`, and `InSetuExtBridgeHistory` to pure `sharedStyles` and Sutram primitives (`<sutram-sidebar-layout>`, `<sutram-view>`, `<sutram-surface>`, `<sutram-card>`, `<sutram-stack>`).
  * Implemented Smart Replace-on-Paste: pasting repaired blocks for files with broken/inactive cells replaces those cells in-place instead of appending duplicates.
  * Implemented optimistic 0ms local cell skips (`skipCellOptimistic`, `skipAllFailedCellsOptimistic`) updating telemetry and `can_commit` without a network round-trip.
  * Added batch triage bar ("Snap All Closest Anchors", "AI Repair All Failed", "Copy Repair Prompt", "Skip All Failed", "Commit N Clean Files Now") and per-patch quick action buttons.
* **External Web-Chat Handoff & Prompt Compiler Hardening (`orchestrator.py`, `engine_agent.py`, `agent.js`)**:
  * Decoupled prompt context inclusion for web_chat/manual handoffs (`include_context=False`), preventing raw `<workspace_context_nonce>` dumps from bleeding into copied prompts while tracking `context_uris` separately.
  * Suppressed bare command slug echoes when `user_prompt` matches the routine ID or slash command.
  * Fixed `serialize_routine_to_markdown` to eradicate literal `---\n---\n\n` double-frontmatter leaks across routine files.
  * Preserved unheaded markdown bodies under `execute_prompt`.
  * Implemented `_read_routine_uri_or_path` checking `ctx.vfs.read()` before reading disk for instant uncommitted routine discovery.
  * Upgraded `_normalize_condition_expr` supporting `contains` expressions (`LHS contains RHS` -> `RHS in LHS`) and mustache default bindings (`{{ var | default }}`).
  * Added `system.extensions.workspace.approve` and `system.extensions.workspace.revoke` to `ROUTINE_BANNED_CAPABILITIES`.
  * Routed `chain_context["sys"]` through `build_sys_landmarks_context`, dynamically providing repository landmarks to routine DAGs.
  * Converted agent components to pure `sharedStyles`, `<sutram-floating-hud>`, and `<sutram-composer>`.
* **Universal LLM Gateway & MCP Server Security Hardening (`engine_llm.py`, `engine_mcp.py`)**:
  * Routed `_run_decisions_inference`, `api_llm_transcribe`, and `_harvest_external_model_catalog` through `fetch_url()` to comply with S4 `OUTBOUND_FETCH_MANDATE`.
  * Migrated endpoint API key vaulting to `get_repeater_secret` and `set_repeater_secret`.
  * Delegated `validate_output_schema` to `insetu.core.agent.schemas.validate_schema_response`.
  * Hardened MCP server with `'agent'` dependency, dynamic `resolve_repo_code_index_uri`, and prompt cascade resolution.
