## Description
* **Akasa Membrane Decoupling (`cartographer.py`, `engine_gather.py`, `engine_prompts.py`, `engine_topology.py`)**:
  * Eradicated direct `akasa.*` framework imports across all Tier 2 core engines, routing framework utilities strictly through `insetu.core.sdk` and `insetu.core.utils_core` to satisfy `AKASA_MEMBRANE_ISOLATION`.
  * Replaced global `@hooks.on(...)` subscriptions with blueprint-scoped `@cartographer_bp.on(...)`, `@gather_bp.on(...)`, `@prompts_bp.on(...)`, and `@topology_bp.on(...)` decorators.
* **Declarative Extension Volume Schemas (`engine_gather.py`, `engine_prompts.py`)**:
  * Migrated `ctx://contexts` and `ctx://prompts` to declarative `volumes={...}` declarations on `InSetuExtension`.
  * Purged manual `mount_volume()`, `hook_request_paths`, `register_driver()`, and `move_tree_contents()` routines, letting the SDK handle mount topologies, path mappings, and directory migrations automatically.
* **JIT Self-Healing Context Resolution (`engine_gather.py`)**:
  * Integrated `_resolve_or_heal_compiled_ctx_artifact` under `@gather_bp.on('vfs_resolve_file')` to intercept read requests for compiled `ctx://` artifacts.
  * Resolves multi-part chunk sets to the first available chunk, and dynamically executes targeted compilations (`generate_context_file` or `_compile_wf`) when physical cache files are missing or cold on disk, protected against reentrancy loops via `_LOCAL_HEAL_GUARD`.
* **Manifest Metadata Preservation & Domain Fallbacks (`engine_gather.py`, `gather.js`)**:
  * Updated `compile_context_payload` to update existing manifest metadata (title, domain, description) in place when content hashes match and physical chunk I/O is skipped.
  * Implemented `_heal_entry_domain` to ensure manifest entries inherit parent repository domains rather than hardcoded fallbacks.
  * Overhauled `getFlattenedBuckets` in `gather.js` to polymorphically handle array, string, or null target parameters and support dynamic module split prefixes.
* **Prompts Sub-Navigation Menu Modernization & RFC 0108 Alignment (`prompts.js`, `engine_prompts.py`)**:
  * Eradicated bespoke `<insetu-ext-prompts-actions>` Web Component and `slots:sub-navigation-actions` registration in favor of declarative `menuStores: ["App"]` and `menuActions: _buildPromptsMenuActions` on the `slots:sub-navigation` slot.
  * Migrated `InSetuExtPrompts` from deprecated `globalBrowsePath` to tab-scoped `browsePath` via `AppStore.getState().getBrowsePath(this._getSubKey())`.
  * Added `warmedPromptUrls` tracking to `PromptsStore` to eliminate duplicate warming requests on prompt lists.
