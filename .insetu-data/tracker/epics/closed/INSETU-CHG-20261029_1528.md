## Description
* **App Shell Public Route Inventory Hardening (`insetu/app.py`)**:
  * Gated `/api/system/panic` behind the token gatehouse (`X-InSetu-Token`), preventing unauthenticated remote clients from triggering process terminations.
  * Pruned `/sm/` from `public_prefixes` and completely eradicated `public_suffixes=(".map",)`, eliminating gatehouse bypass vectors on parameterized route endings.
  * Updated `/recovery` UI script to extract the stored token from `localStorage` or `sessionStorage` before triggering emergency panics.
* **Lifeboat Bottom-Layer Authentication (V4, S8) (`insetu/fallback_bridge.py`)**:
  * Implemented standard-library credential resolution (`_credentials_module`, `current_token`) loading `akasa/auth/credentials.py` by file path or reading `.insetu/auth/session_token`, ensuring the lifeboat shares the durable session token with the primary application.
  * Added fallback 32-byte hexadecimal token generation (`.insetu/lifeboat_token`) with `0o600` file permissions if no saved credential exists.
  * Added `@app.before_request def _lifeboat_gate()` enforcing token verification for all non-static and non-bootstrap endpoints.
  * Implemented DNS rebinding protection via `_host_allowed()` validating requests against loopback, `*.ts.net`, and `allowed_hosts` from `host.json`, rejecting foreign hosts with HTTP 421 Misdirected Request.
* **Symlink-Aware Workspace Read & Write Confinement (`insetu/fallback_bridge.py`)**:
  * Built `_confine()` and hardened `_resolve_patch_target()` using `os.path.realpath`, preventing symlinks from routing reads or patch writes outside authorized workspace boundaries.
  * Enforced absolute isolation for the credential store (`.insetu/auth`), returning HTTP 403 Forbidden on any read or patch write attempts targeting auth files.
* **Lifeboat UI Telemetry & Handshake Resilience (`insetu/fallback_bridge.py`)**:
  * Decoupled panic traceback strings from server-rendered HTML into an authenticated endpoint (`/api/system/panic_details`), preventing information leakage to unauthenticated observers.
  * Added interactive `#token-box` UI prompt allowing operators to supply tokens when accessing recovery consoles from fresh browser contexts.
  * Standardized client-side fetch calls on an authenticated `api()` helper.
  * Preserved tokens across `rebootOS()` cycles to prevent authentication dropouts during daemon handoffs.
