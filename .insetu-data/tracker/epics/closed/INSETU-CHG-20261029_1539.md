## Description
* **Incremental Topology Gitignore Enforcement & Eviction (`engine_topology.py`)**:
  - Implemented `_git_ignored_paths(repo_path, rel_paths, repo_cfg, live_cfg)` executing `git -c core.quotepath=false check-ignore --stdin -z` in single batched subprocess calls per repository, preserving exemptions for `force_include` and managed directories (`.insetu-data`).
  - Integrated candidate filtering into `resolve_topology_buffer(workspace_id)`: prevents burst write storms (such as build tools dropping `*.egg-info` or `dist/`) from ledgering ignored files that full disk scans would skip.
  - Implemented automatic artifact eviction: if an incremental mutation event targets an ignored path that was previously recorded in `topology_ledger`, the engine deletes the row from SQLite, flags the owning repository as dirty, and marks the affected bucket in `dirty_buckets` to trigger downstream reconciliation.
* **Post-Commit Manifest Cache Re-Invalidation (`engine_gather.py`, `engine_topology.py`)**:
  - In `engine_gather.py` (`hook_save_manifest`), wrapped manifest persistence in a `try...finally` block that calls `hook_request_manifest.invalidate(workspace_id=workspace_id)` after `conn.commit()`.
  - In `engine_topology.py` (`force_topology_scan` and `resolve_topology_buffer`), invoked `hook_request_vfs_manifest.invalidate(workspace_id=workspace_id)` immediately after `conn.commit()`.
  - Eradicated a race condition where concurrent readers landing between pre-mutation invalidation signals (`manifest_mutated`, `vfs_manifest_mutated`) and SQLite transaction commits cached stale pre-commit ledger rows for the 2.0-second TTL window, causing Gather cards to linger in a dirty state until subsequent mutations.
