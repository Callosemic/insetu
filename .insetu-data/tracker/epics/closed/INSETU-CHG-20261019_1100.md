## Description
* **Hierarchical VFS Sieve with Standard `.gitignore` Semantics (`engine_topology.py`, `utils_core.py`)**:
  * Implemented `is_file_tracked_by_sieve(rel_path, config, live_cfg, repo_dir)` as the Single Source of Truth (SSOT) for workspace file tracking.
  * Built `_compile_gitignore_regex()` and `matches_gitignore_patterns()` supporting standard `.gitignore` semantics: directory-only matches (`archived/`), root anchors (`/build/`), floating globs, `**` traversal, and sequential `!negation` rules with LRU regex compilation caching.
  * Enforced the Nullable Override Cascade: repository-level configs (`repo_ignore_dirs`, `repo_ignore_files`, `repo_ignore_patterns`, `exts`, `repo_managed_dirs`) override global settings when explicitly non-null (even if empty `[]`), and cleanly fall back to global defaults when `null`/omitted.
  * Refactored `resolve_topology_buffer()` and `get_valid_workspace_files()` to eliminate duplicate inline ignore checks and route strictly through `is_file_tracked_by_sieve()`.
  * Updated `start_filesystem_observer` in `utils_core.py` to evaluate ignore exceptions and ignore patterns via `matches_gitignore_patterns`, and added `scheduled_watches` deduplication to prevent duplicate observer handles.
* **Sub-Bucket Sieve Pattern Cascades (`drop_patterns` vs. `ignore_patterns`) (`engine_topology.py`, `engine_gather.py`, `config.js`)**:
  * Enhanced `resolve_file_bucket()` to evaluate two distinct `.gitignore`-syntax pattern arrays per sub-bucket:
    * `drop_patterns`: Omitted from both the sub-bucket context and Bucket 0 (`main`). Returns `_DROPPED_BUCKET_SENTINEL` (`id: "_dropped"`, `exclude_from_context: True`, `exclude_from_diffs: True`).
    * `ignore_patterns`: Bypasses the sub-bucket and passes through to subsequent sub-buckets or Bucket 0 (`main`).
  * In `engine_gather.py`, handled `b.get("id") == "_dropped"` to suppress dropped files from context compilation.
  * In `config.js`, added UI input fields with descriptive tooltips for `drop_patterns` and `ignore_patterns`.
* **OS Settings Hub Architectural Consolidation (`ui_system_settings.js`, `engine_system.py`)**:
  * Completely eradicated fragmented modals (`manageExtOpen`, `mountsModalOpen`) and horizontal tabs (`system`, `core`, `extensions`).
  * Built a unified Settings Hub featuring breadcrumb navigation (`hub-breadcrumb-bar`), category filter pills (`All`, `System & Workspace`, `Core Engines`, `Extensions`), and a sticky search bar providing real-time fuzzy filtering across module titles, IDs, descriptions, and individual field schemas.
  * Converted "Virtual Mounts & Asset Sharing" and "Manage Workspace Extensions" into in-place drill-down views with centralized footer action bars.
  * Modernized `SYSTEM_SETTINGS_SCHEMA` by setting `export_shared_domains` and `shared_mounts` to `type: "hidden"`, managing them via specialized declarative UI components rather than raw JSON strings.
* **Repository Config Drill-Down UX & In-Place Navigation (`config.js`)**:
  * Replaced nested `<sutram-modal>` dialogs with in-place drill-down navigation (`renderRepoDrillDown`) inside `<insetu-ext-config>`, featuring a sticky breadcrumb bar with "All Repositories" navigation, in-place editing, and explicit "Cancel" / "Keep Edits" / "Create Repository" footer controls.
  * Added override toggle for `repo_managed_dirs` (Cartographer Labels).
* **Chatbot Transport Artifact Healing Pipeline (`bridge_fuzzy.py`, `bridge_vfs.py`, `bridge.js`)**:
  * Implemented `heal_llm_block_artifacts(text, reference_content)`:
    * `heal_chevron_meltdown`: trims trailing markdown fences and conversational chatter following the final `>>>>>>> REPLACE`.
    * `heal_latex_vert`: repairs Gemini math-mode pipe escapes (`\vert{}` to `|`) bounded by `$...$`.
    * `heal_citation_artifacts`: strips leaked LLM citation tags (``, ``, ``, ``).
  * Integrated artifact healing into `apply_block_in_memory` (auto-healing SEARCH and REPLACE blocks).
  * In `bridge.js`, added `view-syntax-error` spatial projection for AST syntax errors and aligned error display.
* **Process Memory Telemetry & Glibc Arena Management (`engine_system.py`, `cli_commands.py`)**:
  * Added `GET / POST /api/<workspace_id>/system/memory` endpoint inspecting process RSS/VmData/VmPeak, internal kernel cache metrics (`_VFS_READ_CACHE`, `_JSON_CACHE`, `_VFS_WRITE_QUEUE` depth), top 15 Python object types by GC shallow size, tracemalloc traces, and active thread groupings. Supports `action=trim` invoking `reclaim_process_memory()`.
  * Injected `Environment="MALLOC_ARENA_MAX=2"` into systemd service generation in `cli_commands.py` and `api_system_reboot` in `engine_system.py` to prevent glibc malloc arena fragmentation.
* **VFS Safety Guardrails & Export Standardization (`fs.js`, `gather.js`)**:
  * In `saveBufferFile`, added guard `if (!state || state.isTruncated) return;` preventing truncated 200KB buffers from overwriting full files on disk.
  * Marked truncated editor projections as read-only (`shouldBeReadOnly = !(m.isFS || m.forceEdit) || !!m.isTruncated;`).
  * Extracted and centralized `resolveEntityExportTarget(data)` across `file-copy`, `file-share`, and `file-download`.
  * Fixed path string normalization in bulk move, rename, archive, and delete operations to strip trailing slashes deterministically.
  * Added `alwaysInclude: f => f.finalCat === 'Quickpacks'` in Gather `filterItems` so Quickpacks are never hidden by repository filters.
  * Replaced direct `concurrent.futures.ThreadPoolExecutor` calls in `cartographer.py` and `engine_gather.py` with `akasa.workers.run_parallel` and `ctx.jobs.map_parallel`.
* **TCP Port Utilities & SSOT Canonical URI Normalization (`utils_core.py`, `engine_gather.py`, `engine_agent.py`)**:
  * Added `is_port_listening()`, `can_bind_port()`, and `allocate_ephemeral_port()` to `utils_core.py`.
  * Added `InSetuURI.canonicalize(raw, default_prefix="vfs://")` as SSOT migration normalizer.
  * Deployed boot migration in `engine_gather.py` (`mount_gather_volumes`) to canonicalize `manifest_ledger` rows to `ctx://` and `vfs://` URIs.
  * Fixed LLM credential resolution in `engine_agent.py` to query `llm` module context rather than `agent`.
