## Description
* **Git-Aware Topology CQRS Ledger (`engine_topology.py`)**: Added `git_status` tracking directly into the `topology_ledger` SQLite schema. Configured full topology scans (`force_topology_scan`) and buffer drains (`resolve_topology_buffer`) to run `git status --porcelain` via `execute_binary()`, caching status per file.
* **Real-Time VFS Manifest Git Delta Sync (`engine_topology.py`)**: Updated `hook_topology_manifest_signatures` to fold git modification counts (`mod_cnt`) into heartbeat signatures (`{cnt}-{max_ts}-{mod_cnt}`), and configured `hook_request_vfs_manifest` and `api_topology_vfs_repo` to expose `git_modified: []` arrays per bucket.
* **VFS Git Diff Gateway (`engine_fs.py`)**: Implemented the `git_diff` synchronous route (`api_fs_git_diff`) on `fs_bp`, resolving Git HEAD content via `execute_binary(['git', 'show', f'HEAD:{rel_path}'])` against active working tree content under the `FileGitDiffResponse` typed contract.
* **Spatial File Diff Projection (`fs.js`, `ui_file_tree.js`)**: Added `<insetu-file-diff-projection>` (`vfs:diff:<normPath>`), rendering side-by-side diffs between Git HEAD and the active working buffer via `<sutram-diff-viewer>`. Added `file-git-diff` polymorphic entity action, highlighted git-modified files with `M` badge and warning intent, and bound `isFileGitModified` and `viewFileGitDiff` to `window.inSetu.vfs`.
* **Yomama Bridge Diff Projections & Preview (`bridge.js`, `bridge_vfs.py`)**: Migrated syntax and anchor diff inspection from generic reports to `<insetu-bridge-diff-projection>` (`bridge:syntax-diff`). Added a live diff preview toggle (`_previewDiff`) in `<insetu-bridge-edit-projection>` to inspect SEARCH vs REPLACE blocks. Synthesized unified diffs on anchor failures in `bridge_vfs.py`.
* **Tree State Traversal Normalization (`fs.js`, `ui_file_tree.js`)**: Migrated manual directory resolution loops in `InSetuFileTree` and `openWorkspaceBrowser` to Sutram's centralized `resolveDirectoryState` utility.
