## Description
* **Two-Tier DAG-Aware Fault Quarantine (`insetu/app.py`)**:
  * Implemented a two-stage topological bootloader separating Tier 2 Core substrate modules from Tier 3 domain extensions.
  * **Stage 1A (Core DAG Evaluation):** Resolves core modules (`_visit_core`) in priority order (`system`, `topology`, `editor`, `fs`, `prompts`, `offline`, `remote`, `llm`, `cartographer`, `gather`, `bridge`, `agent`, `mcp`), detects circular dependencies, and isolates failures into `app._quarantined_modules`. If any Core module crashes, the engine transitions into Degraded Mode (`app._degraded_core = True`).
  * **Stage 1B (Extension DAG Evaluation):** If Core is degraded, all Tier 3 domain extensions are safely paused with `status: "skipped"` rather than cascading crashes into unmounted kernel primitives. When Core is healthy, Tier 3 extensions evaluate dependencies (`_visit_ext`), skipping only extensions whose dependencies are quarantined.
  * Preserved `app._bypassed_extensions`, `app._quarantined_modules`, and `app._loaded_workspace_extensions` for diagnostic visibility.
  * Guarded frontend vendor resolution (`resolve_js_vendors`) against quarantined extension imports, and protected core import specifiers (`core_protected_specifiers`) from extension overrides.
* **S8 Human Approval Gate for Workspace Extensions (`insetu/app.py`, `insetu/cli.py`)**:
  * Replaced un-gated filesystem discovery of `.insetu/extensions/` with cryptographic fingerprint verification (`scan_workspace_extensions(with_contents=True)`).
  * Only user extensions with valid human approvals in `host.json` are loaded; unapproved or modified extensions remain offline.
  * Enforced execution from verified, fingerprinted snapshot bytes (`_verify_and_load_workspace_ext`) guarded by an AST hygiene pre-check:
    * Rejects core module shadowing.
    * Enforces mandatory `__depends__ = []` declaration.
    * Enforces `AKASA_MEMBRANE_ISOLATION` (bans direct `akasa.*` imports).
    * Enforces `SDK_VFS_READ_MANDATE` (bans raw `open()`).
    * Enforces `OUTBOUND_FETCH_MANDATE` (bans raw `urlopen()`).
  * Restricted static asset serving (`serve_extension_static`) and JS bundle delivery (`serve_extension_js`) via `_resolve_workspace_ext_dir(ext_name)` strictly to running workspace extensions whose on-disk files match their approved fingerprint.
  * Updated CLI `insetu create-extension <name>` to scaffold into `.insetu/extensions/<name>/` by default, providing `--bundled` to scaffold into package extensions.
* **Emergency Panic Token Gating (`insetu/templates/index.html`)**:
  * Gated client emergency panic buttons (the unhandled JS error airbag and the `#js-panic-button` retro-boot override) behind durable session token authentication (`X-InSetu-Token` retrieved from `localStorage` or `sessionStorage`).
  * Injected `window.CORE_MODULES = {{ core_modules|tojson|safe }};` into the HTML template header for Inversion of Control.
* **Lifeboat Telemetry & Teardown Resilience (`insetu/fallback_bridge.py`)**:
  * Added defensive null-check on `document.getElementById('token-box')` in the recovery API fetch wrapper.
  * Hardened `rebootOS()` to await non-401 confirmation from `/api/system/reboot` before replacing `document.body.innerHTML`, preventing UI erasure when tokens are stale.
* **Vendor Importmap Synchronization (`insetu/static/vendor.json`)**:
  * Synchronized CodeMirror 6 bundle version numbers (`@codemirror/state` 6.5.2, `@codemirror/view` 6.36.5, `@codemirror/language` 6.11.0, `@codemirror/autocomplete` 6.18.6, `@codemirror/commands` 6.8.1, `@codemirror/lint` 6.8.5, `codemirror` 6.0.1).
  * Registered local `@lezer/common` (1.5.5), `@lezer/highlight` (1.2.1), and `@lezer/lr` (1.4.2) specifiers mapping to vendored code-split modules.
* **Extension Scaffolding Presentation Purity (`insetu/defaults/ext_template_js.txt`)**:
  * Removed custom `:host` CSS blocks to adhere to `CUSTOM_COMPONENT_CSS_BAN` (`static styles = [sharedStyles];`).
  * Wrapped category section inside `<sutram-view>`.
