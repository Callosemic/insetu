## Description
* **S3 Child Process Environment Confinement (`insetu/core/llm/engine_llm.py`, `insetu/core/bridge/bridge_test.py`)**:
  * In `_stream_claude_cli`, migrated process environment generation from raw `dict(os.environ)` to `child_env("tool")`. Strips daemon session tokens and internal panic tracebacks while preserving operator credentials and tool variables.
  * In `run_repo_test_diagnostics`, wrapped test runner subprocess execution via `ctx.exec.run` with `env=child_env("repo_code", ctx.workspace_id, repo)`. Strips sensitive credential variables (`*_KEY`, `*_TOKEN`, `*_SECRET`) before spawning repository test runners.
* **Repository Landmarks & Constitution Discovery (`insetu/core/agent/engine_agent.py`, `insetu/core/agent/orchestrator.py`)**:
  * In `engine_agent.py` (`get_messages`), replaced ad-hoc directory walking of `vfs://{r_dir}/docs/standards` with `discover_constitution_files(ctx)`, dynamically resolving authoritative engineering standards across mounted repositories.
  * In `orchestrator.py`, added `"topology.landmarks"` to `READ_ONLY_MODE_ALLOWED_CAPABILITIES` and integrated `resolve_repo_landmarks(ctx, repo=...)` into `execute_declarative_routine()`.
  * Injected repository landmarks directly into `chain_context["sys"]` (`standards_files`, `contract_files`, `adr_dir`, `tracker_dir`, `test_dirs`, `fitness_dirs`, `repo_name`, `repo_title`, `repo_description`, and `directives`), exposing authoritative repository structure to prompt templates and routine DAGs.
* **Model Context Protocol (MCP 2025-03-26) Optional Macro Resolution (`insetu/core/mcp/engine_mcp.py`)**:
  * Updated prompt macro regex in `_render_mcp_prompt` to `r'\{\{\s*include_prompt\??\s*:\s*([^\s{}]+)\s*(?:\{([\s\S]*?)\})?\s*\}\}'`, supporting optional inclusion syntax (`{{include_prompt?: ...}}`).
  * Passed `workspace_id=ctx.workspace_id` to `resolve_macro_includes()`, allowing prompt templates to evaluate extension enablement status and cleanly collapse disabled extension templates into empty strings.
* **Human-Only Command Approval Documentation (`insetu/core/bridge/engine_bridge.py`)**:
  * Added formal docstrings to `BridgeTestApprovePayload` and `bridge_approve_test_command` explicitly documenting the P5 human-only authorization model and route exclusion from MCP and declarative agent routines.
