## Description
* **Reference Manager & Academic Citations (`engine_citations.py`, `ext_citations.js`)**:
  * Migrated all raw SQLite query invocations to high-level SDK `ctx.db` wrappers (`insert_or_replace`, `update`, `get_by_id`, `delete`).
  * Fixed an external URL parsing defect in `_background_citation_search` where OpenAlex identifiers (`https://openalex.org/...`) were improperly coerced into `InSetuURI`, replacing it with `Path(urllib.parse.urlparse(...).path).name`.
  * Injected database hydration verification (`_ensure_citations_hydrated`) into metadata index generation, URL deduplication checks, and Pandoc middleware injection.
  * Decomposed modal rendering out of `InSetuExtCitations` into a sovereign Web Component `InSetuExtCitationsModals` mounted in `slots:global`.
  * Migrated exploration catalog searches to declarative `this.api.bindJobAction('citations/search', ...)`.
  * Replaced native file upload inputs with direct CSL-JSON textarea input, workspace browser file loading, and added the `cit-open-url` polymorphic entity action.
* **URL Ingestion Substrate (`engine_ingest.py`, `ext_ingest.js`)**:
  * Standardized `allowed_private_hosts` setting type in `INGEST_SETTINGS_SCHEMA` to canonical `string_list`.
  * Standardized runtime exception types to `RuntimeError`.
  * Decoupled `InSetuExtIngestModals` from `window.inSetu.stores.Fs` and removed destructive overwrite confirmation dialogs; routes imported Markdown into `this.editor.insertTextAtCursor` or delegates to `this.vfs.openNewFileModal`.
  * Broadcasts `insetu:post-import-url` CustomEvents with derived slugs and filenames.
* **Markdown Notes Library (`engine_notes.py`, `ext_notes.js`)**:
  * Eliminated destructive `DELETE FROM notes_ledger` table purges across boot hydration and listing in favor of non-destructive surgical mark-and-sweep comparison against `seen_ids`.
  * Extended `api_notes_new` to accept `NoteNewPayload` (`id`, `title`, `repo`, `sub_bucket`, `tags`, `body`), delegating atomic file creation to `ctx.create_entity_file` and returning `{ status: "success", id, filepath }`.
  * Modernized `NotesStore.saveNewNote()` to dispatch `notes/new` via `sys.executeWorkspaceMutation` with optimistic offline outbox queueing.
  * Implemented debounced VFS event listeners (`this._debouncedFetchNotes = this.utils.debounce(..., 300)`) and centralized pre-caching via `window.inSetu.vfs.preCacheFiles(...)`.
  * Removed redundant wrapping `<div>` around `<sutram-textarea slot="title-control">` in `InSetuExtNotesEditor`.
* **Document Publishing (`ext_publish.js`)**:
  * Purged obsolete `activePublishJobId` state from store and element properties.
  * Replaced unstyled `<pre>` containers with `<sutram-textarea readonly ?monospace=${true} size="wide">` and converted error text to `<sutram-label intent="danger">`.
* **Web Research & Scraping Pipeline (`engine_research.py`, `ext_research.js`)**:
  * Standardized search providers (`DuckDuckGoHTMLProvider`, `GooglePlaywrightProvider`, `SerperDevProvider`) to raise typed `RuntimeError`.
  * Fixed SERP pagination bounds in `gather_next_page` (`page_limit = min(10, max(1, max_results - start_index))`) and automated worker transition to `scrape_next_link`.
  * Derived `processed_links` from exact database counts (`scraped_at IS NOT NULL`).
  * Implemented job `rerun` lifecycle action and added `rs-rerun` and `rs-clone` entity actions.
  * Standardized default output directory to canonical `vfs://research/`.
  * Converted preview displays to `<sutram-textarea readonly ?monospace=${true} size="full">` and integrated prompt template hydration for batch AI triage.
* **Skills Spaced-Repetition Tracker (`engine_skills.py`, `ext_skills.js`)**:
  * Consolidated frontmatter updates and file renaming logic into shared `_apply_skill_mutation(...)`.
  * Migrated database queries to SDK `ctx.db` methods.
  * Extracted modal projections into sovereign `InSetuExtSkillsModals` Web Component registered in `slots:global`.
  * Hoisted `editForm`, `newSkillForm`, and `newSkillMetrics` into `SkillsStore`.
* **Automation Hooks & S8 Cryptographic Governance (`engine_hooks.py`, `ext_hooks.js`)**:
  * Hardened boot hydration so rules loaded from `rules.json` or legacy tables remain disabled (`enabled = 0`) until approved by a human.
  * Implemented human-only route `POST hooks/approve` (`mcp_expose=False`, routine-banned) verifying command parity against what was reviewed.
  * Stamped rules with `r["approved"] = _is_hook_approved(...)`, rendered lock icons and warning badges on unapproved cards, added `hook-approve` entity action, and blocked manual execution on unapproved rules.
