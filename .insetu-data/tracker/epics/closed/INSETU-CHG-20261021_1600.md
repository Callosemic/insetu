## Description
* **Synchronous Workspace Swap FSM (`SessionOrchestrator`, `system.js`, `store.js`, `api.js`, `insetu_sdk.js`)**:
  * Implemented the `SessionOrchestrator` Finite State Machine establishing a strict 6-phase sequence (`LOCKED` → `TEARDOWN` → `IDENTITY_SWAP` → `HYDRATE` → `ROUTING` → `READY`) for tenant workspace transitions.
  * In Phase 2 (`TEARDOWN`), flushes dirty text buffers under the outgoing tenant identity, notifies the backend of the impending swap, aborts in-flight network requests via `abortWorkspace(oldWs)`, purges Service Worker caches, and evicts all active spatial projections on `LayoutStore` with persistence suspended (`_suspendPersistence = true`) so the outgoing workspace's layout is not clobbered.
  * Coordinates tenant scope shifts through `StoreRegistry.beginScopeTransition(targetWs)` and `endScopeTransition()`.
  * Deployed the `shouldDropTenantEvent()` telemetry valve in `api.js` and `insetu_sdk.js`, automatically dropping incoming SSE events (`vfs_mutated`, `topology_resolved`, `job_progress`, `outbox_mutated`) during active swap windows.
* **Deterministic 3-Way OCC Concurrency Merge & Ancestor Ring Buffers (`engine_fs.py`, `fs.js`, `utils_core.py`)**:
  * Integrated a 3-way line-based merge engine (`three_way_merge_text`) into `POST fs/save`. When an incoming save presents a divergent `base_hash`, the backend inspects an in-memory ancestor ring buffer (`lookup_vfs_ancestor`) and merges disjoint concurrent modifications cleanly.
  * Confirmed merged text is returned with `status: "merged"`, `merged_content`, and updated `base_hash`, falling back to `.conflict_<timestamp>` file generation and HTTP 409 only on same-line collisions.
  * Enforced causal monotonicity across client editor buffers (`FsStore.activeBuffers`): buffers maintain a monotonic `ancestorHashes` history and reject inbound server reconciliations matching known ancestors.
  * Pinned `originalContent` and `baseHash` to the last server-confirmed baseline while mutations are queued in the offline outbox, ensuring compacted offline saves rebase cleanly upon reconnection.
* **OS Settings Hub Architectural Consolidation (`ui_system_settings.js`, `config.js`, `ui_primitives.js`, `offline_ui.js`)**:
  * Consolidated fragmented standalone modals (`InSetuWorkspaceEditor`, `InSetuCoreOfflineSettings`, `insetu-generic-settings-root`) into in-place drill-down views inside `<insetu-system-settings>`.
  * Embedded `<insetu-ext-config ?embedded=${true}>` under `sys:topology`, and built `<insetu-host-dir-picker>` to provide host directory browsing for workspace provisioning and external repository mounts.
  * Overhauled repository configuration with newline-delimited (.gitignore syntax) textareas for `match_prefixes`, `drop_patterns`, and `ignore_patterns`, and integrated dry-run bucketing test previewers.
* **RFC 0108 Tab-Scoped Navigation State & Domain Decoupling (`store.js`, `fs.js`, `insetu_sdk.js`)**:
  * Completely eradicated `globalBrowsePath` and `currentBrowsePath`, establishing `getBrowsePath(subId)` and `setBrowsePath(pathArray, subId)` to isolate deep folder drill-down state per sub-tab.
  * Decoupled `fs.js` from RAG context compilation and `GatherStore`, delegating freshness verification to the `insetu:ensure-fresh-artifact` Inversion of Control hook and eliminating speculative `onReveal` pre-warming.
* **Declarative Extension VFS Volume Mounting (`sdk/__init__.py`, `legacy.py`)**:
  * Added declarative `volumes` schema declarations to `InSetuExtension`, automatically wiring driver registration, `request_paths`, `workspace_boot`, and legacy directory migrations without boilerplate.
  * Added self-move immunity to `move_tree_contents` to prevent recursive file deletion when source and destination directories coincide.
* **Content-Addressed Filesystem Watchdog Echo Suppression (`utils_core.py`)**:
  * Implemented `_is_watchdog_vfs_echo()` backed by a thread-safe `_NATIVE_VFS_HASHES` OrderedDict ring buffer, suppressing Watchdog self-echoes by comparing on-disk SHA-256 hashes against recent internal VFS commits.
* **Side-by-Side Two-File Comparison & Document Macro Stripping (`fs.js`, `engine_editor.py`)**:
  * Added `viewTwoFileDiff()` (`vfs:pairdiff:<left>::<right>`) and registered the `file-conflict-diff` (Diff Original) and `vfs-compare-selected` entity actions to compare conflict files or multi-selected documents side-by-side using `<sutram-diff-viewer>`.
  * Bound the `@editor_bp.on('pre_compile_document')` hook to strip ephemeral wordcount macros (`strip_macros`) prior to document compilation.
