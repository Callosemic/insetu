## Description

* **Unified `Send` Variant Set & Action Ergonomics (`fs_actions.js`, `gather_quickpack.js`, `ext_publish.js`, `ext_term.js`):**
  * Registered the `send` variant set (`label: 'Send'`, `sections: ['Raw', 'Expanded']`) with entity families (`files`, `structured`, `packs`, `folders`, `records`) and device-local preference defaults in `fs_actions.js`.
  * Joined single-entity actions (`file-copy`, `file-copy-expanded`, `file-share`, `file-share-expanded`, `file-download`, `file-download-expanded`, `vfs-download-zip`, `publish-doc`) and bulk selection tray Quickpack actions (`gather-pack-copy`, `gather-pack-download`, `gather-pack-share`) to the `send` variant set with explicit `successLabel` confirmation states (`Copied`, `Shared`, `Downloaded`).
  * Added single-part Quickpack `Copy Raw` (`gather-pack-copy`) using `ClipboardItem` promise blobs to preserve WebKit user-gesture activation, hiding `Copy Raw` and falling back to `Download Raw` when an artifact or selection resolves to multiple chunks.
  * Removed deprecated `?scrollable=${true}` from `<sutram-entity-actions>` in `ext_term.js` so virtual keyboard actions follow the unified fit-then-overflow row rule.
* **Polymorphic `getChunks` & `isMultiPartArtifact` Single Source of Truth (`fs_store.js`, `fs.js`, `insetu_sdk.js`, `agent_handoff_and_plan.js`):**
  * Added `{ fallbackToKey = true }` to `window.inSetu.utils.extractManifestFiles` so manifest cache misses return `[]` rather than `[targetKey]`.
  * Upgraded `getChunks(filepathOrData, explicitChunks)` and introduced `isMultiPartArtifact(filepathOrData, explicitChunks)` in `fs_store.js` as the single polymorphic resolver across live `AppStore.manifest` entries, inline `data.chunks`, and single-part fallbacks, eliminating 7 duplicated `manifestChunks` ternaries across `fs.js`, `fs_store.js`, `fs_actions.js`, `gather_quickpack.js`, and `agent_handoff_and_plan.js`.
  * Added `fetchArtifactText` and consolidated `window.inSetu.vfs` bindings into a frozen `VFS_PUBLIC_API` projection in `fs.js`.
* **Core Prompts Library & Lexical URI Refinement (`prompts.js`, `bridge.js`, `ui_file_tree.js`, `uri.js`):**
  * Added `corePrompts` manifest declaration on `bridge` (`ctx://prompts/.templates/bridge/yomama_patch_protocol.md`) and `getRegisteredCorePrompts()` in `prompts.js`, rendering a pinned-top `Core prompts` collapsible section in `<insetu-file-tree>` (`slot="pinned-top"`).
  * Extended `InSetuURI` in `uri.js` with `isUserTemplateRoot`, `isRepoPromptRoot`, and `isRepoPrompt`, replacing inline prompt path regexes in `prompts.js` and `ui_file_tree.js`.
* **God-Object Modularization & Context Chunk Ceiling (`fs_actions.js`, `gather_quickpack.js`, `engine_gather.py`, `pyproject.toml`):**
  * Extracted the `fs` `ExtensionRegistry` manifest into `insetu/core/fs/fs_actions.js` (ratcheting `fs.js` ceiling from `2016` to `1535` lines) and Quickpack payload compilation/actions into `insetu/core/gather/gather_quickpack.js`.
  * Reduced the default `max_context_size_kb` chunk limit from `400` KB to `250` KB in `engine_gather.py` and bumped package version to `0.40.0` in `pyproject.toml`.
* **ExtensionRegistry Public Introspection & Static Fitness Hardening (`insetu_sdk.js`, `system.js`, `rules_javascript.py`, `test_js_behavioral_units.py`, `test_bridge_chat_wrappers.py`):**
  * Replaced monkey-patching `ExtensionRegistry.getEntityActions` with `setActionFilterPredicate`, and added `collectManifestField`, `collectManifestEntries`, and `getRegisteredExtensionNames` to eliminate direct `_manifests` access in `system.js`.
  * Added `VFS_ACCESSOR_PARITY_MANDATE`, `AD_HOC_CHUNK_FALLBACK_TERNARY_BAN`, and `PRIVATE_REGISTRY_ACCESS_BAN` in `rules_javascript.py`, Sprint U2 behavioral assertions in `test_js_behavioral_units.py`, and 9-variant web-chat wrapper tests in `test_bridge_chat_wrappers.py`.
