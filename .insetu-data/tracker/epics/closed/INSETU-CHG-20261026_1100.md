## Description
* **Flask Transport Shell Decoupling (`FLASK_TRANSPORT_LEAK_BAN`)**:
  * Eradicated `from flask import jsonify` across all seven DevOps engines (`engine_dev.py`, `engine_format.py`, `engine_git.py`, `engine_preview.py`, `engine_tailscale.py`, `engine_term.py`, `engine_update.py`). All routes return plain Python dictionaries and optional HTTP status codes.
  * Replaced all direct `ctx.req.json`, `ctx.req.args`, and `ctx.req.get_json()` reads with unified `ctx.payload`.
* **Strict Typed Worker Signatures (`WORKER_TYPED_SIGNATURE_MANDATE`, `WORKER_CTX_FIRST_PARAM_MANDATE`)**:
  * Purged `**kwargs` and un-typed signatures across all 26 `@*.worker` tasks across the DevOps suite, providing explicit Python type annotations as the runtime Single Source of Truth for task execution.
* **Declarative Extension Dependency Contracts (`LEGACY_EXTERNAL_DUNDER_BAN`)**:
  * Migrated module-level dunder globals (`__external_depends__`, `__external_binaries__`) to declarative constructor parameters on `InSetuExtension(...)`:
    * `format`: `external_dependencies=["jsbeautifier", "autopep8"]`
    * `preview`: `external_dependencies=["uvicorn"]`
    * `tailscale`: `external_binaries=["tailscale"]`
    * `term`: `external_dependencies=["flask-sock"]`, `requires_reboot_on_install=True`
    * `update`: `external_dependencies=['semantic_release', 'build', 'twine']`, `external_binaries=['git']`
  * Added in-app one-click dependency installation buttons (`installExtensionDependencies()`) to `ext_term.js` and `ext_update.js`.
* **Canonical API Route Prefix Normalization (`CANONICAL_API_ROUTE_PREFIX_MANDATE`, `SEMANTIC_API_ROUTING_MANDATE`)**:
  * Prefixed all `this.api.*` and `window.inSetu.api.*` calls with explicit `<module>/<endpoint>` route identifiers across `ext_dev.js`, `ext_git.js`, `ext_preview.js`, `ext_term.js`, and `ext_update.js`.
  * Purged all legacy `api.workspace.*` and `api.system.*` accessors.
* **Sub-Navigation Slot Modernization (`BANNED_SUB_NAV_ACTIONS_SLOT_BAN`)**:
  * Retired bespoke action Web Components (`InSetuExtDevLogsActions`, `InSetuExtTermActions`) and the deprecated `slots:sub-navigation-actions` registration slot in favor of declarative `menuActions` on `slots:sub-navigation`.
* **Pathlib & Slotted URI Value Object Migration**:
  * Migrated remaining `os.path.exists()` and `os.path.relpath()` calls in `engine_format.py`, `engine_git.py`, `engine_preview.py`, and `engine_update.py` to `pathlib.Path`.
  * Migrated `ext_preview.js` from deprecated `parseURI()` to `InSetuURI`.
* **Presentation Purity & Floating Listener Containment**:
  * Replaced raw `<button>` elements in `ext_dev.js` and `ext_update.js` with `<sutram-btn>` primitives.
  * Encapsulated `insetu:ensure-fresh-artifact` listener within `<insetu-ext-git-diffs>` component lifecycle.
