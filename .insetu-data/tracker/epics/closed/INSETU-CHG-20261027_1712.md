## Description
* **Workflow Batches Viewport Dirty-State Watermark Resolution (`insetu/extensions/flow/ext_flow.js`)**:
  * Extracted and guarded `dirtySet` from `AppStore.getState().dirtyBuckets || new Set()`, eliminating redundant store queries and guarding against uninitialized store access.
  * Added direct URI matching (`dirtySet.has(filename)`) to immediately flag dirty workflow artifacts referenced by logical URI without requiring secondary bucket address translation.
  * Hardened workflow batch bucket key matching with case-insensitive evaluation (`dirtySet.has(String(addr.key).toLowerCase()) || dirtySet.has(addr.key)`), aligning with relational watermark derivation and `BucketAddress` formatting across workspaces.
  * Added direct URI matching for batch dependency entries (`dirtySet.has(inc)`) and case-insensitive dependency bucket address matching (`dirtySet.has(normIncKey) || dirtySet.has(incAddr.key)`), ensuring workflow cards reflect dirty upstream dependencies accurately.
