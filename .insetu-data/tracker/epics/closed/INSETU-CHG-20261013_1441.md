## Description
* **Universal LLM Gateway (`insetu/core/llm/engine_llm.py`)**: Built an extensible inference gateway supporting Anthropic Claude REST streaming, Google Gemini REST streaming, and local Claude CLI execution with secure workspace-scoped credentials.
* **Autonomous ReAct Agent Harness (`insetu/core/agent/engine_agent.py`, `agent.js`)**: Created the `agent` core extension, featuring persistent SQLite chat history (`chat_sessions`, `chat_messages`), multi-turn streaming conversation UI, context-aware prompt packing, Yomama Bridge transaction validation, and self-healing patch retry loops with automated system feedback.
* **JIT CodeMirror Language Vendorization (`insetu/core/editor/engine_editor.py`, `ui_editor.js`)**: Implemented dynamic on-demand CodeMirror 6 language package resolution, downloading and locally caching grammar bundles into `.insetu/vendor/codemirror/` with strict relative-path security verification (ADR 0032).
* **VFS & Yomama Spatial Projection Migration (`fs.js`, `bridge.js`)**: Eradicated legacy `<insetu-vfs-modals>` and Bridge edit modals. Re-architected file operations (move, create file, create folder, link insertion, workspace browser) and patch editing/diffing into spatial projections (`InSetuMoveFileProjection`, `InSetuNewFileProjection`, `InSetuNewFolderProjection`, `InSetuLinkInsertProjection`, `InSetuBrowserProjection`, `InSetuBridgeEditProjection`, `InSetuBridgeDiffProjection`) pinned to the multi-column `LayoutStore`.
* **CLI Substrate Modularization (`cli_commands.py`)**: Extracted core CLI commands into `insetu/core/system/cli_commands.py`, adding headless/interactive workspace initialization (`handle_init`), candidate repository detection, service management, and desktop shortcut generation.
* **Ecosystem Iconography & Presentation Alignment (`bridge.js`, `config.js`, `offline_ui.js`, `ui_primitives.js`, `ui_system_settings.js`)**: Purged remaining raw emoji characters in favour of `<yv-icon>` declarative primitives, centralized `config-repo` card interactions into declarative `entityActions`, and bound Zen Focus Mode to the Fullscreen API and native popovers.
* **URI SSOT Centralization (`utils_core.py`, `engine_gather.py`, `engine_fs.py`)**: Added `is_naked_diff_uri` and `is_naked_context_uri` helpers to `utils_core.py`, ensuring canonical scheme resolution across Gather and VFS file archive handlers.
