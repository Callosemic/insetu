## Description
* **Git Extension Capabilities & Programmatic Routing (`engine_git.py`)**:
  * Implemented `@git_bp.route('compile_diffs')` with `GitCompileDiffsPayload` schema (`force_full: bool`, `target_repos: Optional[List[str]]`), enabling on-demand compilation of `ctx://diffs/*_diffs.txt` artifacts.
  * Implemented `@git_bp.route('list_dirty_diff_buckets')` inspecting `ctx.manifest['ctx']` for active `ctx://diffs/` URIs, reading non-empty compiled text, and returning structured bucket descriptors (`diff_file`, `repo`, `bucket_id`, `title`, `content`).
* **Push Projection Commit Message Pre-Seeding (`ext_git.js`)**:
  * Enhanced `_handleOpenPush(e)` in `ext_git.js` to accept `commitMessage` in event details, pre-populating `gitPushMessage` in `GitStore` and retaining it across asynchronous changelog fetches.
* **Markdown-as-Code Git Agent Routines & Prompts (`git/routines/*.md`, `git/prompts/*.md`)**:
  * Added `close_session.md` routine (`/closeout`) orchestrating `git.compile_diffs` -> `git.list_dirty_diff_buckets` -> `bridge.commit_message` -> `draft_closeout` (thinking tier).
  * Added `diff_audit.md` routine (`/audit`) orchestrating `git.compile_diffs` -> `git.list_dirty_diff_buckets` -> parallel per-bucket audit (`audit_bucket` via `map_over` on fast tier) -> `synthesize_audit_report` (thinking tier).
  * Added supporting prompts `close_session_protocol.md` and `diff_audit_criteria.md`.
* **Tailscale Extension Decommissioning (`engine_tailscale.py`, `ext_tailscale.js`)**:
  * Deleted `engine_tailscale.py` and `ext_tailscale.js`. All Tailscale Serve, peer identity, and HTTPS reverse-proxy capabilities are now completely consolidated under Tier 2 Core Substrate `insetu/core/remote/engine_remote.py`.
* **Preview HTTPS Serve Delegation (`engine_preview.py`)**:
  * Replaced direct `execute_binary` subprocess calls in `_bind_tailscale_https` with `set_tailscale_https_serve(port, enable)` from `insetu.core.remote.engine_remote`.
* **Single-File Frontend Membrane Alignment (`ext_update.js`)**:
  * Refactored `ext_update.js` to import `sharedStyles` and `debounce` exclusively from `/static/extensions/system/insetu_sdk.js`, purging direct vendor imports from `/static/vendor/sutram/*` in strict compliance with `SUTRAM_MEMBRANE_ISOLATION`.
