## Description
* **Pending Protected Changes Pipeline (`insetu/core/protected_changes.py`)**:
  * Implemented kernel-level protected write handler (`handle_protected_write`, `install()`), staging mutations to protected recovery files (`cli.py`, `fallback_bridge.py`, `credentials.py`) into `.insetu/pending_changes/<id>.json`.
  * Returns HTTP 202 `{"status": "pending_confirmation", "change_id"}` for machine-originated writes (MCP, routine, agent, bridge) without altering disk.
  * Direct saves from the Files editor (`origin: "ui"`, `SOURCE_KEY: EDITOR_SOURCE`) are verified via subprocess smoke test and committed immediately with audit logging.
  * Prohibits file moves, renames, and deletion of recovery files, and strictly denies writes targeting inSetu internal control stores (`attestations.json`, `pending_changes/`, `audit/`, `recovery/`).
  * Emits real-time `protected_changes` SSE events and projects pending counts into `api_system_topology`.
  * Added human-only management endpoints: `GET system/protected/pending`, `POST system/protected/confirm` (requiring `change_id` and reviewed `result_hash`), and `POST system/protected/discard`.
  * Enforced append-only audit logging in `.insetu/audit/protected_changes.jsonl`.
* **Unified Attestation Store (`insetu/core/attestations.py`)**:
  * Centralized standing and timed human grants into `.insetu/attestations.json` (`command`, `workspace_extension`, `lan_lease`, `repo_directive`).
  * Enforced digest-based verification (`digest_of`), invalidating grants when commands, fingerprints, or server parameters diverge.
  * Bound approvals strictly to human origins, raising `AttestationRefused` on machine origins (`mcp`, `routine`, `agent`).
  * One-time idempotent migration moving legacy approvals (`approved_test_commands`, `approved_workspace_extensions`, `approved_hooks`) from `host.json` into `attestations.json`.
  * Wired automatic expiration pruning on boot and daemon run isolation for `until_restart` grants.
  * Migrated dev server preview LAN exposure leases to `lan_lease` records in `attestations.py`.
  * Migrated automation hook approvals to `attestations.py`; gated `hooks.save` and `hooks.toggle` as human-only (`mcp_expose=False` and routine-banned).
* **Recovery Subprocess Smoke Testing & Last-Good Fallback (`insetu/recovery_check.py`, `insetu/cli.py`, `insetu/fallback_bridge.py`)**:
  * Built stdlib-only smoke test harness (`recovery_check.py`) validating syntax and execution of `cli` (`--help`), `lifeboat` (Flask initialization and token validation), and `credentials` (token creation, round-trip, rotation) before commit.
  * Implemented last-good copy management in `.insetu/recovery/last_good/` for `fallback_bridge.py` and `credentials.py`.
  * Hardened panic bootloader in `cli.py` (`load_recovery_app`) to import the last-good lifeboat copy if the primary lifeboat fails to load.
  * Hardened lifeboat credential loader to fall back to `.insetu/recovery/last_good/credentials.py` if the active store is unimportable.
* **CLI Session Token Rotation (`insetu/cli.py`, `insetu/core/system/cli_commands.py`)**:
  * Implemented `insetu auth rotate` CLI command delegating to `akasa.auth.credentials.rotate_token`, regenerating `session_token` and invalidating previous client sessions.
