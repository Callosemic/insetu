## Description
* **Freshdesk Engine Quote Parsing (`engine_freshdesk.py`)**: Fixed an `AttributeError` in `_background_post_reply` by replacing `.trim()` with Python's canonical `.strip()` method during email thread quote splitting and clean description extraction.
* **Automation Hooks & Research API Gateway Alignment (`ext_hooks.js`, `ext_research.js`)**: Standardized asynchronous HTTP mutation methods by migrating from `this.api.postJson` to canonical `this.api.post` across rule management (`save`, `toggle`, `delete`) and research inbox operations (`start`, `action`, `disposition`), ensuring uniform payload serialization through the SDK gateway.
* **Skills Tracker VFS Deletion Parity (`engine_skills.py`)**: Refactored practice logging and structural update file mutations (`log_skill_practice`, `update_skill_structure`) to utilize the formalized `ctx.vfs.delete()` API instead of the deprecated and leaky `ctx.vfs.save(..., data={"action": "delete"})` abstraction (ADR 0004, ADR 0018).
* **Semantic Update Engine Config Precedence & Optimization (`engine_update.py`)**:
  * In `_background_bump_task`, reused the pre-computed and boolean-coerced `auto_publish` variable rather than executing redundant settings lookups.
  * In `_background_preview_bump_task`, hoisted `pyproject.toml` parsing prior to setting environment variable parser flags, ensuring `toml_commit_parser` takes precedence over switchboard configuration and aligning with `_background_bump_task`.
  * In `_background_status_task`, aligned commit parser resolution with `toml_commit_parser` precedence and mapped repository-scoped `auto_publish` configuration into the returned status artifact.
* **Issue Tracker Modal Deduplication (`ext_tracker.js`)**: Purged an identical, duplicated active bucket filter resolution block in `InSetuExtTrackerModals._openNewTaskModal()`, eliminating redundant code execution and variable re-assignment during ticket creation modal hydration.
