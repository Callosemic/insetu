## Description
* **Single-File Frontend Membrane Fallback Primitives (`insetu/core/system/insetu_sdk.js`)**:
  * Implemented and exported `SutramCombobox` (`<sutram-combobox>`) supporting filterable dropdown menus, keyboard navigation, outside-click dismissal, and custom badges.
  * Implemented and exported `SutramTargetBinding` (`<sutram-target-binding>`) coupling an endpoint selector (`<sutram-select>`) with a model combobox (`<sutram-combobox>`), normalizing `{ endpoint, model }` composite objects.
  * Re-exported both primitives from the Single-File Frontend Membrane, ensuring client views function reliably even prior to vendor bundle re-synchronization.
* **Declarative Schema Repeater Enhancements (`insetu/core/system/components/ui_system_settings.js`)**:
  * Added `target_binding` leaf input rendering in `<insetu-schema-repeater>` with contextual option resolution via `.optionResolver`.
  * Added dynamic select option derivation via `options_from` (`{ field, value_key, label_key }`), populating dropdowns reactively from sibling repeater data (e.g. `compute_endpoints`).
  * Implemented `_deriveUniqueSlug` providing automated unique slug synchronization (`id_key`, `slug_source`) across item creation and title edits.
  * Upgraded repeater grid layout with full-span spanning for composite controls and multi-line textareas (`.record-grid > .full-span`).
* **Cognitive Profile Tier Healing & Option Resolution (`insetu/core/system/components/ui_system_settings.js`)**:
  * Integrated model catalog harvesting into `_ingestLlmCatalogPayload`, caching harvested pricing and context metadata in `_llmCatalogMap`.
  * Implemented `_resolveTargetBindingModels` resolving candidate models for target endpoints with pricing, context length, and tier recommendation badges (`formatBadge`).
  * Implemented `_healProfileTiersForEndpoints`, automatically converting legacy flat string bindings (`endpoint::model`) into `{ endpoint, model }` records and auto-suggesting valid models when target models are missing or foreign to the driver (`_isModelForeignToDriver`, `_getDefaultModelForEndpointTier`).
  * Wired `sutram-settings-action` to emit `insetu:llm-catalog-updated` upon successful catalog harvesting, immediately re-evaluating tier options.
