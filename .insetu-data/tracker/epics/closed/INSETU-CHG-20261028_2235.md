## Description
* **Application Chassis Membrane Wrapping (`insetu/app.py`)**:
  * Replaced direct imports of `akasa`, `SettingsManager`, `hooks`, `load_config`, `get_workspace_physics`, `get_system_index_path`, and `is_core_module` with unified imports from `insetu.core.sdk`.
  * Routed kernel bootstrap phases through SDK membrane wrappers: `configure_kernel()` (Phase A), `init_kernel_app()` (Phase B), and `boot_kernel()`.
  * Added `"/api/system/llm_catalog.json"` to the `public_routes` set in `init_kernel_app()`, enabling unauthenticated model discovery by the client interface.
  * Pruned redundant `trusted_host_suffixes=(".ts.net",)` argument from `app.py`, delegating trusted host resolution to the remote engine and host configuration.
* **Three-Layer Frontend Ring Vendor Importmaps (`insetu/static/vendor.json`)**:
  * Registered bare specifier `"sutram"` pointing to `"vendor/sutram/js/index.js"` (version 2.0.0, range `>=2.0.0`).
  * Registered bare specifier `"sutram-chassis"` pointing to `"vendor/yenvui/js/index.js"` (version 2.0.0, range `>=2.0.0`).
  * Finalized offline polyglot vendor importmap resolution adhering to ADR 0032 and the Layer 0/1/2 architectural contract.
* **App Bootloader Redundant Import Pruning (`insetu/static/js/app.js`)**:
  * Removed redundant static import of `../vendor/sutram/js/app_shell.js`, eliminating duplicate evaluation alongside `sutram-boot.js`.
* **CSS Presentation Purity & Flow Decoupling (`insetu/static/css/style.css`)**:
  * Removed `.screen:has(.sub-tab-content[data-ext="flow"].active)` from the `.screen:has(...)` overflow-hidden selector, eliminating ad-hoc global CSS overrides for flow views.
* **Declarative Selection Tray Header Customization (`insetu/templates/index.html`)**:
  * Customized `<sutram-selection-tray>` in the application shell with `trayTitle="Quickpack Deck"` and `itemBadge="PACK"`.
