## Description
* **Model Context Protocol (MCP 2025-03-26) Server & Stdio CLI (`engine_mcp.py`, `cli.py`)**:
  * Implemented an MCP specification (protocol version `2025-03-26`) JSON-RPC 2.0 server supporting both HTTP transport (`POST /api/<workspace_id>/mcp`) and standard I/O streaming via `insetu mcp` (`handle_mcp_stdio`).
  * Exposed core tools: `cartographer.extract` for targeted AST symbol extraction, `fs.fetch` for raw source file reads, and `bridge.sync` for atomic patch application.
  * Exposed resources: workspace files, `CODE_INDEX.md`, and compiled RAG context payloads.
  * Exposed prompts: parameterized prompt templates with dynamic `{{ macro_* }}` argument inference, type validation, and recursive macro parameter substitution.
* **Declarative Agent Orchestration & Routines (`orchestrator.py`, `engine_agent.py`)**:
  * Integrated declarative execution DAGs loaded from YAML definitions (`workspace_turn`, `code`, `plan`, `ask`, `yomama`, `map_reduce_audit`, `symbol_refactor`).
  * Implemented safe expression evaluation (`evaluate_when_condition`) supporting boolean checks and template variable interpolation (`interpolate_template`).
  * Integrated 256KB scratch vaulting (`SCRATCH_VAULT_THRESHOLD_BYTES = 256 * 1024`) to spill large prompt contexts or diff outputs to disk, preventing RAM exhaustion.
  * Integrated unified slash command parsing (`_parse_slash_command`) mapping `/code`, `/plan`, `/ask`, `/yomama`, and `/undo`.
  * Integrated one-click transactional rollback via `agent.undo` and `/undo`, reverting disk state atomically through `bridge.revert`.
* **AST-Aware Structural Refactoring & Deferred Chunk Healing (`bridge_ast.py`, `cartographer.py`, `bridge_vfs.py`)**:
  * Added `bridge.ast_relocate` for moving classes, methods, and functions across files byte-for-byte while preserving comments, decorators, and JSDoc, logging full ledger snapshots for atomic reversibility.
  * Added `bridge.ast_rename` for identifier replacement across Python and JavaScript files while strictly skipping string literals and comments.
  * Extended `parse_blocks` with `<<<<<<< RELOCATE` and `<<<<<<< RENAME` directives with backward-compatible search/replace dict envelopes.
  * Enhanced `bridge.sync` with deferred chunk healing: defers failing or overlapping anchor chunks, commits valid chunks to the in-memory buffer, and re-evaluates deferred chunks against the post-valid buffer using `tier='fast'`.
  * Implemented syntax-resilient Cartographer extraction (`extract_file_symbols`) that preserves cached symbols on `SyntaxError` and renders `# [comment required]` sentinels for undocumented public symbols.
* **Semantic LLM Tiers & Output Schema Bouncer (`engine_llm.py`)**:
  * Added semantic tier resolution (`_resolve_tier_model`) for `fast`, `standard`, `thinking`, and `frontier`.
  * Added structural output schema validation (`validate_output_schema`) and an automated self-healing retry loop in `llm.complete`.
* **Lifeboat Recovery Bootloader Handshake & Reboot Hardening (`fallback_bridge.py`)**:
  * Added authentication token synchronization during recovery reboots: `rebootOS()` captures `data.token` from `/auth/bootstrap` and writes it to both `sessionStorage` and `localStorage` before redirecting to `/`, preventing 401 redirect loops.
  * Hardened daemon reboot sequence in `system_reboot()` by removing `.panic_lock`, stripping panic environment variables, and scheduling `os.execv` off-thread after a 0.6s grace period.
* **Agent Architectural Fitness Enforcement (`rules_python.py`)**:
  * Added `AGENT_LLM_GATEWAY_MANDATE` prohibiting direct HTTP or LLM client library imports in agent modules.
  * Added `YOMAMA_PATCH_GATEWAY_MANDATE` prohibiting direct `ctx.vfs.save()` writes in agent modules, mandating transactional execution through `bridge.sync`.
