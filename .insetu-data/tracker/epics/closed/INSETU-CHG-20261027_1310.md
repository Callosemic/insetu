## Description
* **Model Context Protocol (MCP 2025-03-26) Server Substrate (`insetu/core/mcp/__init__.py`, `insetu/core/mcp/engine_mcp.py`, `insetu/cli.py`)**:
  * Implemented native JSON-RPC 2.0 MCP server substrate (`mcp_bp`) supporting both HTTP transport (`POST /api/<ws>/mcp` and `@mcp_bp.route('rpc')`) and stdio transport (`insetu mcp` via `handle_mcp_stdio`).
  * Registered core tools: `cartographer.extract` for targeted symbol AST slicing, `fs.fetch` for raw source file access, and `bridge.sync` for transactional Yomama patch execution.
  * Registered resources: workspace source files, `CODE_INDEX.md`, and compiled contexts (`ctx://contexts/*`, `ctx://diffs/*`, `ctx://workflows/*`).
  * Registered prompts: parameterized prompt templates with automated `{{ macro_* }}` argument introspection, default fallback parsing, and recursive macro expansion (`_render_mcp_prompt`).
  * Added `mcp` subcommand to `cli.py` with automated profile scaffolding via `scaffold_profiles(cwd)`.
* **Relational Watermark Derivation & Architectural Linter Hardening (`rules_javascript.py`, `rules_python.py`)**:
  * Enforced `IMPERATIVE_DIRTY_SET_MUTATION_BAN`: imperative mutations to `dirtyBuckets` and `dirtyRepos` outside `store.js` are banned; staleness is derived reactively from `source_ts` vs `meta.timestamp`.
  * Enforced `YOMAMA_PATCH_GATEWAY_MANDATE`: direct VFS mutations in agent loops are banned; all agent code changes must route through `bridge.sync`.
  * Enforced `AGENT_LLM_GATEWAY_MANDATE`: direct LLM client imports in `engine_agent.py` and `orchestrator.py` are banned; all inference must route through `llm.complete`.
  * Enforced `DIRECT_CWD_MUTATION_BAN`: direct assignment to `._cwd` is banned; working directory mutations must use `akasa.reset_state(cwd=...)` or `set_daemon_cwd()`.
  * Enforced `TOPOLOGY_GIT_STATUS_TIMESTAMP_CLOBBER_BAN`: SQL updates to `topology_ledger.git_status` must not overwrite the `timestamp` column.
  * Whitelisted `cartographer.py`, `bridge_ast.py`, and `engine_mcp.py` for `InSetuURI.from_external_input()`.
  * Refined `CARTOGRAPHER_PLACEHOLDER_BAN` to ignore AST symbol signatures (`def `, `class `) and focus strictly on unresolved file/directory placeholders.
* **Recovery Bootloader Token Synchronization & Reboot Hardening (`fallback_bridge.py`)**:
  * Enhanced client-side `rebootOS()` in Lifeboat Recovery to capture `data.token` from `/auth/bootstrap` and persist it to both `sessionStorage` and `localStorage`, preventing 401 redirect loops.
  * Hardened `system_reboot()` by removing `.panic_lock`, clearing panic environment variables, and executing `os.execv` off-thread after a 0.6s grace period.
* **Unit Test Suite Hardening (`tests/unit/`)**:
  * `test_agent_orchestrator_and_mcp.py`: Validated LLM tier resolution (`fast`, `standard`, `thinking`), output schema bouncer self-healing, declarative routine DAG interpretation, scratch vaulting ($\ge 256\text{ KB}$), `/code`, `/plan`, `/yomama`, and `/undo` rollback, and MCP JSON-RPC handling.
  * `test_cartographer_and_bridge_ast.py`: Validated shallow AST symbol extraction, 3-tier comment waterfall sentinels, `cartographer.extract` source slicing, `bridge.ast_relocate`, and `bridge.ast_rename`.
  * `test_canonical_uris.py`: Added `test_relational_watermark_lifecycle_from_mutation_to_gather_compile` verifying the end-to-end relational watermark contract.
  * `test_fallback_bridge.py`: Added `test_recovery_reboot_token_sync_contract` asserting token storage persistence.
  * `test_ext_preview_unit.py` & `test_sdk_improvements.py`: Cleaned up imports and migrated CWD manipulation to `akasa.reset_state`.
