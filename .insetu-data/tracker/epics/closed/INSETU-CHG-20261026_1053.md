## Description
* **Flask Transport Shell Decoupling (`engine_agent.py`, `engine_bridge.py`, `engine_llm.py`)**:
  * Eradicated all direct imports of `from flask import jsonify` across Tier 2 Core AI and Bridge engines, returning plain Python dictionaries and status codes (`{"status": ...}, 202`) to comply with `FLASK_TRANSPORT_LEAK_BAN`.
  * Consolidated route request parameter extraction by replacing direct `ctx.req.json` and `ctx.req.get_json()` calls with unified `ctx.payload`.
* **Akasa Capability Backbone & In-Process Dispatch (`engine_agent.py`, `engine_llm.py`)**:
  * Replaced private cross-module imports and helper invocations (`__pack_selection_worker`, `_stream_anthropic`, `_stream_gemini`, `_stream_claude_cli`, `_execute_bridge_sync`) in `engine_agent.py` with in-process capability dispatch via `ctx.call("gather.pack_selection", ...)`, `ctx.read_compiled_context(...)`, `ctx.call("llm.complete", ...)`, and `ctx.call("bridge.sync", ...)`.
  * Implemented synchronous aggregated inference endpoint `POST /api/<workspace_id>/llm/complete` (`api_llm_complete`) in `engine_llm.py`, allowing ReAct agents and background workers to request full text completions cleanly.
* **Semantic API Route Prefixing & Client Alignment (`agent.js`, `bridge.js`)**:
  * Migrated deprecated `window.inSetu.api.workspace.*` invocations to canonical `window.inSetu.api.*`.
  * Normalized job submission in `bridge.js` from relative `'sync'` to canonical `'bridge/sync'` to comply with `CANONICAL_API_ROUTE_PREFIX_MANDATE`.
* **Bridge Sub-Navigation Menu Consolidation (`bridge.js`)**:
  * Eradicated the standalone `<insetu-ext-bridge-history-actions>` Web Component and deprecated `slots:sub-navigation-actions` registration to fulfill `BANNED_SUB_NAV_ACTIONS_SLOT_BAN`.
  * Migrated Receipts history view toggling (`transaction` vs `file`) to declarative `menuStores: ["Bridge"]` and `menuActions: () => [...]` on the `history` sub-navigation slot.
  * Pinned `headerActionComponent: "insetu-ext-bridge-actions"` directly to the `bridge` sub-navigation slot definition.
  * Migrated URI repo extraction in `InSetuExtBridgeHistory` from deprecated `parseURI` to `new this.utils.InSetuURI(r.filepath).repo` to satisfy `PARSE_URI_DEPRECATION_BAN`.
* **Pathlib Compliance & Typed Worker Signatures (`bridge_vfs.py`, `engine_agent.py`, `engine_bridge.py`)**:
  * Replaced legacy `os.path.splitext` with `Path(resolved_path).suffix.lower()` in `bridge_vfs.py`, fulfilling the `PATHLIB_MANDATE`.
  * Enforced explicit parameter type annotations and `ctx` first positional parameter declarations across `@*.worker` functions (`_execute_agent_turn`, `_background_bridge_sync`, `_sweep_ledger_worker`), satisfying `WORKER_CTX_FIRST_PARAM_MANDATE` and `WORKER_TYPED_SIGNATURE_MANDATE`.
