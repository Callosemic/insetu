## Description
* **Bridge Console Sanitization & Safe Status Output (`bridge.js`)**: Eliminated raw `.innerHTML=${this.consoleOutput}` DOM assignment in `InSetuExtBridge._renderTelemetry()` in favor of native Lit template text node escaping. Replaced HTML string error formatting with prefix matching (`startsWith('[!]')`), dynamically binding `--intent-danger` styling and monospace formatting while protecting against XSS vulnerabilities.
* **Sutram Card Intent Token Alignment (`bridge.js`, `fs.js`)**: Standardized `<sutram-card>` presentation attributes across `bridge.js` telemetry cards and `fs.js` link insertion cards, replacing legacy `intentColor="${...}"` attribute strings with canonical `.intent=${...}` property bindings (`primary`, `warning`, `danger`, `neutral`, `highlight`).
* **File Tree Virtual List Closing Tag Repair (`ui_file_tree.js`)**: Restored the missing closing `</sutram-virtual-list>` tag within the non-search `directoryEntries` branch of `InSetuFileTree.render()`, resolving layout collapse and virtual list scroll-tree parsing failures.
* **Telemetry & UI String Formatting Normalization (`offline_ui.js`, `bridge.js`)**: Added missing spaces in poison pill re-queueing telemetry logs (`[${item.method}] ${item.path}`), pre-cache success status notices (`files for ${repoDir}`), and Bridge target file patch count summaries (`of ${totalCount}`).
