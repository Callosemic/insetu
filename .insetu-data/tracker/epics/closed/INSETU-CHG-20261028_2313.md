## Description
* **Single-File Frontend Membrane Isolation (`SUTRAM_MEMBRANE_ISOLATION`)**:
  * Unified all frontend imports of Tier 0 presentation primitives, stores, and utilities under the Single-File Frontend Membrane in `insetu/core/system/insetu_sdk.js`.
  * Re-exported all required vendor and micro-kernel symbols (`SutramElement`, `createSutramStore`, `StoreRegistry`, `StatusStore`, `ToastStore`, `SelectionStore`, `EnvironmentStore`, `LayoutStore`, `canUseMultiWindowPopout`, `SutramDB`, `OfflineHttpProvider`, `NetworkHysteresisManager`, `OutboxReconciler`, `bootSutramServiceWorker`, `purgeSutramCaches`, `createJobPoller`, `initShortcutRouter`, `sharedStyles`, `SutramCard`, `SutramEditor`, `SutramProjectionWindowControls`, `SutramModal`, `SutramAsyncBtn`, `SutramBtn`, `SutramInput`, `SutramSelect`, `SutramTextarea`, `SutramToggle`, utilities) from the bare specifier `'sutram'` importmap.
  * Purged all direct imports from `/static/vendor/sutram/*`, `../../vendor/sutram/*`, and `/static/vendor/yenvui/*` across `config.js`, `fs.js`, `offline_ui.js`, `api.js`, `ui_editor.js`, `ui_file_tree.js`, `ui_filter_pills.js`, `ui_primitives.js`, `ui_system_settings.js`, `store.js`, and `system.js`.
* **Declarative Schema Repeater & Universal Repeater Secret Vaulting**:
  * Introduced `<insetu-schema-repeater>` (`InSetuSchemaRepeater` in `ui_system_settings.js`) supporting `type: "repeater"` settings schemas with bounds validation (`min_items`, `max_items`), reordering controls (`chevron-up`, `chevron-down`), add/remove operations, conditional field visibility (`show_if`), nested `record` schemas, and datalist suggestions.
  * Migrated sub-bucket configuration in `config.js` (`renderSubBuckets`) from manual collapsibles to `<insetu-schema-repeater>` via `_getSubBucketsRepeaterSchema()`.
  * Implemented `vault_repeater_secrets_for_schema()` in `engine_system.py`, automatically scanning repeater schemas for subfields declaring `secure: True`, extracting plaintext secrets into `.insetu/secrets.json` under `secrets[ext_name][f"{repeater_id}__{item_id}__{subfield_id}"]`, and masking them as `'********'` in configuration files.
  * Formatted `shared_mounts` in `SYSTEM_SETTINGS_SCHEMA` as `type: "repeater"` with explicit `item_schema`, and refactored `_renderMountsDrillDown()` to use `<insetu-schema-repeater>` for both `shared_mounts` and `export_shared_domains`.
* **Template Overlay VFS Driver & Backend Membrane Consolidation**:
  * Implemented `TemplateOverlayVFSDriver` in `insetu/core/sdk/__init__.py` providing the 3-Tier Same-Name Override Cascade (Workspace Override > Global User Template > Built-in Module Template) for `.templates/` virtual volumes.
  * Enhanced `InSetuExtension(volumes={...})` with declarative `module_subdir` support to automatically instantiate and mount `TemplateOverlayVFSDriver`.
  * Added PEP 562 lazy `__getattr__` in `sdk/__init__.py` for `_UTILS_CORE_REEXPORTS`, eliminating circular import hazards during module bootstrap.
  * Refactored `utils_core.py` to import exclusively from `insetu.core.sdk`, strictly fulfilling the 4-File Akasa Membrane Mandate (`AKASA_MEMBRANE_ISOLATION`).
  * Re-exported `PeerInfo`, `classify_peer`, `register_proxy_header`, `register_allowed_host`, `CycleError`, `resolve_dag_wavefronts`, `extract_template_variables`, and `interpolate_template_variables` through the SDK membrane.
* **Yomama Patch Protocol v4 Block Parsing & AST Directives**:
  * Enhanced `parse_blocks()` in `utils_core.py` with multi-marker scanning and support for `<<<<<<< TEXTEDIT`, `<<<<<<< JSON_PATCH`, `<<<<<<< MOVE_FILE`, `<<<<<<< ARCHIVE_FILE`, and `<<<<<<< DELETE_FILE` directives terminated by `>>>>>>> EXECUTE`.
  * Built `_project_textedit_search_replace()` projecting inline `{{-delete}}` and `{{+insert}}` spans into canonical search/replace envelopes for 100% diff viewer and `/undo` rollback compatibility.
  * Added `dump_yaml_string()` for safe round-trip YAML serialization.
* **Chassis Polish & Legacy Purge**:
  * Purged obsolete `allow_tailscale_origin` and `host_identity_handshake` hooks from `engine_system.py`.
  * Purged obsolete legacy flow migration from `legacy.py`.
  * Hardened tab indent shortcut in `ui_editor.js` to inspect active shadow DOM elements and dispatch bubbling composed input events.
