## Description
* **Flow Extension Decommissioning (`engine_flow.py`, `ext_flow.js`)**:
  * Formally deleted `insetu/extensions/flow/engine_flow.py` and `ext_flow.js`. All workflow automation, context batching, and prompt staging capabilities are now fully superseded by Tier 2 Core sovereign Markdown-as-Code Agent Routines (`ctx://routines/`, `orchestrator.py`) and topological DAG wavefronts.
* **Automation Hooks Protected Bridge Paths (`engine_hooks.py`)**:
  * Registered `@hooks_bp.on('register_protected_bridge_paths')` returning `[".insetu/hooks/", ".insetu-data/hooks/", "rules.json"]`, safeguarding automation rule definitions against unauthenticated LLM patch modifications via the Yomama Sync Bridge.
* **Tracker Settings Schema Repeater Migration (`engine_tracker.py`, `ext_tracker.js`)**:
  * Upgraded `parent_tabs`, `global_views`, and `kanban_profiles` in `TRACKER_SETTINGS_SCHEMA` from `"type": "hidden"` to first-class `"type": "repeater"` settings schemas with bounds validation and explicit `item_schema` contracts.
  * Replaced bespoke form manipulation methods (`_onSelectSchema`, `_createNewSchema`, `_updateSchemaForm`, `_deleteSchema`, `_addParentTab`, `_removeParentTab`, `_updateParentTab`, `_addGlobalView`, `_removeGlobalView`, `_updateGlobalView`, `_updateGlobalViewFilter`) in `InSetuExtTrackerSettings` with declarative `<insetu-schema-repeater>` components.
  * Added `_getCustomProfilesRepeaterSchema()`, `_getParentTabsRepeaterSchema()`, and `_getGlobalViewsRepeaterSchema()` with custom toggles for explicit repository selection and ticket type/status filtering.
  * Sanitized `target_tier` in `saveSettings()` to ensure numerical types and stripped ephemeral client `_uuid` keys.
