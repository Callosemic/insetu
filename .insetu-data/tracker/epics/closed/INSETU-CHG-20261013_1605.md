## Description
* **Extension Modal Annihilation & Spatial Projections (`ext_*.js`)**: Eradicated monolithic fullscreen `<sutram-modal>` dialogs across the Tier 3 extension suite, migrating all long-form inspection, editing, and preview workflows into multi-column spatial viewport projections pinned to `LayoutStore`:
  * **Flow (`ext_flow.js`)**: Decoupled batch execution inspection and batch editing into `InSetuFlowViewProjection` (`flow:view`) and `InSetuFlowEditProjection` (`flow:edit`).
  * **Git (`ext_git.js`)**: Converted commit message drafting into `InSetuGitPushProjection` (`git:push`) and pull dry-run inspection into `sutram-report-projection` (`git:preview`) with integrated reconciliation controls.
  * **Notes (`ext_notes.js`)**: Converted `InSetuExtNotesEditor` into a spatial window projection (`notes:editor`) opened via `NotesStore.openNoteEditor()`.
  * **Research (`ext_research.js`)**: Decoupled scraped document preview and triage into `InSetuResearchPreviewProjection` (`research:preview`).
  * **Skills (`ext_skills.js`)**: Migrated spaced-repetition training sessions into `InSetuSkillsSessionProjection` (`skills:session`).
  * **Tracker (`ext_tracker.js`)**: Decoupled the monolithic ticket editing modal into `InSetuTrackerEditProjection` (`tracker:edit`).
  * **Update (`ext_update.js`)**: Decoupled dry-run release previews and execution logs into `sutram-report-projection` (`update:preview`).
* **Store Eviction Governance (`createExtensionStore`)**: Added declarative `onEvict` schemas across all domain stores (`FlowStore`, `GitStore`, `NotesStore`, `ResearchStore`, `SkillsStore`, `KanbanStore`, `UpdateStore`) to reset volatile buffers and item pointers automatically when projections close.
* **Declarative Iconography Standardization**: Eradicated raw emoji characters across toolbar buttons, card tags, and status headers, migrating to `<yv-icon name="...">` and `<sutram-btn icon="...">` / `<sutram-async-btn icon="...">` attributes.
* **Semantic Update Engine DAG Integration (`engine_update.py`)**: Added delayed compile cancellation (`cmp_del_{workspace_id}`) and chained post-bump execution directly into `resolve_dag_chain(ctx, 'register_compilation_steps')` to compile release artifacts and code indices automatically. Added repository-scoped `commit_parser` and `auto_publish` configuration support.
* **Git Substrate & Sweep Hardening (`engine_git.py`, `ext_git.js`)**: Standardized `coerce_git_uris` with `is_naked_diff_uri`, guarded `git-sweep` action with `has_untracked_files` checks, and added `git-ctrl-init`, `git-ctrl-remote`, `git-ctrl-pull`, and `git-ctrl-branch` repository actions.
* **Bug Fixes**: Corrected malformed closing tag in `InSetuTrackerTicket` (`</insetu-card>` -> `</sutram-card>`), purged deprecated prompt entity actions in `ext_prompts.js`, and removed redundant inline imports in `engine_research.py`.
