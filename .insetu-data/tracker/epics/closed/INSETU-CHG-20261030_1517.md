## Description
* **App Server Network Exposure Leases (S2) (`engine_preview.py`, `ext_preview.js`)**:
  * Bound managed preview servers to loopback (`127.0.0.1`) by default across `PREVIEW_SETTINGS_SCHEMA` and `start_repo_server()`.
  * Implemented human-only LAN exposure leases via `POST preview/open_lan` and `POST preview/close_lan`, permitting `0.0.0.0` binding only under explicit time-limited grants (`run`, `15m`, `1h`, `8h`) with automated timer expiration returning servers to loopback.
  * Added `static_cors` setting (default `False`), preventing arbitrary web pages from performing cross-origin reads on served files unless explicitly enabled by an operator.
  * Hardened static HTTP serving (`_STATIC_SERVER_SCRIPT`) with `NoCacheHandler`: blocked dotfiles (`.git`, `.env`) and paths outside the served root via symlink traversal with HTTP 404. Restricted default CORS methods to `GET, OPTIONS, HEAD`.
  * Enforced access token authentication for browser code execution: replaced insecure `--no-token` in `marimo` mode with `--token-password <access_token>` using cryptographically random 18-byte tokens.
* **Human-Only Custom Command Approval (P5) (`engine_preview.py`, `ext_preview.js`)**:
  * Added `PreviewApprovalRequired` (HTTP 403) and command authorization verification (`is_command_approved`) for custom commands and Hugo arguments.
  * Added `preview.approve_command` and `preview.open_lan` endpoints marked with `mcp_expose=False` (human-only, banned from MCP and declarative agent routines).
  * Built UI exposure bar in `<insetu-ext-preview>`: renders approval prompts with "Approve & Start", active LAN lease banners with "Back to Loopback", and duration selectors.
  * Built remote viewer reachability detection (`_isLocalViewer`, `_isUnreachableHere`): displays an informative notification when a server binds loopback on a remote host, providing a one-click action to enable Tailscale HTTPS.
* **Protected Recovery Targets & Core Module Priority Loading (`insetu/app.py`)**:
  * Passed `protected_vfs_targets=INSETU_PROTECTED_VFS_TARGETS` to `configure_kernel()`, ensuring recovery path files (`cli.py`, `fallback_bridge.py`, `credentials.py`) are protected against VFS mutation or import shadowing.
  * Hardened `load_workspace_extensions()`: sorted directory inspection, filtered non-blueprint packages (`sdk`, `languages`), sorted Python vendor dependencies, and prioritized Tier 2 Core Substrate DAG loading order (`priority_order`).
