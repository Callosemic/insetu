## Description
* **Dynamic `/code` Routine Context Scouting (`routines/code.md`, `orchestrator.py`)**:
  * Added conditional topology overview inspection (`load_overview` via `capability: topology.overview`) and fast-tier target scouting (`scout_targets`) to `/code` when `has_attached_files` evaluates to false.
  * Ingested scouted files into `gather.pack_selection` with automatic topology boundary clamping (`clamp_rag_files_to_topology`), allowing developers to issue zero-attachment `/code` commands without manual file selection.
* **Interactive Web-Chat Handoff Composer (`agent.js`, `engine_agent.py`, `orchestrator.py`)**:
  * Re-architected external LLM handoffs from passive message bubbles into an interactive `.input-panel.handoff-mode` bottom composer.
  * Added multi-branch stepper navigation, unified "Copy Context" (with file count badges), "Share", and "Copy Prompt + Directives" clipboard helpers.
  * Enabled direct paste ingestion in the chat composer with automatic multi-branch response mapping, resuming routine DAGs seamlessly without inserting synthetic user messages into conversation history.
* **Conversational Prose & Yomama Patch Splitting (`orchestrator.py`, `agent.js`, `engine_agent.py`)**:
  * Implemented `strip_yomama_blocks_keep_prose()` in `orchestrator.py` to decouple conversational text from raw patch envelopes.
  * Rendered clean prose alongside transactional commit receipts (`✅ Applied patches to N file(s)`) in chat transcripts, while routing unapplied or dry-run patches directly to `BridgeStore.parseAndAppendCells()` on the Yomama Bridge staging surface.
* **Cognitive Profile Target Bindings & Model Catalog Tier Inference (`engine_llm.py`)**:
  * Added `web_chat` driver support and populated `DRIVER_TIER_DEFAULTS` across all supported compute drivers.
  * Built `_infer_model_cognitive_tier()` to classify models harvested from OpenRouter, Models.dev, LiteLLM, and local Ollama endpoints into semantic cognitive tiers (`decision`, `fast`, `standard`, `thinking`, `frontier`).
  * Converted `active_profile_id` to a dynamic `select` dropdown and converted profile tier bindings to declarative `target_binding` record schemas.
  * Upgraded `compute_endpoints` and `llm_profiles` repeater schemas with automated slug resolution (`id_key: "id"`, `slug_source`).
