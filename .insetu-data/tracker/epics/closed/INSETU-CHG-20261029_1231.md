## Description
* **Decoupled LLM Target Resolution Capability (`engine_llm.py`)**:
  - Implemented `@llm_bp.route('resolve_target', methods=['GET', 'POST'])` with typed `LlmResolveTargetPayload` request schema.
  - Resolves cognitive profiles and compute endpoint pool bindings to return execution target metadata (`endpoint_id`, `provider`, `model`, `is_web_chat`, `is_decision_model`, `has_api_key`) without exposing plaintext API keys.
  - Decoupled `orchestrator.py` from private cross-module imports of `_resolve_tier_execution_target`, enforcing compliance with `CROSS_MODULE_PRIVATE_IMPORT_BAN`.
* **Reentrant Routine Handoff Propagation & Root-Boundary Reply Splitting (`orchestrator.py`)**:
  - Enhanced `type: routine` delegation in `execute_declarative_routine` to capture and bubble `status == "paused_for_user"` results from nested sub-DAGs directly to the session runner.
  - Unified external Web-Chat and manual transport branch collection into a single level-order wavefront compilation loop using `ctx.call("llm.resolve_target")`.
  - Scoped conversational prose and patch splitting strictly to root execution depth (`_depth == 0`), ensuring intermediate sub-routines retain raw patch blocks while root transcripts display clean prose alongside transactional commit receipts.
* **Dual-Representation Chat Transcript Persistence (`engine_agent.py`)**:
  - Extended `AGENT_SCHEMA["chat_messages"]` with `raw_content` column.
  - Persisted raw model output in `raw_content` alongside clean conversational text in `content`.
  - Rehydrated `history_messages` in `_execute_agent_turn` preferring `raw_content` to guarantee downstream turns retain structural model context without conversational UI bloat.
