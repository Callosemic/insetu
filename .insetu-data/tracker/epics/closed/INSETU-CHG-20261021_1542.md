## Description
* **Akasa Kernel Two-Phase Encapsulation (`insetu/app.py`)**:
  * Consolidated disparate process limit configurations, glibc arena limits, WSGI proxy fix middleware, token security gate hooks, thread database cleanup, and Server-Sent Events (SSE) telemetry streaming into declarative Phase A (`akasa.configure()`) and Phase B (`akasa.init_app()`) invocations.
  * Standardized runtime daemon boot sequencing on `akasa.boot(skip_if_reloader_parent=...)`, eliminating redundant background worker ignition during Werkzeug master supervisor reloads.
  * Hoisted function-level imports to module top-level scope, replaced static `_cwd` accesses with dynamic evaluation via `_akasa_utils.get_daemon_cwd()`, and exported `core_modules` to the root template context.
* **CLI Sibling Path Resolution & Profile Scaffolding (`insetu/cli.py`)**:
  * Added sibling `akasa` repository path discovery to `sys.path` to facilitate local development checkouts without requiring editable package re-installation.
  * Updated `scaffold_profiles` to provision `host.json` and `workspaces.json` baseline files during profile creation.
* **Extension Scaffolding Template Parity (`insetu/defaults/ext_template_js.txt`)**:
  * Updated SDK import path from `/static/extensions/system/sdk.js` to `/static/extensions/system/insetu_sdk.js`.
  * Migrated component store subscription from a two-argument coarse subscription to a three-argument selector-scoped subscription (`this.subscribe(Store, selector, listener)`), satisfying the `COARSE_STORE_SUBSCRIPTION_MANDATE`.
* **Lifeboat FS Resilience & Multi-Part Context Chunking (`insetu/fallback_bridge.py`)**:
  * Exposed the `/auth/bootstrap` route within the fallback bridge returning `{"status": "recovery", "mode": "lifeboat"}`, resolving browser reboot polling deadlocks.
  * Updated client-side reboot polling in the recovery UI to append cache-busting timestamps (`Date.now()`) and detect transitions out of recovery mode.
  * Integrated an automatic 10-attempt socket bind retry loop with 0.5-second pauses in `run_recovery_app()` to absorb `EADDRINUSE` race conditions during fast process restarts.
  * Capped emergency context dump bucket files at 256KB (`max_chunk_bytes = 256 * 1024`) with multi-part partitioning (`_part{idx}`) and stripped inline base64 source maps from vendor JavaScript files.
