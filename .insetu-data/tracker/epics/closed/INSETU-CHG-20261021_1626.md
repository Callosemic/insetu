## Description
* **Akasa Kernel Membrane Decoupling (`engine_citations.py`, `engine_notes.py`, `engine_publish.py`, `engine_research.py`, `engine_skills.py`)**:
  * Eradicated all direct imports from `akasa.*` (`akasa.hooks`, `akasa.vfs`, `akasa.utils`, `akasa.vfs.mount_volume`, `akasa.vfs.register_driver`) across all 5 knowledge extensions, routing exclusively through `insetu.core.sdk` and `insetu.core.utils_core` to satisfy the 4-File Membrane standard.
  * Converted all raw `@hooks.on(...)` subscriptions across these engines to blueprint-scoped decorators (`@citations_bp.on`, `@notes_bp.on`, `@publish_bp.on`, `@research_bp.on`, `@skills_bp.on`), passing `ctx` as the first argument.
* **Declarative Extension Volume Schemas (`engine_notes.py`, `engine_skills.py`)**:
  * Migrated `notes` and `skills` from imperative driver mounting (`mount_volume`, `register_driver`), manual directory resolution (`request_paths`), and manual directory migrations (`move_tree_contents`) to declarative `volumes` dictionary schemas on `InSetuExtension` (`volumes={"notes": ...}`, `volumes={"skills": ...}`).
  * Automated Phase 1 boot volume driver binding (`NotesVFSDriver`), directory provisioning in `.insetu/data/`, and legacy path self-migrations via kernel lifecycle hooks.
* **Citations IoC Topology Compilation & Memory Caching (`engine_citations.py`, `ext_citations.js`)**:
  * Replaced monolithic direct file writes in `@hooks.on('compile_contexts')` with `@citations_bp.on('gather_declare_topology')`, yielding generator and recall callbacks (`_make_callbacks`) for both global (`ctx://contexts/citations_context.txt`) and repository-scoped (`ctx://contexts/{repo}_citations_context.txt`) citation libraries.
  * Cached declared virtual contexts in `citations_ui.json` via `ctx.store.set()`, allowing `@citations_bp.on('mutate_workspace_config')` to hydrate UI metadata without issuing blocking SQLite queries during boot.
  * Purged un-scoped `localSync: ['pinnedRepos']` from `CitationStore` in `ext_citations.js`.
* **Substack & Rich-Text HTML Snippet Publishing (`engine_publish.py`, `ext_publish.js`)**:
  * Introduced the `html_snippet` format in `engine_publish.py` and `ext_publish.js`, generating standalone HTML fragments optimized for direct pasting into Substack, Medium, and Ghost editors.
  * Stripped YAML frontmatter from snippet bodies, removed Pandoc auto-generated heading IDs (`re.sub(r'(<h[1-6])\s+id="[^"]*"([^>]*>)', r'\1\2', html_str)`), and stripped standalone and inline wordcount macros (`strip_macros` collected via `pre_compile_document`).
  * Enhanced `<insetu-ext-publish-modals>` with instant dual-action clipboard controls: rich-text HTML copy (`copyRichHtml`) and raw HTML tags copy (`copyToClipboard`).
  * Removed component-level `executeUnload('publish')` in `disconnectedCallback()` to comply with `COMPONENT_EXECUTE_UNLOAD_BAN`.
* **Notes Sub-Navigation Menu Actions & In-Place Frontmatter Push (`engine_notes.py`, `ext_notes.js`)**:
  * Eradicated `<insetu-ext-notes-actions>` and `slots:sub-navigation-actions` in favor of declarative `menuActions` (`New Note`, `Pre-Cache Notes`) directly on `slots:sub-navigation`.
  * Replaced deprecated `@insetu:request-frontmatter` pub/sub events with direct in-place frontmatter synchronization (`fmEditor.syncFrontmatter(yamlPatch, true)`), and normalized save triggers to `fmEditor.save()`.
  * Hardened VFS deletion traps in `InSetuExtNotesEditor` to handle relocated notes dynamically (`relocated_to` / `movedSave`), resolving filenames via `InSetuURI(deletedFp).basename`.
* **Research Extension Lifecycle Safety & Diagnostic Ledger Guarding (`engine_research.py`, `ext_research.js`)**:
  * Replaced unmanaged `setTimeout` polling loops in `ext_research.js` with managed `this.registerTimeout()` and `this.clearManagedTimeouts()`.
  * Injected active workspace parity checks (`getActiveWorkspace() !== fetchWs`) into `fetchState` to prevent background polling loops from leaking across tenant workspace swaps.
  * Added `ignore_ledger: True` on diagnostic SERP failure HTML dumps to prevent polluting the VFS event ledger.
* **Skills Ledger URI Normalization & Entity Creation (`engine_skills.py`)**:
  * Replaced raw SQL URI string updates in `_ensure_skills_hydrated` with `ctx.db.heal_uri_column("skills_ledger", "filepath", "ctx://skills/")`.
  * Purged all imperative `init_skills_storage()` invocations across route handlers.
  * Standardized new skill item generation on `ctx.create_entity_file()`.
