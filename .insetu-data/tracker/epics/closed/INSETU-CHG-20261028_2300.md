## Description
* **Cartographer AST Symbol Drift Tracking & Ledger Watermarking (`cartographer.py`)**:
  * Introduced `CARTOGRAPHER_SCHEMA` declaring `symbol_ledger` (`symbol_key`, `repo`, `filepath`, `symbol_name`, `signature`, `body_hash`, `verified_hash`, `comment`, `status`, `updated_at`) and bound it to `cartographer_bp`.
  * Built normalized AST body hashing (`_compute_normalized_py_body_hash` and `_compute_normalized_js_body_hash`) to isolate functional code modifications from whitespace and comment formatting.
  * Integrated symbol ledger reconciliation into `map_repositories`: tracks `body_hash` against `verified_hash`, tagging drifted documentation with `[stale?]` in `CODE_INDEX.md`.
  * Exposed `POST cartographer/verify_symbols` endpoint to clear `[stale?]` flags upon operator verification.
  * Exposed `POST cartographer/enrich` and `@cartographer_bp.worker("enrich_task")` background worker to batch undocumented/stale symbols into fast-tier LLM enrichment.
  * Added Tier 2 Markdown frontmatter and heading fallback in `map_repositories` for `.md` documentation (Routines, Prompts, ADRs).
* **Template Overlay VFS Driver Delegation & 3-Tier Prompt Cascade (`engine_prompts.py`)**:
  * Refactored `PromptsVFSDriver` to subclass `TemplateOverlayVFSDriver` from `insetu.core.sdk`, eliminating redundant module path resolution logic.
  * Implemented `_read_with_cascade` in `api_prompts_resolve`, providing the 3-Tier Same-Name Override Cascade (Workspace Override > Global User Template > Built-in Module Template) for both direct prompt resolutions and recursive `{{include_prompt: ...}}` macro inclusions.
* **Topology Upkeep Audit Engine, Plan Verification, and Structural Overview (`engine_topology.py`)**:
  * Added `GET topology/overview` compiling lightweight summaries of target repositories, active sub-buckets, and `CODE_INDEX.md` headers.
  * Added `POST topology/verify_plan_targets` validating that `vfs://` and `ctx://` URIs referenced in architectural plans exist on disk or are flagged as creation targets.
  * Added `GET/POST topology/audit_upkeep` executing a deterministic 3-pillar upkeep audit:
    1. Documentation & Symbol Drift (`docs_drift`): missing `CODE_INDEX.md` comments, stale symbol implementations via `symbol_ledger`, and broken `vfs://` links in documentation.
    2. God-Object Decomposition Candidates (`god_objects`): oversized files ($\ge 550$ lines or $\ge 15$ symbols) with symbol span breakdowns.
    3. Test Suite Relevance (`test_relevance`): stale test imports (missing exported symbols) and untested registered capabilities.
    * Auto-populates `target_files` (up to 12 files) for routine / agent triage.
