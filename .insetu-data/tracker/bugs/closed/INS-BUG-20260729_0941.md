## Description
Investigated domain strategy configuration persistence across the Settings Hub and repository config injection. The setting is declared in `TRACKER_SETTINGS_SCHEMA` under `domain_strategy` (options: `default`, `repo`, `custom`) and `domain_custom_value` with `scope: "workspace"`. Verified that mutations persist to `<control_dir>/workspace.settings.json` via `SettingsManager` and are read authoritatively by `inject_tracker_config` on `mutate_workspace_config` to route sub-bucket domain definitions without resetting to defaults.
