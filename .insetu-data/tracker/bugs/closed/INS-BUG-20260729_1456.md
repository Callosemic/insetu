## Description
Resolved. Monolithic `<sutram-modal>` dialogs in the Git extension were completely eliminated. The commit message input interface was re-architected into `InSetuGitPushProjection` (`git:push`) pinned directly into the multi-column spatial grid (`LayoutStore`), and the pull preview was converted to a spatial `sutram-report-projection` (`git:preview`). This eradicates unmounted modal backdrops and eliminates click-blocking overlay anomalies entirely.
