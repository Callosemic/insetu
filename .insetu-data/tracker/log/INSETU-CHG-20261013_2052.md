## Description
* **Yomama Bridge Spatial Projection Migration (`bridge.js`)**: Replaced the custom `InSetuBridgeDiffProjection` and volatile `syntaxErrorDiff` state with the platform-standard `<sutram-report-projection>` (`bridge:syntax-diff`) pinned to `LayoutStore`, standardizing syntax failure diff reviews.
* **Declarative Eviction Governance (`bridge.js`)**: Migrated window eviction teardown logic in `BridgeStore` to the declarative `onEvict` schema within `createExtensionStore`, removing raw window listeners for `sutram-evict-projection`.
* **Smart Alert Toast Resolution (`system.js`)**: Enhanced `window.alert` to automatically infer notification intent (`success`, `warning`, `danger`) based on regex matching of message prefixes and success patterns, stripped redundant emoji indicators, and ensured dual resolution against `inSetu` and `Sutram` toast stores.
