## Description
* **Python AST Fitness Linter Hardening (`rules_python.py`)**: Added `DEPRECATED_VFS_DELETE_ACTION` AST validation rule in `BackendFitnessVisitor.visit_Call`. Mathematically flags calls to `ctx.vfs.save()` passing `data={'action': 'delete'}`, enforcing strict adoption of the canonical `ctx.vfs.delete()` API across extensions and core modules (ADR 0004, ADR 0018).
* **JavaScript Fitness Linter Hardening (`rules_javascript.py`)**:
  * Implemented `LEGACY_BATCH_ACTIONS_BAN` rule detecting deprecated `batchActions:` declarations, enforcing full migration to `entityActions` configured with `bulkable: true`, `targetEntities`, and `bulkGroupKey` (ADR 0061).
  * Expanded `BANNED_UI_ZONES` rule scope to sweep Tier 2 core JS modules (`core/`) in addition to Tier 3 extensions (`(is_extension or 'core' in filepath.parts)`), permanently preventing regression to deprecated `uiHooks` and `zone:*` string hooks (ADR 0041).
* **Code Index ADR Realignment (`CODE_INDEX.md`)**: Realigned the architectural decision ledger, reflecting the movement of deeply embedded and superseded ADRs (0021, 0023, 0025, 0026) to `adrs/archived/` and formally recording ADR 0060 (Git-Aware Topology Manifest Sync) and ADR 0061 (Polymorphic Bulk Entity Actions) in the active index.
