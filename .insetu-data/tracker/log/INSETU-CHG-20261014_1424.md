## Description
* **VFS Bulk Operations & Subsumption Pruning (`fs.js`)**: Implemented `pruneSubsumedTargets(items)` to deduplicate bulk operations when ancestor folders and child nodes are simultaneously selected. Introduced `executeBulkMove`, `executeBulkArchive`, and `executeBulkDelete` alongside atomic mutation routines (`_relocateVfsNode`, `_archiveVfsNode`, `_deleteVfsNode`). Added `_evictDeletedNodeFromState` to close active buffers and unpin/evict layout projections from `LayoutStore` across all spatial columns.
* **Polymorphic Entity-Action Consolidation (`fs.js`)**: Standardized `vfs-move`, `vfs-rename`, `vfs-archive`, and `vfs-delete` across `targetEntities: ['file', 'folder']`, binding `bulkGroupKey`, `bulkable: true`, and `bulkAction` handlers.
* **Explorer Actions Multi-Select Integration (`fs.js`)**: Subscribed `InSetuVFSExplorerActions` to `SelectionStore`, dynamically mounting aggregatable file actions from `ExtensionRegistry.getAggregatableActions` and displaying a dynamic selection badge counter with layer iconography.
* **Recursive Directory Buffer Tracking (`fs.js`)**: Enhanced `renameFileTracking` to recursively migrate active buffer tracking in `FsStore.activeBuffers` for all child paths when parent directories are renamed or moved.
* **Batch Actions Migration to Polymorphic Entity Actions (`gather.js`)**: Deprecated isolated `batchActions` array and migrated `gather-pack-download` and `gather-pack-compile` into standard `entityActions` with `bulkable: true`, `bulkOnly: true`, and `targetEntities: ['*']`.
* **CQRS Subtree Deletion Filtering (`ui_file_tree.js`)**: Enhanced `_getTree` and active search filtering in `InSetuFileTree` to recursively suppress child files (`f.startsWith(d + '/')`) when parent folders are deleted.
