## Description
* **Akasa Kernel Membrane Decoupling (`engine_dev.py`, `engine_git.py`, `engine_preview.py`, `engine_tailscale.py`, `engine_term.py`)**:
  * Purged all direct imports of `akasa.hooks`, `akasa.utils`, `akasa.vfs`, `akasa.db`, and `akasa.extension` across Tier 3 DevOps and system extensions, routing framework access strictly through `insetu.core.sdk` and `insetu.core.utils_core` to satisfy `AKASA_MEMBRANE_ISOLATION`.
  * Migrated all raw `@hooks.on(...)` subscriptions to blueprint-scoped decorators (`@dev_bp.on`, `@git_bp.on`, `@preview_bp.on`, `@tailscale_bp.on`), injecting `ctx` directly into callback signatures to eradicate redundant `get_context()` invocations.
  * Replaced manual database connection pooling in `engine_dev.py` with `ctx.get_db("workers")` and `ctx.get_db(clean_db_name)`.
* **Declarative Diff Volumes & Sub-Bucket Addressing (`engine_git.py`, `ext_git.js`)**:
  * Replaced imperative `request_paths`, `mount_volume`, and `move_tree_contents` hooks in `engine_git.py` with declarative `volumes={"diffs": {"scheme": "ctx", "tier": "cache", "path_key": "diffs_dir", "legacy_dirs": [...]}}` schema definitions.
  * Standardized the Git diff DAG compilation step on `anchor="body"` and `order=30` in `register_compilation_steps`.
  * Unified chunk text reading and physical disk validation in `generate_diff_context` via `ctx.read_compiled_context(out_filename, manifest=working_manifest)` and `ctx.is_context_on_disk()`.
  * Standardized sub-bucket diff file addressing to include repository prefixes (`ctx://diffs/{safe_r_dir}_{module}_diffs.txt`), eliminating cross-repository naming collisions in multi-repo workspaces.
  * Replaced manual emit aggregation loops in `api_git_changelogs` with `ctx.emit_merge_list('request_changelog_suggestions', repo=repo)`.
  * Connected `ctx://diffs/` artifacts to JIT compilation triggers via the `insetu:ensure-fresh-artifact` event listener.
* **UI Action Grouping & Presentation Hygiene (`ext_git.js`, `ext_dev.js`)**:
  * Reassigned `git-push` to `group: 'vcs'` and consolidated sub-navigation menu actions on `slots:sub-navigation` for `diffs` with `bulkActionGroup: "vcs"` and `bulkEntityTypes: ["diff"]`, satisfying `QUICKPACK_SHARE_GROUP_ISOLATION` and `DECLARATIVE_SUBTAB_MENU_MANDATE`.
  * Replaced manual path string splitting with `new this.utils.InSetuURI(uri).basename` and purged manual `chunks` declarations from card `.entityData`.
  * Removed obsolete `insetu:soft-refresh` state-wiping listener from `ext_dev.js` to preserve store lifecycle integrity under the `SessionOrchestrator` workspace swap FSM.
* **Terminal Gesture Resource Management (`ext_term.js`)**:
  * Replaced unmanaged raw `clearTimeout` and `setTimeout` tracking in gesture handling with `this.registerTimeout()` and `this.clearManagedTimeouts()`, preventing memory leaks on component unmount and complying with `DEBOUNCE_MANDATE`.
* **Update Store Multi-Tenant Race Hardening (`ext_update.js`)**:
  * Hardened `UpdateStore.fetchRepoStatus` against cross-tenant background worker races by injecting `_statusEpoch` tracking and comparing origin workspace tokens before executing asynchronous status updates.
  * Updated `InSetuExtUpdate.onWorkspaceLoad` to delegate cleanly to `super.onWorkspaceLoad(workspaceId)`.
