## Description
* **Universal Canonical URI Enforcement (`engine_*.py`)**:
  * Eradicated all usage of `InSetuURI.from_any()` across Tier 3 extension engines (`dev`, `flow`, `git`, `notes`, `tracker`), enforcing strict instantiation of `InSetuURI(uri)` with mandatory scheme prefixes (`vfs://`, `ctx://`, `ws://`).
  * Purged deprecated `@hooks.on('coerce_naked_uri')` handlers from `engine_flow.py` and `engine_git.py`.
  * Deployed database boot migrations across `tracker_tickets`, `skills_ledger`, `cronic_jobs`, and `favorites` to automatically normalize legacy scheme-less path rows to canonical `vfs://` and `ctx://` URIs.
  * Standardized Markdown document creation across `engine_tracker.py`, `engine_notes.py`, and `engine_skills.py` to use `ctx.create_entity_file()`.
* **Inter-Workspace Virtual Mounts (`ws://`) Extension Adoption (`engine_flow.py`, `engine_notes.py`, `ext_flow.js`, `ext_notes.js`)**:
  * Implemented `_discover_mounted_batches` in `engine_flow.py`, discovering workflow batches declared in peer workspaces mounted via `ctx.get_shared_mounts(domain="flow")`. Batch identifiers are namespaced (`{target_ws}__{id}`), instruction prompts are mapped to `ws://{target_ws}/prompts/...`, and mutative entity actions are suppressed (`match: (data) => !data?.is_shared`).
  * Implemented `NotesVFSDriver` subclassing `DefaultVFSDriver` in `engine_notes.py` to transparently resolve notes co-located inside `<repo>/.insetu-data/notes/`, and implemented `_discover_mounted_notes` to mount virtual `ws://` note trees into the Notes Library.
  * Enhanced `ext_notes.js` to render mounted `ws://` notes with distinct globe iconography and read-only source projections.
* **Universal SDK Ergonomics & UDF Alignment (`ext_*.js`)**:
  * Migrated all 11 Tier 3 domain extensions (`citations`, `cronic`, `dev`, `favorites`, `flow`, `freshdesk`, `git`, `hooks`, `notes`, `research`, `skills`, `tracker`, `update`) to `this.bindStore()` with declarative `autoFetch` handlers.
  * Replaced duplicated fuzzy search and repository filter pipelines across `ext_citations.js`, `ext_flow.js`, `ext_git.js`, `ext_notes.js`, and `ext_tracker.js` with `this.filterItems()`.
  * Added `allow_popout: true` to the layout slot definitions of `tracker`, `notes`, and `term`.
  * Added popout presence checks (`window.inSetu.ui.focusActivePopout`) in `NotesStore` and added `<insetu-projection-window-controls>` to `ext_term.js`.
* **System Binary & URI Ingress Hardening**:
  * Replaced direct `subprocess.run` invocations in `engine_tailscale.py` with `execute_binary()`, enforcing compliance with `EXECUTE_BINARY_MANDATE`.
  * Resolved the `DOWNLOAD_URI_PATH_BAN` violation in `ext_dev.js` by routing invocation log downloads through `window.inSetu.vfs.resolveFileFetchUrl()`.
  * Declared dynamic pacing configuration parameters (`gather_interval_ms`, `gather_jitter_ms`, `scrape_interval_ms`, `scrape_jitter_ms`) within `RESEARCH_SETTINGS_SCHEMA` in `engine_research.py`.
  * Fixed the `row['ticket_id']` typo in `engine_freshdesk.py`.
  * Refactored `on_tracker_settings_updated` in `engine_tracker.py` to submit the full compilation DAG chain via `ctx.resolve_dag_chain('register_compilation_steps')` and `ctx.jobs.submit_chain()`.
