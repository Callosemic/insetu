## Description
* **Dirty Context Card Iconographic Alignment (`ext_flow.js`, `ext_git.js`)**: Replaced `alert-triangle` with the platform-standard `construction` icon token for dirty context and diff cards (`isDirty ? 'construction' : 'package'`), satisfying the `DIRTY_CARD_CONSTRUCTION_ICON_MANDATE` across Flow and Git extensions.
* **Notes Multi-Projection Spatial Windowing & Pop-Out Parity (`ext_notes.js`)**: Refactored `openNoteEditor` in `NotesStore` to key spatial windows by file path (`id: filepath`) with `allow_popout: true` and active column focus deduplication across spatial viewports (`left`, `center`, `right`), enabling parallel editing of multiple notes.
* **Sub-ID Viewport & Pop-Out Projection Hydration (`ext_notes.js`, `ext_tracker.js`)**: Enhanced `InSetuExtNotesEditor` and `InSetuTrackerEditProjection` to resolve and hydrate target file paths dynamically from `this.dataset.subId` (with `vfs://` URI prefix stripping in Tracker), supporting seamless mounting inside detached pop-out windows and direct route links.
* **Declarative CustomEditor Component Mapping (`ext_notes.js`, `ext_tracker.js`)**: Explicitly declared `component: 'insetu-ext-notes-editor'` and `component: 'insetu-tracker-edit-projection'` within the `customEditors` registry payloads for `notes` and `tracker`, standardizing custom editor component resolution across the micro-kernel.
* **Deep Layout Teardown on Note Eviction (`ext_notes.js`)**: Updated `_deleteNote()`, "Raw Edit" switching, and `vfs_mutated` delete traps to close file-specific window IDs (`deletedFp` / `fp`), legacy `'notes:editor'`, and recursively unpin notes from all spatial columns (`layout.unpinFromColumn`).
* **Selector-Scoped Store Subscription Migration (`ext_notes.js`, `ext_tracker.js`)**: Replaced coarse store subscriptions in `InSetuExtNotesModals`, `InSetuExtNotesEditor`, `InSetuExtNotes`, and `InSetuTrackerEditProjection` with 3-argument selector-scoped subscriptions (`this.subscribe(Store, selector, listener)`), eliminating render thrashing across manifest updates.
