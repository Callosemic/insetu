## Description
* **App Shell HTTP Cache Lockdown & SW Bump (`app.py`, `sw.js`)**: Implemented `disable_http_caching` in `insetu/app.py` via `@app.after_request`, enforcing `Cache-Control: no-store, no-cache, must-revalidate, max-age=0` across all dynamic HTTP responses to ensure runtime assets are managed exclusively by the Service Worker. Incremented `self.OS_CACHE_VERSION = 'v3'` in `sw.js` to force an immediate cache update cycle and purge stale HTTP assets.
* **Core Module Registration (`app.py`)**: Registered `llm` and `agent` as trusted Tier 2 core modules in `akasa.utils.register_core_module`.
* **CLI Substrate Modularization (`cli.py`)**: Relocated daemon service management (`handle_service`), desktop shortcut creation (`create_desktop_shortcut`), GUI launching (`launch_gui`), extension scaffolding (`scaffold_extension`), and workspace onboarding (`handle_init`) from `cli.py` into `insetu/core/system/cli_commands.py`. Streamlined `cli.py` into a minimal entrypoint dispatcher and zero-dependency recovery bootstrapper.
* **Fallback Bridge Macro Sanitization (`fallback_bridge.py`)**: Removed aggressive regex patterns in `expand_macros` that stripped underscores, source citations, and citation markers.
* **Architectural Fitness Linter Scope Expansion (`core.py`, `rules_javascript.py`, `results.txt`)**: Expanded the frontend JavaScript fitness function sweep to include Tier 2 `insetu/core` JS modules. Added the `EVENT_PATH_RESOLVER_MANDATE` rule flagging raw `e.composedPath()` calls in favor of SDK `getEventPath(e)`. Whitelisted `system.js` for dropdown click listener checks, and added `cli_commands.py` to Python backend whitelists.
* **Code Index Parity (`CODE_INDEX.md`)**: Synchronized repository tree layout, documenting core modules `agent/`, `llm/`, and `cli_commands.py`, and organizing archived ADR references.
