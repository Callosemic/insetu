## Description
* **Dedicated Viewport Projection Pop-Out Windows (`fs.js`, `ui_editor.js`, `api.js`, `system.js`)**: Implemented `popoutProjection(filepath)` allowing text buffer projections to detach into dedicated browser windows. Pop-out windows run with minimal UI chrome (`variant="popout"`), bypass IndexedDB outbox mutation queuing for direct network operations, extract session auth tokens across origin boundaries via URL query injection, and synchronize real-time file and job progress via a dedicated `BroadcastChannel('insetu_telemetry')` relay without spawning duplicate SSE connections.
* **Optimistic Concurrency Control (OCC) & Debounced Auto-Saving (`fs.js`, `engine_fs.py`, `ui_editor.js`)**: Enforced physical disk integrity across concurrent editors by capturing SHA-256 baseline hashes (`baseHash`) upon file hydration. Buffer saves verify `base_hash` on `fs/save`, generating localized `.conflict_<timestamp>` fallback files on external disk modifications and returning HTTP 409 Conflict. Editor projections wire a 2000ms debounced auto-save alongside a `beforeunload` emergency flush utilizing `fetch(..., { keepalive: true })` to prevent keystroke loss during unexpected tab teardowns.
* **Focus-Aware Idle Hot-Swapping (`fs.js`)**: Connected text buffer projections to `insetu:vfs-mutated` events. If an active buffer has no unsaved changes (`!isDirty`) and CodeMirror does not hold active user focus, external file updates on disk automatically re-hydrate the in-memory buffer without manual browser reloads.
* **Memoized CQRS Manifest Derivation & Structural Selector Subscriptions (`store.js`, `fs.js`, `gather.js`, `ui_file_tree.js`, `insetu_sdk.js`)**: Decoupled high-frequency manifest parsing from frontend component rendering by adding `derivedVfsFiles`, `derivedGitModifiedSet`, and `derivedCtxKeys` directly to `AppStore`. These memoized sets update only when underlying manifests or target configurations experience structural changes (evaluated via `shallowEqual`), eliminating render thrashing across `InSetuVFSExplorer`, `InSetuFileTree`, and `InSetuExtGather`. Coarse store subscriptions were migrated across substrate components to selector-scoped subscriptions.
* **Deep URL Routing & Folder Navigation Parity (`store.js`, `fs.js`, `insetu_sdk.js`)**: Added `setBrowsePath(pathArray, subId)` to `AppStore` to ensure directory navigation changes cleanly update `globalBrowsePath`, `tabBrowsePaths`, and browser hash routes simultaneously. Added `sutram:resolve-route-hash` UI hook in `insetu_sdk.js` to preserve deep paths during tab reloads.
* **Universal Binary Execution & AST Linter Remediation (`utils_core.py`, `engine_llm.py`, `engine_agent.py`, `engine_bridge.py`, `bridge_vfs.py`, `cartographer.py`, `engine_fs.py`, `engine_gather.py`, `legacy.py`)**: Upgraded `execute_binary()` in `utils_core.py` to accept `popen=True`, routing local Claude CLI streaming in `engine_llm.py` through centralized PATH resolution and eradicating direct `subprocess.Popen` invocations. Hoisted top-level imports and aliased inline imports across backend modules to satisfy AST linter rules.
