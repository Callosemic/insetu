## Description
Resolved. Monolithic report projections and raw text character diffs were replaced with platform-standard side-by-side `<sutram-diff-viewer>` interfaces across the Yomama Sync Bridge, Git working tree revisions, and arbitrary file pairs:
1. **Bridge Diff Projection (`InSetuBridgeDiffProjection`)**: Pinned to `LayoutStore` (`bridge:syntax-diff`), providing side-by-side inspection between live disk state and proposed patch blocks upon AST syntax or anchor validation errors.
2. **Bridge Edit Projection Diff Preview (`InSetuBridgeEditProjection`)**: Added a dual-mode toggle allowing operators to switch seamlessly between CodeMirror raw patch editing and side-by-side `<sutram-diff-viewer>` comparison of SEARCH and REPLACE blocks.
3. **VFS File Revision Diff Projection (`InSetuFileDiffProjection`)**: Pinned to `LayoutStore` (`vfs:diff:<normPath>`) via the `/api/fs/git_diff` endpoint, comparing Git HEAD baselines against active working buffers or physical disk modifications.
4. **Arbitrary Two-File & Conflict Diff Projection (`InSetuFileDiffProjection`)**: Expanded `InSetuFileDiffProjection` to support two-file pair comparisons via `viewTwoFileDiff(leftFilepath, rightFilepath)` (`vfs:pairdiff:<left>::<right>`). Registered the `file-conflict-diff` ("Diff Original") action on `.conflict_<timestamp>` files and the `vfs-compare-selected` ("Compare Selected (2)") bulk action on multi-selection trays to compare arbitrary files side-by-side.
