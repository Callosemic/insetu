## Description
* **Core Prompt Engine & Virtual Module Template Projection (`engine_prompts.py`, `prompts.js`, `yomama_patch_protocol.md`)**:
  * Graduated the prompt management subsystem from an optional Tier 3 extension into a Tier 2 Core Substrate engine (`prompts`).
  * Implemented `PromptsVFSDriver` subclassing `DefaultVFSDriver` to mount `ctx://prompts` and dynamically project active module templates (`ctx://prompts/.templates/<module>/`) alongside global user templates stored at `ws://default/prompts/.templates/user/`.
  * Implemented recursive macro resolution for `{{include_prompt: <filename>}}` with parameter injection.
  * Added the `prompt-fork-template` polymorphic entity action allowing operators to fork read-only module templates into sovereign workspace prompts (`ctx://prompts/`).
  * Enforced read-only protection across all VFS mutation endpoints (`_is_readonly_template_path`), rejecting writes, moves, archives, or deletions targeting built-in templates with HTTP 403 Forbidden.
  * Packaged `yomama_patch_protocol.md` as the default prompt template for the Sync Bridge.
* **Akasa Kernel Background Job API Unification (`engine_agent.py`, `engine_bridge.py`, `engine_gather.py`, `engine_topology.py`, `engine_system.py`)**:
  * Purged legacy `submit_immediate_job`, `update_immediate_job_status`, `register_callback`, and direct SQLite queries to `immediate_jobs` in favor of the Akasa `ctx.jobs` SDK.
  * Standardized asynchronous task execution using `@bp.worker` decorators, `ctx.jobs.submit(..., job_category=...)`, `ctx.jobs.submit_one_shot()`, `ctx.jobs.update_progress()`, and `ctx.jobs.find_active_pipeline_job()`.
  * Migrated ephemeral artifact tracking to `ctx.jobs.register_ephemeral()`, `ctx.jobs.get_ephemerals()`, and `ctx.jobs.clear_ephemerals()`.
  * Purged legacy `workflows.json` creation and `load_workflows()` shims.
* **Cartographer Caching & Incremental Payload Hashing (`cartographer.py`, `engine_gather.py`)**:
  * Implemented thread-safe signature caching in Cartographer (`_CARTOGRAPHER_SIG_CACHE`, `_CARTOGRAPHER_CACHE_LOCK`) to prevent redundant `CODE_INDEX.md` writes when physical file sets, mtimes, and managed directory configs remain identical.
  * Optimized Cartographer Git comment fallback to query Git HEAD only when live comments are absent or require placeholders.
  * Filtered hidden managed directories (e.g. `.insetu-data`) from Cartographer indices.
  * Optimized `compile_context_payload` to compute SHA-256 hashes incrementally across block streams, eliminating multi-megabyte string allocations in RAM, and assembled bin parts into memory arrays before single-pass joins.
  * Routed gather debug log writes through `ctx.vfs.save` with `is_absolute_artifact=True, ignore_ledger=True`.
* **Universal Selector-Scoped Store Subscription Migration (`agent.js`, `fs.js`, `offline_ui.js`, `ui_primitives.js`, `ui_system_settings.js`)**:
  * Migrated all remaining coarse `this.subscribe(Store, state => { ... })` listeners across core UI Web Components to 3-argument selector-scoped subscriptions (`this.subscribe(Store, selector, listener)`), satisfying `COARSE_STORE_SUBSCRIPTION_MANDATE`.
* **UI Filename Truncation & Bulk Quickpack Sharing (`insetu_sdk.js`, `utils_core.py`, `gather.js`, `fs.js`)**:
  * Introduced and exported `truncateFilename(filename, maxLen, ellipsis)` across `insetu_sdk.js` and `utils_core.py`, wiring it into diff projections and spatial grid route labels.
  * Added the `gather-pack-share` bulk action to `gather.js` with instant native share fallbacks.
  * Added `workspaces: {}` to `AppStore` initial state.
  * Added `_cache_evict` cache invalidation on binary file uploads in `engine_fs.py`.
