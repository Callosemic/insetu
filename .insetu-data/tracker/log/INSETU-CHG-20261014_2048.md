## Description
* **Workspace Config Store Subscription Optimization (`config.js`)**: Migrated the `AppStore` subscription in `InSetuExtConfig` from a coarse monolithic state listener to a selector-scoped subscription targeting `state.isConfigOpen`. This enforces compliance with the selector-scoped subscription mandate, preventing unnecessary re-evaluations during unrelated workspace, manifest, or telemetry state shifts.
