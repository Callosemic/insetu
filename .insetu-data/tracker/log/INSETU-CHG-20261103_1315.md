## Description
* **Interleaved AST Diff Projections (`format_interleaved_file_diff`, `bridge.turn_diff`)**:
  * Implemented AST-enclosing single-stream interleaved diffs in `insetu/core/languages/__init__.py`: expands modified hunks to their enclosing function or class definitions, retains top-level imports, and collapses untouched sibling functions to signatures with `... # [lines X-Y unchanged]` interface skeletons.
  * Upgraded `bridge.turn_diff` to render interleaved AST diffs for modified files and explicit blocks for newly created (`=== NEW FILE: {fp} ===`) and deleted (`=== DELETED FILE: {fp} ===`) files.
* **Lexer Transport Macro Escaping Isolation (`parser.py`)**:
  * Refined `_preclean_web_chat_artifacts` to preserve `{{ymm:...}}` transport macros through lexical scanning, preventing escaped markers inside code blocks or patch bodies from being mistaken for outer block boundaries.
* **Cartographer Persistent Working Memory & Directory Descriptions (`cartographer.py`, `languages/__init__.py`)**:
  * Introduced `file_descriptions` SQLite working memory with source tracking (`genesis_comment`, `code_index`, `code_index_orphan`) and a 90-day retention TTL (`ORPHANED_DESCRIPTION_TTL_SECONDS`), ensuring descriptions survive file renames, branch shifts, and volume remounts.
  * Implemented `describe_directory()` deriving directory purposes from child `README.md`, `__init__.py`, or `package.json` manifests.
  * Implemented `describe_source_file()` covering Markdown frontmatter/headings, shell/hash comments, TOML metadata, JSON manifests (`package.json`, `package-lock.json`), and software licenses.
  * Dynamically resolved canonical index paths via `resolve_repo_code_index_uri()`, honoring `is_core_chassis` and custom repo `index_path` settings.
  * Added `@cartographer_bp.on('ensure_cartography_fresh')` hook and migrated index file reads to `VFSTransaction`.
* **Topology Sieve Reconciler, Dynamic Gitignore Eviction & Models Landmark (`engine_topology.py`)**:
  * Implemented `clamp_uris_to_topology(workspace_id, candidate_uris, expand_dirs=False, gather_only=False)`: clamps candidate paths against `topology_ledger` and expands folder prefixes into valid tracked files.
  * Added `reconcile_topology_on_config_mutated` (`@topology_bp.on('config_mutated', priority=20)`) and `_reconcile_repo_ledger_with_sieve()`: automatically evicts newly ignored or excluded rows and indexes newly tracked files when `.gitignore`, `.git/info/exclude`, or `config.json` changes.
  * Added the `models` landmark kind (`docs/models/*.md`, `docs/*mental_model*.md`) to `DEFAULT_LANDMARK_KINDS`.
  * Removed the 80-line truncation from `api_topology_overview`.
  * Centralized `sys.*` landmark variable construction into `build_sys_landmarks_context()` and deterministic repository inference into `infer_target_repo()`.
* **Context Assembly Clamping & Stale Affinity Pruning (`context_assemble.py`)**:
  * Clamped edit targets, callee/caller radii, reference files, and Hebbian affinity peers strictly against `topology_ledger` via `clamp_uris_to_topology()`.
  * Implemented `prune_stale_affinity_edges(ctx, grace_period_seconds=14*86400)` to safely garbage-collect dead affinity edges without risking transient branch desynchronization.
* **Non-Interleaving Context Part Packing (`engine_gather.py`)**:
  * Implemented `_split_oversized_block()` and `_pack_blocks_into_bins()`: packs oversized text blocks into consecutive part bins without interleaving other files, ensuring stitched multi-part reading preserves block continuity.
* **Prompt Cascade Reader, Mustache Chaining & Repo-Scoped Prompts (`engine_prompts.py`, `prompts.js`, `utils_core.py`)**:
  * Centralized 3-tier cascade resolution in `read_prompt_with_cascade()` and macro expansion in `resolve_prompt_text()`.
  * Implemented `interpolate_mustache_chain()` and `resolve_context_var_path()` in `utils_core.py` to evaluate fallback chains (`{{ var | sys.* | default }}`) without premature template stripping.
  * Enabled repository-scoped prompt authoring under `vfs://{repo}/.insetu-data/prompts/` with automatic `.gitkeep` discovery and menu creation actions.
* **S4 CodeMirror Local Language Packs & Filename Mode Matching (`engine_editor.py`, `ui_editor.js`)**:
  * Added `GET editor/languages`, updated `POST editor/vendorize` to return full language descriptors, and added `GET editor/vendor/<path:filename>` for local packs in `.insetu/vendor/codemirror/`.
  * Re-architected `resolveEditorMode()` to prioritize exact filename matches (`Dockerfile`, `.bashrc`, `CMakeLists.txt`) before extension matches, with fallback to `plaintext`.
* **Two-Tier DAG-Aware Fault Quarantine (`engine_system.py`, `system.js`, `ui_primitives.js`)**:
  * Implemented Degraded Boot mode: isolates failing Core and Tier 3 extension modules, displays a diagnostic quarantine banner, and preserves pinned layout slots via `<insetu-quarantined-slot-placeholder>`.
* **S8 Human Approval Gate for Workspace Extensions (`engine_system.py`, `utils_core.py`, `ui_primitives.js`, `cli_commands.py`)**:
  * Built cryptographic fingerprint verification for user extensions in `.insetu/extensions/<name>/`, requiring explicit human approval (`system/extensions/workspace/approve`, `mcp_expose=False`) before code execution.
  * Added in-app "Review Files" and "Approve & Restart" workflows to `<insetu-config-banner>`.
* **Universal Repeater Secret Scoping & Mountable Domain Discovery (`utils_core.py`, `sdk/__init__.py`)**:
  * Centralized `get_repeater_secret()` and `set_repeater_secret()` with mandatory `scope: 'daemon' | 'workspace'`.
  * Added `get_mountable_data_domains()` dynamically enumerating all registered `tier: "data"` VFS volumes.
* **Zero-CSS Presentation Modernization & Universal Sutram Membrane (`api.js`, `config.js`, `fs.js`, `offline_ui.js`, `ui_system_settings.js`, `ui_file_tree.js`, `ui_filter_pills.js`, `insetu_sdk.js`)**:

  * Re-exported all symbols from `'sutram'` in `insetu_sdk.js` and purged redundant fallback classes.
  * Eradicated custom CSS blocks across all core modules, converting layouts to pure Sutram Lego primitives.
