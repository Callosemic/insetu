## Description
* **Fast-Path Web Share Pre-Warming & Immutable Text Extraction (`fs.js`, `api.js`, `sdk.js`)**: Implemented pre-warming for Web Share card actions using `shareTextCache` triggered via `yenvui-overlay-opened` events. Added `fetchImmutableText()` to `window.inSetu.api` and `InSetuElement` SDK accessors to bypass OfflineHttpProvider proxy streams while warming SutramDB.
* **Gather Quickpack Caching & Topology Selection (`engine_gather.py`, `gather.js`, `utils_core.py`)**: Added `gather_only` parameter to `hook_expand_selection()` and `pack_selection` worker, querying topology ledgers directly instead of walking physical disk. Added stateful quickpack caching (`_lastPackItemsHash`, `_lastPackSelection`) incorporating live manifest timestamps into hash keys.
* **VFS Manifest Local State Mutated Synchronization (`fs.js`, `system.js`)**: Updated `updateManifestState()` in `fs.js` to handle `delete` and `save` operations natively from `insetu:vfs-mutated` events. Removed redundant `refreshManifest()` polling calls in favor of SSE heartbeat telemetry updates.
* **Mounted Extensions Normalization & System Config Alignment (`engine_system.py`, `system.js`)**: Added `mounted_extensions` to `get_system_config()` metadata output and updated `executeBootSequence()` and `performSoftRefresh()` to evaluate `mounted_extensions` over unmounted `config.extensions`.
* **SSE Telemetry Query Separator & Cache Eviction Fixes (`system.js`, `bridge.js`, `bridge_vfs.py`)**: Fixed query parameter separator logic (`?` vs `&`) in `checkManifestVersion()`, added cache queue eviction on context deletion, and enhanced Yomama Bridge error display with full backend tracebacks.
