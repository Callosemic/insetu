## Description
* **Thread Stack Sizing & Virtual Memory Bounding (`insetu/app.py`, `insetu/cli.py`)**:
  * Bound thread stack allocation to 1MB (`threading.stack_size(1024 * 1024)`) instead of Linux glibc's default 8MB stack size across both application server (`app.py`) and command-line interface (`cli.py`) entry points.
  * Injected `os.environ.setdefault("MALLOC_ARENA_MAX", "2")` into `cli.py` to ensure CLI-invoked background workers and services share identical arena fragmentation protections with daemon processes.
  * Prevents multi-threaded compilation and worker tasks from triggering runaway virtual memory (`VmData`) heap expansion.
* **Dynamic Working Directory Resolution Alignment (`insetu/app.py`)**:
  * Replaced the static by-value import `from akasa.utils import _cwd as __cwd` with `import akasa.utils as _akasa_utils` and dynamic evaluation via `Path(_akasa_utils._cwd)`.
  * Eliminates import-time working directory freezing and achieves 100% compliance with the `BANNED_CWD_VALUE_IMPORT` AST fitness linter.
