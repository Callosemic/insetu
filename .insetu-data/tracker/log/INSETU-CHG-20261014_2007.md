## Description
* **VFS Driver Registration & Dynamic Volume Mounting (`engine_flow.py`)**: Registered `ctx` volume driver (`DefaultVFSDriver`) and bound `mount_flow_volumes` to ensure `ctx://workflows` is properly mounted during compilation tasks, batch saves, and batch deletions.
* **Inversion of Control URI Scheme Coercion (`engine_flow.py`)**: Implemented `@hooks.on('coerce_naked_uri')` handler `coerce_flow_uris` to intercept legacy or naked workflow path strings (e.g., `workflows/`, `.insetu/ext/flow/data/workflows/`, `workflow_*_context.txt`) and normalize them to canonical `ctx://workflows/{filename}` URIs (ADR 0055).
* **DAG Compilation Step Alignment (`engine_flow.py`)**: Tagged workflow background compilation artifact with `"step_id": "flow_workflows"` to match the registered compilation step ID and facilitate real-time telemetry updates.
* **Asynchronous Flow Batch Job Submission & Polling (`engine_flow.py`, `ext_flow.js`)**: Updated `api_flow_batches_save` and `api_flow_batches_delete` to submit background compilation tasks with `job_category="ui_blocking"` and return `job_id`. Connected `InSetuFlowEditProjection` to `this.api.pollJob(responseData.job_id)` to poll progress asynchronously and refresh the manifest upon completion.
* **Store Hygiene & Selector-Scoped Subscriptions (`ext_flow.js`)**: Added `availableOptions` directly to `FlowStore`, removed the unneeded `coalescedAsync` wrapper from `fetchBatches`, and migrated `InSetuExtFlow`, `InSetuFlowViewProjection`, and `InSetuFlowEditProjection` to selector-scoped store subscriptions (`this.subscribe(Store, state => slice, (slice) => ...)`) to eliminate render thrashing.
* **URI Canonicalization & Path Normalization (`ext_flow.js`)**: Exported `canonicalizeFlowUri` to standardize path normalization across workflow batch configurations, and normalized `filepath` and `archive_path` in `saveBatchResponse` via `this.vfs.normalizeVfsURI`.
* **Dead Modal Code Annihilation (`ext_flow.js`)**: Purged obsolete inline `<sutram-modal>` markup and state handling from `InSetuExtFlow.render()`, completing the spatial projection migration (ADR 0059).
* **Automation Hooks Telemetry Guard (`engine_hooks.py`)**: Refined `process_vfs_triggers` to short-circuit on empty events prior to executing telemetry formatting prints.
