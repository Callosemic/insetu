## Description
* **DevOps Extension Suite Zero-CSS Modernization (`ext_dev.js`, `ext_git.js`, `ext_preview.js`, `ext_term.js`, `ext_update.js`)**:
  * Eradicated custom CSS blocks (`css` template tags) across all five DevOps extensions, enforcing complete compliance with `CUSTOM_COMPONENT_CSS_BAN` and standardizing on `static styles = [sharedStyles];`.
  * `ext_dev.js`: Migrated `InSetuExtDevDash`, `InSetuExtDevLogs`, `InSetuExtDevSql`, and `InSetuExtDevMemory` to `<sutram-view>`, `<sutram-stack>`, `<sutram-surface>`, `<sutram-tag>`, and `<sutram-label>`. Removed redundant manual `this.requestUpdate()` calls.
  * `ext_git.js`: Modernized `InSetuExtGitDiffs`, `InSetuGitPushProjection`, and `InSetuExtGitCtrl` into Sutram Lego primitives. Replaced card opacity overrides with the semantic `?stale=${isLocked}` property and converted push projection actions to `slot="footer"` button tracks.
  * `ext_preview.js`: Eliminated >150 lines of custom CSS. Structured toolbar with `<sutram-surface>` and `<sutram-action-bar>`, converted status badges to `<sutram-tag>`, configuration grid to `<sutram-stack direction="grid">`, exposure bars to `<sutram-surface variant="tinted" intent="warning">`, and logs drawer to `<sutram-surface slot="footer">`.
  * `ext_term.js`: Removed redundant `requestUpdate()` calls in keyboard and context handlers. Modernized missing dependency alerts to `<sutram-view>` and `<sutram-surface>`.
  * `ext_update.js`: Replaced custom CSS with `<sutram-view>` and `<sutram-surface variant="panel">` layouts across version management cards, prerelease toggles, and multi-step release workflows.
* **Batched Git HEAD Blob Pre-Fetching & AST-Enclosing Interleaved Diffs (`engine_git.py`)**:
  * Implemented `_batch_read_git_head_blobs(git_root, lookup_paths)` pre-fetching all modified files' `HEAD:<path>` contents in a single `git cat-file --batch` subprocess call, replacing sequential `git show` subprocess executions.
  * Integrated single-stream AST-enclosing interleaved diffs via `format_interleaved_file_diff(canon_vfs_uri, base_content, content)`, presenting modified hunks inside their enclosing function or class definitions with 1-line signature skeletons for untouched sibling methods.
  * Standardized diff header identifiers: `>>>MODIFIED FILE (INTERLEAVED AST DIFF) :: {canon_vfs_uri}`, `>>>DELETED FILE :: {canon_vfs_uri}`, and `>>>NEW FILE :: {canon_vfs_uri} | ADDED FILE`.
* **Topology Sieve Diff Parity & Flush Synchronization (`engine_git.py`)**:
  * Implemented `diffable_changes(changed_files, config, live_cfg)`: evaluates porcelain changes through `is_file_tracked_by_sieve(entry[0], config, live_cfg, repo_dir=...)`. Guarantees that files ignored by `.gitignore` or excluded by sieve rules stay out of `ctx://diffs/` context payloads and route exclusively to the Sweepable State tray.
  * In `_background_sweep_status`, added `resolve_topology_buffer(ctx.workspace_id)` prior to querying `topology_ledger` to flush in-flight filesystem mutation events before computing sweepable files.
  * Handled git renames (`->`) by tracking `rename_head_map`, resolving original paths for accurate `HEAD` blob lookup.
* **Dynamic Landmark-Driven Closeout Protocols (`close_session_protocol.md`)**:
  * Standardized `close_session_protocol.md` with dynamic `sys.*` repository landmarks (`sys.repo_title`, `sys.contract_stack`, `sys.adr_dir`, `sys.standards_doc`, `sys.guardrail_rules`, `sys.hardening_target`).
  * Integrated optional prompt template inclusion for tracker tickets (`{{include_prompt?: ctx://prompts/.templates/tracker/close_session_tickets.md}}`) and Yomama patch protocols.
* **Terminal Engine Import Hygiene (`engine_term.py`)**:
  * Purged dead and orphaned imports (`subprocess`, `TypedDict`, `ExtensionContext`).
