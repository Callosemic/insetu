- **Strict Contract & Mental Model Adherence:** Adhere strictly to `docs/01_engineering_standards.md`, `docs/02_extension_api_contract.md`, `docs/07_sdk_v2_contracts.md`, `docs/08_sutram_contracts.md`, human-authored subsystem mental models (`docs/models/*.md`), and active ADRs (`docs/adrs/`).
- **Blueprint & Tracker Driven:** Use architectural plans (`docs/plans/`) and `.insetu-data/tracker/` tickets as the blueprint for coordinated development.
- **Single Source of Truth (SSOT) & DRY Centralization:** Ensure shared logic, schemas, and configurations exist in one canonical place, the module that owns them (find it in `CODE_INDEX.md`), without duplicate helpers. Extensions reach shared helpers only through the SDK membrane (`insetu.core.sdk`, `insetu_sdk.js`).
- **Membrane & VFS Confinement:** Verify strict Single-File SDK membrane isolation (`insetu/core/sdk/__init__.py` and `insetu_sdk.js`), canonical URI usage (`vfs://`, `ctx://`, `ws://`), and VFS write-path boundaries (`ctx.vfs`).
- **Unidirectional Data Flow (UDF) & Zero-CSS Purity:** Ensure UI components subscribe to Zustand stores via selector slices (`this.subscribe` / `this.bindStore`) and compose `<sutram-*>` primitives with `static styles = [sharedStyles];` and zero custom CSS or inline styles.
- **Non-Blocking I/O & Process Confinement:** Run heavy work off-thread in typed `@*.worker` tasks (`job_category` required) and build subprocess environments exclusively via `child_env()`.
