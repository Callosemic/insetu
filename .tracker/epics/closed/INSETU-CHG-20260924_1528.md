## Description
* **Flow Batch Visibility Logic Fix (`ext_flow.js`)**: Corrected the evaluation array logic for workflow batch visibility prerequisites to match the intended conditional behavior. 
  * Fixed `show_if_exists` to evaluate as an `OR` condition using `.some()` instead of `.every()`, ensuring the batch is visible if *at least one* of the required context files exists.
  * Updated `show_if_missing` to explicitly verify that all listed files are absent using `.every(f => !checkLiteralExists(f))`.
  * Updated UI labels in the batch edit modal to clarify the "at least one" and "all of these" conditional requirements for the end user.
