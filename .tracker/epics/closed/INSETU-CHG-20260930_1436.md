## Description
* **`InSetuURI.resolve_if_exists` Addition (`utils_core.py`)**: Added `resolve_if_exists(workspace_id)` method to `InSetuURI`, returning the resolved physical path if it exists on disk, or `None` if absent.
* **`ExtensionContext.resolve_path` Extension (`sdk/__init__.py`)**: Updated `_sdk_resolve_path` on `ExtensionContext` to accept `must_exist=True` (defaulting to `False`), delegating directly to `uri.resolve_if_exists()` when set.
* **Substrate Path Resolution Cleanup (`engine_fs.py`, `engine_gather.py`, `utils_core.py`)**: Updated `download_file` in `engine_fs.py`, `compile_context_payload` in `engine_gather.py`, and `vacuum_manifest_artifacts` in `utils_core.py` to consume `resolve_if_exists` and `resolve_path(..., must_exist=True)`.

## Notes / Execution Log
* Validated full codebase against Engineering Standards and eliminated redundant `os.path.exists()` checks following path resolution.
