## Description
* **Two-Pass Boot Lifecycle Alignment (ADR 0045 Compliance)**: Migrated `cronic`, `dev`, `tailscale`, and `tracker` extensions from `@hooks.on('workspace_boot')` (Phase 1 read-only spatial discovery) to `@hooks.on('topology_boot_complete')` (Phase 2 deferred mutations and background task scheduling) to eliminate boot-time Watchdog I/O storms and event loop deadlocks.
* **Cronic Extension VFS Hardening (`engine_cronic.py`)**: Replaced raw file operations (`os.makedirs`, raw `open()`, `os.remove()`) with `Path.mkdir()`, `ctx.vfs.read()`, `ctx.vfs.save(..., data={"is_absolute_artifact": True, "ignore_ledger": True})`, `ctx.vfs.delete()`, and `ctx.sync_vfs_barrier()` for atomic commit logging and VFS event ledger parity.
* **Artifact Resolution Boundary Guardrails (`engine_flow.py`, `engine_git.py`, `engine_prompts.py`, `engine_publish.py`)**: Hardened `vfs_resolve_file` hooks with strict logical URI prefix matching (`ctx://` / `vfs://`) and path checks to prevent path hijacking and arbitrary file resolution.
* **Thread-Safe Git Diff Caching (`engine_git.py`)**: Added `_DIFF_FILE_CACHE` and `_DIFF_FILE_CACHE_LOCK` in `engine_git.py` to cache unchanged diff text blocks based on `mtime`, `size`, and status, skipping redundant `git diff` subprocess executions for clean files.
* **Terminal Stream & Gesture Fixes (`engine_term.py`, `ext_term.js`)**: Fixed WebSocket PTY stream double-encoding in `engine_term.py` by outputting raw binary chunks. Fixed swipe gesture interference during text selection in `ext_term.js`, removed obsolete touch listeners, and updated `tc-copy` context action to fallback to copying the last 150 buffer lines when selection is empty.
* **Offline Cache Warming Consolidation (`ext_notes.js`, `ext_prompts.js`)**: Replaced individual `api.request` loops with `enqueueWarming(urlsToWarm)` batch calls on `AppStore`.
* **Tracker Extension Tier & Worker Defaults (`engine_tracker.py`)**: Corrected tier evaluation and YAML rewrite conditions in `enforce_declarative_tickets`, split Phase 1 and Phase 2 boot hooks, and added defensive default kwargs to background workers.
