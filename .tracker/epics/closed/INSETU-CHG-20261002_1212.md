## Description
* **Spatial Multi-Column Viewport Projections & Buffer State Management (`fs.js`, `bridge.js`, `ui_primitives.js`, `store.js`)**: Extracted file modal editing and Yomama patch editing out of monolithic overlays into multi-projection text buffers (`activeBuffers`, `saveBufferFile`) rendered via `InSetuEditorProjection` (`<insetu-editor-projection>`) and pinned to multi-column spatial viewports (`left`, `center`, `right`). Deprecated `InSetuBlobViewer` in favor of virtual file buffer projections (`virtual://${filename}`). Added drag-to-grid gesture overlay in `InSetuFileModal` for multi-column layout pinning.
* **Lucide Iconography Migration & UI Refinements (`bridge.js`, `fs.js`, `gather.js`, `offline_ui.js`, `ui_file_tree.js`, `ui_system_settings.js`)**: Replaced legacy emoji icons across bridge cards, file tree cards, gather cards, offline ledger cards, and settings dropdowns with SVG `<i data-lucide="...">` icons. Added container query support (`@container (max-width: 480px)`) for card container padding responsiveness.
* **Domain Colors Configuration & Gather Domain Mapping (`engine_gather.py`, `gather.js`)**: Added `domain_colors` settings schema to `GATHER_SETTINGS_SCHEMA` mapping intent colors to keyword filters. Dynamically styled Gather card icons based on intent color settings. Removed redundant emoji prefixes from quickpack titles and removed unused `InSetuExtGatherActions` element.
* **System Settings, Viewport Grid & JSON Schema Improvements (`ui_system_settings.js`, `engine_system.py`, `api.js`)**: Added Viewport Grid capacity controls (1-Col, 2-Col, 3-Col) in the system menu. Updated `sutram-settings-save` event listener to automatically parse JSON strings for `object`/`json` settings schema types. Moved `socket` import to module scope in `engine_system.py`. Added `disconnect()` cleanup method to `SSEPipeline` in `api.js`.
* **Artifact Formatting (`sdk.js`)**: Updated `formatArtifactSize` to display size in MB/KB alongside chunk count for multi-chunk payloads.
