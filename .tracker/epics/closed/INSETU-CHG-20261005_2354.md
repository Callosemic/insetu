## Description
* **SDK System Import Path Standardization (`ext_*.js`)**: Standardized import specifiers across all 18 frontend extension modules (`citations`, `cronic`, `dev`, `favorites`, `flow`, `format`, `freshdesk`, `git`, `hooks`, `ingest`, `notes`, `prompts`, `publish`, `research`, `skills`, `term`, `tracker`, `update`) to import SDK base classes and helpers from `/static/extensions/system/insetu_sdk.js` in compliance with ADR 0056.
* **Sutram Modal Body Slot Layout Flattening (`ext_*.js`)**: Refactored projected body slots across all extension modal dialogs to use `style="display: contents;"`, eliminating inset double-scrollbar "box-in-box" visual artifacts and delegating scrolling to `<sutram-modal>`.
* **Sutram Presentation Primitives & Lucide Iconography Alignment (`ext_*.js`)**: Replaced raw HTML `<button class="btn-sm">` tags and emoji icon attributes across extension cards, toolbars, and action rows with Tier 0 Sutram presentation components (`<sutram-btn>`, `<sutram-async-btn>`, `<sutram-scroll-view>`) and declarative Lucide iconography (`icon="..."`) paired with intent variables (`intent="..."`).
* **Git Staging & Diff Check Hardening (`engine_git.py`)**: Updated `_background_sweep_push` and `_background_git_push` to stage files via `git add -A -- <files>` and evaluate staged changes via `git diff --cached --name-only` before committing.
* **Entity Action Target Refinement (`ext_prompts.js`)**: Updated entity action declarations in `ext_prompts.js` to target `'prompt'` rather than `'file:prompt'`.
