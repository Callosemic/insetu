## Description
* **API Schema & Type Contract Alignment**: Added explicit `TypedDict` request and response payload schemas and docstrings across `@*.route()` endpoints in 18 Python extension engines (`citations`, `cronic`, `dev`, `favorites`, `flow`, `format`, `freshdesk`, `git`, `hooks`, `ingest`, `notes`, `publish`, `research`, `skills`, `tailscale`, `term`, `tracker`, `update`).
* **System Error Telemetry & Dev Dashboard**: Integrated `system_errors` table schema into `engine_dev.py` via `@hooks.on('system_error')`, added `api_dev_exec` (`POST /exec`) for sandbox shell command execution, updated thrashing metric queries to target `vfs_event_log` in `workers.db`, and added error ledger UI cards to `ext_dev.js`.
* **Flow & Git Extension State Synchronization**: Refactored `_background_compile_workflows` and `_background_compile_diffs` to use `InSetuURI.from_any()` and `BucketAddress`, returning structured state deltas. Updated frontend components (`ext_flow.js`, `ext_git.js`) to evaluate dirty buckets reactively and trigger background re-syncs.
* **Kanban Tracker CQRS Optimizations & Enforcer Hardening**: Added hardware indices on `tracker_tickets`, updated `api_tracker_files` to compile JSON directly via SQLite JSON1 C-extensions (`json_group_array`, `json_object`), pre-fetched cache ledgers in `enforce_declarative_tickets` to eliminate O(N) queries, and added background harmonization and variable-enabled template spawning.
* **Update Extension Execution & VFS Logical URI Migration**: Replaced raw `subprocess.run` calls in `engine_update.py` with `execute_binary()`, migrated `pyproject.toml` file operations to logical VFS URIs (`vfs://{repo}/pyproject.toml`), and added dry-run version bump preview capabilities to `ext_update.js`.
