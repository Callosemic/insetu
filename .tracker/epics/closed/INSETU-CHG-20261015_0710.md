## Description
- Refactored `scripts/vendor_lit.sh` to package Lit core, decorators, and standard directives (`repeat`, `style-map`, `class-map`, `unsafe-html`, `ref`, `live`) into a unified `lit-core.min.js` ESM distribution.
- Introduced `litSingletonPlugin` within esbuild compilation for `@lit-labs/virtualizer` to mark core Lit packages external, eliminating duplicate reactive substrate instances across vendorized bundles.
- Hardened static analysis checks in `tests/fitness/rules_javascript.py`:
  - Enforced `VENDOR_MANIFEST_CDN_BAN` against external HTTP/HTTPS CDN URLs in `vendor.json` manifests.
  - Added `LIT_INNER_HTML_BAN` to intercept direct `.innerHTML` assignments within LitElement component definitions.
  - Added `SUTRAM_CARD_INTENT_TOKEN_MANDATE` to enforce declarative `intent` tokens on `<sutram-card>` over raw CSS variable bindings (`intentColor="var(--intent-*)"`).
