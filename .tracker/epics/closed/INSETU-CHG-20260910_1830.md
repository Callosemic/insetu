## Description
* **Unified Watchdog Debouncing & Pre-I/O Intent Tracking (`utils_core.py`):** Replaced per-file `threading.Timer` objects with a single background debouncing loop (`_watchdog_debouncer_loop`) and pre-write intent tracking (`_track_intent_vfs_writes` on `@hooks.on('pre_file_save')`) to permanently seal Watchdog double-fires and race conditions.
* **Yomama Genesis Patch Resolution & Path Candidate Scoring (`bridge_vfs.py`, `utils_core.py`):** Added genesis patch candidate search logic using `get_omniscient_workspace_files` and directory suffix/basename matching. Refactored candidate scoring via `find_path_candidates` in `utils_core.py` and added a `5.0`s timeout guard to Node.js AST validation subprocess calls.
* **Thread-Local Short-TTL Manifest Caching (`engine_gather.py`, `engine_topology.py`):** Implemented `_manifest_thread_cache` and `_vfs_manifest_thread_cache` (`threading.local`) with 2.0s TTL in `request_manifest` and `request_vfs_manifest`, with automatic cache invalidation on `save_manifest`, `force_topology_scan`, and `resolve_topology_buffer`.
* **Barrier Timeout Circuit Breakers (`engine_bridge.py`, `engine_gather.py`):** Added `timeout_loops < 50` (5s max) circuit breaker to the VFS write queue settlement loop in `_background_bridge_sync`, and `timeout_loops < 20` (10s max) circuit breaker to the Topology Barrier wait loop in `_background_compile` to prevent event loop starvation during I/O bursts or stalled upstream jobs.
* **Cross-Tenant Path Resolution & Artifact Routing (`engine_topology.py`, `engine_gather.py`, `routes_fs.py`):** Registered `@hooks.on('resolve_owning_workspaces')` in `engine_topology.py` to map physical file paths to owning tenant workspace IDs. Updated `resolve_gather_artifacts` and `resolve_vfs_file` to dynamically resolve output directories from `ctx://` URIs and manifest metadata.
