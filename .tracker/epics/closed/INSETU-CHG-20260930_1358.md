## Description
* **Defensive Path Resolution Null Guarding (`engine_format.py`, `engine_notes.py`, `engine_publish.py`, `engine_tracker.py`)**: Injected explicit non-None checks (`if abs_path:`, `if abs_path and os.path.exists(abs_path):`) around `ctx.resolve_path()` return values across code formatting, notes library, document publishing, and issue tracking extension engines to prevent `TypeError` and `AttributeError` exceptions when path resolution yields `None`.
