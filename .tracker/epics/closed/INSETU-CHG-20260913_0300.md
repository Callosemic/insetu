## Description
* **Frontend Extension Import Path Standardization:** Standardized all 18 JavaScript frontend extensions (`ext_citations.js`, `ext_cronic.js`, `ext_dev.js`, `ext_favorites.js`, `ext_flow.js`, `ext_format.js`, `ext_freshdesk.js`, `ext_git.js`, `ext_hooks.js`, `ext_ingest.js`, `ext_notes.js`, `ext_prompts.js`, `ext_publish.js`, `ext_research.js`, `ext_skills.js`, `ext_term.js`, `ext_tracker.js`, `ext_update.js`) to consume absolute web-root specifiers (`/static/extensions/system/sdk.js` and `/static/vendor/sutram/js/shared_styles.js`), eliminating brittle relative path traversals (`../` and `../../`).
* **Issue Tracker Event Ledger Parity (`engine_tracker.py`):** Added `hooks.emit('vfs_mutated', ...)` events and `vfs_event_log` entries in `create_ticket`, `transition_ticket`, `enforce_declarative_tickets`, and `archive_stale_tickets` for `save` and `delete` operations, maintaining strict VFS Event Ledger parity (ADR 0018).
* **Workspace API Route Alignment (`ext_citations.js`, `ext_update.js`):** Updated system status and config endpoints from `window.inSetu.api.system.get` to `window.inSetu.api.workspace.get('system/...')`, ensuring multi-tenant request headers and workspace tokens are properly injected.
* **Reactive Module Compilation Pipeline (`ext_flow.js`, `ext_git.js`):** Added `isPipelineActive` property tracking and subscribed to `insetu:compile-progress` and `insetu:compile-step-complete` events to ensure workflow and version control UI spinners/module states remain synchronized during multi-stage background compilations.
* **Extension Settings Registration (`ext_skills.js`, `ext_tracker.js`):** Added `settingsCategory` declarations (`"Practice"` and `"Tracker"`) to extension registry definitions for uniform settings menu rendering.
