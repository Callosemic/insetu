## Description
* **Entity Action Metadata & VFS Parity Alignment (`ext_*.js`)**: Added explicit `group` classifications (`edit`, `file`, `share`, `tools`) and `vfsBound` flags across entity action declarations in `citations`, `flow`, `format`, `git`, `publish`, `skills`, and `tracker` extensions, supporting ADR 0055 VFS action middleware auto-saves and UI action tray grouping.
* **Hash Routing Alignment (`ext_favorites.js`, `ext_tracker.js`)**: Replaced legacy `AppStore.setActiveRoute` calls in `ext_favorites.js` and `ext_tracker.js` custom editor callbacks with direct `window.location.hash` routing targeting spatial viewport columns (`left`, `center`), adhering to ADR 0028 and ADR 0055.
* **Naked URI Coercion Event Hooks (`engine_git.py`, `engine_prompts.py`)**: Implemented `@hooks.on('coerce_naked_uri')` event handlers in `engine_git.py` (`coerce_git_uris`) and `engine_prompts.py` (`coerce_prompts_uris`) to coerce naked URI strings (`_diffs.txt`, `prompts/`) into canonical `ctx://` schemes (`ctx://diffs/`, `ctx://prompts/`), satisfying ADR 0055.
* **Prompts Extension Function Hoisting Cleanup (`ext_prompts.js`)**: Moved `syncPromptsState` definition to top of `ext_prompts.js` to eliminate function hoisting ambiguity and purged duplicate trailing definition block.
