## Description
* **Akasa Kernel Framework Migration**: Completed the sweep across all 16 extension modules (`citations`, `cronic`, `dev`, `favorites`, `flow`, `git`, `hooks`, `notes`, `prompts`, `publish`, `research`, `skills`, `tailscale`, `term`, `tracker`, `update`), replacing legacy `insetu.kernel` imports with `akasa.hooks`, `akasa.utils`, `akasa.workers`, and `akasa.db`.
* **InSetuURI Domain Helper Integration**: Replaced legacy `split('/')[-1]` string operations across `citations`, `favorites`, `flow`, `git`, `prompts`, and `publish` with canonical `InSetuURI(path).basename` evaluations.
* **Subprocess & Execution Context Alignment**: Refactored raw `subprocess.run`/`check_output`/`Popen` calls in `cronic`, `git`, `hooks`, and `publish` to route through `ctx.exec.run` and `ctx.exec.popen`.
* **VFS & Event Bus Hygiene**: Standardized `tracker` event emissions from `hooks.emit(...)` to `ctx.emit('vfs_mutated', ...)`, and replaced direct file reads with `ctx.vfs.read(..., is_absolute_artifact=True)`.
