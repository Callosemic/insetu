## Description
* **User-Space Extension Discovery (`insetu/app.py`)**: Added dynamic scanning and `sys.path` injection for local `<workspace>/.insetu/extensions/` directories during `load_workspace_extensions()`, enabling workspace-isolated extension development.
* **Bootloader & CLI Module Scope Cleanups (`insetu/app.py`, `insetu/cli.py`)**: Standardized aliased imports (`_load_config`, `_get_workspace_physics`, `_run_app`, `_Response`, `_is_core_module`) to prevent namespace collisions and satisfy Python AST linter rules.
* **Lucide Icon Vendorization (`scripts/vendor_lucide.sh`, `insetu/static/icons.js`, `insetu/templates/index.html`)**: Created `vendor_lucide.sh` to compile Lucide SVG symbol paths into a `window.INSETU_ICONS` JS dictionary, loading it in `index.html` for offline `<yv-icon>` rendering.
* **Vendor Script Upgrades (`scripts/vendor_codemirror.sh`, `scripts/vendor_lit.sh`)**: Added `@codemirror/merge` to CodeMirror core bundles and `@lit-labs/virtualizer` (`lit-virtualizer.min.js`) to Lit vendor bundles.
* **Extension Template Alignment (`insetu/defaults/ext_template_js.txt`)**: Replaced legacy `<insetu-card>` tags in default extension Lit templates with standard `<sutram-card>` primitives.
* **DOM X-Ray Diagnostic Tool (`scripts/x-ray-dom-nodes-and-events.js`)**: Created a standalone Chrome DevTools diagnostic script for auditing DOM node counts and Shadow DOM event listener allocations.
* **AI Workbench Rebranding (`README.md`, `pyproject.toml`)**: Updated repository descriptions and documentation titles from "AI Developer OS" to "AI Workbench".
