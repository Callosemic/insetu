## Description
* **Non-Destructive Loading States (`ext_gather.js`, `fs.js`)**: Updated `InSetuVFSExplorer` and `InSetuExtGather` to preserve DOM structure during background context compilations and VFS manifest refreshes. Replaced view unmounting/hiding with opacity fading, pointer-event isolation, and `<sutram-spinner>` progress bars.
* **Web Share API Hardening (`fs.js`)**: Added defensive `navigator.canShare` checks and user-activation exception handling (`NotAllowedError`), providing clear UI status feedback when browser share gestures require user re-engagement.
* **Polymorphic Action & Entity Type Parity (`bridge.js`, `fs.js`, `gather.js`)**: Cleaned up deprecated `has-actions` attributes from `<insetu-card>` instances. Standardized `targetEntity` definitions for context files (`context` vs `file`). Converted clipboard/copy/share action handlers from `asyncAction` to `onClick` to preserve user gesture execution contexts.
* **Sync Status Integration & ADR 0041 Compliance (`gather.js`)**: Subscribed `InSetuExtGather` to the `sutram-sync-status` event bus, rendering a reactive warning banner when context compilations are pending. Removed deprecated `uiHooks: {}` configuration. Removed redundant full context compilation triggers from `onWorkspaceLoad`.
