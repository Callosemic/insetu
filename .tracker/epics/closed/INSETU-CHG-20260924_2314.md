## Description
* **Extension OpenAPI 3.0 Request Schema & Docstring Declarations**: Added explicit `TypedDict` request schemas (`DeleteCitationPayload`, `DownloadLogsPayload`, `FavoriteDeletePayload`, `FreshdeskTicketPayload`, `GitSweepStatusPayload`, `ExportContextPayload`, `TailscaleBindPayload`, `TrackerRestorePayload`) and comprehensive docstrings across public `@*.route()` endpoints in 18 Python extension engines (`citations`, `cronic`, `dev`, `favorites`, `flow`, `format`, `freshdesk`, `git`, `hooks`, `ingest`, `prompts`, `publish`, `research`, `tailscale`, `term`, `tracker`, `update`).
* **Prompt Library Entity Actions & Logical URI Alignment (`engine_prompts.py`, `ext_prompts.js`)**: Registered `prompt-edit`, `prompt-copy`, and `prompt-delete` entity actions in `ext_prompts.js` for `file:prompt` cards, and normalized prompt template resolution and whitelist paths to canonical `ctx://prompts/` logical URIs.
* **Terminal Process Execution Encapsulation (`engine_term.py`)**: Replaced direct `subprocess.Popen` invocations with `ctx.exec.popen` to ensure execution environment consistency across desktop and systemd user daemon environments.
* **Tracker VFS Scheme Validation & CQRS Cleanup (`engine_tracker.py`)**: Added explicit `vfs` scheme filtering to `handle_tracker_vfs_mutations` to prevent non-VFS URIs from triggering ticket cache re-parsing.
* **Substrate Import Cleanup & Redundant Import Hoisting**: Cleaned up inline imports and hoisted top-level module imports across `engine_dev.py`, `engine_flow.py`, `engine_prompts.py`, `engine_research.py`, `engine_tracker.py`, and `engine_update.py`.
