## Description
* **One-Shot Job Ledger Scheduling**: Introduced `submit_one_shot_job()` in `insetu/kernel/workers.py` and `submit_one_shot()` in `JobManager` (`insetu/kernel/extension.py`) to support explicit one-time delayed task scheduling with automatic ledger eviction upon execution completion.
* **Type Contract Alignment**: Updated `JobSchedulePayload` in `insetu/kernel/types.py` to formally document `interval_ms` (recurring) vs `delay_ms` (one-shot) execution lifecycles.
* **VFS Folder Expansion & Selection Filtering**: Refactored `ExtensionContext.expand_selection()` in `insetu/kernel/extension.py` to filter folder traversals against `request_vfs_manifest` tracked files, preventing untracked filesystem artifacts from polluting selection payloads.
* **Relative VFS Walk Resolution**: Refactored `VFSTransaction.walk()` in `insetu/kernel/vfs.py` to compute relative paths against the target directory rather than `ws_root`, guaranteeing deterministic path resolution.
* **Hash Routing Sub-Navigation Fallback**: Enhanced `app.js` hash routing (`handleHashChange` and `shell-tab-changed`) to dynamically query `ExtensionRegistry` layout slots for default sub-navigation targets when sub-tab route state is unassigned.
* **Service Worker Caching**: Upgraded `sw.js` GET handler to a true Stale-While-Revalidate strategy.
* **Recovery UI Refactoring**: Replaced HTML form POST submit buttons with asynchronous `fetch()` handlers in `app.py` and `index.html`.
* **Fitness Linter Guardrails**: Added `DIRECT_JOB_TABLE_MUTATION_BAN` in `rules_python.py`, alongside `BANNED_HAS_ACTIONS_ATTRIBUTE` and `WEB_SHARE_GUARD_MANDATE` in `rules_javascript.py`.
