## Description
* **Multi-Tenant Spatial Event Routing (`hooks.py`):** Enhanced `HookRegistry.emit()` and `HookRegistry.emit_background()` for `vfs_mutated` events to query `@hooks.on('resolve_owning_workspaces')` for target file paths, resolving all tenant workspace IDs for cross-tenant event isolation before dispatching callbacks.
* **Worker ThreadPool Expansion & Step Chaining (`workers.py`):** Increased `ThreadPoolExecutor` worker capacity from 3 to 20 threads in `start_workers()`. Implemented worker step chaining (ADR 0037) in `_execute_immediate_job` via `_chain` dict parameter parsing (`steps`, `on_complete_hook`), and defensively handled `args_json` when passed directly as a Python `dict`.
* **Binary VFS Payload Safety & Scheme-Wrapped Sandbox Pathing (`vfs.py`, `utils.py`):** Added `is_dir()` check and `UnicodeDecodeError` fallback returning `"[Binary Data]"` in `VFSTransaction.read()`. Updated `resolve_sandbox_path()` in `utils.py` to strip logical scheme wrappers (`vfs://`) before path normalization, preventing literal directory creation errors on disk.
* **Path Disambiguation SDK Method & Thread-Local Caching (`extension.py`):** Added `ctx.find_path_candidates()` method to `ExtensionContext` for opt-in path candidate resolution. Implemented thread-local manifest caching in `ExtensionContext.manifest` with explicit cache invalidation in `save_manifest()`.
* **Network-Adaptive Cache Warmer & Boot Settlement Guard (`app.js`, `sync.py`):** Updated client `checkManifestVersion()` in `app.js` with dynamic chunk throttling based on `navigator.connection` effective types and downlink speed. Added `backend_boot_ts` to `sync.py` system deltas, suspending background cache warming during active compilation or for 150 seconds post-boot.
* **Hook Signature Parity & WSGI Boot Guardrail (`app.py`, `db.py`, `vfs.py`, `workers.py`):** Added `**kwargs` to `@hooks.on('system_boot')` and `@hooks.on('system_shutdown')` handlers across `db.py`, `vfs.py`, and `workers.py`. Refactored `app.py` boot guardrail so `system_boot` fires under WSGI/production setups or non-`serve` commands.
