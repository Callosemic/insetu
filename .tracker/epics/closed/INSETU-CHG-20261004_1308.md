## Description
* **VFS Parity Gatekeeper Action Middleware (`system.js`)**: Introduced a global pre-flight action middleware (`registerActionMiddleware`) in `window.ExtensionRegistry`. Intercepts entity actions configured with `vfsBound: true` and verifies whether target files have unsaved changes in `FsStore.activeBuffers`. If dirty buffers exist, prompts the user to auto-save before proceeding.
* **Singleton Modal Deprecation & Multi-Column Viewport Projections (`fs.js`, `ui_editor.js`, `ui_primitives.js`)**: Permanently deprecated `InSetuFileModal` and singleton `fileModal` store state. Routed all file viewing, editing, text blob inspection (`viewVirtualInWindow`), and Yomama patch editing to multi-projection text buffers (`FsStore.activeBuffers`) rendered via `<insetu-editor-projection>` pinned to spatial layout columns (`LayoutStore`).
* **Sutram UI Primitive & Iconography Standardization (`bridge.js`, `config.js`, `fs.js`, `gather.js`, `offline_ui.js`, `ui_file_tree.js`, `ui_system_settings.js`)**: Replaced raw HTML `<button class="btn-sm">` and loading `.spinner` elements across bridge, config, file browser, gather, offline, tree, and settings views with Tier 0 presentation primitives (`<sutram-btn>`, `<sutram-async-btn>`, `<yenvui-spinner>`, `<yenvui-scrub-track>`). Replaced inline Lucide SVGs in Gather cards with declarative `<i data-lucide="...">` attributes.
* **Yomama Sync Bridge Diff Analysis & Candidate Disambiguation (`bridge_fuzzy.py`, `bridge_vfs.py`, `bridge.js`)**: Corrected `difflib.ndiff` argument ordering in `apply_block_in_memory` so diff signs (`-` for expected search, `+` for actual on-disk content) accurately display discrepancies. Added a guardrail preventing false idempotency when a `REPLACE` block is a subset of the `SEARCH` block. Added early candidate resolution (`resolve_confirmed`) in `_process_sync_transaction`.
* **Inversion of Control URI Scheme Coercion (`utils_core.py`, `engine_gather.py`)**: Replaced hardcoded string suffix checks (`_context.txt`, `_diffs.txt`, `prompts/`) in `InSetuURI.from_any()` with `@hooks.on('coerce_naked_uri')` event bus listeners, allowing extensions to claim custom URI namespaces natively.
* **AppStore Hash Routing Alignment (`store.js`, `system.js`)**: Purged redundant `activeTab` and `activeSubTabs` properties from `AppStore` in favor of Sutram layout column focus states and `window.location.hash` routing. Replaced manual `localStorage` writes in `setPinnedRepos` with `{ localSync: ['pinnedRepos'] }`.
