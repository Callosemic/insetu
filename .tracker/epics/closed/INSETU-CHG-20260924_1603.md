## Description
* **Rebase & Merge State Resolution (`engine_git.py`, `ext_git.js`)**: Added pending operation detection (`pending_operation`) in `api_git_status` for rebasing and merging states. Implemented worker `_background_resolve_state` (`resolve_state_task`) and REST endpoint `POST git/resolve_state` supporting `continue` (with `GIT_EDITOR=true`) and `abort`.
* **Polymorphic UI Entity Actions (`ext_git.js`)**: Registered `git-state-continue` and `git-state-abort` actions on `repo` target entities matching active `pending_operation` states.
* **Multi-Repo Sweep Error Isolation (`engine_git.py`)**: Refactored `_background_sweep_push` to catch per-repository push errors independently, verify staged changes prior to committing, and report aggregated push logs without crashing multi-repo sweeps.
* **Dynamic Upstream Pushing & Non-Fast-Forward Handling (`engine_git.py`, `ext_git.js`)**: Replaced hardcoded `HEAD` target pushing in `_background_sweep_push`, `_background_git_push`, and `_background_git_add_remote` with dynamic current branch resolution (`curr_branch`), catching non-fast-forward remote rejections gracefully.
* **Autostash Pulls (`engine_git.py`)**: Added `--autostash` to `_background_git_pull` execution args.
