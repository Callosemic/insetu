## Description
* **Canonical VFS URI Scheme Normalization (`fs.js`, `engine_fs.py`, `system.js`)**: Standardized `normalizeVfsURI` across `FsStore` buffer state methods (`openBuffer`, `updateBuffer`, `closeBuffer`) and file operations (`saveBufferFile`, `renameFileTracking`, `executeMove`, `deleteEmptyFolder`, `viewSourceFile`). Updated `updateManifestState` to strip `vfs://` prefixes cleanly. Standardized `InSetuURI` usage in `engine_fs.py` for file archive and upload routes.
* **Sutram Button Declarative Label Standardization (`bridge.js`, `config.js`, `gather.js`, `offline_ui.js`, `ui_editor.js`, `ui_file_tree.js`, `ui_system_settings.js`)**: Converted remaining raw text child nodes inside `<sutram-btn>` elements across core substrate views into declarative `label="..."` attributes, ensuring full component contract compliance and visual label rendering uniformity.
* **SSE Telemetry Event Loop & Reactive State Hardening (`api.js`, `system.js`)**: Added equality checks (`JSON.stringify`) in `SSEPipeline` `job_progress` listeners before updating `AppStore` state (`activeModules`, `pendingModules`), eliminating infinite reactive render cycles during background telemetry streaming.
* **VFS Action Middleware Target Normalization (`system.js`)**: Fixed dirty buffer detection in `registerActionMiddleware` by normalizing target file paths (`normFp`) before querying `FsStore.activeBuffers`.
* **File Tree Responsive Layout & CQRS Path Normalization (`ui_file_tree.js`)**: Normalized pending and deleted mutation paths (`normalizeToNaked`) in `InSetuFileTree` `_getTree()` and search filters to match `vfs://` URIs against raw relative paths. Introduced `--tree-item-px` container query variable to fix mobile tree item padding collapse.
* **Offline Ledger Virtualizer Item Wrapper Fix (`offline_ui.js`)**: Wrapped virtual list item key elements in `InSetuCoreOfflineLedger` with a 100% width box-sizing container to prevent layout collapse in Lit virtualizer flex containers.
* **Yomama Sync Bridge Deep Search & Candidate State Alignment (`bridge.js`)**: Added `_allowDeepSearch` and `_confirmedCandidates` state properties to `InSetuExtBridge`, enabling deep candidate search triggers and explicit path confirmation overrides.
* **Obsolete Asset Cleanup (`shared_styles.js`)**: Marked `shared_styles.js` as obsolete following universal vendorization into `/static/vendor/sutram/js/shared_styles.js`.
