## Description
* **Generic Akasa DAG Compilation Chain Resolution (`engine_gather.py`, `cartographer.py`, `engine_topology.py`, `sdk/__init__.py`)**: Refactored `get_ordered_compilation_steps` in `engine_gather.py` to delegate step resolution and topological sorting directly to Akasa's generic DAG orchestrator (`resolve_dag_chain`), re-exporting `ChainStepSchema`, `ChainStepArtifact`, and `resolve_dag_chain` from `insetu.core.sdk`.
* **Positional Compilation Step Anchoring (`cartographer.py`, `engine_gather.py`, `engine_topology.py`)**: Standardized compilation step declarations across `topology` (`source`, order `10`), `gather` (`body`, order `20`), and `cartographer` (`sink`, order `90`), replacing ad-hoc `compilation_sequence_complete` event hooks with integrated sink step execution.
* **Client Step-Complete Telemetry & Event Ordering (`gather.js`, `api.js`)**: Added `insetu:compile-step-complete` listener in `gather.js` to trigger surgical manifest rehydration as individual pipeline steps complete, and re-ordered SSE telemetry dispatch in `api.js` to ensure completion events fire prior to job termination state updates.
* **Case-Insensitive Code Index & Manifest Watchdog Exclusion (`utils_core.py`)**: Enhanced Watchdog file filtering in `utils_core.py` to perform case-insensitive checks for `CODE_INDEX.md` and explicitly exclude `manifest.json` from triggering filesystem observer events.
