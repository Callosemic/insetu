## Description
* **Real-Time Server-Sent Events (SSE) Telemetry Pipeline (`api.js`, `system.js`)**: Integrated `SSEPipeline` listening to `/api/system/stream` for `vfs_mutated`, `topology_resolved`, and `job_progress` events. Dynamically updates `AppStore` reactive state (`dirtyRepos`, `dirtyBuckets`, `activeModules`, `pendingModules`) and enables adaptive client polling backoff (degrading from 3s to 30s polling intervals when SSE is active).
* **Stage 1 RAM Queue Slew Limiting (`engine_topology.py`)**: Introduced `_TOPOLOGY_RAM_QUEUE` and `_topology_slew_limiter_loop()` worker thread to buffer high-velocity VFS mutations in RAM before executing bulk SQLite commits into `topology_event_buffer`, completely shielding the database from I/O storms during rapid file saves or git operations.
* **On-Demand Context Freshness Barrier (`fs.js`, `gather.js`)**: Added `ensureFreshContext()` helper to `fs.js` which verifies if a requested file's repository or bucket is marked dirty before fetching/viewing context content, automatically compiling fresh contexts on demand. Replaced static "Contexts Stale" warning banner with dynamic card warning highlights.
* **Thread-Safe Cache Invalidation (`engine_topology.py`, `engine_gather.py`)**: Migrated manual dictionary manifest caches to `@thread_safe_cache(ttl=2.0)` decorators for `hook_request_manifest` and `hook_request_vfs_manifest`, triggering thread-safe cache eviction on `manifest_mutated` and `vfs_manifest_mutated` events.
* **Explicit Job Category Declarations (`engine_gather.py`, `engine_topology.py`, `engine_system.py`)**: Standardized background job submissions to explicitly pass `job_category="ui_blocking"`, deprecating the legacy `evaluate_blocking_task` string hook checks.
* **Watchdog Lifecycle & System Boot Binding (`utils_core.py`, `legacy.py`)**: Bound `start_filesystem_observer` and `stop_filesystem_observer` directly to `@hooks.on('system_boot')` and `@hooks.on('system_shutdown')`. Relocated legacy physical sandbox migration routines to `insetu/core/system/legacy.py` with multi-workspace self-healing database recovery.
