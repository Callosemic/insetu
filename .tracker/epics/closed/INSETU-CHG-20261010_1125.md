## Description
* **Dynamic JS Import Map Resolution (`app.py`, `index.html`)**: Implemented `resolve_js_vendors()` in `app.py` to scan `vendor.json` manifests across core and active extensions, dynamically assembling and injecting browser-native `<script type="importmap">` payloads into `index.html` during template rendering.
* **CodeMirror Core Language Pack Consolidation (`vendor_codemirror.sh`, `vendor.json`)**: Bundled all language packs (`markdown`, `python`, `javascript`, `json`, `yaml`, `html`, `css`) directly into `codemirror-core.js`, removing individual language bundle loops and purging redundant import map entries from `vendor.json`.
* **Lucide & Zustand Vendorization Upgrades (`vendor_lucide.sh`, `vendor_zustand.sh`)**: Updated `vendor_lucide.sh` to output icon JS dictionaries to `/static/vendor/lucide/icons.js` and export `window.SutramIcons`. Updated `vendor_zustand.sh` with explicit entry points (`entry_vanilla.js`, `entry_middleware.js`) to preserve named exports (`createStore`, `devtools`, `subscribeWithSelector`). Removed obsolete `insetu/static/icons.js`.
* **Emergency Recovery OS Context Bucket Isolation (`fallback_bridge.py`)**: Updated `api_emergency_dump` in `fallback_bridge.py` to route `sutram/sutram/` and `sutram/yenvui/` paths into dedicated `vendor_sutram.txt` and `vendor_yenvui.txt` context buckets.
* **UI Style & Primitive Cleanups (`style.css`, `index.html`)**: Removed obsolete form element styles from `style.css` in favor of Sutram/yenVUI theme tokens (`theme-tokens.css`, `yenvui-primitives.css`) and included `yenvui-primitives.css` link in `index.html`.
* **Linter Rule & Documentation Parity (`rules_javascript.py`, `CODE_INDEX.md`, `README.md`)**: Added `SUTRAM_BUTTON_DECLARATIVE_LABEL_MANDATE` rule to `rules_javascript.py` and updated `CODE_INDEX.md` and `README.md` to document the 3-repo sibling development setup (`akasa` + `insetu` + `sutram`).
