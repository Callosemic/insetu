## Description
* **Sutram Offline HTTP Provider Integration (`api.js`, `offline_ui.js`):** Integrated `OfflineHttpProvider` and `SutramDB` into `window.inSetu.api`, routing `GET` requests through Stale-While-Revalidate caching and `POST`/`PUT`/`DELETE` mutations through an IndexedDB outbox queue with optimistic UI updates.
* **Core Offline Engine (`offline_ui.js`, `sdk.js`):** Created the Tier 2 `offline` core extension featuring `OfflineStore`, `InSetuCoreOfflineLedger` (outbox, dead-letter queue, and cache inspector), `InSetuCoreOfflineSettings` (per-repo offline toggle and pre-caching), and `InSetuCoreOfflineLog` (real-time telemetry log).
* **Declarative Extension Offline Mode Contract (`sdk.js`, `config.js`, `bridge.js`, `gather.js`, `fs.js`, `ui_editor.js`):** Added the `offline_mode` property (`"full"`, `"read_only"`, `"none"`) to `ExtensionRegistry` configuration schemas and added `getOfflineMode()` helper to `InSetuElement`.
* **API Route & Multi-Tenant Scope Corrections (`ui_system_settings.js`, `config.js`):** Corrected `system/config` REST calls to route through `window.inSetu.api.workspace`, ensuring proper tenant workspace headers (`X-Workspace-ID`) are passed to backend handlers.
* **Yomama Sync Bridge Regex Hardening (`bridge.js`):** Updated `_handleSwap` block extraction with a strict multiline regex anchored to line starts (`^(<<<<<<< SEARCH)` / `^(=======)` / `^(>>>>>>> REPLACE)`), preventing inline `=======` strings inside code blocks from breaking block parsing.
* **VFS & UI Component Compliance (`ui_file_tree.js`, `fs.js`, `store.js`):** Refactored `InSetuFileTree` to subclass `InSetuElement` (satisfying `SDK_ELEMENT_MANDATE`), added Stage 1 VFS resolving lock tracking (`setResolvingLock`) to `AppStore` and `fs.js`, and rendered outbox pending mutation icons ('🌩️') on file cards.
