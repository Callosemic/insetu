## Description
* **Yomama Anchor Auto-Healing Protocol (`bridge_vfs.py`, `bridge.js`)**: Implemented automated search anchor healing for Yomama Sync Bridge patch collisions. When a search anchor fails to match the target file on disk exactly, `resolve_anchor_failure` in `bridge_vfs.py` calculates the closest matching lines (`actual_lines`), base64-encodes them as `actual_anchor`, and exposes the `heal_anchor` available action.
* **Bridge UI Auto-Heal Console Action (`bridge.js`)**: Added the "🩹 Auto-Heal Anchor" UI action button in `_renderTelemetry()` and handled the `heal-anchor` console click event, dynamically replacing the cell's `SEARCH` block with `actual_anchor` and re-dispatching the transaction.
* **Preformatted Blob & Diff Viewing (`ui_primitives.js`)**: Configured `<textarea readonly wrap="off">` with `white-space: pre; overflow-x: auto;` inside `InSetuBlobViewer`, preventing line-wrapping distortion for code diffs and raw text buffers.
