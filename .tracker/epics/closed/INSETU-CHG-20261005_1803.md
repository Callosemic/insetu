## Description
* **SDK Substrate Module Renaming (`insetu_sdk.js`)**: Renamed `sdk.js` to `insetu_sdk.js` and updated system import specifiers across core substrate modules (`bridge.js`, `config.js`, `fs.js`, `gather.js`, `offline_ui.js`, `ui_editor.js`, `ui_file_tree.js`, `ui_primitives.js`, `ui_system_settings.js`, `store.js`, `system.js`). Added spatial viewport column and tab keyboard navigation shortcuts (`ctrl+1..3`, `ctrl+shift+left/right/up/down`) to the system extension declaration.
* **Spatial Multi-Column Viewport Routing (`fs.js`, `ui_editor.js`, `system.js`, `store.js`)**: Extracted `routeToSpatialGrid()` utility in `fs.js` to standardize pinning text buffer projections to spatial viewport columns (`Sutram.stores.Layout`). Replaced duplicate inline layout pinning blocks across `viewInWindow`, `viewAndCopy`, `viewSourceFile`, and `openVirtualFile`. Deprecated `viewVirtualInWindow()`. Added `tabBrowsePaths` persistence to `AppStore` state (`localSync: ['pinnedRepos', 'tabBrowsePaths']`). Refactored `getActiveEditorPath()` in `ui_editor.js` to perform direct UDF LayoutStore queries.
* **Zen Focus Mode Integration (`fs.js`, `ui_editor.js`)**: Integrated Zen Focus Mode (`_toggleZenMode`, `zen-mode` attribute, HTML Fullscreen API toggle, and floating exit button) into `InSetuEditorProjection` (`fs.js`) and `InSetuFrontmatterEditor` (`ui_editor.js`). Removed `.editor-title` header element from `InSetuEditorProjection`.
* **Sutram Presentation Primitives & Iconography Alignment (`bridge.js`, `config.js`, `fs.js`, `gather.js`, `offline_ui.js`, `ui_file_tree.js`)**: Replaced raw Lucide SVG tags and `intentColor` CSS variables across cards and lists with declarative `icon` and `intent` properties (`icon="file-code-2"`, `intent="highlight"`, `intent="primary"`, `intent="warning"`). Replaced custom card container divs in Gather with `<sutram-scroll-view>`.
* **Tree-Sitter JS/TS Template Literal False Syntax Error Fallback (`bridge_vfs.py`)**: Added fallback validation using `execute_binary(['node', '--input-type=module', '-c'])` when Tree-Sitter flags root node syntax errors on Lit template literals in JS/TS/MJS files during Yomama Sync Bridge pre-flight validation.
* **Module Import Scope Hardening (`engine_system.py`)**: Refactored internal imports (`_current_app`, `_typeddict_to_openapi`, `_re`, `_get_connection`, `_resolve_dag_chain`, `_sanitize_workspace_config`, `_get_default_repo_template`, etc.) to eliminate re-export namespace pollution and satisfy AST linter rules.
* **Navigation & Router Cleanup (`system.js`)**: Purged obsolete `onViewActivated()` handlers, `shell-tab-changed` / `shell-subtab-changed` event listeners, and manual `activeTab`/`activeSubTabs` route reset logic in `performSoftRefresh()` in favor of Sutram spatial viewport layout state.
