## Description
* **Service Worker Core Vendorization (`sw.js`, `app.js`)**: Refactored `sw.js` to delegate service worker caching to `sw-core.js`. Configured `HOST_ASSETS` and `HOST_BYPASS_PATTERNS` to manage static offline caching. Added dynamic module cache warming on first installation.
* **Network Hysteresis & Outbox Reconciliation (`app.js`)**: Integrated `NetworkHysteresisManager` and `OutboxReconciler.drain()` into a recurring metronome tick (`network_ping`). Automatically drains queued mutations to backend REST endpoints when network connectivity is restored.
* **Offline Boot Hydration & UI Fallbacks (`app.js`)**: Enhanced `executeBootSequence()` to hydrate workspace topologies, configurations, and manifests from `localStorage` during offline sessions. Added safety fallbacks for missing offline tab orders and synchronized `isOffline` state with `Sutram.stores.Environment`.
* **In-DOM Security Handshake (`app.js`, `fallback_bridge.py`)**: Replaced native browser `prompt()` dialogs with an in-DOM HTML security gate modal for manual static token verification. Configured `executeSecurityHandshake()` to validate cached tokens in `localStorage` when offline.
* **Hash-Delta Cache Warmer & Resolving Lock Eviction (`app.js`)**: Added low-priority background pre-fetching for offline-capable VFS files and CTX entries during manifest signature sync. Implemented expiration and eviction tracking for resolving locks.
* **PyPI Packaging & Documentation (`README.md`, `CODE_INDEX.md`)**: Added PyPI installation instructions (`pip install insetu[all]`), updated the 3-minute video demo link, and updated architectural Substack essay references.
* **Local Vendorization Scripts (`vendor.json`, `vendor_lit.sh`, `vendor_zustand.sh`)**: Added `zustand/vanilla` and `zustand/middleware` ESM mappings to `vendor.json`. Created standalone shell scripts to automate local esbuild bundling of Lit and Zustand dependencies.
* **iOS PWA Support (`index.html`)**: Injected Apple mobile WebApp meta tags (`apple-mobile-web-app-capable`, `apple-mobile-web-app-title`) and touch icon references for PWA standalone display.
