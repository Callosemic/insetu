## Description
* **Polymorphic InSetuURI Coercion (`utils_core.py`, `bridge_vfs.py`, `engine_fs.py`)**: Introduced `InSetuURI.from_any(raw)` to accept `InSetuURI`, `AkasaURI`, dict objects, or raw string/path inputs, automatically coercing logical schemes (`vfs://` and `ctx://`) and volume roots.
* **BucketAddress Value Object SSOT (`utils_core.py`, `fs.js`)**: Enhanced `BucketAddress.from_uri()` to handle explicit root repository definitions (`repo=""`) without falling back to `"orphan"`. Updated `ensureFreshContext()` in `fs.js` to evaluate bucket freshness using `BucketAddress.fromFilepath()`.
* **SSE Telemetry Un-blocking (`api.js`)**: Updated `SSEPipeline` `job_progress` event listener to ALWAYS emit `insetu:compile-step-complete` when worker steps complete, ensuring surgical manifest rehydration regardless of background job execution category.
* **Root VFS Volume Mounting (`engine_topology.py`)**: Added `mount_volume(workspace_id, 'vfs', '', ws_root)` to root `mount_topology_volumes_dynamically` hook, guaranteeing root workspace folder visibility in VFS volume tables.
* **Service Worker & Cache Eviction Hardening (`system.js`, `fs.js`)**: Hardened `fullRefresh()` in `system.js` to unregister active Service Workers and purge browser `CacheStorage` before triggering hard reloads. Normalized all `d.targets` key getters to canonical `d.target_repos` across frontend scripts.
