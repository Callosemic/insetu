## Description
* **VFS Optimistic Offline Queue Integration (`fs.js`)**: Updated all core Virtual File System (VFS) modal and context operations (`saveModalFile`, `renameModalFile`, `executeMove`, `archiveModalFile`, `deleteEmptyFolder`, `deleteModalFile`, `saveNewFile`, `saveNewFolder`) to explicitly pass `collapseKey`, `pendingMutations`, and `deletedMutations` configuration flags to `executeWorkspaceMutation`. This guarantees correct optimistic UI rendering and prevents stale cache reads during offline IndexedDB outbox queueing[cite: 3].
* **Yomama Bridge Remapping UX (`bridge.js`)**: Added intelligent "Suggested Matches" UI for Yomama Bridge target files that fail verification. It natively queries the global manifest and suggests matches based on exact file fragment suffixes or basenames, allowing one-click swapping[cite: 3].
* **Yomama Offline Read-Only Mode (`bridge.js`)**: Upgraded the Yomama Sync Bridge extension's `offline_mode` declarative contract from `"none"` to `"read_only"`, enabling offline viewing of historical patch ledgers without allowing offline patch queues[cite: 3].
* **Offline Cache Warming Queue (`store.js`)**: Added `warmingQueue` state and `enqueueWarming` mutator to the `AppStore` to facilitate background asset caching loops for the offline service worker[cite: 3].
