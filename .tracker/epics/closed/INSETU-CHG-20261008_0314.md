## Description
* **Workspace Swap State Integrity (`system.js`)**: Fixed a critical data bleed vector during workspace hot-swaps. Reordered `executeWorkspaceSwap` and `performSoftRefresh` so that `Layout` projections are forcibly evicted *before* the tenant identity changes, guaranteeing that transient auto-saves hit the correct outgoing workspace database.
* **UI Primitive Alias Purge & Lucide Decoupling (`ui_primitives.js`, `ui_file_tree.js`, `bridge.js`, `gather.js`)**: Permanently removed legacy `insetu-card`, `insetu-modal`, and `insetu-async-btn` compatibility wrappers in favor of direct `<sutram-*>` primitives. Migrated all raw `<i data-lucide>` tags to the declarative `<yv-icon>` component to eliminate manual `lucide.createIcons` DOM queries.
* **Spatial Grid File Rename Tracking (`fs.js`)**: Implemented `renameFileTracking` to seamlessly transition active file buffers and spatial viewport column projections (`Sutram.stores.Layout`) when a file is renamed or moved, immediately updating the URL hash.
* **Zen Mode Popover Upgrades (`ui_editor.js`)**: Upgraded Zen Focus Mode inside `insetu-editor-projection` and `insetu-frontmatter-editor` to use the native HTML `popover` attribute and Fullscreen API, removing rigid `100vw/100dvh` dimensions to respect container queries.
* **System Rebranding (`engine_system.py`, `system.js`)**: Updated default workspace titles and the OpenAPI 3.0 specification title from "Developer OS" to "inSetu Workbench".
* **History Virtual List Pagination (`bridge.js`)**: Added IntersectionObserver pagination (`_renderLimit`) to `insetu-ext-bridge-history` to prevent DOM locking when parsing massive transaction ledgers.
* **SDK Initial State Coalescing (`insetu_sdk.js`)**: Updated `createExtensionStore` to automatically evaluate and coalesce initial state properties starting with `fetch*` via `coalescedAsync`.
