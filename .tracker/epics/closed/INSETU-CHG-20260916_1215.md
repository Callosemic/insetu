## Description
* **Yomama Sync Bridge Event Redundancy Cleanup (`bridge_vfs.py`)**: Removed redundant manual `vfs_event_log` SQL insertions and `vfs_mutated` hook emissions from `_process_sync_transaction`, as `vfs.save()` inside `VFSTransaction` natively handles write queueing and mutation event broadcasts.
* **Canonical Logical VFS Pathing in Cartographer (`cartographer.py`)**: Updated `map_repositories` to save `CODE_INDEX.md` files using canonical logical URIs (`vfs://{repo_dir}/docs/CODE_INDEX.md` or `vfs://{repo_dir}/CODE_INDEX.md`) instead of relative physical paths.
* **OCC Conflict VFS Event Ledger Parity & Security Guards (`engine_fs.py`)**: Sanitized payload `data` in `api_fs_save` to delete client-injected `is_absolute_artifact` and `ignore_ledger` flags. Refactored Optimistic Concurrency Control (OCC) conflict save generation to route through `execute_vfs_save` with logical URI paths rather than native file `open()` calls. Removed `is_absolute_artifact` parameter from `api_fs_fetch` and standardized headers in `download_file`.
* **Context Chunking Newline Preservation & VFS Search Migration (`engine_gather.py`)**: Updated `compile_context_payload` chunking logic to search for newlines when splitting oversized text blocks, preventing bisection of multi-byte characters or code syntax. Replaced native `open()` calls in `hook_vfs_search` with `ctx.vfs.read()`.
* **Orphaned Context Tombstoning & Targeted Sweep Vacuuming (`engine_gather.py`)**: Enhanced `_surgically_update_manifest` and `generate_context_file` to identify orphaned RAG context entries for affected repositories, tombstone them in `manifest_ledger`, and physically delete artifacts via `ctx.vfs.delete(..., data={"ignore_ledger": True})`.
* **Gather Reactive Progress & Module Step State Sync (`gather.js`)**: Updated `insetu:compile-progress` event listener in `InSetuExtGather` to evaluate job chain history (`pollData.artifact.chain_history`) and step ownership (`pollData.ext_name`), ensuring compilation spinners and loading messages ("Waiting for prerequisite contexts...") reflect multi-stage background pipeline status accurately without UI flickering.
* **Offline Blob Cache Eviction & Global Panic Fetch (`system.js`)**: Updated `checkManifestVersion()` in `system.js` to purge outdated blob entries from `SutramDB` when CTX or VFS signatures are modified or tombstoned. Updated `simulatePanic()` to execute raw `fetch('/api/system/panic')` to bypass tenant header injection during global system recovery.
* **Multi-Tenant Watchdog Keying & Debounce Tuning (`utils_core.py`)**: Keyed `_WATCHDOG_PENDING` entries by `(workspace_id, abs_key)` to isolate Watchdog events across multi-tenant workspaces. Reduced `_WATCHDOG_DEBOUNCE_WINDOW` to 2.0 seconds and dropped directory `modified` events while preserving directory creations, deletions, and moves.
* **Longest Prefix Matching for Sub-Directory Repositories (`utils_core.py`, `engine_topology.py`)**: Refactored `resolve_logical_path` in `utils_core.py` and `resolve_topology_buffer` in `engine_topology.py` to match paths against registered repository configurations using longest prefix matching, preventing path resolution errors for nested or sub-directory repository structures.
* **Multi-Tenant Workspace Resolution in Topology (`engine_topology.py`)**: Updated `resolve_owning_workspaces` to iterate all registered workspace IDs via `get_all_workspace_ids()` and evaluate both absolute and relative path matches against workspace roots and registered repository physical paths.
