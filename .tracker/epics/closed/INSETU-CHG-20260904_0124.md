## Description
* **Sync Bridge Event Propagation (`bridge_vfs.py`):** Emitted a background `vfs_mutated` event upon atomic transaction commitment, ensuring the Topology Engine and downstream event listeners awaken even when patched target directories lie outside active filesystem watchdog scopes.
* **Context Compilation Content-Hash Idempotency (`engine_gather.py`):** Introduced SHA-256 `content_hash` evaluation in `compile_context_payload` and DB-level entry comparison in `hook_save_manifest` to eliminate redundant disk writes and timestamp updates when context blocks remain unchanged.
* **Granular Manifest Updates & Topology Settlement Barrier (`engine_gather.py`):**
  - Refactored `_pack_selection_worker` and `_background_compile` to pass granular manifest delta dictionaries to `ctx.save_manifest(..., is_full_compile=False)`.
  - Added a Topology Settlement Barrier wait loop (`tpl_%` job check) in `_background_compile` to prevent gather compilation race conditions while topology buffer resolution is processing.
* **Topology Engine Directory Mutation Handling & Read Parity (`engine_topology.py`):**
  - Expanded directory save/delete events (ending in `/`) in `resolve_topology_buffer` to process all nested directory contents via `os.walk` or prefix matches.
  - Removed read-time `resolve_topology_buffer` invocations from `hook_topology_manifest_signatures`, `api_topology_vfs_repo`, and `hook_request_vfs_manifest` to prevent read-path side effects.
  - Added database indexes (`idx_topology_repo`, `idx_topology_bucket`) to `topology_ledger` at workspace boot.
  - Added defensive `(config.get(...) or [])` fallbacks across list iterations to prevent `TypeError` when keys are explicitly set to `null` in JSON configurations.
* **Watchdog Directory Observer & Pruning (`utils_core.py`):**
  - Updated `FileSystemObserver` in `start_filesystem_observer` to capture directory creation, deletion, and move events with trailing slashes.
  - Added memory leak prevention pruning to `_NATIVE_VFS_WRITES` when tracking cache size exceeds 1,000 entries.
* **System Settings Merging & Offline Engine Scaffolding (`routes_system.py`, `engine_offline.py`):**
  - Registered `offline_cache_limit_mb` (default 250 MB) in `core_system` settings schema and updated `save_system_config` to merge incoming payloads with existing configuration data before saving.
  - Replaced hardcoded `core_engines` set with kernel `CORE_MODULES` in `get_system_config`.
  - Scaffolded Tier 0 `offline` core extension (`InSetuExtension('offline', ...)`) in `insetu/core/offline/engine_offline.py`.
