## Description
* **Universal BucketAddress Value Object (`utils_core.py`, `sdk.js`)**: Introduced the `BucketAddress` value object (`<repo>::<bucket_id>`) across Python and JavaScript layers, standardizing URI generation (`contextUri`, `diffUri`) and key resolution (`from_key`, `from_uri`, `from_vfs_path` / `fromFilepath`).
* **System Pipeline Gateway & Gather Decoupling (`engine_system.py`, `engine_gather.py`, `gather.js`)**: Added the `/api/system/pipeline/submit` endpoint in `engine_system.py` to handle DAG pipeline submission at system scope via Akasa `resolve_dag_chain`. Deprecated the legacy `/api/<ws>/gather/submit` endpoint and refactored `gather.js` to submit via the system pipeline gateway using `window.inSetu.utils.pollJob`.
* **Standardized Step Telemetry & Centralized Invalidation (`api.js`, `store.js`, `cartographer.py`, `engine_gather.py`)**: Centralized `insetu:compile-step-complete` event handling in `store.js` to clear dirty bucket states incrementally as individual steps finish. Updated `SSEPipeline` in `api.js` to emit step completion telemetry on every finished step while maintaining UI loading spinners until chain termination. Refactored `cartographer.py` to return structured step artifact metadata.
* **Config Extension Gateway Alignment (`config.js`)**: Updated `InSetuExtConfig` API calls in `config.js` to route system configuration GET/POST requests through `window.inSetu.api.system.get('config')` and `window.inSetu.api.system.post('config')`.
* **System Error Telemetry Propagation (`engine_bridge.py`, `engine_gather.py`, `engine_topology.py`)**: Added `hooks.emit_background('system_error', ...)` logging across background worker exception blocks to guarantee system-wide error telemetry collection.
* **SDK Force-Refresh Event Matching & Debug Flags (`sdk.js`, `engine_topology.py`, `system.js`, `bridge.js`)**: Enhanced `InSetuElement` event matching for `insetu:force-refresh` events, gated verbose topology logging behind `INSETU_DEBUG`, and exported `StatusStore` in `system.js`.
