## Description
* **Extension Offline Resilience & Mode Declarations (`ExtensionRegistry`)**: Standardized `offline_mode` declarations (`"full"`, `"read_only"`, `"none"`) across all active extension registrations. Added global listeners for `sutram-sync-complete` across extensions to trigger automatic store re-fetching following offline reconciliation.
* **Optimistic Offline Queue State Handling (`citations`, `favorites`, `notes`, `skills`, `tracker`)**: Updated state store mutators and mutation action handlers to handle `data.job_id === 'offline_queue'` optimistically, preventing offline network re-fetch errors.
* **Namespaced Event Bus Standardization (`git`, `flow`, `update`)**: Standardized custom event dispatches and listeners to use explicit domain namespaces (`insetu:git:diffs-refreshed`, `insetu:git:open-push-modal`, `insetu:git:generate-diffs`).
* **Developer Daemon Logs Extension (`dev`)**: Added `/api/<workspace_id>/dev/logs` REST endpoint in `engine_dev.py` utilizing `journalctl` to inspect daemon logs. Added `InSetuExtDevLogs` and `InSetuExtDevLogsActions` components in `ext_dev.js`.
* **Publish Document Middleware Fix (`publish`)**: Updated `compile_document_payload` in `engine_publish.py` to compile resolved multi-chunk and pre-compile middleware text via a temporary `input.md` file rather than reading raw paths directly. Refactored `InSetuExtPublishModals` to use `<sutram-async-btn>` and `this.api.bindJobAction`.
* **Automation Hooks Execution Guardrails (`hooks`)**: Added telemetry logging, enforced a 300-second timeout on subprocess command execution, and added a 300-second lock expiration window to worker deduplication queries.
