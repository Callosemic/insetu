## Description
* **OpenAPI 3.0 Type Contract & Docstring Alignment**: Added explicit `TypedDict` request schemas (`AttachCitationPayload`, `SearchCitationsPayload`, `ImportCitationsPayload`, `CronicSchedulePayload`, `CronicTogglePayload`, `CronicIdPayload`, `CmdExecPayload`, `CmdExecResponse`, `SqlQueryPayload`, `FavoriteAddPayload`, `FlowBatchSavePayload`, `FlowBatchDeletePayload`, `FormatCodePayload`, `FreshdeskReplyPayload`, `FreshdeskFetchPayload`, `HookSavePayload`, `HookTogglePayload`, `HookIdPayload`, `IngestUrlPayload`, `NoteNewPayload`, `CompileDocumentPayload`, `ResearchStartPayload`, `ResearchActionPayload`, `InboxDispositionPayload`, `LogSkillPayload`, `UpdateSkillPayload`, `DeleteSkillPayload`, `CreateSkillPayload`, `GitSweepPushPayload`, `GitRepoPayload`, `GitPushPayload`, `GitInitPayload`, `GitPullPayload`, `GitRemoteAddPayload`, `GitCheckoutPayload`, `TrackerSpawnPayload`, `TrackerVocabPayload`, `TrackerNewPayload`, `TrackerTransitionPayload`, `UpdateRepoPayload`, `UpdatePreviewBumpPayload`, `UpdateTomlPayload`, `UpdateManualBuildPayload`, `UpdateForceVersionPayload`, `UpdateInitPayload`) and comprehensive `docstring` declarations across public API endpoints in all 18 extension engines.
* **Universal Binary Execution Parity (`engine_git.py`, `engine_update.py`)**: Replaced direct `subprocess.run` invocations with `execute_binary()` from `utils_core.py`, guaranteeing PATH, virtual environment (`sys.executable`), and CLI binary resolution across systemd user services and desktop GUI shells (ADR 0050).
* **Logical VFS URI Package Operations (`engine_update.py`)**: Migrated `pyproject.toml` read and write operations to logical VFS URIs (`vfs://{repo}/pyproject.toml`), preserving Event Ledger parity and VFS barrier synchronization (ADR 0042).
* **Dev System Error Ledger & Sandbox Execution (`engine_dev.py`, `ext_dev.js`)**: Integrated `@hooks.on('system_error')` logging into `dev_bp` schema, exposed sandbox command execution via `api_dev_exec` (`POST /exec`), and added system error UI cards and SQL console presets in `ext_dev.js`.
* **Flow & Git Context Delta Telemetry (`engine_flow.py`, `engine_git.py`, `ext_flow.js`, `ext_git.js`)**: Updated `_background_compile_workflows` and `_background_compile_diffs` to process path inclusions natively via `InSetuURI.from_any()` and `BucketAddress`, returning structured state deltas to trigger reactive client UI card updates.
