## Description
* **Canonical VFS Path Preservation & De-truncation (`fs.js`, `bridge.js`, `gather.js`)**: Eliminated lossy `basename` and `cleanName` path stripping across client VFS utilities (`getChunks`, `openPartsModal`, `shareFiles`, `viewAndCopy`, and entity action handlers), preserving full canonical `ctx://` and workspace-relative paths throughout the client pipeline, and URL-encoded raw file paths for `/download/` REST endpoints.
* **Yomama Telemetry Deselection Indexing (`bridge.js`)**: Corrected patch deselection off-by-one errors in multi-patch file groups by tracking `origFileCounters` per file and aligning `_deselectSpecificPatch` array indexing with full file patch item arrays.
* **AppStore Reactive Module Compilation Pipeline (`store.js`, `gather.js`)**: Introduced `activeModules` and `pendingModules` reactive state arrays to `AppStore`, and updated `InSetuExtGather` to subscribe to these state updates so compilation spinners and skeleton loaders accurately reflect multi-stage background compilation progress.
* **Folder Selection Trailing Slash Normalization (`fs.js`)**: Updated `confirmFolderSelection` to guarantee trailing slash formatting on selected directory paths (`path/`), ensuring clean path concatenation when moving or creating nested files.
