## Description
* **Sutram Presentation Primitive Migration (`ext_*.js`)**: Replaced all remaining legacy `<insetu-card>` element tags with standard `<sutram-card>` presentation primitives across `ext_citations.js`, `ext_cronic.js`, `ext_dev.js`, `ext_favorites.js`, `ext_flow.js`, `ext_freshdesk.js`, `ext_git.js`, `ext_hooks.js`, `ext_notes.js`, `ext_research.js`, `ext_skills.js`, and `ext_tracker.js`[cite: 1, 2, 3].
* **Modal Conditional Rendering & Shadow DOM Optimization (`ext_*.js`)**: Wrapped modal dialog components (`<sutram-modal>`) in explicit boolean template conditionals (`${this.modalOpen ? html`...` : ''}`) and early return checks across 13 frontend extension modules, eliminating hidden DOM node initialization and reducing shadow DOM memory overhead[cite: 1, 2, 3].
* **Responsive Container Query Adaptation (`ext_*.js`)**: Added `container-type: inline-size;` to `:host` styles across extension views (`ext_cronic.js`, `ext_dev.js`, `ext_favorites.js`, `ext_flow.js`, `ext_git.js`, `ext_hooks.js`, `ext_notes.js`, `ext_prompts.js`, `ext_research.js`) for layout-agnostic responsive container query support[cite: 1, 2, 3].
* **Favorites Iconography & Action Alignment (`ext_favorites.js`)**: Added `InSetuFavLabel` component, replaced raw emoji stars with declarative `<yv-icon name="star">` in `InSetuFavBtn`, and added `label` and `icon` properties to entity actions[cite: 2].
* **Research Engine Ingest Pre-Flight Validation (`engine_research.py`)**: Added pre-flight check in `start_job` ensuring extension `ingest` is enabled in the workspace prior to starting a research job[cite: 1].
* **Automation Hooks Command Execution Safety (`engine_hooks.py`)**: Updated `_background_execute_rule` to use `shlex.split` and shell character detection for safer command line parsing and execution[cite: 2].
* **Toolbar Actions Layout & Placeholder Styling (`ext_*.js`)**: Added flex alignment styling to extension action bars (`ext_hooks.js`, `ext_notes.js`, `ext_prompts.js`, `ext_flow.js`, `ext_tracker.js`) and removed emoji prefixes from toolbar search placeholders[cite: 1, 2, 3].
