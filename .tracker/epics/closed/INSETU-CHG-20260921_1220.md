## Description
* **Desktop GUI Shell & Cross-Platform Shortcuts (`insetu/cli.py`)**: Implemented `launch_gui(cwd)` utilizing `pywebview` to embed the inSetu Developer OS within a desktop shell window (`insetu gui`), automatically attaching to active background daemons. Added `create_desktop_shortcut(cwd)` (`insetu shortcut`) to generate native application launchers across Linux (`.desktop`), macOS (`.app` bundle in `~/Applications`), and Windows (Start Menu `.lnk` via PowerShell).
* **Server-Sent Events (SSE) Telemetry Stream & Namespace Registration (`insetu/app.py`)**: Added `/api/system/stream` endpoint on core Flask app shell, connecting clients directly to `akasa.events.sse_bus`. Registered trusted core (`insetu.core.`) and extension (`insetu.extensions.`) namespaces with the event bus on boot. Refactored config cache invalidation to use the decoupled `hooks.emit('config_mutated')` event emitter.
* **Recovery OS Cache Eviction & Service Worker Unregistration (`fallback_bridge.py`, `templates/index.html`, `app.py`)**: Enhanced recovery triggers and UI buttons across `fallback_bridge.py`, `index.html`, and `app.py` to purge browser `caches` (`caches.delete()`) and unregister active Service Workers (`navigator.serviceWorker.getRegistrations()`) prior to initiating kernel panics or redirecting to `/recovery`. Added `/` redirect to `/recovery` in recovery app.
* **Architectural Fitness Linter Expansion (`tests/fitness/`)**: Added `EXPLICIT_JOB_CATEGORY_MANDATE` rule in `rules_python.py` requiring explicit `job_category` declarations on all background job submissions. Added `UNSCOPED_PERSISTENT_STORAGE` and `DOMAIN_STORE_TOPOLOGY_MIRROR_BAN` rules in `rules_javascript.py`. Added `legacy.py` to fitness whitelists in `core.py`.
* **Topology Index Alignment (`CODE_INDEX.md`)**: Updated the repository topological map to index ADR 0049 and `insetu/core/system/legacy.py`.

## Notes / Execution Log
