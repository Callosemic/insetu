## Description
* **Tree-Sitter Native AST Syntax Validation (`bridge_vfs.py`):** Integrated Tree-Sitter native AST parsers (`tree_sitter_python`, `tree_sitter_javascript`) into the Yomama Sync Bridge pre-flight syntax gate for `.py`, `.js`, `.mjs`, `.cjs`, `.ts`, and `.tsx` files, falling back gracefully to standard `ast.parse` and `node -c` when C-extensions are absent.
* **Optimistic Concurrency Control Save Conflict Handling (`routes_fs.py`):** Added `base_hash` SHA-256 validation to `api_fs_save`. If physical disk content diverges from the client's expected base state, a `.conflict_<timestamp>` file is generated and HTTP 409 Conflict is returned to prevent silent lost updates.
* **Workspace Creation Schema Provisioning & Boot (`routes_system.py`):** Enhanced `api_create_workspace` to execute `apply_declarative_schema` across all registered extension schemas and emit the `@hooks.on('workspace_boot')` lifecycle event, ensuring newly created workspaces possess fully initialized database schemas and background workers.
* **Dual-Root Partitioned Manifest Alignment (`engine_gather.py`):** Corrected manifest dictionary accessors from monolithic reads (`ctx.manifest`) to dual-root partitioned reads (`ctx.manifest.get("ctx", {})`) across context compilation, quickpack clearing, and surgical updates. Replaced direct SQL `DELETE FROM jobs` with `cancel_job` from `insetu.kernel.workers`.
* **Surgical Event Buffer Deletion & Draining (`engine_topology.py`):** Upgraded `resolve_topology_buffer` to execute surgical ID-based deletions (`DELETE FROM topology_event_buffer WHERE id IN (...)`) rather than wiping the entire table, and added a multi-pass draining loop to `_background_resolve_topology` to guarantee complete settlement during burst I/O.
* **Watchdog Settings SSOT & Frontmatter Consolidation (`utils_core.py`):** Updated `start_filesystem_observer` to read watchdog toggle state from `SettingsManager('core_system', 'default')` SSOT, removed duplicate `parse_uri` definitions, and consolidated frontmatter parsing utilities.
