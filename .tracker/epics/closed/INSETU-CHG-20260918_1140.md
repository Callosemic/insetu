## Description
* **Universal Extension View Activation Lifecycle (`onViewActivated`)**: Implemented `onViewActivated()` across all 11 UI extension Web Components (`ext_citations.js`, `ext_cronic.js`, `ext_dev.js`, `ext_favorites.js`, `ext_git.js`, `ext_hooks.js`, `ext_notes.js`, `ext_research.js`, `ext_skills.js`, `ext_tracker.js`, `ext_update.js`), ensuring reactive state re-hydration when tabs become active without reading DOM state or relying solely on `connectedCallback()`.
* **Systemd Invocation Boot Logs Export (`engine_dev.py`, `ext_dev.js`)**: Added `download_boot_logs_worker` (`download_boot_logs_task`) and `/api/<ws>/dev/logs/download` endpoint filtering `journalctl` by `_SYSTEMD_INVOCATION_ID`, along with a "⬇️ Export Boot Logs" UI action button in the Dev Daemon Logs view.
* **Extension Artifact Path Resolution Hardening (`engine_cronic.py`, `engine_freshdesk.py`, `engine_update.py`)**: Replaced hardcoded `.insetu/data/` and relative string paths with `Path(ctx.paths["artifacts_base"])` or `ctx.resolve_path()` and `is_absolute_artifact=True`, enforcing Spatial Physics and Configuration SSOT across execution logs and temporary build files.
* **Cronic Process Security & Boot Reconstruction (`engine_cronic.py`)**: Applied `shlex.quote` and `re.escape` sanitization to background script executions and termination processes, and enhanced boot hook state-healing to reconstruct missing crontab jobs.
* **Layout Slot Prefix Correction (`ext_hooks.js`)**: Corrected extension registration layout slots from unqualified strings (`primary-navigation`) to canonical `slots:` prefixes (`slots:primary-navigation`, `slots:sub-navigation`, `slots:sub-navigation-actions`).
* **Notes Context Filename Alignment (`engine_notes.py`)**: Standardized notes topology output filename to `ctx://contexts/notes_context.txt`.
* **Tailscale Boot Coalescing & Guardrails (`engine_tailscale.py`)**: Restricted automatic `tailscale serve` boot binding to the default workspace and added `coalesce=True` to job submission.
