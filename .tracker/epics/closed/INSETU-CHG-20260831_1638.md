## Description
- **UI & Presentation (`sutram-spinner`)**: Replaced raw loading divs and inconsistent spinner elements across Citations, Favorites, Flow, Freshdesk, Git, Notes, Prompts, Research, and Skills extensions with `<sutram-spinner>` components and non-destructive container opacity/pointer-events transitions.
- **Terminal Extension (`term`)**: Integrated virtual keyboard action controls, touch and pointer gesture tracking (swipes, long-press, double-tap), terminal context menu actions (`tc-copy`, `tc-paste`, `tc-sigint`), and enhanced Xterm cleanup handlers on component disconnect.
- **Kanban Tracker (`tracker`)**: Extracted `<insetu-tracker-ticket>` component for modular rendering, added blocker and downstream dependency indicators to ticket cards, introduced a dedicated dependency inspection modal (`insetu:tracker:open-deps`), and enforced tier preservation during ticket creation and template spawning.
- **Publish Extension (`publish`)**: Subscribed `resolve_publish_artifacts` to `@hooks.on('vfs_resolve_file')` for resolving compiled document outputs via VFS, and added download error handling in the modal.
- **Developer Extension (`dev`)**: Replaced direct SQL worker job insertion with the kernel `submit_job` worker API.
- **Semantic Update Extension (`update`)**: Enhanced `_clean_semantic_release_logs` regex noise filters and improved version string normalization for prerelease build artifact matching.
