## Description
* **Canonical `vfs://` URI Event Standardization (`engine_gather.py`, `engine_topology.py`, `utils_core.py`):** Standardized `vfs://` scheme normalization across VFS event logging, filesystem observers, topology event buffers, and RAG recall callbacks. Added `_to_canonical_event()` and `_get_fp()` helpers in `engine_gather.py` to guarantee consistent `vfs://` or `ctx://` URI prefixes prior to event set deduplication.
* **URI Parsing & Logical Path Resolution (`engine_topology.py`, `utils_core.py`):** Introduced `parse_uri()` SDK helper in `utils_core.py` to split URI schemes and relative paths into `(repo_dir, rel_path)`. Refactored `resolve_topology_buffer` to parse URIs and reconstruct clean `vfs://` paths. Hardened `resolve_logical_path` to handle `vfs://` boundaries, match workspace root directory names, and check direct downstream fallbacks.
* **Centralized Repository Path Accessor (`engine_gather.py`, `engine_topology.py`):** Centralized repository path resolution across `provide_base_workspaces` and `force_topology_scan` using `ctx.get_repo_path(repo_dir)`.
* **`ruamel.yaml` Frontmatter Engine (`utils_core.py`):** Upgraded `parse_frontmatter` and `update_frontmatter` with `ruamel.yaml` AST parsing (`_get_yaml_engine`), preserving quotes, indentation, key order, and multi-line strings during YAML frontmatter read/write operations with graceful fallback to standard parser.
* **Bridge Worker Keyword Argument Alignment (`engine_bridge.py`):** Updated `submit_immediate_job` invocation in `bridge_sync` to pass `workspace_id=ctx.workspace_id` explicitly as a keyword argument.
