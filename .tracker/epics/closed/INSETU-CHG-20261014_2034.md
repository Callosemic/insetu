## Description
* **Bootloader DAG Bypassed Extension Telemetry (`insetu/app.py`)**: Enhanced `load_workspace_extensions()` to capture structured records (`{"extension": ext, "missing_dependency": dep, "reason": msg}`) for extensions bypassed during topological dependency resolution. Subscribed `inject_bypassed_extensions` to `@hooks.on('mutate_workspace_config')` to populate `cfg["bypassed_extensions"]`, surfacing missing dependency status to client-side diagnostics.
* **Security Token Gate Source Map Passthrough (`insetu/app.py`)**: Expanded `enforce_token_gate()` to allow source map requests (`/sm/` path prefix and `.map` filename suffix) alongside public static assets, eliminating 401 Unauthorized errors during browser devtools debugging sessions.
* **AST Import Hygiene & Linter Alignment (`insetu/app.py`)**: Consolidated standard library imports (`operator`, `re`, `sys`) at the module top-level and aliased runtime function-scoped imports (`_load_config`, `_get_workspace_physics`, `_SettingsManager`) to comply with AST linter rules (`UNALIASED_INLINE_IMPORT`). Purged redundant mid-file re-imports of `os`, `sys`, and `akasa.hooks`.
