## Description
* **Background Worker Signature Standardization (`engine_*.py`)**: Updated worker function definitions across 9 Python extensions (`citations`, `format`, `freshdesk`, `git`, `hooks`, `ingest`, `publish`, `research`, `update`) to include `**kwargs`, absorbing worker execution metadata safely.
* **Explicit Job Category Declarations**: Added explicit `job_category="ui_blocking"` or `job_category="system_background"` kwargs to all `ctx.jobs.submit()` and `submit_one_shot()` calls across 13 backend extension modules (`citations`, `cronic`, `dev`, `format`, `freshdesk`, `git`, `hooks`, `ingest`, `publish`, `research`, `tailscale`, `tracker`, `update`).
* **Notes Logical URI Scheme (`engine_notes.py`, `ext_notes.js`)**: Migrated Notes Library from legacy `.insetu/notes/` physical path strings to canonical `ctx://notes/` logical URIs across volume mounting, path resolution, VFS mutation handlers, notes list APIs, frontmatter generation, and frontend custom editor matchers. Included auto-migration for legacy disk files and database records.
* **UI Compile Progress & Card State Alignment (`ext_flow.js`, `ext_git.js`)**: Refactored `insetu:compile-progress` listeners to evaluate compilation chain step ownership and handle job termination signals. Replaced top-level spinner banners with card-level locking (`isLocked`, `opacity: 0.6`) and dynamic status icons (`⏳`, `⚠️`, `📦`).
* **Git Sweep Optimistic Cleanup (`ext_git.js`)**: Fixed `_getRepoSweepAction` to optimistically remove swept repo files from memory upon task submission, updating UI cards immediately.
