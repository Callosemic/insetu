## Description
* **Atomic VFS Bulk Operations (`POST fs/bulk`, `engine_fs.py`, `fs.js`)**: Consolidated multi-item selection mutations (`executeBulkMove`, `executeBulkArchive`, `executeBulkDelete`) into a single atomic backend dispatch. Replaced sequential N+1 client-side iteration loops with the `FileBulkPayload` REST contract, delegating execution directly to `akasa.vfs.execute_vfs_bulk` to eliminate race conditions and satisfy `BULK_VFS_LOOP_BAN`.
* **Sutram Service Worker & Cache Purge Consolidation (`system.js`)**: Migrated custom Service Worker registration, cache warming, and event loop listeners to the vendorized `bootSutramServiceWorker()` primitive from `/static/vendor/sutram/js/offline.js`. Replaced manual `caches.delete()` loops in `fullRefresh()` with `purgeSutramCaches()`.
* **Pop-Out Telemetry Presence Handshake & Fallback Stream (`api.js`, `system.js`)**: Implemented bidirectional presence ping/pong negotiation over `BroadcastChannel('insetu_telemetry')`. Pop-out windows probe for a parent application shell; if running in standalone mode (no primary window responds), the pop-out lazily establishes a direct SSE connection to `/api/system/stream`. Unified request handling so pop-outs route through `offlineProvider.get` and `executeMutation`.
* **Editable Context Viewport Relaunch (`fs.js`)**: Enhanced pointer relaunch logic in `InSetuEditorProjection` to treat editable virtual contexts (`ctx://notes/`, `ctx://prompts/`) as physical/editable buffers upon window hydration.
* **Dynamic Pop-Out Extension Module Hydration (`system.js`)**: Added deep sub-id resolution in `bootExtensions()` for pop-out windows, automatically fetching and loading extension scripts (`notes`, `tracker`, `prompts`) based on active projection URIs.
* **Universal Mutation Toast Telemetry (`system.js`)**: Enhanced `executeWorkspaceMutation` with automated non-silent toast notifications dispatched via `ToastStore.getState().addToast`, surfacing instant operational feedback for save, move, archive, delete, upload, and bulk actions.
* **CodeMirror Internal Exception Isolation (`system.js`)**: Added defensive error filtering in the global `window.onerror` handler to suppress non-fatal internal CodeMirror 6 exceptions from bubbling to the panic overlay.
* **Declarative Settings Schema & Icon Standardization (`engine_gather.py`, `gather.js`, `bridge.js`)**: Replaced raw inline HTML in `domain_colors` settings schema with declarative `intent_legend` array. Replaced `alert-triangle` with `construction` icon on dirty Gather context cards to comply with `DIRTY_CARD_CONSTRUCTION_ICON_MANDATE`. Streamlined `InSetuBridgeDiffProjection` header presentation.
* **Offline Engine Flow Scope & Outbox Store Mirroring (`api.js`)**: Added `'flow'` to `offlineProvider.isOfflineCapable` and added proactive outbox state mirroring to `OfflineStore`.
