## Description
* **Background Worker Signature Standardization**: Updated worker function signatures across Python extension engines (`citations`, `format`, `freshdesk`, `git`, `hooks`, `ingest`, `publish`, `research`, `update`) to accept `**kwargs`, enabling safe absorption of job execution metadata.
* **Explicit Job Category Declarations**: Added explicit `job_category` declarations (`"ui_blocking"` or `"system_background"`) to all `ctx.jobs.submit()` and `submit_one_shot()` calls across 13 backend extension modules (`citations`, `cronic`, `dev`, `format`, `freshdesk`, `git`, `hooks`, `ingest`, `publish`, `research`, `tailscale`, `tracker`, `update`).
* **Notes Logical URI Scheme Migration**: Standardized the Notes Library (`engine_notes.py`, `ext_notes.js`) on canonical `ctx://notes/` logical URIs instead of legacy `.insetu/notes/` physical strings across volume mounting, path resolution, VFS mutation handlers, notes list APIs, frontmatter generation, and frontend custom editor matchers.
* **UI Compile Progress & Card State Alignment**: Refactored `insetu:compile-progress` listeners in `ext_flow.js` and `ext_git.js` to evaluate step ownership and terminated job statuses. Replaced top-level loading spinners with card-level locking (`opacity: 0.6`, `pointer-events: none`) and dynamic status icons (`⏳`, `⚠️`, `📦`).
* **Git Sweep Optimistic Cleanup**: Fixed `_getRepoSweepAction` in `ext_git.js` to optimistically clear swept files from memory upon task submission, updating UI cards immediately.
