## Description
Track and prioritize architectural infrastructure enhancements for modular development optimization across backend engines and client-side web components.

### Planned Tasks
*   **Backend (Auto-Migration Core):** Introduce automatic validation and schema delta mapping loops inside `InSetuExtension`. Detect structure edits to schema definitions on startup and incrementally issue `ALTER TABLE` operations directly to local cache datastores to minimize manual data migration scripts.
*   **Frontend (Two-Way Form Binding Boilerplate):** Creating declarative forms currently requires verbose, repetitive `@input` event handlers mapping targets back to Zustand stores. Develop a custom Lit directive (e.g., `bindTo(this, '_editForm.title')`) within the `InSetuElement` SDK. This directive will automatically read the bound value, attach the update listener, and request a render, effectively cutting UI form boilerplate in half.
