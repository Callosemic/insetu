## Description
Complete the code-level alignment for the 3-Tier Configuration Cascade (ADR 0040) so behavioral settings can be safely removed from `config.json` without breaking the application shell or bootloader[cite: 1, 12]:

1. **`app.py` & `kernel/utils.py`**: Update `load_workspace_extensions()` and `is_extension_enabled()` to read the active extensions list from `SettingsManager('core_system', ws_id).get('extensions')` instead of `config.json`[cite: 1, 12].
2. **`app.js` & `ui_system_settings.js`**: Update frontend header branding initialization (`instance_title` and `instance_emoji`) to hydrate from `core_system` settings schema endpoints rather than the root `config.json` object[cite: 1, 12].
3. **`routes_system.py`**: Update `api_system_topology` to fetch `category_order` from `SettingsManager('core_system', ws_id)`[cite: 1, 12].

Once these three code paths are updated, `config.json` can be reduced strictly to physical disk topology (`target_repos`, `sub_buckets`, `ignore_dirs`, `include_extensions`, `managed_dirs`)[cite: 12].
