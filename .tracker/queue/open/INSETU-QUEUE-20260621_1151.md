## Description
Research replacing native browser `alert()` and `confirm()` calls with a non-blocking toast notification system.
The system needs to render temporary UI alerts in the corner of the DOM (e.g., "File Saved", "Network Error") that auto-destruct after 3 seconds, keeping the main thread free and the workflow uninterrupted.
