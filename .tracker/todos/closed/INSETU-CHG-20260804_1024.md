## Description
* **VFS Manifest SQLite CQRS Ledger (`engine_gather.py`, `utils_core.py`)**:
  * Registered `vfs_index` schema declaring `manifest_ledger` and `sync_metadata` tables.
  * Converted `hook_request_manifest` and `hook_request_manifest_chunks` to read from `manifest_ledger` via relational SQL queries instead of reading flat `manifest.json` files from disk.
  * Refactored `hook_save_manifest` to perform atomic SQL `INSERT OR REPLACE` and `DELETE` transactions against `manifest_ledger`, updating `last_full_compile_time` in `sync_metadata`.
  * Refactored `_surgically_update_manifest` and `api_clear_quickpacks` to pass targeted tombstone/delta payloads to `ctx.save_manifest(..., is_full_compile=False)`.
  * Updated `get_available_contexts` in `engine_gather.py` and `utils_core.py` to query manifest state via `hooks.emit('request_manifest')`.
  * Migrated the boot-time Offline Mutation Guard in `init_gather_workers()` to read `last_full_compile_time` from `vfs_index.db` (`sync_metadata` table).
* **Manifest Versioning & Delta REST Gateway (`engine_gather.py`)**:
  * Exposed `/api/gather/manifest/version` returning the latest update timestamp (`MAX(timestamp)`).
  * Exposed `/api/gather/manifest/deltas?since=<timestamp>` returning delta objects modified since the specified timestamp.
* **Daemon Reboot REST Endpoint (`routes_system.py`)**:
  * Exposed `/api/system/reboot` and `/api/<workspace_id>/system/reboot` POST endpoints offloading `os.execv` process replacement to a background daemon thread while returning an immediate `200 OK` response.
