## Description
* **SDK V2 Completed Elements:** Migrated Git, Tracker, Research, Citations, Prompts, Flow, and Skills extensions to the `InSetuExtension` and `InSetuElement` base classes.
* **Tier 2 Settings Abstraction:** Ripped out standalone configuration modals from `ext_tracker.js` and `ext_skills.js`. Backend modules now declare a `settings_schema` array, delegating their rendering to the unified OS Settings UI, safely queryable via `ctx.settings.get()`.
* **State Isolation:** Transitioned all extension properties away from floating variables and decoupled `createStore` models, safely confining them to tenant-bound `createExtensionStore` ledgers.
* **UI Cleanups:** Improved chunk visualization in Git and Flow diff components, mapping them to robust Web Component modals.
