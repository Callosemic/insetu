## Description
* **Automation Hooks Extension (`engine_hooks.py` & `ext_hooks.js`)**: Deployed a fully compliant V2 SDK extension enabling IFTTT-style local shell command automation triggered by VFS file mutations (`repo_update`, `repo_bucket_update`). Features persistent SQLite rule storage, off-thread worker execution, execution log tracking, and full Lit/InSetuElement UI integration registered under the `Ctrl` -> `Hooks` sub-navigation track.
* **Workflow Batch Compilation Refinement (`engine_flow.py`)**: Enhanced `compile_batch` path resolution and fallback logic for prompts, diffs, and context artifacts. Safely generates `(NO PENDING DIFFS)` blocks when diff artifacts have not yet been generated without throwing exceptions.
* **Git Sweepable Status Clean-Up (`engine_git.py`)**: Removed redundant `managed_dirs` filter checks in `generate_diff_context` and `_background_sweep_status`, ensuring sweepable status strictly tracks files explicitly excluded by workspace ignore matrices.
* **Prompts Blueprint Clean-Up (`engine_prompts.py`)**: Deprecated redundant `target_repos` argument from `InSetuExtension` instantiation to align with core topology standards.
