## Description
In a multi-workspace layout, it appeared that only the default layout was presenting itself as a PWA, causing ghosting or cross-contamination between environment profiles.

## Notes / Execution Log
* **Resolution:** Implemented localized instance scopes within the `/manifest.json` endpoint payload in `app.py`. We now map `manifest_data["id"]` and the `start_url` to `cfg.get("instance_pwa_scope", "default")`, ensuring complete PWA isolation and correct installation prompts for separate workspace nodes.
