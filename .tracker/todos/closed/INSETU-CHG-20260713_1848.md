## Description
This session establishes a highly optimized, high-performance differential context compilation engine within the core RAG Gather substrate, alongside absolute multi-tenant lifecycle decoupling via stateless frontend shell demolition.

### Key Enhancements
* **Differential Compilation Engine:** Refactored `_background_compile` to implement Git-porcelain (`git status --porcelain -uall`) status delta checks and differential updates via `_surgically_update_manifest()`, eliminating full disk serialization bottlenecks for standard repositories.
* **Unmanaged Workspace Tracking Ledger:** Integrated native `watchdog` capabilities by registering a declarative `workers` database schema tracking `nongit_fixtures` for local, unmanaged, or non-Git file targets.
* **Stateless Shell Demolition (Inversion of Control):** Overhauled `performSoftRefresh` in `app.js` to clear extension views dynamically using generic element prefix scanning (`INSETU-EXT-`), achieving complete structural decoupling of the core micro-kernel from domain extensions.
* **Selective Sweeps & Queue Coalescing:** Added `target_repos` granularity to `generate_context_file` and engineered a queue-coalescing guardrail in the manifest compiler to short-circuit intermediate passes when high-velocity bulk mutations are draining.
* **Full-Bleed Terminal Presentation Layer:** Unified terminal styling by removing legacy `term.css` and implementing a CSS container query lookahead selector (`.screen:has(#sub-term.active)`) to automatically clear layout padding and container scrollbars.
* **Flask Debug Reloader Protection:** Wrapped core `system_boot` hooks inside a `WERKZEUG_RUN_MAIN` environment guardrail to prevent background worker thread-pool double-initialization.
