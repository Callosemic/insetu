## Description
* **Decentralized Manifest Signature Sync (`engine_gather.py`, `routes_system.py`, `engine_topology.py`)**:
  * Exposed `/api/system/deltas` (and `/api/<workspace_id>/system/deltas`) system gateway route in `routes_system.py` leveraging kernel `get_system_deltas`.
  * Implemented `@hooks.on('register_manifest_signatures')` in `engine_topology.py` (`vfs` domain) yielding count and max-timestamp signatures per repository.
  * Implemented `@hooks.on('register_manifest_signatures')` in `engine_gather.py` (`ctx` domain) yielding timestamp signatures per context path.
  * Added surgical fetch REST endpoints `/api/topology/vfs` and `/api/gather/manifest/entry`.
  * Deprecated monolithic `/manifest/deltas` endpoint in favor of decentralized signature providers and surgical entry getters.
* **Topology Boot Chain & VFS Event Gatekeeper (`engine_topology.py`, `engine_gather.py`)**:
  * Shifted workspace boot ownership to `topology` engine via `@hooks.on('workspace_boot')` submitting `boot_scan_task` and emitting `topology_boot_complete`.
  * Re-anchored Gather boot compilation (`init_gather_workers`) to `@hooks.on('topology_boot_complete')` with `force_full="compile_only"` to eliminate redundant disk sweeps on startup.
  * Added gatekeeper path filtering in `buffer_topology_events` to ignore internal system artifacts (`ctx://`, `/data/contexts/`, `/data/diffs/`, `/data/workflows/`, `.insetu/data/`), stopping recursive event loops.
  * Replaced native `open()` in `.gitkeep` file initialization with `execute_vfs_save()` to preserve VFS Event Ledger parity (ADR 0018).
* **Gather Deadlock Elimination & Compiler Tuning (`engine_gather.py`)**:
  * Removed `ctx.sync_vfs_barrier()` during `pre_compile` hook execution to prevent VFS queue deadlocks from stalling the context compiler thread.
  * Tuned Stage 2 Slew Limiter debounce from 15.0s to 12.0s and added job self-destruction for `cmp_del_{workspace_id}` jobs in `_execute_delayed_compile`.
  * Standardized `fallback_path` calculation in `provide_base_workspaces` to consume `pathlib.Path`.
* **Watchdog Filesystem Observer Restoration (`utils_core.py`, `routes_system.py`)**:
  * Restored `start_filesystem_observer` in `utils_core.py` with pre-event-bus directory and pattern filtering for CPU optimization.
  * Simplified `get_system_config` and `api_workspaces` in `routes_system.py` to route strictly through `load_config` and `sniff_tenant_id`.
