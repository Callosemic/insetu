## Description
* **DRY Utility Centralization:** Extracted repository templating and configuration sanitization logic into `utils_core.py` (`get_default_repo_template`, `sanitize_workspace_config`). These are now universally consumed by `routes_fs.py` and `routes_system.py`, completely eliminating redundant schema generation logic across the transport shells.
* **Flexbox Chassis Stabilization:** Eradicated `position: fixed` from structural layout shells (`.top-bar`, `.bottom-bar`, `.sub-tabs-bar`, `.sticky-header`) in favor of resilient `flex-shrink: 0` constraints and `container-type` definitions, natively resolving overflow clipping artifacts and z-index stacking wars.
* **CodeMirror Interactive Overlays:** Transitioned interactive Markdown wiki links from `MatchDecorator` widgets to non-disruptive `hoverTooltip` overlays in `ui_editor.js`. Added a native DOM event handler for seamless checkbox toggling directly within the editor buffer without needing full markdown re-parsing.
* **VFS Navigation Hardening:** Whitelisted `.insetu/prompts/` in the global manifest extraction to guarantee prompt resolution in modal pickers, and refactored `<insetu-vfs-explorer>` to consume the robust `<insetu-file-tree enableSearch=true>` component natively.
