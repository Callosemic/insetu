## Description
* **Settings VFS Write-Barrier Synchronization (`insetu/kernel/extension.py`)**: Integrated `_sync_vfs_barrier()` into `SettingsManager` `set()` and `update()` methods to guarantee read-after-write consistency. Refactored `InSetuExtension.update_settings` route handler to dynamically evaluate `requires_refresh` flags emitted by lifecycle listeners.
* **Target Repo Config Whitespace Sanitization (`insetu/kernel/utils.py`)**: Enhanced `load_config()` to defensively strip leading and trailing whitespace from `repo_dir` and `physical_path` attributes in `target_repos` configurations.
* **Ergonomic VFS Atomic Deletion Helper (`insetu/kernel/vfs.py`)**: Added `delete(filepath, data)` helper method on `VFSTransaction` to streamline queued atomic file deletions.
* **App Shell Compile Polling & Error Isolation (`insetu/static/js/app.js`, `insetu/templates/index.html`)**:
  * Expanded `executeSystemCompile()` polling timeout in `app.js` from 15 seconds to 3 minutes (720 retries) to accommodate large initial workspace topology compilations without timing out.
  * Isolated runtime extension errors in `app.js` via `e.stopImmediatePropagation()`.
  * Guarded global error airbag in `index.html` with `if (window.BOOT_COMPLETE) return;` to prevent post-boot UI overrides during transient non-fatal errors.
  * Updated open modal selector in `initShortcutRouter` and standardized generic settings menu labels and icons.
