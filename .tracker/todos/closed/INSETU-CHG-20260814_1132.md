## Description
* **Default Template Naming Standardization (`insetu/defaults/`, `insetu/cli.py`)**: Renamed default workspace configuration templates to `config_json.txt` and `system_json.txt` to align with the `.txt` extension convention for scaffolding templates, updating `cli.py` profile initialization logic accordingly.
* **WebSocket Module Attribute Hardening (`insetu/app.py`)**: Updated `flask-sock` integration in extension bootloader to safely evaluate `getattr(mod, 'sock', None) is not None`, preventing potential attribute errors during dynamic extension mounting.
* **Synchronous VFS Mutation Event Emissions (`insetu/kernel/vfs.py`)**: Aligned VFS write pipeline and transaction commit handlers to fire `hooks.emit('vfs_mutated', ...)` synchronously within worker threads, guaranteeing immediate event processing across downstream listeners.
* **Shadow DOM & Modal Shortcut Routing Hardening (`insetu/static/js/app.js`)**: Enhanced `initShortcutRouter` in `app.js` to pierce shadow DOM boundaries when determining active elements and accurately capture open modal contexts (`insetu-file-modal`, `yenvui-modal`, `sutram-modal`).
* **Architectural Code Index Synchronization (`CODE_INDEX.md`)**: Synchronized repository topology mappings to reflect template file renames and static asset directory structures.
