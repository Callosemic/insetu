## Description
* **Manifest Domain Partition Parameter (`sdk.js`)**: Enhanced `window.inSetu.utils.extractManifestFiles` with an explicit `domain` parameter (`'vfs'`, `'ctx'`, `'auto'`) to isolate manifest file extraction strictly to physical VFS files or compiled context artifacts.
* **DRY Manifest Domain Extraction (`fs.js`)**: Delegated `fs.js` `extractManifestFiles` to `window.inSetu.utils.extractManifestFiles` and updated `getChunks()` to explicitly target `'ctx'` or `'vfs'` partitions based on virtual URI or file suffix signatures.
* **DRY VFS File View Refreshes (`fs.js`)**: Consolidated repeated manifest updates, VFS mutation event emissions, and system compilation triggers into a centralized `refreshActiveFileViews()` helper.
* **Path Array Replacement Helper (`fs.js`)**: Abstracted duplicated array path replacement logic in `updateManifestState()` into a `_replacePathInArray()` helper.
