## Description
* **Document Publishing Extraction (`engine_publish.py`, `ext_publish.js`)**: Extracted Pandoc document compilation routines from the `format` extension into a standalone `publish` extension. Re-scoped the `format` extension purely to source code beautification (`format-code`).
* **UI Zones Deprecation (`ext_citations.js`, `ext_prompts.js`, `ext_format.js`)**: Removed deprecated `zone:modal-ext-menu` hook integrations across citations, prompts, and formatting extensions, aligning with ADR 0041 presentation decoupling mandates.
* **ExtensionContext Accessor Standardization (`engine_dev.py`, `engine_git.py`, `engine_hooks.py`)**: Replaced raw `ExtensionContext` instantiations with `bp.get_context(workspace_id)` and `kernel_db.get_connection('workers', ...)` to satisfy strict Tier 1 isolation and multi-tenant SDK compliance (`EXTENSION_CONTEXT_ACCESSOR_MANDATE`).
* **Settings Schema Scoping (`engine_skills.py`, `engine_freshdesk.py`)**: Appended explicit `scope: "workspace"` designations to Skills and Freshdesk configuration schemas to satisfy the settings hierarchical scope linter.
* **Notes Editor Modernization (`ext_notes.js`)**: Refactored the `<insetu-ext-notes-editor>` modal layout to project action controls (`🗑️ Delete`, `📝 Raw Edit`, `💾 Save`) explicitly into the `<sutram-modal>` footer slot. Bound `@editor-dirty` state to the Lit property `_isDirty` for reactive Save button rendering.
* **Flow Batch Viewer Update (`ext_flow.js`)**: Added the `file-view-parts` entity action to the `baseFile` view inside the Flow batch workflow modal to properly support multi-part context payloads.
