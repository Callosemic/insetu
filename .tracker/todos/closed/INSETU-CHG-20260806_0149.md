## Description
* **Sutram Presentation Controls Migration (`ext_flow.js`, `ext_ingest.js`)**: Replaced raw HTML `<input>`, `<select>`, `<textarea>`, and radio buttons with `<sutram-input>`, `<sutram-select>`, `<sutram-toggle>`, and `<sutram-textarea>`. Replaced raw feedback containers with `<insetu-spinner>` and `<insetu-empty-state>`.
* **Date Formatting Standardization (`ext_dev.js`, `ext_freshdesk.js`, `ext_hooks.js`)**: Standardized date and time string rendering to consume `this.utils.formatDate()` across all active extension views, resolving `DATE_FORMATTING_MANDATE` linter warnings.
* **Extension Name Getter Enforcement (`ext_favorites.js`, `ext_freshdesk.js`, `ext_ingest.js`)**: Injected `static get extensionName()` getters across Web Components inheriting from `InSetuElement` to ensure deterministic API routing and component isolation.
* **Virtual URI Scheme Sanitation (`engine_flow.py`, `engine_format.py`, `ext_flow.js`, `engine_prompts.py`)**: Purged legacy `system://` URI string handling across Flow, Document Formatting, and Prompts engines in favor of standardized `ctx://` URI schemes.
* **Transactional VFS Abstraction (`engine_flow.py`, `engine_git.py`)**: Replaced direct `VFSTransaction` instantiations and raw `execute_vfs_delete` calls with context-bound `ctx.vfs.walk()` and `ctx.vfs.save(..., data={"action": "delete"})` calls.
* **Format Engine Manifest Decoupling (`engine_format.py`)**: Refactored `run_formatter()` to query the `ExtensionContext('format', 'default').manifest` property instead of performing manual file reads on legacy `manifest.json` files.
* **Extension File Relocations (`tailscale`, `notes`)**: Standardized extension layout locations by placing `ext_tailscale.js` and `ext_notes.js` inside their respective extension root directories (`insetu/extensions/tailscale/` and `insetu/extensions/notes/`).
