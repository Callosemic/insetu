## Description
This changelog records the absolute, deterministic record of all uncommitted local modifications finalized during this session, addressing architecture alignment, frontend state leakages, and core utility standardization.

### Implemented Enhancements & Refinements

* **Unified Repository Filtering Engine (`ext_git.js`):** Added robust repository filtering parameters (`pinnedRepos`, `allRepos`, and `_showFilters`) directly into the Git pending diffs extension. Enabled real-time tree and sweepable state filtering mapped to the centralized `AppStore`, accompanied by an automatic click-outside listener to dismiss the filter box safely.
* **Simplification of Localized State (`ext_tracker.js`, `ext_citations.js`):** Discarded obsolete local bucket and repository filter mechanisms from individual extension stores (`KanbanStore`, `CitationStore`). These components now stream filtering definitions fluidly from the global application scope, reducing memory overhead and removing state fragmentation.
* **Strict DOM-Based View Isolation (`ext_tracker.js`, `ext_skills.js`):** Replaced leaky `localStorage` tab layout synchronization checks with local DOM containment validation (`this.closest('.sub-tab-content')?.classList.contains('active')`). This prevents background tab instances from triggering out-of-order component updates or overlay modal conflicts.
* **Centralization of Clipboard Utilities (`ext_flow.js`, `ext_prompts.js`, `ext_research.js`):** Cleaned up duplicate inline browser `navigator.clipboard` logic by routing text capture interactions explicitly through standard SDK helper structures (`this.utils.copyRawText`, `this.utils.copyToClipboard`).
* **Declarative Virtual Context Integration (`engine_flow.py`):** Extended the initialization of the `flow` Python extension blueprint to specify declarative `virtual_contexts` metadata, ensuring deterministic indexing of workflow batch automation payloads within the central VFS manifest.
