## Description
* **Browse Modal Execution Fix:** Eradicated the legacy, hardcoded `<div id="browse-modal">` structure from `index.html`. This forces `fs.js` to correctly spin up the `<insetu-modal>` Web Component programmatically, restoring the "Browse" button functionality across Gather view cards and adhering to our transient DOM injection standards.
* **Card Overlay Click-Through:** Modified the `<insetu-card>` action overlay CSS to use `pointer-events: none` on the background while retaining `pointer-events: auto` for the slotted action buttons. This allows ambient clicks to successfully pass through to the main card area.
* **Streamlined Card Interaction:** Removed the `e.stopPropagation()` trap inside `_handleMainClick`. Clicking a file card while its action overlay is open now natively closes the overlay *and* triggers the expected file-open operation simultaneously.
