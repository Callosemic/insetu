## Description
This release unifies filesystem mutation event signatures across backend and frontend layers, integrates yenVUI editor and toolbar primitives, introduces Web Component DOM node caching in the App Shell, and updates architectural fitness function guardrails.

### Key Enhancements & Refinements
* **Unified VFS Lifecycle Event Bus (`context.py`, `routes_fs.py`, `hooks.py`, `fs.js`, `bridge.js`):** Replaced legacy fragmented event subscriptions (`post_file_save`, `post_file_delete`, `vfs_transaction_committed`) with the unified `vfs_mutated` / `zone:vfs-mutated` event bus payload containing a normalized array of mutation objects (`[{ filepath, operation, ignore_ledger }]`).
* **yenVUI Editor Integration (`ui_editor.js`, `app.js`):** Refactored `<insetu-markdown-editor>` to consume the standalone `<yenvui-editor>` component, stripping dynamic language import boilerplate and inline CodeMirror 6 setup from the core chassis.
* **yenVUI Toolbar & Primitive Cleanup (`ui_primitives.js`, `ui_file_tree.js`, `gather.js`):** Deprecated `<insetu-standard-toolbar>` and `<insetu-category-section>` in favor of `<yenvui-toolbar>` and `<yenvui-category-section>`.
* **App Shell Component Caching (`ui_app_shell.js`):** Implemented a Map-based DOM node cache (`_componentCache`) in `<insetu-app-shell>` to preserve Web Component instances and active socket connections (e.g., Terminal PTY sessions) across tab switches.
* **Yomama Sync Bridge Regex Anchoring & Status Granularity (`engine_bridge.py`, `bridge.js`):** Enhanced Yomama chunk status reporting (`genesis`, `no_op`, `idempotent`, `error`, `success`) and sanitized multiline log formatting regexes.
* **Linter Guardrail Enforcement (`fitness_functions.py`):** Added `LEGACY_HOOK_BAN` and `LEGACY_UI_HOOK_BAN` fitness functions to statically catch deprecated hook registrations.
