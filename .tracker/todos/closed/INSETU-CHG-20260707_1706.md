## Description
* **Config Editor Migration:** Upgraded `ext_config.js` to the `InSetuExtConfig` LitElement, replacing imperative DOM creation loops with reactive HTML templates and `sharedStyles` shadow DOM encapsulation.
* **Flow & Prompts Upgrades:** Migrated `ext_flow.js` and `ext_prompts.js` to fully compliant LitElements, adopting the `static styles = [sharedStyles]` array for styling isolation.
* **Tracker Card Adoption:** Refactored `ext_tracker.js` to utilize the global `<insetu-card>` web component for rendering Kanban tickets, eliminating manual `document.createElement('div')` stacking.
* **Citations Text Insertion Decoupling:** Replaced manual `mdeInstance.codemirror` and `textArea` mutation strings inside `ext_citations.js` with the unified `insertTextAtCursor` OS utility to prevent context leakage.
* **View Cleanups:** Stripped redundant "Refresh" buttons from `ext_term.js` and `ext_git.js` in favor of declarative `zone:force-refresh` and `subtab-changed` OS event hooks.
