## Description
This release introduces the Global Multi-Select Selection Tray ("Shopping Cart"), refactors legacy Quickpacks into a non-blocking selection worker, modularizes architectural fitness functions, and hardens background polling resilience.

### Core Refinements & Enhancements
* **Global Multi-Select Selection Tray (`store.js`, `app.js`, `ui_app_shell.js`, `ui_file_tree.js`)**:
  - Established `SelectionStore` in `store.js` using Zustand to track heterogeneous multi-entity selection (`selectedItems` Map, `toggleSelection`, `clearSelection`).
  - Created the `<insetu-selection-tray>` Web Component and mounted it directly inside the `<insetu-app-shell>` header actions slot.
  - Upgraded `<insetu-card>` and `<yenvui-card>` with reactive `selected` and `disableSelection` Lit properties and `@yenvui-card-select-toggled` event handling.

* **Batch Action Engine & Non-Blocking Selection Worker (`gather.js`, `engine_gather.py`, `fs.js`)**:
  - Registered declarative `batchActions` (`Download`, `Share`) in `ExtensionRegistry`.
  - Refactored legacy synchronous quickpacks into `@gather_bp.worker("pack_selection_task")` running off-thread in background worker queues.
  - Added `InSetuExtGatherActions` dropdown for clearing ephemeral quickpacks (`gather/clear_quickpacks`).

* **Modular Architectural Fitness Subsystem (`tests/fitness/`, `fitness_functions.py`)**:
  - Deconstructed monolithic `fitness_functions.py` into a structured `tests/fitness/` package (`core.py`, `rules_python.py`, `rules_javascript.py`).
  - Added linter rules enforcing SDK global listeners (`GLOBAL_LISTENER_MANDATE`), custom event dispatching (`CUSTOM_EVENT_DISPATCH_MANDATE`), and banned direct SDK imports in extensions.

* **Network Resilience & SDK Teardown Hygiene (`sdk.js`, `app.py`)**:
  - Hardened `window.inSetu.utils.pollJob` to handle 401 token expiration with auto re-handshake and 404 missing job errors gracefully.
  - Fixed basename path extraction in `app.py` `download_file` handler.
