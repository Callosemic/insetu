## Description
* **ADR 0041 Legacy String Hooks Deprecation (`fs.js`, `ui_editor.js`, `gather.js`, `sdk.js`)**: Replaced all remaining legacy `zone:*` string hooks with canonical `insetu:*` event bus hooks. Removed deprecated `uiHooks` definition from `files` extension registration and removed `executeUIHook` fallback from `window.inSetu.events.emitHook`.
* **DRY Artifact Size Formatting Centralization (`gather.js`, `sdk.js`)**: Centralized `formatArtifactSize(meta)` in `window.inSetu.utils` and exposed it via `InSetuElement.prototype.utils`, replacing duplicated file size calculation logic in `InSetuExtGather`.
* **Client Gateway Semantic Method Routing (`api.js`, `config.js`, `fs.js`)**: Migrated raw `window.inSetu.api.system(...)` and `window.inSetu.api.workspace(...)` call sites across `config.js` and `fs.js` to semantic shorthand methods (`.get()`, `.post()`).
* **Debounce Verification Token Hardening (`sdk.js`)**: Refactored `ExtensionRegistry.utils.debounceVerifyFile` to use token counter tracking (`_verifyTokens`) instead of `clearTimeout` handles (`_verifyTimers`), avoiding linter warnings and preventing async verification race conditions.
* **SDK Utils Accessor Expansion (`sdk.js`, `sdk_v2_contracts.md`)**: Expanded `InSetuElement.prototype.utils` getters to include `debounce` and `formatArtifactSize`, updating SDK interface contracts documentation accordingly.
