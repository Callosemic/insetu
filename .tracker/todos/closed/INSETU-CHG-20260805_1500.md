## Description
* **Decoupled Topology Core Engine (`engine_topology.py`)**:
  * Established `topology` core engine (`InSetuExtension`) backed by `topology_ledger` (`filepath`, `repo`, `bucket_id`, `is_tracked`, `timestamp`) as the Single Source of Truth (SSOT) for physical workspace file inclusion and bucket routing.
  * Relocated `get_valid_workspace_files()` and `resolve_file_bucket()` out of `utils_core.py` into `engine_topology.py`.
  * Implemented Stage 1 Slew Limiter (`buffer_topology_events`) listening to `vfs_mutated` events to buffer high-velocity I/O mutations into `topology_event_buffer` and execute `resolve_topology_task` off-thread with an absolute settlement delay.
  * Implemented `resolve_topology_buffer()` which updates `topology_ledger` and emits `topology_resolved` carrying `dirty_repos`, `dirty_buckets`, and `events`.
  * Registered `@hooks.on('force_topology_scan')` for physical disk scans and `@hooks.on('request_vfs_manifest')` returning the `vfs` portion of the partitioned manifest.
  * Added `get_omniscient_workspace_files()` SQL query against `topology_ledger` as a fast replacement for `os.walk` in the Yomama Sync Bridge.
* **Yomama Sync Bridge Telemetry & Anchor Failure Diffing (`bridge_vfs.py`)**:
  * Re-anchored `get_omniscient_workspace_files` imports to `insetu.core.topology.engine_topology`.
  * Updated fuzzy patch resolution to auto-skip single-candidate replacement blocks already matching the target replace block state.
  * Added Step e.5 Anchor Failure Diff Generation: calculates `difflib.ndiff` on search anchor mismatches, base64-encodes the diff into `syntax_error`, and flags the patch with `status = "needs_confirmation"` and `resolution_type = "anchor_failed"`.
* **Cartographer Topology Ledger Alignment (`cartographer.py`)**:
  * Re-anchored `get_valid_workspace_files` imports to `engine_topology`.
  * Updated Pass 2 of `map_repositories()` to query SSOT `topology_ledger` directly via SQL instead of executing physical disk / Git walks.
* **Gather Engine Decoupling & Stage 2 Slew Limiter (`engine_gather.py`)**:
  * Replaced `_process_vfs_ledger` daemon with Stage 2 Slew Limiter `@hooks.on('topology_resolved')` (`handle_topology_resolved`), scheduling a delayed RAG compilation (15s debounce) to prevent event loop thrashing during active editing.
  * Migrated `init_gather_workers` from `@hooks.on('system_boot')` to tenant-scoped `@hooks.on('workspace_boot')`.
  * Updated `provide_base_workspaces()` to query `topology_ledger` for file lists instead of performing disk walks.
  * Updated `_pack_selection_worker()` to handle `vfs://` and `ctx://` URIs cleanly when reading files.
  * Updated `api_manifest_deltas` to return partitioned delta structure `{"deltas": {"ctx": deltas}, "timestamp": ...}`.
* **VFS URI & Path Resolution Normalization (`routes_fs.py`, `routes_system.py`, `utils_core.py`)**:
  * Updated `resolve_vfs_file()` and `hook_vfs_resolve_path()` to strip `vfs://` prefixes and convert `system://` to `ctx://`.
  * Updated `api_system_manifest()` to emit `request_manifest` (`ctx`) and `request_vfs_manifest` (`vfs`) returning `{"vfs": ..., "ctx": ...}`.
  * Removed decoupled functions (`get_valid_workspace_files`, `get_omniscient_workspace_files`, `resolve_file_bucket`) from `utils_core.py`.
