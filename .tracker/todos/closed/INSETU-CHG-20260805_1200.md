## Description
* **Flow Context Tombstoning & Vacuuming (`engine_flow.py`)**: Enhanced `_background_compile_workflows` with stale context key detection. Active workflow keys are cross-referenced against `current_manifest`; orphaned workflow keys are assigned `None` in `manifest_deltas` to register tombstone entries in the SQLite CQRS manifest ledger (`vfs_index.db`). Unreferenced workflow `.txt` artifacts are physically purged via `execute_vfs_delete`.
* **Git Diff Vacuuming & Manifest Synchronization (`engine_git.py`)**: Updated `generate_diff_context` to identify stale `_diffs.txt` keys in `working_manifest`. Assigned tombstone `None` values to `manifest_deltas` for removed target repos/buckets and physically deleted unreferenced diff files in `diffs_dir` using `VFSTransaction.walk` and `execute_vfs_delete`.
