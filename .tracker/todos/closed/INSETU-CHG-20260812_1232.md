## Description
* **Sutram Form Control Migration (`ui_system_settings.js`, `config.js`)**: Replaced raw HTML `<input type="text">`, `<input type="checkbox">`, and `<select>` controls in `InSetuSystemSettings`, `InSetuWorkspaceEditor`, and `InSetuExtConfig` with `<sutram-input>`, `<sutram-select>`, `<sutram-toggle>`, and `<sutram-async-btn>` primitives.
* **Action Bar Scroll Consolidation (`ui_editor.js`, `ui_primitives.js`)**: Consolidated horizontal action bar scrolling by delegating directly to `<sutram-entity-actions ?scrollable=${true}>`, purging redundant `.action-bar-scroll` flexbox styles.
* **File Tree Memoization & String Slicing (`ui_file_tree.js`)**: Memoized file tree generation in `InSetuFileTree` using `_cachedTree` with `willUpdate` invalidation on property changes. Replaced dynamic regex prefix stripping (`new RegExp(...)`) with high-performance `startsWith()` and `slice()` operations.
* **Modal Style Cleanup (`ui_system_settings.js`, `fs.js`)**: Removed deprecated custom modal backdrop inline styles (`--modal-backdrop`) across settings and VFS modal components.
