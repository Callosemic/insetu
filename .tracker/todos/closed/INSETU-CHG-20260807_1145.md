## Description
* **Sutram Collapsible Grouping Migration (`ext_flow.js`, `ext_git.js`)**: Migrated Flow and Git Diffs views from legacy category list/section wrappers to standardized `<sutram-collapsible>` groups sorted by `categoryOrder`. Refactored card detail text bindings to use `.detailPrefix`, `.detailText`, and `.detailSuffix` properties.
* **Notes Editor Modernization & Deletion Handler (`ext_notes.js`)**: Updated `<insetu-ext-notes-editor>` and modals with `:host { display: contents; }` CSS, borderless auto-resizing `<sutram-textarea>` title control, and explicit `@insetu:editor-delete` deletion handler via `sys.executeWorkspaceMutation('fs/delete', ...)`.
* **Tracker Ticket Editor & Smart Bucket Resolution (`ext_tracker.js`)**: Replaced manual title textarea height adjustments with `<sutram-textarea>`, modernized modal form fields using `meta-grid` and `bindStoreInput` helpers, integrated frontmatter editor delete/raw edit actions, and implemented smart bucket resolution in `_openNewTaskModal` based on active bucket filters.
* **Prompts Entity Action Cleanup (`ext_prompts.js`)**: Removed legacy `copy-prompt` entity action from extension registry, delegating prompt text copying to standard entity actions.
