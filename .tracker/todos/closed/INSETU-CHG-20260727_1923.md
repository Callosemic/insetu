* **Toast Container Web Component (`ui_primitives.js`)**: Created `<insetu-toast-container>` extending `InSetuElement` (`static get extensionName() { return 'toast'; }`). Subscribes to `ToastStore` and renders `<yenvui-toast-container>` with automated `#insetu-toast-root` DOM mounting.
