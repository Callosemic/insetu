## Description
* **InSetuElement Lifecycle Hook Harmonization (`insetu/static/js/core/sdk.js`, `fs.js`, `bridge.js`, `config.js`, `gather.js`)**: Standardized tenant workspace hydration hook from `onWorkspaceChanged` to `onWorkspaceLoad`, ensuring predictable initialization across all extending components.
* **View Activation Lifecycle Hook (`insetu/static/js/core/sdk.js`)**: Added `onViewActivated()` hook listeners for `insetu:tab-changed` and `insetu:subtab-changed` to enable lazy view loading.
* **Deep Search Polling Offload (`insetu/static/js/core/fs.js`)**: Replaced unmanaged `while(true)` polling loop in `executeDeepLinkSearch` with `window.inSetu.utils.pollJob`, eliminating blocked thread risks.
* **Event Bus Zone Deprecation (`insetu/static/js/core/fs.js`)**: Migrated legacy `zone:file-fetch-url` to `insetu:file-fetch-url` per ADR 0041.
* **Modal Focus Re-Center Guard (`insetu/static/js/core/fs.js`)**: Guarded `dialog.close()` / `dialog.showModal()` in `InSetuFileModal.updated` to prevent dialog bouncing during text input.
* **Sub-Bucket ID Auto-Assignment (`insetu/static/js/core/config.js`)**: Ensured new sub-buckets receive deterministic IDs (`b.id || bucket_${Date.now()}`) and slugified title updates.
* **System Settings UI Refinement (`insetu/static/js/core/components/ui_system_settings.js`)**: Cleaned up system dropdown styling, labels, and item groupings.
* **Active Extension Filter Guard (`insetu/static/js/core/sdk.js`)**: Updated `ExtensionRegistry` filter predicate and `getLayoutSlots` to safely handle uninitialized `window.ACTIVE_EXTENSIONS` arrays.
