## Description
* **PyPI Initial Release Pipeline (`engine_update.py`)**: Added `first_release_task` background worker and `first_release` POST endpoint to build distribution packages (`python -m build`), validate non-Python extension assets (`insetu/extensions/`) inside wheel zip archives, execute `twine check`, upload to PyPI using PyPI API tokens (`TWINE_PASSWORD`), tag initial release in Git (`v{version}`), and push tag to remote origin.
* **PyPI Registry Publishing Verification (`engine_update.py`)**: Enhanced `_background_status_task` to query the PyPI.org JSON API (`https://pypi.org/pypi/{package_name}/json`) off-thread to verify if the active version is published on PyPI, returning `pypi_published` and `package_name` flags in status artifacts.
* **VCS Release Configuration Management (`engine_update.py`)**: Expanded `_background_update_toml_config` worker to support toggling `vcs_release` (boolean) in `pyproject.toml` under `[tool.semantic_release]`.
* **Semantic Update UI Hardening & Release Log Viewer (`ext_update.js`)**: Updated `UpdateStore` and `InSetuExtUpdate` to support initial PyPI release triggers, `vcs_release` configuration checkboxes with GitHub API token warning notices, dynamic step 2 button states for PyPI publishing vs. standard release publishing, and modal execution log output viewing.
