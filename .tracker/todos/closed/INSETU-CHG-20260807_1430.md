## Description
* **Extension Force-Refresh Consolidation**: Migrated tab re-selection / force-refresh behavior across 7 active extensions (`flow`, `freshdesk`, `git`, `notes`, `prompts`, `research`, `skills`) away from legacy `zone:force-refresh` UI hooks in favor of the native `InSetuElement.prototype.onForceRefresh()` class lifecycle method.
* **UI Hook Noise Reduction**: Stripped deprecated `zone:force-refresh` registrations from extension `uiHooks` maps, ensuring clean event isolation and preventing redundant event bus dispatches.
* **Deterministic Re-Hydration**: Aligned `onForceRefresh()` implementations to invoke targeted store clearing and re-fetching logic (`fetchBatches`, `fetchTickets`, `generateDiffs`, `fetchNotes`, `fetchPrompts`, `fetchState`, `fetchPlaylist`/`fetchAllSkills`).
