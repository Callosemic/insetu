## Description
* **Gather Inversion of Control (IoC) Refactor (`engine_gather.py`)**: Transitioned RAG context compilation from monolithic disk-walking to a declarative topology contract via `@hooks.on('gather_declare_topology')`. Extensions yield topology schemas specifying `generator_callback` and `recall_callback`, decoupling the Gather engine from domain directory physics.
* **Compilation Step Chaining (`engine_gather.py`)**: Introduced `@hooks.on('register_compilation_steps')` pipeline orchestration in `api_gather_submit` and `_process_vfs_ledger`. The Gather engine sorts steps topologically, dispatches the chain through background worker jobs, and emits `compilation_sequence_complete` upon final step completion.
* **Cartographer Completion Trigger (`cartographer.py`)**: Registered `@hooks.on('compilation_sequence_complete')` listener `hook_cartographer_compile_complete` to trigger `cartographer/map_task` repository mapping automatically after context compilation finishes.
* **Chunk Slicing Overflow Defense (`engine_gather.py`)**: Enhanced `compile_context_payload` to slice single monolithic text blocks exceeding `max_context_size_kb` into 95% segment chunks, eliminating single-block context file overflow bugs.
* **Stateless Workspace Route Cleanup (`routes_system.py`)**: Removed `active_workspace` global state persistence in `workspaces.json` to enforce client-driven Zustand store routing (UDF), and added `workspace_shutdown` event emissions during workspace swaps and deletions.
* **Topology-Driven Context Resolution (`utils_core.py`)**: Refactored `get_available_contexts` to inspect `gather_declare_topology` declarations statelessly. Hardened `resolve_logical_path` against infinite loops during redundant repo prefix stripping and provided fallback anchor paths for new file creation.
