## Description
* **Terminal Interface Upgraded**: Removed the complex legacy multi-process `ttyd` binary orchestration model, sequential port-probing loops, and associated system lifecycle boot hooks from `engine_term.py`.
* **Native PTY Pipeline Integration**: Developed an integrated full-duplex PTY pipeline using Python's native `pty`, `select`, and `fcntl` modules combined with `flask_sock` WebSockets. Added full support for declarative canvas resizing events driven via JSON wire packets.
* **Frontend Component Graduation**: Completely refactored `ext_term.js` to inherit from `InSetuElement`, wrapping client connections in a high-performance `Xterm.js` canvas with `FitAddon`. Implemented defensive `MutationObserver` theme switching logic for Dark, Light, and E-Ink palettes.
* **Tracker Housekeeping Automation**: Automated the silent background task execution for archiving and logging stale tickets inside `engine_tracker.py` by integrating with the `insetu.workers` metronome ledger to execute every hour. Optimized compilation footprints by executing housekeeping strictly during deep full-sweep events.
