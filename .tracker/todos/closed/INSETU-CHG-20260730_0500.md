## Description
* **Three-Tier Namespace Alignment (All 13 Extensions)**: Systematically refactored all backend extension engines (`engine_citations`, `engine_favorites`, `engine_flow`, `engine_format`, `engine_freshdesk`, `engine_git`, `engine_hooks`, `engine_ingest`, `engine_prompts`, `engine_research`, `engine_skills`, `engine_term`, `engine_tracker`) to import from Tier 1 (`insetu.kernel.utils`, `insetu.kernel.hooks`, `insetu.kernel.workers`) and Tier 2 (`insetu.core.sdk`) modules.
* **Frontend SDK V2 & Sutram Vendor Alignment**: Updated all 13 frontend extension Lit components (`ext_*.js`) to import from `../core/sdk.js` and `../core/shared_styles.js`.
* **VFS Non-Blocking I/O Hardening (`engine_flow.py`)**: Replaced synchronous `shutil.move` and `shutil.rmtree` file archiving operations with non-blocking `ctx.vfs.read` and `ctx.vfs.save` transactions.
* **VFS Barrier & Parts Modal Integration (`engine_git.py`, `ext_git.js`, `ext_flow.js`)**: Replaced direct internal `_VFS_WRITE_QUEUE` calls with `ctx.sync_vfs_barrier()` and refactored multi-chunk view triggers to route through `this.vfs.openPartsModal` and `insetu:vfs:view-parts`.
* **Terminal Engine Visibility & PTY Resiliency (`engine_term.py`, `ext_term.js`)**: Wrapped terminal initialization in `IntersectionObserver` and `ResizeObserver` to prevent 0x0 geometry calculation errors on tab swaps, added thread locks to WebSocket frames during disconnects, and added diagnostic messaging for Tailscale/HTTPS WebSocket proxy errors.
