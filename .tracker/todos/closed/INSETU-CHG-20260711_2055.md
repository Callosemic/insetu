## Description
* **Core SDK Migration**: Upgraded `citations`, `research`, and `term` extensions to `InSetuExtension` (Backend) and `InSetuElement` (Frontend) to enforce spatial physics and tenant isolation.
* **Asynchronous Jobs Integration**: Offloaded heavy operations (Citation catalog search, Git sweep status/push, Research context export) to the background worker Metronome using `ctx.jobs.submit()` and `this.api.pollJob()`.
* **VFS Parity**: Stripped raw `open()`, `os.walk`, and `os.remove` calls from `engine_tracker.py` and `engine_git.py`, enforcing `ctx.vfs.read`, `ctx.vfs.walk`, and `execute_vfs_delete`.
* **UDF / DOM Hygiene**: Removed manual DOM manipulation (e.g., toggling spinner visibility by ID) in `ext_git.js` and editor text replacement in `ext_citations.js` in favor of state-driven updates and OS-level API bridges (`window.getEditorContent`).
* **Database Optimization**: Refactored the citations index to leverage native SQLite `json_extract`, completely removing the legacy Python memory cache loop.
