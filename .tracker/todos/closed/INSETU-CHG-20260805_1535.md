## Description
* **Virtual URI Scheme Normalization (`ctx://`)**: Standardized virtual context URIs across `flow`, `git`, `format`, `prompts`, and `favorites` extensions from `system://` to `ctx://`.
* **Topology Ledger SSOT Integration**: Refactored `engine_git.py` (`_background_sweep_status`) and `engine_hooks.py` (`process_vfs_triggers`) to query `topology_ledger` directly and listen to `@hooks.on('topology_resolved')`, eliminating redundant filesystem inspections.
* **Manifest CQRS Schema Alignment**: Updated `ext_flow.js` and `ext_git.js` to read context entries from `AppStore.manifest.ctx`.
* **VFS Transactional Deletion**: Replaced raw `execute_vfs_delete` calls in `engine_flow.py` with transactional `vfs.save(..., data={"action": "delete"})`.
* **Dev Dashboard Telemetry Enhancements**: Added `zone:vfs-mutated` debounced refresh handlers to `ext_dev.js` and normalized `init_dev_workers` hook signature.
