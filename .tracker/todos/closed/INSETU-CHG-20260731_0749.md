## Description
* **Sutram Vendor Path Normalization (`app.js`, `index.html`, `rules_javascript.py`)**: Normalized relative imports for vendorized Sutram primitives to explicitly target `vendor/sutram/js/`. Updated fitness function rules in `rules_javascript.py` to ban legacy `<yenvui-*>` tags/events (`BANNED_YENVUI_TAG_BAN`) and enforce explicit `sutram/js/` import paths (`VENDOR_SUTRAM_JS_SUBDIR_MANDATE`).
* **VFS Idempotency Gatekeeper (`vfs.py`)**: Injected an idempotency check inside `execute_vfs_save_physical()` that compares incoming file content against existing disk content, dropping phantom writes before touching hardware storage or emitting redundant `vfs_event_log` events.
* **Core Module Event Bus Authorization (`hooks.py`, `utils.py`)**: Updated `HookRegistry._is_authorized()` and `utils.is_extension_enabled()` to explicitly recognize Tier 1 and Tier 2 core system modules (`bridge`, `gather`, `cartographer`, `config`, `fs`, `system`, `workers`, `auth`), guaranteeing core lifecycle event callbacks bypass tenant extension config checks.
* **Status Bar Sync State Integration (`app.js`)**: Wired `setSyncStatus` helper to broadcast `sutram-sync-status` events, connecting VFS mutation lifecycle hooks and context compilation passes directly to the status bar UI indicator.
* **Database Connection & Styles Cleanup (`db.py`, `style.css`, `CODE_INDEX.md`)**: Reordered connection parameter lookups in `get_connection()` to prioritize cache hits, removed deprecated CodeMirror/EasyMDE and e-ink CSS overrides, and updated `CODE_INDEX.md`.
