## Description
* **Context Payload Timestamp Stamping (`engine_gather.py`)**: Prepended ISO timestamp header (`Generated: YYYY-MM-DD HH:MM:SS`) to compiled context payloads to provide temporal auditing across generated RAG artifacts.
* **Centralized Artifact Vacuuming (`engine_gather.py`, `utils_core.py`)**: Refactored step 3 of `generate_context_file` to delegate artifact garbage collection to `utils_core.vacuum_manifest_artifacts()`, eliminating duplicated file-sweeping loops across engines.
* **Smart Chunk Path Auto-Resolution (`routes_fs.py`, `utils_core.py`)**: Enhanced `resolve_vfs_file` and `hook_vfs_resolve_path` to query `request_manifest` when evaluating un-prefixed filenames. Automatically classifies matching chunk names as virtual artifacts and resolves their physical URI paths (`ctx://contexts/`, `ctx://diffs/`, `ctx://workflows/`).
