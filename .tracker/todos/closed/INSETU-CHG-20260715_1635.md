## Description
The multi-file multipart parser introduced within `routes_fs.py` provides a highly stable, off-thread file ingestion routine. However, leaving it marooned inside the file system transport shell creates a domain silo, forcing future extensions that require binary stream ingestion (e.g., Research Inbox bulk imports) to duplicate the form processing boilerplate.

### Planned Generalization
* **Utility Centralization**: Abstract the `request.files` multi-pass secure name evaluation and physical target layout mapping logic out of `routes_fs.py`.
* **Core Core Migration**: Package the routine into a reusable method inside `utils_core.py` (e.g., `utils_core.process_multipart_upload_stream(request_obj, dest_dir, workspace_id)`).
* **Framework Integrity**: Ensure the abstracted helper loops securely through the database transaction logs to preserve absolute VFS Event Ledger parity natively.
