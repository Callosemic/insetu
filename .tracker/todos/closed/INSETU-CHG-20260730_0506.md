## Description
* **Core Substrate & Route Relocation (`insetu/core/`)**: Relocated Tier 2 Developer OS engines (`bridge`, `gather`, `cartographer`) and system routes (`routes_fs.py`, `routes_system.py`) to `insetu/core/` to enforce physical Three-Tier Architecture boundaries (ADR 0029).
* **Frontend Core Substrate Migration (`insetu/static/js/core/`)**: Migrated core client JS modules (`api.js`, `bridge.js`, `gather.js`, `config.js`, `fs.js`, `sdk.js`, `store.js`, and `components/`) to `insetu/static/js/core/`.
* **VFS Logical Path Resolution Hook (`insetu/core/utils_core.py`)**: Registered `@hooks.on('vfs_resolve_path')` (`hook_vfs_resolve_path`) in `utils_core.py` to resolve `repo::path` boundaries and `system://` URIs natively within the Kernel VFS without introducing Tier 1 to Tier 2 circular dependencies.
* **Kernel & SDK Import Alignment**: Refactored import targets across `bridge_fuzzy.py`, `bridge_vfs.py`, `engine_bridge.py`, `cartographer.py`, `engine_gather.py`, and `utils_core.py` to import directly from `insetu.kernel.*` and `insetu.core.*`.
* **Bridge Parser Deprecation (`insetu/core/bridge/bridge_parser.py`)**: Marked legacy `bridge_parser.py` as deprecated, delegating block parsing strictly to the Tier 1 Kernel `parse_blocks` utility.
