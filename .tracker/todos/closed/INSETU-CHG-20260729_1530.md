## Description
* **Dynamic Importmap Resolver (`insetu/app.py` & `index.html`)**: Implemented `build_dynamic_importmap()` in the bootloader, scanning core `vendor.json` and active extension `vendor.json` manifests to generate browser-native HTML importmaps with compound SemVer evaluation (`>=`, `<=`, `&&`) and scoped fallback routes.
* **Extension Static Asset Serving (`insetu/app.py`)**: Added `/static/extensions/<ext_name>/<path:filename>` endpoint with path traversal security checks to serve vendored libraries and static assets directly from extension subdirectories.
* **Core Vendor Baseline (`insetu/static/vendor.json`)**: Added baseline vendor manifest declaring localized dependencies for `lit` and `@codemirror` packages.
* **CDN Import Ban Fitness Rule (`tests/fitness/rules_javascript.py`)**: Codified `BANNED_CDN_IMPORT` static analysis check to flag hardcoded imports from external CDNs (`esm.sh`, `cdn.jsdelivr.net`, `unpkg.com`), enforcing offline resilience.
* **Legacy Domain Accessor Guardrail (`tests/fitness/rules_javascript.py`)**: Added `LEGACY_DOMAIN_ACCESSOR_VIOLATION` check catching direct `window.executeSystemCompile` calls in favor of SDK domain accessors (`this.sys.executeSystemCompile`).
