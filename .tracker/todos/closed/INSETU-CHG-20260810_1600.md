## Description
* **System Index Migration (`system.json`)**: Migrated system switchboard and daemon configuration index from `workspaces.json` to `.insetu/system.json` across kernel (`utils.py`, `workers.py`, `app.py`), CLI (`cli.py`), and default assets (`defaults/system.json`). Added automated backward-compatibility migration in `SettingsManager`.
* **Multi-Scoped Settings Manager (`kernel/extension.py`)**: Enhanced `SettingsManager` to support multi-scoped settings (`daemon`, `workspace`, `repo`), routing `daemon` settings to `.insetu/system.json`, `workspace` settings to `workspace.settings.json`, `repo` settings to `repo.settings.json`, and secure settings to `secrets.json`. Updated settings REST endpoints to pass target `repo` parameters.
* **Extension Preload Preference (`app.py`)**: Added `preload_all_extensions` daemon configuration option to scan and mount all available extensions on startup.
* **Branding & Instance Metadata Encapsulation (`app.py`)**: Updated `manifest()` and `index()` routes to retrieve `instance_title` and `instance_emoji` from `SettingsManager('core_system', 'default')`.
* **Security Settings Scope Annotation (`kernel/auth.py`)**: Marked `master_fernet_key` in `security_bp` with `scope: "daemon"`.
* **Stateless Job Poller Workspace Safety (`static/js/app.js`)**: Wrapped `pollJob` callback invocations to verify workspace parity (`getActiveWorkspace()`) and swallow callbacks if the active tenant shifts mid-flight.
* **Workspace Tab Persistence & Router Fallback (`static/js/app.js`)**: Persisted active tab and subtab routes per workspace in `localStorage` (`insetu_active_tab_${ws}`, `insetu_active_subtab_${ws}_${tab}`). Restored tab routes on workspace swap (`executeWorkspaceSwap`) and added fallback tab selection in `performSoftRefresh` if a saved tab is no longer active or valid.
