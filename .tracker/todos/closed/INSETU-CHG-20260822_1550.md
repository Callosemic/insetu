## Description
* **REST Route Exception Isolation (`insetu/core/routes_fs.py`, `insetu/core/routes_system.py`)**: Wrapped REST API handlers (`api_fs_search`, `api_fs_move`, `api_fs_archive`, `api_fs_delete`, `api_fs_save`, `api_system_config`, `api_system_topology`, `api_create_workspace`, `api_delete_workspace`, `api_system_config_test_bucketing`) in robust `try...except` blocks with standardized `500` JSON error responses and server traceback printing.
* **Defensive Request JSON Parsing (`insetu/core/routes_fs.py`, `insetu/core/routes_system.py`)**: Migrated raw `request.json` calls to `request.get_json(silent=True) or {}` across core route endpoints to prevent unhandled `400 Bad Request` HTML exceptions on missing or malformed content-type headers.
* **Workspace CRUD Helper Alignment (`insetu/core/routes_system.py`)**: Refactored `api_create_workspace` and `api_delete_workspace` to consume `load_json_file` and `save_json_file` directly, eliminating manual `open()` file reads, enforcing atomic JSON writes, and invalidating memory caches synchronously.
* **Extension Metadata Extraction Guard (`insetu/core/routes_system.py`)**: Updated extension sorting in `get_system_config` to evaluate `key=lambda x: x.get('title') or ""` to defensively handle missing title keys.
