## Description
Evaluate and replace low-level, hand-rolled algorithms across the micro-kernel with battle-tested, zero-dependency micro-libraries to improve execution speed and eliminate edge-case maintenance without violating zero-bundler or local-first architecture.

### Tasks
- [ ] **Fuzzy Search Engine (`sutram/js/utils.js`)**: Swap the handwritten scoring loop in `fuzzyFilterObjects()` for a zero-dependency ESM search utility (e.g., `uFuzzy` or `fuzzysort`) for C-like speed and typo tolerance at scale.
- [ ] **SQLite Schema Migration (`insetu/kernel/db.py`)**: Replace custom `PRAGMA table_info` and `ALTER TABLE` dictionary diffing in `apply_declarative_schema()` with `sqlite-utils`.
- [ ] **JS Fitness Linter (`insetu/tests/fitness/rules_javascript.py`)**: Upgrade regex-based JS linter rules to AST parsing via a lightweight JS AST parser (e.g., `acorn`/`esprima` via Node) for 100% deterministic linter checks.
- [ ] **Yomama String Alignment (`insetu/core/bridge/bridge_fuzzy.py`)**: Under the hood of `apply_block_in_memory()`, reinforce character/line index loops with `diff-match-patch` / `python-Levenshtein` while preserving the exact `SEARCH`/`REPLACE` contract.
