## Description
expand the file checkbox UI for more granular controls...copying a specific patch or specific chunk, skipping a specific chunk, maybe have the paste separate out patches so only one chunk is visible at a time for easier editing.

possible execution method:
- split pane: top 2/3 is the patches, the rest is the files selector
- on paste, every patch gets its own textarea, sized exactly so there's no scroll, and stacked so that it is functionally one big textarea in wrapper (maybe a dividing line between them to signify they are now separated)
- the file checkbox below graduates to using cards, with the ability to view, download, and copy the files directly. selection pills at the bottom of the card play the old role of selecting patches ("All" or just particular chunks). textareas can get greyed out or something to show they aren't going to be processed. double or long taps on pills can scroll patches into view
