## Description
* Extract the cross-boundary editor resolution sequence (`window.getEditorContent` and `window.setEditorContent`) currently localized inside `ext_citations.js`.
* Abstract this logic into a unified `EditorBridge` utility residing in `ui.js` or `sdk.js`.
* Expose standard `.insertText()` and `.getText()` methods for all extensions to securely interact with the global OS editor instance while remaining safely outside of the LitElement Shadow DOM boundaries.
