## Description
The URL importing and web scraping functionalities (`utils_scraping.py` and the `/api/fs/import-url` route) are currently baked into the Core Micro-Kernel (`app.py`). This violates the core design principle that the Micro-Kernel should remain strictly domain-agnostic, handling only orchestration and I/O.

**Action Items:**
1. Rip out the `/api/fs/import-url` endpoint from `insetu/app.py`.
2. Extract `utils_scraping.py` and package it into a new dedicated ingestor extension (e.g., `engine_ingest.py`).
3. Update the `research` extension to declare `"ingest"` (or equivalent) in its `__depends__` array to maintain its background scraping capabilities.
4. Refactor the frontend "Import from URL" modal to rely on the new extension's API endpoints instead of the core FS namespace.

This paves the way for a modular ingestion pipeline (e.g., PDF to markdown, YouTube transcript extraction) without bloating the core OS for users who only want a lightweight code editor.
