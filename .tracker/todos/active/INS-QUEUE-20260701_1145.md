## Description
Instead of building an offline CLI initialization tool (`卓越 init`), merge workspace bootstrapping directly into the standard Configuration Editor extension (`ext_config.js`). Because the micro-kernel handles empty directory vacuums gracefully by entering a safe fallback state, the UI can natively guide first-time users through creating their initial workspace setup profiles entirely within the web environment.

## Action Items
- [ ] **Intercept Fallback States:** Update the Configuration Editor extension to evaluate the platform state store's `config_missing` flag upon application load.
- [ ] **Build the Initialization Wizard:** Implement a clean modal layout that prompts the user for essential workspace tokens:
    * Instance Title & Display Emoji
    * Path to target repositories (leveraging the directory browser)
    * Multi-select toggles for standard extensions (`tracker`, `git`, `citations`)
- [ ] **Execute Dynamic Scaffolding:** Wire the wizard submit handler to dispatch save commands directly to the core configuration API endpoints, programmatically generating the missing `.insetu/workspaces.json` and profile files.
- [ ] **Trigger Soft Refresh:** Upon successful file generation, execute a stateless tenant profile hot-swap behind the scenes to instantly hydrate the core file trees and unmask the main operating systems dashboard without a manual hard browser reload.
