## Description
The Yomama Sync Bridge parser matched `>>>>>>> REPLACE` tags inline or within arbitrary text blocks, causing chunk parsing desynchronization when patch replace blocks contained embedded replace tokens.

## Notes / Execution Log
* **Resolution (2026-07-20):** Updated chunk matching regex in `bridge.js` (`parseAndAppendCells`) from `/<<<<<<< SEARCH[\s\S]*?>>>>>>> REPLACE/g` to `/^<<<<<<< SEARCH[\s\S]*?^>>>>>>> REPLACE\s*$/gm`, enforcing multiline line-boundary constraints so `>>>>>>> REPLACE` is strictly parsed when standing alone on a line.
