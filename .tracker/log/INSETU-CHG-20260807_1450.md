## Description
* **InSetuElement Force-Refresh Integration**: Updated `InSetuElement.connectedCallback()` in `sdk.js` to register a global listener for `'insetu:force-refresh'`, routing refresh triggers directly to the `onForceRefresh()` instance method.
* **Event Bus Hook Bridge**: Updated `window.inSetu.events.emitHook` in `sdk.js` to dispatch an `'insetu:force-refresh'` CustomEvent on `window` whenever `zone:force-refresh` is emitted, providing backward compatibility.
* **Gather Extension Lifecycle Consolidation**: Refactored `gather.js` to implement `onForceRefresh()` on `InSetuExtGather` and removed legacy `zone:force-refresh` from `uiHooks`, bringing the extension into compliance with `LEGACY_FORCE_REFRESH_HOOK_BAN`.
