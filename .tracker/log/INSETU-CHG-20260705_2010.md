## Description
* **Extension Extraction:** Physically separated domain-specific logic from the core micro-kernel. All backend extension engines (`engine_git.py`, `engine_tracker.py`, etc.) were relocated to `insetu/extensions/`. Frontend extension scripts (`ext_*.js`) were moved to `static/js/extensions/`. `app.py` and `app.js` were updated to resolve modules from these new boundaries securely.
* **Pathlib Integration:** Commenced transition from fragile string concatenation (`os.path.join`) to POSIX-compliant `pathlib.Path` structures within `utils_core.py` and `cartographer.py`.
* **Metronome I/O Optimization:** Replaced synchronous raw `open()` reads of `workspaces.json` inside the `workers.py` metronome tick with `load_json_file` to utilize the `mtime` memory cache, eliminating idle disk thrashing.
* **State Bleed Fixes:** Migrated floating global variables (e.g., `activeSweepJobId`, `dirtyDiffRepos`) from ES6 module scopes into the centralized Zustand `AppStore` in `store.js`.
