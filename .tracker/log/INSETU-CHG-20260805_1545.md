## Description
* **Dual-Root VFS Manifest Support (`fs.js`, `store.js`)**: Refactored `AppStore.manifest` initialization to `{ vfs: {}, ctx: {} }` and updated manifest transformers (`updateManifestState`, `getGlobalManifest`, `InSetuVFSExplorer._updateState`, `extractManifestFiles`) to handle partitioned physical (`vfs`) and compiled artifact (`ctx`) keys in accordance with ADR 0037.
* **Polymorphic System Controls (`ui_system_settings.js`, `config.js`)**: Registered `sys-refresh-files`, `sys-reboot`, and `sys-lifeboat` entity actions under the `system_control` entity type on the `config` extension and replaced manual modal footer buttons in `ui_system_settings.js` with `<sutram-entity-actions .entityType=${'system_control'}>`.
* **Yomama Sync Bridge Telemetry Actions (`bridge.js`)**: Fixed patch index resolution for `deselect-patch` actions, rendered fallback confirmation buttons for candidate path overrides, and exposed the "⚡ Apply Patch" action during dry run verification states.
* **VFS URI Sanitation & Parts Modal (`fs.js`)**: Sanitized `viewAndCopy` to strip `ctx://` and `system://` prefixes, updated Parts modal layout to flexbox containers, and guaranteed JIT manifest state true-ups on upload completion.
