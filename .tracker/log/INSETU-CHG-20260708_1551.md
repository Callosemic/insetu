## Description
* **Extension Infrastructure Expansion:** Introduced the `favorites` and `skills` extensions to the inSetu ecosystem, expanding local-first capabilities for workspace pinning and spaced-repetition training.
* **Declarative Schema Updates:** Migrated the `git` extension (`ext_git.js`) to the formal `ExtensionRegistry.registerExtension` declarative layout schema.
* **Tenant Routing Standardization:** Replaced raw `request.headers.get('X-Workspace-ID')` extractions across `engine_git.py` and `engine_tracker.py` with the centralized `sniff_tenant_id()` utility to guarantee secure, stateless multitenancy.
* **Kanban Enhancements:** Added `delivery_date` tracking to Kanban tickets, complete with retroactive SQLite schema healing (`ALTER TABLE`), form fields, and visual tags in the UI.
* **DRY Slug Generation:** Abstracted scattered markdown string normalization into the unified `window.generateSafeSlug()` utility across `ext_ingest.js` and `ext_research.js`.
