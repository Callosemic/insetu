## Description
* **Editor Preferences Persistence API (`engine_editor.py`)**: Added `file_preferences` database schema (`filepath`, `writing_mode`, `doc_type`) and GET/POST `/preference` endpoints to persist per-file editor display preferences in SQLite.
* **Gather Event Trap Healer & Buffer Sync (`engine_gather.py`)**: Streamlined topology event buffer draining in `provide_base_workspaces` and `_background_compile`. Implemented Event Trap Healing to merge trapped events from pending delayed compilation jobs (`cmp_del_*`) into active compilation tasks and purge the delayed job, preventing missed events and ghost re-compilations.
* **Synchronous VFS Upload Event Emission (`routes_fs.py`)**: Replaced asynchronous `hooks.emit_background('vfs_mutated', ...)` with synchronous `hooks.emit('vfs_mutated', ...)` in `api_fs_upload` to ensure VFS mutation events are processed deterministically during file uploads.
* **Topology Buffer Extension Filtering (`engine_topology.py`)**: Enforced file extension and filename validation against `allowed_exts` inside `resolve_topology_buffer` to prevent unallowed file types from entering `topology_ledger` when processing buffered disk mutations.
