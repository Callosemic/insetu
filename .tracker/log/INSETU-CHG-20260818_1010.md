## Description
* **Semantic API Gateway Client Standardization (`app.js`, `ext_template_js.txt`)**: Migrated direct `api.workspace()` and `api.system()` calls in `app.js` and extension boilerplate templates to use semantic `.get()` and `.post()` methods.
* **JavaScript & Python Fitness Linter Suite Hardening (`rules_javascript.py`, `rules_python.py`)**: Codified `SEMANTIC_API_ROUTING_MANDATE` and `LEGACY_BOUNDARY_SYNTAX_BAN` static analysis rules to prohibit legacy direct API calls and `repo::`/`path::` URI boundaries.
* **Extension Static Sweep Expansion (`rules_css.py`, `rules_javascript.py`)**: Expanded static analysis rule sweeps to inspect `insetu/extensions/` alongside `static/` directories.
* **Core vs Extension Static Asset Resolution (`app.py`)**: Enhanced `serve_extension_static` in `app.py` using `is_core_module()` to dynamically serve assets from `insetu/core/` or `insetu/extensions/`. Added root `/README.md` REST endpoint.
* **VFS Logical URI Path Resolution (`vfs.py`)**: Updated `VFSTransaction.read()` to strip `vfs://` logical URI prefixes before evaluating path existence.
