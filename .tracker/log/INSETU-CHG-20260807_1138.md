## Description
* **Client SDK API Gateway Expansion (`api.js`)**: Added `window.inSetu.api.post(path, payload, options)` shorthand method for workspace-scoped POST API transactions.
* **Frontmatter Editor Component & Layout Modernization (`ui_editor.js`)**: Integrated `sharedStyles` into `InSetuMarkdownEditor`. Redesigned `InSetuFrontmatterEditor` layout topology with full-width title slot, entity action bar row, right-aligned metadata toggle button, collapsible metadata drawer, and single-row footer bar with dirty-state save trigger. Added `insetu:request-frontmatter` pub/sub event handling to synchronize frontmatter before dirty evaluation and save operations.
* **File Modal Bidi & E-Ink Theme Styling (`fs.js`)**: Added `unicode-bidi: plaintext;` to `InSetuFileModal` header titles to preserve correct directory path rendering and added high-contrast `.btn-back` e-ink theme styling overrides.
* **Gather Card Detail Decomposition (`gather.js`)**: Refactored `<insetu-card>` properties in `InSetuExtGather` to pass `.detailPrefix`, `.detailText`, and `.detailSuffix` as distinct reactive properties.
