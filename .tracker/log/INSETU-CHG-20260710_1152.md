## Description
* **Backend SDK Migration**: Migrated the core `bridge` and `gather` modules from raw Flask Blueprints to the `InSetuExtension` SDK paradigm. Added a `core=True` parameter to bypass standard tenant authentication gates for internal OS engines.
* **Frontend SDK Extraction**: Abstracted `InSetuElement` and `createExtensionStore` out of `app.js` and into a dedicated `sdk.js` file for standardized consumption by ecosystem extensions.
* **Component Refactoring**: Updated `bridge.js` and `gather.js` to extend `InSetuElement`. Replaced raw `fetch` calls with the context-aware `this.api` wrapper and transitioned to automated lifecycle subscriptions (`this.subscribe`).
* **VFS Decoupling**: Extracted the `VFSTransaction` class out of `extension.py` and into its own dedicated `context.py` module to prevent circular dependencies.
* **Editor Consolidation**: Fully excised legacy `mdeInstance`/EasyMDE references, standardizing the entire frontend on the modular `insetu-markdown-editor` CodeMirror 6 web component.
* **Resilience & Proxy Fixes**: Introduced WSGI middleware (`ForceHTTPSProxyFix`) to natively support HTTPS routing through Tailscale tunnels. Upgraded the kernel panic lifeboat to capture and display full tracebacks in the UI.
* **Template Utilities**: Added a new domain-agnostic `resolve_macro_includes` utility to `utils_core.py` for recursive template expansion.
