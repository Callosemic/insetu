## Description
* **Tailscale Network Manager Extension (`engine_tailscale.py` & `ext_tailscale.js`)**: Implemented pure declarative `tailscale` extension (`has_ui=False`) providing automated `tailscale serve` HTTPS port binding on workspace boot (`@hooks.on('workspace_boot')`).
* **Non-Blocking Worker Execution**: Offloaded serve binding to background worker task (`bind_serve_task`) with a 10-second subprocess timeout, supporting `sudo -n` non-interactive invocation with user-space fallback.
* **Port Mode Configuration**: Added declarative settings schema supporting standard HTTPS port 443, dynamic syncing to the active inSetu application port, or custom port overrides.
* **REST Action Endpoint**: Exposed `/api/<workspace_id>/tailscale/bind` POST endpoint returning instant `202 Accepted` receipts.
