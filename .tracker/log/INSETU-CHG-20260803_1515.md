## Description
* **Extension Scaffolding CLI (`cli.py`, `defaults/`)**: Added `insetu create-extension <name>` command, generating boilerplate backend (`engine_<name>.py`), frontend (`ext_<name>.js`), `__init__.py`, and `vendor.json` from templates.
* **Abortable VFS Barrier Synchronization (`insetu/kernel/extension.py`)**: Refactored `ExtensionContext.sync_vfs_barrier()` from raw `queue.join()` to an abortable polling loop evaluating `_VFS_SHUTDOWN_SIGNAL` to prevent deadlocks during system shutdowns or workspace swaps.
* **Event Bus Re-Entrancy Guard & Telemetry (`insetu/kernel/hooks.py`)**: Added thread-local `active_events` re-entrancy tracking to `HookRegistry.emit()` to prevent infinite event recursion loops. Added telemetry logging for callbacks exceeding 1.0s execution time.
* **Tenant Hook Authorization Enforcement (`insetu/kernel/hooks.py`, `tests/fitness/rules_python.py`)**: Explicitly banned extension modules (`insetu.extensions.*`) from subscribing to `system_boot` in favor of tenant-scoped `workspace_boot`. Codified `SYSTEM_BOOT_EXTENSION_BAN` and `STATELESS_EVENT_ISOLATION` fitness rules.
* **App Shell Endpoint & Store Streamlining (`insetu/static/js/app.js`)**: Updated route URLs (`/system/topology` and `/system/manifest`), bound status bar pinned repos directly to `AppStore`, and simplified `updateRefreshText()` to use `window.inSetu.utils.timeAgo()`.
* **Lifeboat FS Context Compression (`insetu/kernel/fallback_bridge.py`)**: Stripped base64 inline source maps from vendor JS files during emergency core dumps to optimize LLM context limits.
