## Description
* **CQRS Manifest Delta Synchronization (`app.js`)**: Implemented `checkManifestVersion()` and registered a 3-second background metronome tick (`manifest_sync`) querying `/api/<workspace_id>/gather/manifest/version` and `/api/<workspace_id>/gather/manifest/deltas?since=<timestamp>` to perform optimistic Zustand store splicing for multi-instance client alignment without full page reloads.
* **Autopilot Job Chaining (`insetu/kernel/extension.py`)**: Enhanced `InSetuExtension.worker` to support `_chain` payloads, allowing background workers to automatically chain sequential multi-step tasks and trigger completion hooks off-thread.
* **Tenant-Scoped Auth Resolution (`insetu/kernel/utils.py`)**: Refactored `extension_auth()` to resolve tenant `workspace_id` via route `kwargs` or request headers, enforcing tenant-isolated extension authorization checks.
* **Declarative Extension Virtual JS Fallback (`insetu/app.py`)**: Updated `serve_extension_js(ext_name)` to return a virtual empty ES module (`export default {};`) with `application/javascript` headers when an extension lacks a physical `ext_<name>.js` file, supporting headless/UI-less extensions.
* **Workspace Shutdown Teardown Hook (`insetu/kernel/db.py`)**: Registered `@hooks.on('workspace_shutdown')` listener `close_workspace_connections()` to evict and close thread-local SQLite connections when a tenant workspace unmounts.
* **Selection Payload Chunk Expansion Hook (`insetu/kernel/extension.py`)**: Replaced hardcoded manifest chunk expansion in `ExtensionContext.expand_selection()` with event bus hook emission (`resolve_payload_chunks`).
* **App Shell Hash Routing & Workspace Swap Order (`insetu/static/js/app.js`)**: Re-ordered boot sequence in `executeBootSequence()` to establish workspace context prior to fetching system configuration, and updated hash routing and tab change event listeners to emit `zone:force-refresh` when active tabs/subtabs are re-selected.
* **Fitness Function Enforcement (`rules_javascript.py` & `rules_python.py`)**: Added `SETTINGS_ACTION_EXPLICIT_API_MANDATE` checking for raw `fetch()` in settings action listeners, added `MANIFEST_FILE_IO_BAN` catching direct file I/O on legacy `manifest.json` files, and verified 100% test suite compliance.
