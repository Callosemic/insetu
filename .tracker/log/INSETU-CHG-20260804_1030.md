## Description
* **CQRS Manifest Delta Synchronization (`app.js`)**: Implemented `checkManifestVersion()` and registered a 3-second background metronome tick (`manifest_sync`) querying `/api/<workspace_id>/gather/manifest/version` and `/api/<workspace_id>/gather/manifest/deltas?since=<timestamp>` to perform optimistic Zustand store splicing for multi-instance client alignment without full page reloads.
* **Declarative Extension Virtual JS Fallback (`app.py`)**: Updated `serve_extension_js(ext_name)` to return a virtual empty ES module (`export default {};`) with `application/javascript` headers when an extension lacks a physical `ext_<name>.js` file, supporting headless/UI-less extensions (e.g., `tailscale`).
* **Boot Sequence & Routing Initialization (`app.js`)**: Reordered boot sequence to initialize `loadWorkspaces()` prior to fetching system configuration, guaranteed `handleHashChange()` fires on startup to hydrate `activeTab` in `AppStore`, and added `sutram-status-update` event emissions in `setGlobalStatus()`.
* **Fitness Linter Enforcement (`rules_javascript.py` & `rules_python.py`)**: Added `SETTINGS_ACTION_EXPLICIT_API_MANDATE` checking for raw `fetch()` calls in `sutram-settings-action` listeners and `MANIFEST_FILE_IO_BAN` catching direct file I/O references to legacy `manifest.json` files.
* **Architectural Map Synchronization (`CODE_INDEX.md`)**: Updated `CODE_INDEX.md` to reflect ADR 0036 and added directory mappings for the `tailscale` extension.
