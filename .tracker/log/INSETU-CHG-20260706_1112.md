## Description
* **Bridge Idempotency Guardrails:** Replaced the rigid "Patch Sandwich" regex evaluation in `bridge.js` with a robust `isIdempotencyRisk` function. The system now safely evaluates whether replacement blocks contain exact copies of their search blocks, preventing infinite LLM duplication loops while permitting flexible leading/trailing context.
* **Gather UDF Hardening:** Eliminated direct DOM value reading (e.g., `document.querySelectorAll('.sc-file-checkbox:checked')`) within `gather.js`. The Batch Editor now natively stores `flowFormIncludes`, `flowActiveResponse`, and temporal drafts in the centralized Zustand `AppStore`.
* **DOM Annihilation Fixes:** Eradicated `innerHTML = ''` DOM-clearing anti-patterns within `ui.js` (`openSelectorModal`) in favor of the performant `replaceChildren()` method.
* **Fitness Functions Expansion:** Hardened `fitness_functions.py` to identify bracket-notation UDF bypasses (`['value']`), detect `__import__('sqlite3')` encapsulation escapes, and police `pathlib` write/delete bypasses. The codebase currently reports 0 architectural violations.
