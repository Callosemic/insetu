## Description
* **Tenant-Isolated Compilation Locks:** Swapped the global `_COMPILER_LOCK` for a dynamic `_COMPILER_LOCKS` dictionary in `app.py`, enabling concurrent RAG context compilations across independent workspace tenants.
* **Blueprint Extraction:** Extracted Gather/Batch REST endpoints into `engine_gather.py` (via `gather_bp`) and routed Pandoc document formatting to a specialized `engine_format.py` module to maintain shallow transport shells.
* **UI Factory Standardization:** Overhauled major frontend modules to abandon raw HTML string templates for modals, transitioning exclusively to `UIFactory.createModal()`.
* **Git Bulk Diff Optimization:** Refactored `engine_git.py` to execute a single `git diff HEAD --` command for all changed files, eliminating the severe N+1 subprocess execution bottleneck.
* **Workspace Physics Precision:** Hardened `resolve_workspace_path` inside `utils_core.py` to dynamically evaluate unmatched genesis file paths by calculating which route fragments require the fewest new subdirectories.
