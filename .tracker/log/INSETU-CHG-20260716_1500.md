## Description
Graduated the core micro-kernel and frontend presentation layout to a fully decoupled, state-driven model, eliminating legacy imperative DOM rendering patterns and technical debt.

### Implemented Enhancements
* **Polymorphic Entity-Action Card Registry (ADR 0023):** Completely refactored `<insetu-card>` and `<insetu-file-tree>` to be 100% stateless regarding application business logic. Cards now broadcast an `entityType` classification string and an `entityData` property map to dynamically evaluate context menus and action button matrices from the central registry.
* **Off-Thread Multi-File Upload Subsystem:** Introduced a native multipart/form-data transaction endpoint (`/api/<workspace_id>/fs/upload`) in `routes_fs.py` to ingest bulk binary streams safely off the HTTP event loop, updating the central VFS Event Ledger synchronously.
* **Two-Pass Layout Compilation:** Refactored `ExtensionRegistry.compileLayout()` inside `store.js` into a segmented two-pass rendering sequencer. This eliminates layout hoisting race conditions by ensuring primary navigation tab containers are fully mounted in the DOM before sub-navigation slots attempt initialization.
* **Dynamic Language Grammars splitting:** Modified `<insetu-markdown-editor>` to import CodeMirror 6 language grammar bundles (`@codemirror/lang-python`, `@codemirror/lang-javascript`, etc.) lazily via asynchronous ES6 dynamic `import()` modules, accelerating core bootstrap speeds.
* **Spatial Physics Isolation:** Realigned the extension `SettingsManager` and `StoreManager` layers to resolve persistent asset states strictly through the centralized `get_tenant_control_dir(workspace_id)` utility, completely eradicating profile directory layout leakage.
* **Security & Fallback Hardening:** Injected robust containment checks inside `get_workspace_physics` to isolate corrupted or missing tenant profiles inside a safe fallback state, preventing unverified file paths from bleeding across boundaries.

### Excised Technical Debt
* Excised the legacy `insetu-file-actions` element wrapper and hardcoded template string injection mechanisms from `ui_file_tree.js`.
* Permanently removed the deprecated `/api/<workspace_id>/bridge/fetch` transport shell endpoint, routing all resource requests through the unified VFS fetch interface.
* Deleted stale, un-migrated tooling scripts (`bulk_pathlib_fixer.py`, `bulk_theme_fixer.py`, `test_pathlib_migration.py`).
