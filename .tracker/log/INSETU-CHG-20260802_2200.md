## Description
* **Gather Engine Boot-Time Heuristic (`engine_gather.py`)**: Implemented an Offline Mutation Guard within `init_gather_workers()`. On system boot (`@hooks.on('system_boot', priority=90)`), the engine compares the current `SYSTEM_BOOT_TIME` against `last_full_compile_time` stored in `manifest_cache.json`. If external/offline mutations occurred while the daemon was down, it automatically dispatches a non-blocking background context compilation job (`compile_contexts` with `force_full=True`) to heal the context index.
