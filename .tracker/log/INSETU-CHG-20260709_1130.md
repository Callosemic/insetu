## Description
* **UI Primitives Abstraction:** Abstracted `.fuzzy-search-wrapper` and `.system-action-btn` into `shared_styles.js` to eliminate redundant inline styling and class replication across extensions.
* **Global Component Migration:** Relocated `InSetuFileActions` from the `gather.js` extension silo into the global `ui_file_tree.js` component matrix, ensuring all file cards natively support hook-based slot injections.
* **UDF Hardening:** Replaced an imperative DOM lookup (`document.getElementById('sub-gather')`) in the Gather extension's tab-change hook with a reactive `gatherForceRefreshTick` subscription routed through the centralized `AppStore`.
* **Fitness Functions Integration:** Added `imperative_dom_create_pattern` to `fitness_functions.py` to strictly ban the use of `document.createElement` inside LitElement extensions, enforcing declarative `lit-html` template usage.
