## Description
* **Declarative Menu Bar Extension:** Removed manual DOM mutations (`appendChild`, `document.getElementById`) for toolbar buttons across `ext_citations.js`, `ext_format.js`, and `ext_prompts.js`. Migrated to declarative `zone:modal-ext-menu` injections, aligning with UDF paradigms and eliminating horizontal toolbar clutter.
* **Multi-Tenant Database Initialization:** Updated `engine_research.py`'s database initialization logic to dynamically pull from `.insetu/workspaces.json`, creating per-workspace DB connections instead of a singular global database lock.
* **Workspace Scope Enhancements:** Fixed the `/api/fs/search` fetch in `ext_citations.js` to correctly apply the `workspace_id` tenant scope, resolving cross-tenant boundary risks.
* **Extension Enablement Checks:** Added explicit activation checks (`if "ext" not in cfg["extensions"]: return`) to OS hooks in `engine_flow.py` and `engine_prompts.py` to prevent logic execution when extensions are disabled.
* **UI Layout Standardization:** Replaced inline styles with a stable CSS Grid layout (`repeat(3, 1fr)`) for Task Card action buttons in `ext_tracker.js`. Refined the attachment modal verbiage in `ext_citations.js` for clarity.
