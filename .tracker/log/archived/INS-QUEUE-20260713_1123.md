## Description
Decoupled the core Micro-Kernel from optional domain extensions during the workspace hot-swap soft-reload lifecycle phase.

### Resolution Summary
* Replaced the hardcoded, fragile dictionary array of component selectors with an elegant Inversion of Control sweeping loop using `.tab-content *` scanning.
* Standardized element eviction by matching any elements whose tag name conforms to the custom naming convention prefix `INSETU-EXT-` or specific core abstractions like `INSETU-VFS-EXPLORER`.
* Eradicated cross-tenant layout leaks and ghost states by flushing active extension stores and unmounting visual wrappers dynamically, simplifying the teardown architecture to zero maintenance overhead.
