## Description
This release introduces responsive container layout properties, expands Git capabilities, and hardens the Prompts extension.

* **Container Queries Integration:** Added `container-type: inline-size` to the `:host` styles of all primary extension components. The Kanban Tracker was refactored to utilize `@container` queries for its column layouts, decoupling its responsiveness from the global viewport.
* **Remote Git Management:** Added comprehensive UI support for connecting local repositories to remotes. Features include a fallback resolution modal to handle "unrelated histories" via pull-and-merge or forced-push overwrites without leaving the OS. `git init` was also updated to support custom branch names.
* **Git Sweep Isolation:** Fixed a bug where untracked files from the base workspace root bled into local-only repository sweepable states.
* **Prompts Store Decoupling:** Migrated prompt state out of the monolithic `AppStore` into an isolated `PromptsStore` via `createExtensionStore`. Bound extensive file-lifecycle hooks (`zone:post-file-move`, `zone:post-folder-create`) to accurately track the prompt library directory asynchronously.
* **Workflow Prompt Resolution:** Workflows in the Flow extension now dynamically resolve saved prompt paths against the active runtime list to prevent broken links during profile swaps.
