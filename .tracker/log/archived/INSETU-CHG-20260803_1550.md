## Description
* **Manifest Hydration Standardization (`ext_git.js`, `ext_flow.js`)**: Replaced direct, ad-hoc `fetch` requests to `gather/manifest` in `generateDiffs()` with the core domain accessor `window.inSetu.sys.refreshManifest()`.
* **Flow VFS Mutation Listener Enhancement (`ext_flow.js`)**: Updated `zone:vfs-mutated` UI hook and `git-diffs-refreshed` event handlers in the Flow extension to detect mutations across `diffs/`, `contexts/`, `workflows/`, `_diffs.txt`, and `_context.txt` files, triggering immediate manifest true-ups and workflow batch re-fetches.
