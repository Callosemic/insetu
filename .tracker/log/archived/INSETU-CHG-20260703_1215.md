## Description
* **UI Upgrade:** Replaced the legacy `<select>` dropdown in the Batch Editor ("2. Instruction Prompt") with a read-only text input and a dedicated "Select Prompt" button[cite: 417].
* **Fuzzy Search Integration:** The button dynamically imports and opens the `openSelectorModal` from `ui.js`, allowing users to quickly search and filter through deeply nested prompt directories[cite: 500].
* **Quality of Life:** Added a dedicated clear button ("❌") to easily un-map a prompt without needing to navigate the selector modal.
