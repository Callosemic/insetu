## Description
This release executes the Three-Tier Core Kernel Extraction, modernizes the Workspace Configuration UI with yenVUI collapsibles and isolated editing modals, and introduces automated CSS fitness functions.

### Key Enhancements & Refinements
* **Core Kernel Extraction (ADR 0029 & Blueprint):**
  - Renamed `insetu/context.py` to `insetu/vfs.py` to eliminate semantic overloading and accurately reflect atomic `VFSTransaction` capabilities[cite: 1, 2]. Updated relative imports across `routes_fs.py`, `sdk/extension.py`, and `app.py`[cite: 1, 2].
  - Relocated Tier 2 Developer OS engines (`engine_bridge.py`, `engine_gather.py`, `cartographer.py`) and frontend scripts (`bridge.js`, `gather.js`) to `insetu/core/` and `insetu/static/js/core/`[cite: 1, 2, 3].
  - Implemented dynamic blueprint bootloader logic in `app.py` for Tier 2 engines[cite: 1].
* **Workspace Configuration UI Modernization (`config.js`):**
  - Refactored repository editing into a dedicated modal (`renderRepoEditorModal`) using `<yenvui-card-group>` and `<yenvui-card>` with state backup rollback (`_repoBackup`)[cite: 2].
  - Converted sub-bucket editing and general settings sections to `<yenvui-collapsible>` components[cite: 2].
* **Automated CSS Fitness Guardrails (`rules_css.py` & `rules_python.py`):**
  - Implemented `tests/fitness/rules_css.py` enforcing `STRICT_CSS_SPECIFICITY_MANDATE` to ban `!important` flags outside whitelisted OS utility classes[cite: 2].
  - Added `CORE_TIER_ISOLATION_MANDATE` in `rules_python.py` to prevent Tier 2 core OS modules from importing Tier 3 extensions[cite: 2].
* **Context & VFS Path Resolution (`fs.js`, `routes_fs.py`, `utils_core.py`):**
  - Updated `updateManifestState` in `fs.js` with path normalization to support clean manifest updates on file moves/renames[cite: 2].
  - Added fallback search path resolution for absolute system artifacts in `api_fs_fetch` (`routes_fs.py`)[cite: 1].
  - Expanded `get_available_contexts` in `utils_core.py` to accept `exclusion_flags` for dynamic context target evaluation[cite: 2].
