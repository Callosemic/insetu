## Description
* **Sync Bridge Schema Isolation (`engine_bridge.py`)**: Declared `BRIDGE_SCHEMA` (`bridge_ledger` table) in `InSetuExtension` to manage patch transaction history, snapshots, and TTL expiration state.
* **VFS File Resolution & Search Hook Decoupling (`engine_gather.py`, `routes_fs.py`, `utils_core.py`)**:
  - Deprecated `get_gather_paths` and `search_workspace_files` from `utils_core.py`.
  - Introduced `@hooks.on('vfs_resolve_file')` handler `resolve_gather_artifacts` in `engine_gather.py` to dynamically resolve `system://contexts` and `system://gather` URIs and fallback paths.
  - Decoupled workspace searching (`api_fs_search`) in `routes_fs.py` to trigger `@hooks.on('vfs_search')` hook listeners.
* **System Topology & Manifest Gateway Endpoints (`routes_system.py`)**:
  - Added `/api/system/topology` (and `/api/<workspace_id>/system/topology`) endpoint returning target repository topologies, port configurations, and tab order configurations.
  - Added `/api/system/manifest` (and `/api/<workspace_id>/system/manifest`) endpoint emitting `request_manifest`.
* **Gather Lock Acquisition Hardening (`engine_gather.py`)**: Added a 15.0s timeout to `ws_lock.acquire()` in `_background_compile` to prevent event loop thread lockup during heavy compilation passes.
