## Description
* **Yomama Sync Bridge Telemetry UI (`bridge.js`)**: Integrated Phase C structured JSON telemetry rendering (`_renderTelemetry()`) displaying total, resolved, skipped, and failed patch metrics, syntax error diff inspection, candidate path confirmation buttons, deep search triggers, and ignore syntax controls.
* **Ephemeral Patch Ledger Receipts & History View (`bridge.js`)**: Added `historyRecords` and `fetchHistory()` to `BridgeStore`, mounted the `<insetu-ext-bridge-history>` component ("Receipts" sub-tab), added `<insetu-ext-bridge-history-actions>` view toggle (Transaction/Turn vs File grouping), and registered polymorphic entity actions (`yomama-turn-undo`, `yomama-turn-restore`, `patch-receipt-undo`, `patch-receipt-restore`, `patch-receipt-copy`).
* **Gather Quickpack Categorization (`gather.js`)**: Updated `finalCat` logic to properly classify `quickpack_` and `selection_` context files under the "Quickpacks" category.
