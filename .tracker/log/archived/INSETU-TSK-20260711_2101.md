## Description
* **Resolved:** Extracted the cross-boundary editor resolution sequence (`window.getEditorContent`, `window.setEditorContent`, `insertTextAtCursor`, and `insertLinkToEditor`) out of the monolithic `app.js` and `fs.js`.
* Abstracted this logic into the domain-specific `components/ui_editor.js` module.
* Exposed standard `.insertTextAtCursor()`, `.getEditorContent()`, and `.setEditorContent()` methods to securely interact with the global OS editor instance while remaining safely outside of the LitElement Shadow DOM boundaries, completing the Editor Domain decoupling.
