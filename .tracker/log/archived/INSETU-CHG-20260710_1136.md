## Description
* **SDK V2 Backend Upgrades:** Migrated `engine_favorites.py`, `engine_ingest.py`, and `engine_prompts.py` to inherit the declarative `InSetuExtension` blueprint wrapper. Substituted raw database connections and file reads with pre-scoped `ctx.db` and `ctx.vfs` pipelines.
* **SDK V2 Frontend Upgrades:** Graduated `ext_favorites.js`, `ext_ingest.js`, and `ext_prompts.js` to inherit the `InSetuElement` base class. Rewrote raw network intercepts into strict `this.api` endpoints and standardized `createExtensionStore` usage.
* **Asynchronous Ingestion Pipeline:** Refactored URL scraping in `engine_ingest.py` out of the HTTP thread. It now invokes `submit_immediate_job()`, resolving a major I/O Block Ban violation while the frontend polls progress seamlessly via the metronome.
* **CodeMirror 6 Topology Polish:** Purged obsolete EasyMDE CSS structural hacks from the Kanban tracker. Refactored the `citations` extension reference-injection logic to target the active `#global-os-editor` CodeMirror 6 node over the legacy `.EasyMDEContainer`.
