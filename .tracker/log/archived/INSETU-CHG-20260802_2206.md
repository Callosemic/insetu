## Description
* **Security & Secret Encryption Subsystem (`insetu/kernel/auth.py`, `insetu/kernel/extension.py`)**: Integrated local Fernet master key management (`get_master_key()`) reading/writing `.insetu/master_key.txt`. Registered the `security` core blueprint (`InSetuExtension`) and upgraded `SettingsManager` to automatically encrypt/decrypt secure configuration fields prefixed with `v1:` in `secrets.json`. Added `get_repo_path()` helper to `ExtensionContext`.
* **Retro Bootloader & Reboot UI Modernization (`app.js`, `index.html`, `fallback_bridge.py`)**: Enhanced the retro bootloader overlay with dynamic progress bar animation (`#retro-bar-fill`), event-driven status messages (`sutram:extension-registered`), and smooth CSS transitions. Replaced fixed timeout reloads in `simulatePanic()` and `rebootOS()` with non-blocking polling tickers (`fetch('/?t=' + Date.now())`).
* **Dependency & Package Cleanup (`pyproject.toml`)**: Added `cryptography>=41.0.0` and `mistune>=3.0.0` to core dependencies, added `[project.optional-dependencies]` table for optional tooling, and purged legacy `rjsmin`/`rcssmin` entries.
* **VFS & Worker Boot Hardening (`vfs.py`, `workers.py`)**: Added JSON syntax validation error catching in `execute_vfs_save()`. Streamlined boot-time job cleanup in `start_workers()` to protect background context compilations during startup.
* **Architectural Fitness Rules (`core.py`, `rules_javascript.py`, `rules_python.py`)**: Added `BOOT_HOOK_NONBLOCKING_MANDATE` checking for synchronous context compilation or file walking in `@hooks.on('system_boot')`. Added `RAW_DIALOG_OVERLAY_BAN` checking for unwrapped `<dialog>` tags without `@cancel` handlers. Sanitized local absolute paths in test reports (`[workspace]/insetu/...`). Removed stale `tests/results` file.
