## Description
This release introduces critical infrastructure hardening across the background worker threads, VFS transactional loops, and the system configuration cache.

* **Thread Pool & Metronome Stability (`workers.py`, `app.py`)**: 
  * Implemented `_shutdown_event.is_set()` circuit breakers across task submission endpoints (`submit_immediate_job`, `submit_job`) to prevent `RuntimeError: cannot schedule new futures after shutdown` exceptions during tenant hot-swaps and system reboots.
  * Swapped the global `_COMPILER_LOCK` in `app.py` to a reentrant lock (`threading.RLock()`) to prevent deadlock conditions during deep nested compilation calls.
  * Cleaned up 'ghost jobs' gracefully on system boot.
* **Config Cache Optimization (`utils_core.py`)**: 
  * Refactored `load_config` to perform deep-copy caching of the *mutated* configuration matrix (`_MUTATED_CONFIG_CACHE`). This dramatically reduces I/O and CPU overhead by eliminating redundant `mutate_workspace_config` Event Bus emissions on every configuration read.
  * Added a strict containment guardrail to `get_workspace_physics`: if a non-default workspace is missing its physical configuration file, it forces an empty fallback rather than silently leaking the default workspace's state.
* **VFS & Bridge Enhancements (`context.py`, `engine_bridge.py`, `engine_gather.py`)**: 
  * Shifted the `vfs_transaction_committed` hook emission to `hooks.emit_background()` to prevent blocking the atomic VFS write-path loop.
  * Injected strict `_VFS_WRITE_QUEUE.join()` barrier locks in `_surgically_update_manifest` *before* acquiring the compiler lock, guaranteeing that the compiler never reads stale disk states.
  * Optimized the Yomama Sync Bridge by caching `get_omniscient_workspace_files()` across multi-file patches, preventing $O(N)$ redundant filesystem sweeps.
* **Frontend Resiliency (`app.js`)**: 
  * Added an absolute 10-minute timeout (600 retries) to the `executeSystemCompile` polling loop to prevent infinite ghost polling if the daemon drops the job.
  * Stopped `executeSystemCompile` from automatically thrashing the background queue on every soft-refresh if a manifest already exists.
* **Workspace Instantiation (`routes_system.py`)**: 
  * Fixed a physical pathing bug where new workspaces were mounting their `.insetu/data` directories incorrectly.

## Notes / Execution Log
