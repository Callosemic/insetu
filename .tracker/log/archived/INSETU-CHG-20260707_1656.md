## Description
* **Web Component Migration:** Deployed global `<insetu-card>`, `<insetu-file-tree>`, `<insetu-folder-browser>`, and `<insetu-modal>` LitElements, reducing imperative DOM mutation significantly.
* **Declarative Extensions:** Extracted the Gather panel into a native `<insetu-ext-gather>` Web Component, complying with the zero-bundler import map architecture.
* **Tenant Event Authorization:** Hardened `hooks.py` with an `_is_authorized` barrier to strictly drop event callbacks for extensions disabled in the active workspace.
* **Mobile UX:** Added CSS touch-swipe interactions to reveal file card actions natively without relying on JavaScript event overlap.
