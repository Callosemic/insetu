## Description
- **UI DRY Standardization:** Extracted bespoke `.sticky-header` search and filter wrapper logic across `ext_citations.js`, `ext_flow.js`, `ext_git.js`, and `ext_tracker.js`, consolidating them into the unified `<insetu-standard-toolbar>` Web Component.
- **Flexbox Scroll Containers:** Added strict flex layouts (`flow-body`, `git-body`, `prompts-body`, `tracker-body`) with `flex: 1` and `overflow-y: auto` to ensure edge-to-edge view compliance and eliminate nested scrolling artifacts.
- **Event Listener Cleanup:** Removed manual document click listeners (e.g., `_handleDocumentClick` in `ext_tracker.js`) which were used to handle click-outside events for custom filter drop-downs, relying instead on the encapsulated components to respect Unidirectional Data Flow (UDF).
- **Tracker Filters Refactor:** Implemented an expansive, declarative slot-based filter layout inside the Tracker toolbar, utilizing collapsible tags, sub-buckets, and repository pins to dramatically improve horizontal screen real estate.
