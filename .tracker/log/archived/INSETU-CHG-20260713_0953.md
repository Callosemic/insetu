## Description
A comprehensive refactoring and hardening sweep across the core inSetu extensions to enforce full V2 SDK compliance, strengthen multi-tenant data containment, and eradicate duplicate UI primitives.

### Implemented Enhancements
* **Backend SDK Adherence & Decoupling**:
  * **Citations (`engine_citations.py`)**: Migrated global library registration directly into the declarative `virtual_contexts` SDK constructor parameter, purged raw file writes in favor of `ctx.vfs.save`, and switched to the high-performance `ctx.db.get_all` wrapper.
  * **Favorites (`engine_favorites.py`)**: Eradicated raw SQL strings and manual transaction commits by implementing `ctx.db.get_all`, `ctx.db.insert_or_replace`, and `ctx.db.delete` database abstractions.
  * **Flow & Git Blueprints**: Replaced raw `load_json_file`/`save_json_file` invocations on `manifest.json` with the managed `ctx.manifest` and `ctx.save_manifest()` primitives to prevent race conditions.
  * **Tracker (`engine_tracker.py`)**: Stripped physical path mutations out of `get_tracker_path` to avoid cross-platform deployment side-effects, migrated file system sweeps to `ctx.vfs.walk`, and implemented targeted O(1) single-file healing on active UI save events.
* **Frontend Component Graduation & DRY Centralization**:
  * **Citations UI (`ext_citations.js`)**: Substituted custom fuzzy search input markup elements with the unified `<insetu-search-bar>` Web Component primitive.
  * **Flow UI (`ext_flow.js`)**: Stripped manual blob downloads and clipboard interaction streams, routing execution through centralized core helpers (`fetchAndDownloadState`, `fetchAndCopy`). Replaced raw grouping/sorting loops with the declarative `<insetu-categorized-list>` element.
  * **Format UI (`ext_format.js`)**: Eliminated verbose, stateful tracking variables and manual Zustand observer cleanups by mounting the stateless `<insetu-job-tracker>` component.
