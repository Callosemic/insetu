## Description
This changelog records the absolute, deterministic remediation of static analysis linter violations across the core extension ecosystem, specifically aligning paths with the Pathlib Mandate (ADR 0013) and refactoring configuration fetching to use the Extension SDK Context (ADR 0017).

### Completed Modifications:
* **Pathlib Migration Compliance (`engine_flow.py`, `engine_format.py`, `engine_tracker.py`, `engine_prompts.py`)**: Migrated legacy, string-based path operations (`os.path.basename` and `os.path.dirname`) to native `pathlib.Path` properties (`Path.name` and `Path.parent.as_posix()`), mitigating platform-specific pathing vulnerabilities and string-slicing brittle zones.
* **SDK Context Alignment (`engine_git.py`)**: Excised manual `load_config(workspace_id)` calls in favor of brokered `ExtensionContext('git', workspace_id)` orchestration, ensuring strict containment and cache-safe access via `ctx.config`.
