## Description
* **DOM Element-Sniffing Elimination**: Eradicated imperative `document.querySelector('insetu-ext-...')` calls in `ext_flow.js` and `ext_tracker.js` entity actions and dropdown action items, fulfilling UDF requirements and ADR 0023/ADR 0024 standards.
* **Store-Level Task Transitions**: Moved task status transition logic (`transitionTask`) into `KanbanStore` in `ext_tracker.js`, enabling element-decoupled execution from polymorphically rendered entity actions.
* **Event-Driven Modal & Action Dispatch**: Introduced `insetu:flow:edit-batch`, `insetu:tracker:open-new-task`, `insetu:tracker:open-edit-task`, and `insetu:tracker:generate-changelog` event dispatchers and listeners for loose, decoupled communication between toolbar actions and views.
* **yenVUI Component Graduation**: Migrated dropdown menus across `ext_flow.js`, `ext_prompts.js`, and `ext_tracker.js` from legacy `<insetu-dropdown>` to `<yenvui-dropdown>`.
