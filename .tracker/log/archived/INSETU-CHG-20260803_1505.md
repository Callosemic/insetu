## Description
* **SDK V2 Action Binding Standardization**: Refactored async job submission across frontend extensions (`ext_freshdesk`, `ext_git`, `ext_hooks`, `ext_ingest`, `ext_research`, `ext_skills`, `ext_tracker`) to use `this.api.bindJobAction` and `this.api.postJson`, replacing imperative `pollJob` boilerplate.
* **Event Loop Protection & Background Worker Offloading**:
  * `engine_flow`: Offloaded workflow batch compilation during system sweep to a background worker (`compile_flow_batches`) to prevent event loop starvation and compilation locks.
  * `engine_tracker`: Offloaded single-file and full-sweep ticket enforcement (`enforce_declarative_tickets`) to a background worker (`enforce_tickets_task`).
  * `engine_git`: Parallelized git status and diff generation across repositories using `ThreadPoolExecutor` and `--no-optional-locks`.
* **Workspace Boot Hook Isolation**: Migrated `@hooks.on('system_boot')` to tenant-scoped `@hooks.on('workspace_boot')` in `engine_dev` and `engine_tracker`.
* **Topology & Store Decoupling**: Refactored extensions (`ext_citations`, `ext_flow`, `ext_git`, `ext_hooks`, `ext_prompts`, `ext_tracker`, `ext_notes`) to read repository filter states and topologies from `AppStore` / `this.ecosystem` rather than cross-coupling directly with `GatherStore`.
* **DRY Utility & Formatting Centralization**: Standardized date formatting across `ext_dev`, `ext_research`, and `ext_tracker` to use `this.utils.formatDate()`. Replaced manual frontmatter regex parsing in `engine_tracker` with `parse_frontmatter` / `update_frontmatter` core utilities.
* **Multi-Tenant Scoping**: Fixed `workspace_id` parameter propagation in `SerperDevProvider` and `gather_next_page` within `engine_research`.
