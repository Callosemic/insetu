## Description
* **Sutram Vendor Import Normalization**: Standardized relative ES6 module imports across core JavaScript substrate modules (`api.js`, `bridge.js`, `ui_editor.js`, `ui_file_tree.js`, `ui_filter_pills.js`, `ui_primitives.js`, `ui_system_settings.js`, `config.js`, `fs.js`, `gather.js`, `sdk.js`, `shared_styles.js`, `store.js`) to route explicitly to the vendorized `sutram/js/` subdirectory.
* **API Client Gateway 401 Re-Authentication (`api.js`)**: Introduced `_attemptReAuthAndRetry()` inside `window.inSetu.api.workspace` and `window.inSetu.api.system`. When receiving HTTP 401 Unauthorized responses, the client automatically requests a session bootstrap via `/auth/bootstrap`, updates `sessionStorage` and `AppStore`, and retries the network transaction.
* **Sutram Presentation Primitive Alignment (`ui_editor.js`, `ui_file_tree.js`, `gather.js`)**: Refactored component templates to consume `<sutram-editor>`, `<sutram-async-btn>`, `<sutram-dropdown>`, `<sutram-card-group>`, and `SutramCard` primitives.
* **VFS Context Parts & Action Resolution (`fs.js`, `gather.js`)**: Updated `viewAndCopy()` to sanitize `system://contexts/` prefixes, enabled downloading and sharing of multi-part chunks directly from browser modals, and hardened `mountVFSModals()` to verify `document.readyState`.
