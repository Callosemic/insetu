## Description
A comprehensive stability, performance, and guardrail hardening sweep across the core inSetu Micro-Kernel frameworks and frontend client stores:
* **Asynchronous VFS Protection**: Refactored the core write synchronization barrier from a rigid, blocking `.join()` thread lock to an abortable, non-blocking polling loop that gracefully handles `_VFS_SHUTDOWN_SIGNAL` events during profile swaps.
* **Macro Slew Limiter Optimization**: Tuned the file-change aggregation debounce delay down from 5.0 seconds to 1.5 seconds, boosting interface responsiveness while preserving safe cluster-coalescing bounds.
* **DRY State Centralization**: Extracted duplicate, mutative reference assignments from `fs.js` and `bridge.js` into a unified `optimisticallyAddFileToManifest` slice action inside the global `AppStore`, reinforcing absolute Unidirectional Data Flow (UDF) conformity.
* **Resilient Bootloading Subsystem**: Hardened the extension boot mechanics with a defensive `safe_import` wrapper capable of cleanly intercepting missing external pip dependencies (`__external_depends__`) and reporting them directly to the system settings UI instead of bricking the kernel server.
* **JIT Ledger Schemas Allocation**: Structured a JIT schema execution pass within the metronome dispatcher loops to instantly provision infrastructure ledgers for newly mounted tenant workspaces.
* **Polymorphic Layout Polish**: Extended `<insetu-card>` action drawers with dynamic viewport bounding calculations and a smart upward overflow rendering strategy (`_openUpwards`), paired with high-precision dropdown scannability adjustments (`height: calc(100dvh - 170px)`).
* **Static Analysis Validator Guard**: Codified the `BANNED_MAGIC_GENERATOR` rule pass into `fitness_functions.py` to programmatically reject raw `yield` patterns within background worker execution contexts.
