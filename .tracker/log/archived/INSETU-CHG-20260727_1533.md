## Description
* **CSS Tech Debt Sweep:** Purged massive blocks of legacy, hardcoded E-Ink `!important` visual overrides from `style.css`. Removed `#file-modal` and `.fullscreen-modal` specific styling, progressing the declarative UI web component migration.
* **File Tree Stability:** Hardened `currentPath` traversal logic in `<insetu-file-tree>`. Instead of wiping the path and crashing when encountering a missing intermediate directory, the loop now intelligently builds a `validPath` array and safely falls back to the deepest valid directory structure.
* **yenVUI Component Integration:** Wrapped file tree search and normal categorizations inside native `<yenvui-card-group>` grids.
* **Modal Slot and Property Extension:** Upgraded `<insetu-modal>` to support a default pass-through `<slot></slot>` and pass standard `?flush=${this.flush}` properties down into the underlying yenVUI modal wrapper.
