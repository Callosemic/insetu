## Description
This release systematically eliminates imperative DOM element querying in polymorphic entity actions and static UI hooks across all extension modules, replacing element sniffing with decoupled custom DOM events and managed SDK listeners. Additionally, WebSocket connections for the Terminal extension now require security token authentication.

### Key Enhancements & Refinements
* **Event-Driven Entity Actions & UI Hooks (`ext_citations.js`, `ext_freshdesk.js`, `ext_git.js`, `ext_hooks.js`, `ext_research.js`, `ext_term.js`):**
  * Stripped imperative `document.querySelector('insetu-ext-...')` calls inside `entityActions` and `uiHooks` handlers across all 6 extension modules.
  * Replaced direct component invocations with custom event dispatches (`insetu:citations:*`, `insetu:freshdesk:*`, `insetu:git:*`, `insetu:hooks:*`, `insetu:research:*`, `insetu:term:*`).
  * Removed legacy helper objects (`FreshdeskActions`) and in-line DOM queries in favor of pure custom event broadcasting.

* **SDK Brokered Global Listeners (`InSetuElement`):**
  * Migrated all custom event listeners inside component `connectedCallback` lifecycle methods to `this.registerGlobalListener(eventName, target, callback)`.
  * Replaced manual `window.addEventListener` / `removeEventListener` bindings in `InSetuExtGitDiffs` and `InSetuExtTerm` with managed SDK registrations to guarantee automatic teardown upon component unmounting and prevent memory leaks.

* **Terminal Security Hardening (`ext_term.js`):**
  * Injected authentication tokens into the Terminal WebSocket endpoint URL (`wsUrl = ...?token=${token}`), ensuring parity with REST token gate enforcement (ADR 0016).

* **Research Inbox Capability Expansion (`ext_research.js`):**
  * Added explicit `rs-delete` entity action for research jobs allowing direct deletion from polymorphic entity cards.
