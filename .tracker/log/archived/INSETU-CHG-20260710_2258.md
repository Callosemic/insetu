## Description
* **Async Job Offloading:** Migrated `compile_contexts` and `quick_pack` operations off the main Flask thread and onto the SQLite-backed `immediate_jobs` worker queue. Transitioned the frontend to a resilient polling architecture.
* **Bridge Resilience:** Extracted the core VFS transaction loop into `_process_sync_transaction` to dramatically reduce cyclomatic complexity. Introduced support for Regex anchoring (`<<<<<<< SEARCH REGEX`) in the patch protocol.
* **VFS Traversal:** Centralized directory ignore rules within `VFSTransaction.walk()` to natively respect workspace configuration bounds, preventing extraneous I/O sweeps.
* **Frontend Rendering & CSS:** Resolved edge cases in file-card overflow, standardized Lit element slot hydration, and enforced Kanban column rendering order via CSS flexbox ordering (`order: -1`).
* **Extension SDK:** Hardened extension name resolution inside `InSetuElement`, prioritizing static `extensionName` declarations over implicit tag-name inferences to prevent routing collisions.
