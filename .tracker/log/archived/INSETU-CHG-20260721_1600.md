## Description
* **Eradication of ES6 Chassis Imports**: Systematically removed relative cross-boundary imports (`from '../app.js'`, `from '../fs.js'`, `from '../store.js'`) across all 11 frontend extension modules (`citations`, `favorites`, `flow`, `format`, `freshdesk`, `git`, `ingest`, `prompts`, `research`, `skills`, `tracker`).
* **Domain Accessor Migration**: Replaced direct `window.*` global invocations with structured SDK getters on `InSetuElement` (`this.vfs`, `this.sys`, `this.ui`, `this.editor`, `this.utils`) and centralized `window.inSetu` namespace properties.
* **Event-Driven Decoupling**: Converted global window functions (`window.generateDiffs`, `window.loadTrackerBoard`) to custom event listeners (`insetu:git:generate-diffs`, `insetu:tracker:load-board`), achieving true Inversion of Control.
