## Description
* **Terminal Extension Vendorization**: Implemented Dynamic Polyglot Vendorization for the `term` extension, strictly removing external CDN dependencies (`esm.sh`) for security and offline capabilities.
* **Vendor Manifest Registration**: Added a declarative `vendor.json` manifest specifying versions and strict ranges for `xterm` (v5.3.0) and `xterm-addon-fit` (v0.8.0).
* **Local Asset Routing**: Migrated `xterm.css`, `xterm.js`, and `xterm-addon-fit.js` into the local `vendor/` directory and updated `<link>` attributes and ES6 imports to utilize bare specifiers and localized static paths.
