## Description
* **Extension Modal Migration to yenVUI**: Replaced all remaining legacy `<insetu-modal>` web components and `@modal-closed` / `@modal-closing` event listeners across extension JS modules (`ext_citations.js`, `ext_flow.js`, `ext_format.js`, `ext_freshdesk.js`, `ext_git.js`, `ext_hooks.js`, `ext_ingest.js`, `ext_research.js`, `ext_skills.js`, and `ext_tracker.js`) with standardized `<yenvui-modal>` and `@yenvui-modal-closed` / `@yenvui-modal-closing` events.
* **Terminal Engine Hardening & WS Teardown Parity (`engine_term.py` & `ext_term.js`)**: Added fatal exception handling wrapper (`_run_term_stream`) in PTY WebSocket stream, protected socket send operations with a `ws_lock` mutex and `is_closing` teardown flag, and handled WebSocket `CONNECTING` states gracefully in frontend teardowns. Added a 100ms delayed resize message on open to prevent full-duplex proxy collisions.
* **Context & Diff Type Filtering Alignment (`engine_flow.py` & `engine_git.py`)**: Added `exclude_types=["diff", "flow"]` to context lookups in `engine_flow.py` and `include_types=["gather"]` in `engine_git.py` to prevent context recursion.
* **Prompts Directory Tree Support (`engine_prompts.py`)**: Updated `provide_available_prompts` to include `.gitkeep` and `.keep` files, enabling empty prompt directories to render in UI file trees.
* **Flow UI Hydration (`ext_flow.js`)**: Added explicit `this.requestUpdate()` calls following batch additions and deletions to ensure immediate UI re-rendering.
