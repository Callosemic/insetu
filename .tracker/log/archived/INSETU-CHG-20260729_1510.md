## Description
* **InSetu Modal Event Delegation (`ui_modal.js`)**: Removed `if (e && e.target !== e.currentTarget) return;` guard clause in `InSetuModal.close(e)` to allow composed `@yenvui-modal-closed` events from child `<yenvui-modal>` instances to trigger parent component closure and dispatch standard `modal-closing` and `modal-closed` custom events.
* **Generic Settings SDK Domain Accessor Migration (`ui_system_settings.js`)**: Refactored `InSetuGenericSettingsModal.saveSettings()` to invoke `window.inSetu.sys.executeSystemCompile` instead of legacy un-namespaced `window.executeSystemCompile`, enforcing strict ADR 0024 domain accessor compliance.
