## Description
* **Context Event Bus Standardization (`engine_flow.py`, `engine_git.py`)**: Replaced raw, global `hooks.emit()` calls with tenant-scoped `ctx.emit()` methods across the Flow and Git backend engines, ensuring lifecycle events automatically inherit request scope and authorization boundaries.
* **Flow Engine VFS & Store Refactoring (`engine_flow.py`, `ext_flow.js`)**: Refactored workflow batch compilation and deletion to utilize `ctx.store` and `ctx.vfs.save` instead of legacy filesystem helpers (`load_workflows`, `execute_vfs_delete`). Wrapped `sys.executeWorkspaceMutation` in async try/catch handling and normalized batch card entity paths.
* **yenVUI Component & Chunk Resolution (`ext_flow.js`, `ext_hooks.js`)**: Refactored batch chunk selection modals to render using `<yenvui-card>` and `<yenvui-async-btn>` primitives with `disableSelection=${true}`. Replaced legacy `<insetu-async-btn>` instances in the Hooks extension with `<yenvui-async-btn>`.
* **Static Extension Name Getters (`ext_citations.js`, `ext_flow.js`, `ext_format.js`, `ext_freshdesk.js`)**: Added `static get extensionName()` methods across `InSetuExtCitationsModals`, `InSetuExtFlowActions`, and `InSetuExtFormatModals` to fulfill static fitness guardrails (`EXTENSION_NAME_GETTER_MANDATE`). Cleared obsolete non-static getters.
* **Hooks Topology Scoping (`engine_hooks.py`)**: Updated VFS mutation trigger processing in the Automation Hooks extension to inspect repository topologies via `ExtensionContext('gather', workspace_id)`, referencing the Gather domain SSOT.
