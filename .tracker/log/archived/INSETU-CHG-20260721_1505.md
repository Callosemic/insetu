## Description
* **FS Utility Migration**: Physically relocated file-system specific functions (`fetchAndCopy`, `fetchAndDownloadState`, `viewSourceFile`, `createFileCard`) from the monolithic `app.js` to their proper domain in `fs.js`. Refactored imports in `ext_flow.js`, `ext_git.js`, and `ext_tracker.js` to comply with strict domain boundaries.
* **Tracker SDK Compliance**: Eradicated legacy `get_connection()` imports from `engine_tracker.py`. All database executions now route properly through the `ExtensionContext('tracker', workspace_id).db` interface, ensuring strict multi-tenant isolation and V2 SDK compliance.
* **Prompt Parameter Support**: Upgraded the `engine_prompts.py` regex parser (`{{include_prompt: ...}}`) to capture optional inline parameter blocks, enabling dynamic context passing into prompt templates.
* **Active Workspace Abstraction**: Migrated `ext_prompts.js` to use the centralized `window.inSetu.utils.getActiveWorkspace()` helper instead of deep-sniffing the `AppStore` state tree.
