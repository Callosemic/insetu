## Description
This release focuses heavily on decoupling the core frontend monolith and centralizing utility pipelines to satisfy the UDF and Single Source of Truth mandates.

### Frontend Decoupling
* **The "Junk Drawer" Eradication:** Purged the monolithic `app.js` of domain-specific operational logic.
* **VFS Domain (`fs.js`):** Extracted `fetchAndCopy`, `fetchAndDownloadState`, `shareFiles`, and `deleteEmptyFolder`.
* **Gather Domain (`gather.js`):** Extracted `executeQuickPack`, `openQuickPackModal`, and `clearQuickPacks` into the contextual gather engine logic.
* **Editor Domain (`ui_editor.js`):** Extracted `resolveEditorMode`, `getEditorContent`, `setEditorContent`, `insertTextAtCursor`, and `insertLinkToEditor` into a unified editor abstraction layer.
* **Active Workspace DRYing:** Introduced `window.inSetu.utils.getActiveWorkspace()` inside `store.js` to standardize tenant sniffing across the frontend, replacing localized `sessionStorage` fallback blocks in `api.js`, `app.js`, `sdk.js`, and `ui_system_settings.js`.

### Backend Enhancements
* **VFS Deep Directory Deletion:** Upgraded the `fs/delete` execution layer in `routes_fs.py` to utilize `shutil.rmtree` when targeting directories, natively supporting recursive folder removal.
* **Job Ledger DRYing:** Centralized job payload generation in `workers.py` via `_prepare_job_payload`, eradicating duplicate connection pooling code.
* **Cartography DRYing:** Moved `build_tree_dict` and `generate_ascii_tree` out of `cartographer.py` and `engine_gather.py` to the central `utils_core.py` SSOT to prevent logic drift.
* **Yomama Auto-Healing:** Upgraded the Sync Bridge (`engine_bridge.py`) parser to detect missing `<<<<<<< SEARCH` tags (common in LLM genesis patch hallucinations) and seamlessly auto-heal them into valid replace-only operations without failing the transaction.
