## Description
* **Declarative Zone Hooks:** Upgraded the `zone:file-card-actions` hooks inside the Favorites and Git extensions. Replaced the legacy, imperative `document.createElement` node injections with declarative Lit `html` templates, closing the final gaps in our Web Component migration.
* **UDF State Hardening:** Eradicated the N+1 network fetch penalty in the Flow extension by enabling surgical state splices. Removed `FormData` DOM scraping from the Skills extension in favor of reactive `@input` variable bindings.
* **Component Standardization:** Standardized the HTML structure of the `fuzzy-search-wrapper` across all active extensions. Migrated floating UI action buttons in sub-navigation slots to use the unified `system-action-btn` class alongside encapsulated `sharedStyles`.
