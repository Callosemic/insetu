## Description
* **Asynchronous Bridge Sync:** Migrated the core Yomama Sync Bridge (`/api/bridge/sync`) into the `immediate_jobs` ledger. The controller now instantly returns a `202 Accepted` response with a tracking `job_id`, unblocking the HTTP event loop and satisfying the I/O Block Ban.
* **Bridge Telemetry Polling:** Integrated frontend telemetry into `bridge.js`, utilizing the centralized Metronome dispatcher (now running at 100ms resolution) to poll background job statuses and reconcile the UI without hanging the browser.
* **True LRU Database Eviction:** Refactored the `get_connection` function in `db.py` to pop and re-insert accessed keys. This ensures the connection pool executes a genuine Least Recently Used (LRU) eviction rather than a naive First-In-First-Out (FIFO) queue, preventing frequent cache misses and connection churn.
* **VFS Barrier Synchronization:** Implemented the `_VFS_WRITE_QUEUE.join()` barrier within the background bridge sync worker to ensure physical parity is achieved before completing the job state.
* **Markdown Preview Streamlining:** Eradicated the standalone DOMPurify/Marked preview pane from `fs.js` and `index.html`. We now rely exclusively on `EasyMDE`'s native read-only capabilities, significantly reducing XSS vectors and stripping unnecessary UI toggle states.
* **Idempotency Guardrails:** Upgraded `routes_bridge.py` to calculate deterministic job hashes using `json.dumps(data, sort_keys=True)`, ensuring duplicate requests for the same patch matrix safely reattach to the running transaction.
