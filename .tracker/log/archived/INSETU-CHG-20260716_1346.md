## Description
Graduated the entire extension ecosystem to the Polymorphic Entity-Action Card Registry framework, completely separating the presentation layer from domain-specific actions and reinforcing the Unidirectional Data Flow (UDF) contract.

### Architectural Restructuring
* **Ecosystem Decoupling:** Migrated all core extensions (`citations`, `favorites`, `flow`, `format`, `git`, `ingest`, `prompts`, `research`, `skills`, `term`, `tracker`) into explicit, self-contained subdirectories under `insetu/extensions/` and `insetu/static/js/extensions/`.
* **Polymorphic Action Mapping:** Replaced legacy, high-maintenance UI hooks (like `zone:file-card-actions`) with declarative `entityActions` registry matrices mapped to specific types (`file`, `repo`, `task`, `citation`, `skill`, `research_job`).
* **Metadata Alignment:** Standardized human-readable `title` and `description` string allocations across all backend blueprint extension constructors.
* **PTY Stream Isolation:** Hardened the embedded terminal engine (`engine_term.py`) to resolve active tenant roots statelessly via the encapsulated `ctx.paths` descriptor.
