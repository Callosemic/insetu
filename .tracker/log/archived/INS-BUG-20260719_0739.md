## Description
alongside its own stuff, a newly initialized repo that is local-only appears to also list all untracked artifacts from the base workspace root.

## Notes / Execution Log
* **Resolution (2026-07-21):** Modified `_background_sweep_status` in `engine_git.py`. Removed `status == "??"` from the global `files.append` condition. Sweepable State now strictly catches files explicitly excluded from normal Diffs by the `.insetu/config.json` ignore matrices, preventing global workspace untracked files from bleeding into localized repository views.
