## Description
This session finalized the core alignment of the background execution layer with the V2 SDK specification, eradicated the `yield` generator-hijack anti-pattern, and introduced a fully compliant support integration module.

### Core Enhancements & Refinements
* **Localized Background Worker Decorators:** Migrated backend extensions (`engine_git.py`, `engine_format.py`, `engine_research.py`, `engine_tracker.py`) from floating global callback definitions to the blueprint-level `@blueprint.worker` decorator tracking framework.
* **Eradication of Magic Generators:** Replaced brittle generator `yield` progress sequences with explicit calls to `ctx.jobs.update_progress()`, protecting standard data iteration capabilities.
* **Freshdesk Support Extension Integration:** Deployed a brand-new, fully architecture-compliant extension (`engine_freshdesk.py`, `ext_freshdesk.js`) featuring asynchronous multi-page ticket streaming, automated timeline conversation threading, localized file system thread archival, and interactive polymorphic entity action controls.
* **Research Inbox Graduation:** Upgraded `ext_research.js` to handle asynchronous context packing via the centralized SDK download wrappers, implemented localized metronome-safe element polling loops, and wired new tab refresh filters.
* **Terminal Memory Hygiene and Lifecycle Hardening:** Upgraded `ext_term.js` to defensively trap trailing initialisation and communication timers (`_initTimer`, `_wsTimer`), safely severing reactive WebSocket handlers upon element disconnection to block cross-tenant view leaks.
* **Linter Guardrail Enforcement:** Codified the `BANNED_MAGIC_GENERATOR` rule into `fitness_functions.py` to programmatically reject the use of raw `yield` patterns inside extension worker tasks.
