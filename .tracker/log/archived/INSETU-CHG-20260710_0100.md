## Description
* **Explicit API Client Integration:** Established `window.inSetu.api` to provide `workspace` and `system` scoped fetch capabilities, fully replacing the greedy global fetch interceptor.
* **Extension SDK V2 (Frontend):** Shipped `InSetuElement` LitElement base class and `createExtensionStore`, abstracting tenant lifecycle teardowns and API route mapping.
* **Extension SDK V2 (Backend):** Shipped `InSetuExtension`, `ExtensionContext`, and `VFSTransaction` to eliminate boilerplate path resolving and unguarded VFS bypasses.
* **Declarative SQLite Schemas:** Implemented auto-migrating declarative schemas (`register_schema`) that evaluate and execute natively on system boot.
* **UI Standardization:** Added native fuzzy search capabilities directly to `<insetu-file-tree>` and implemented the `<insetu-async-btn>` for unified, stateful button feedback.
* **Fitness Functions Enforcement:** Upgraded `fitness_functions.py` to strictly ban raw `os.walk`, raw `open()`, and raw `fetch()` across all extension domains to ensure absolute framework compliance.
