## Description
This release introduces batch sweep operations across repositories, hardens Git diff path filtering against sister repo collisions, and decouples modal components from multi-instance sub-tab views in the Issue Tracker.

### Git Version Control (`engine_git.py` & `ext_git.js`)
* **Global Sweep Action**: Added a `🚀 Sweep All` batch transaction control to commit and push all untracked/excluded files across pinned repositories simultaneously.
* **Diff Target Boundary Sanitization**: Fixed false-positive prefix matching in `generate_diff_context()` to prevent sister repository name collisions (e.g., matching `core` against `core-api`).
* **Git Porcelain Path Parsing**: Injected `.strip('"')` on incoming porcelain status lines to sanitize quoted file paths.
* **Resilient Cache Hydration**: Implemented manifest fallback hydration for `cachedDiffFiles` upon component mounting and injected job locks to block overlapping diff generation triggers.

### Issue Tracker (`ext_tracker.js`)
* **Global Modal Slot Decoupling**: Refactored ticket creation and editing modals into `InSetuExtTrackerModals`, registered under `slots:global`. This prevents DOM duplication and memory leaks across active sub-tabs.
* **Frontmatter Serialization Alignment**: Fixed frontmatter serialization to write `closed_at` timestamps correctly during ticket save sequences.
