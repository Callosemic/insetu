## Description
Implemented granular conditional visibility for workflow batches and updated manifest hydration logic.

* **Workflow Visibility Prerequisites:** Added `show_if_exists` and `show_if_missing` capabilities to the Flow extension (`engine_flow.py`, `ext_flow.js`). Workflows can now be dynamically hidden or shown based on the presence of specific contextual artifacts within the central `AppStore.manifest`.
* **Git Manifest Synchronization:** Appended a `setTimeout` loop in `ext_git.js` to automatically rehydrate the frontend manifest state upon the completion of a background diff generation sweep, ensuring diff metadata is immediately available for the new UI repository filtering tools.
