## Description
Refactored all core backend engine extensions and frontend interface components to utilize standard InSetu SDK ecosystem structures, stabilizing data initialization and communication channels.

### Implemented Enhancements
*   **Backend Standardization:** Converted Flask `Blueprint` usage to `InSetuExtension` across all 8 core modules. Normalized route handlers to relative endpoints, delegating multi-tenant path routing and permission evaluation to the base layer.
*   **Declarative Schema Mapping:** Replaced procedural `CREATE TABLE` execution hooks with structured schema matrices (`CITATIONS_SCHEMA`, `SKILLS_SCHEMA`, `TRACKER_SCHEMA`) handled transactionally by the system loader.
*   **Frontend Modernization:** Shifted client extensions from standard `LitElement` to `InSetuElement`. Transitioned state tracking from vanilla Zustand configurations to the unified `createExtensionStore` manager, enabling automated UI subscriptions and self-cleaning lifecycle boundaries.
*   **Unified Job Polling:** Replaced scattered client-side `registerTick` timers with a standardized `this.api.pollJob` reactive listener architecture.
