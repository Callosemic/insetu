## Description
* **System Reboot Action Trigger (`ui_system_settings.js`)**: Integrated a `🔄 Reboot System` button inside the `InSetuSystemSettings` modal footer, allowing operators to trigger a daemon reboot (`/api/system/reboot`) with progress overlay feedback (`isRebooting`) and automatic server recovery polling.
* **Modal Footer Flex-Wrap (`ui_system_settings.js`)**: Applied `flex-wrap: wrap;` to the settings modal footer controls to prevent button overflow on smaller screens.
* **Settings Action Event Listener (`ui_system_settings.js`)**: Implemented a global `sutram-settings-action` listener in the system settings module that routes extension settings action button clicks to `/api/<workspace_id>/<endpoint>` via `window.inSetu.api.workspace`, with automatic job polling for asynchronous worker receipts.
* **Bridge Actions Store Reactivity (`bridge.js`)**: Added `this.requestUpdate()` inside the `AppStore` subscription callback in `InSetuExtBridgeActions` to guarantee immediate UI re-rendering when pinned repository filters update.
