## Description
* **Yomama Sync Bridge UI Refactoring (`bridge.js`)**: Replaced monolithic raw text area with group-collapsed `<sutram-collapsible>` file cards containing patch chunks in `<sutram-card-group>`. Added chunk editor modal using `<sutram-modal>`, `<sutram-editor>`, swipe and button navigation (`_navigateChunk`), and registered `yomama` entity actions (`yomama-copy`, `yomama-delete`, `yomama-swap`). Integrated `InSetuExtBridgeActions` with `<sutram-filter-dropdown>` and `<insetu-repo-filter>` bound to `GatherStore`.
* **Frontmatter Editor Component (`ui_editor.js`)**: Implemented `InSetuFrontmatterEditor` Lit component extending `InSetuElement` with collapsible YAML metadata controls, integrated `<insetu-markdown-editor>`, `<sutram-entity-actions>`, and custom event hooks (`insetu:frontmatter-loaded`, `insetu:request-frontmatter`). Registered `editor` extension in `ExtensionRegistry`.
* **Sutram Component & Vendor Alignment (`ui_file_tree.js`, `ui_filter_pills.js`, `ui_system_settings.js`, `config.js`, `gather.js`)**: Replaced all remaining `<yenvui-*>` tags and event listeners with vendorized `<sutram-*>` primitives (`<sutram-toolbar>`, `<sutram-card-group>`, `<sutram-collapsible>`, `<sutram-modal>`, `<sutram-pill>`).
* **VFS Modals & Drag Utilities (`fs.js`)**: Replaced custom ghost drag DOM elements with `bindGhostDrag` from Sutram utilities. Delegated file downloads and blob creation to `sutramDownloadFile` and `downloadBlob`. Converted `InSetuFileModal` and `InSetuVFSModals` to native `<dialog>` elements and `<sutram-async-btn>` footer controls.
* **Topology Store Decoupling (`store.js`, `gather.js`)**: Migrated `pinnedRepos` state management and `localStorage` persistence from `AppStore` to `GatherStore`.
* **Declarative System Reboot Overlay (`ui_primitives.js`, `config.js`, `sdk.js`)**: Added `InSetuRebootOverlay` Web Component responding reactively to `AppStore.isRebooting` and `rebootType`. Updated workspace config saves to trigger declarative reboot state and poll for server recovery. Added `setStatus` and `compileSystem` helpers to `InSetuElement`. Added `window.inSetu.utils.serializeFrontmatter`.
