## Description
This ledger item records the systemic stabilization and tech-debt mitigation effort to resolve critical I/O bottlenecks and frontend state leaks:

* **Immediate Jobs Substrate:** Deployed the `immediate_jobs` SQLite ledger and `submit_immediate_job` dispatcher in `workers.py`, providing a tracked, polling-compatible surface for heavy background operations.
* **Asynchronous Event Bus:** Extended `HookRegistry` with `emit_background` to dispatch long-running lifecycle hooks (e.g., `post_file_save`) to the ThreadPool, freeing the VFS commit queue from downstream paralysis.
* **Ephemeral Artifacts Ledger:** Replaced fragile string-matching garbage collection with a formal `ephemeral_artifacts` SQLite table and an automated Metronome sweep, guaranteeing deterministic cleanup of transient files (like quick-packs).
* **Surgical Tracker & Citation Reconciliation:** Eliminated O(N) DOM re-renders. `ext_tracker.js` and `ext_citations.js` now update local Javascript state and surgically replace specific HTML nodes in-place. Tracker backend hooks were upgraded to perform surgical SQLite UPSERTs rather than global repository walks.
* **UDF Hardening & Floating Globals:** Swept the frontend to remove floating variables (`globalBrowsePath`, `currentPushRepo`, `browserConfig`, etc.) from module scopes, merging them directly into the central Zustand `AppStore`. This guarantees safe cache evictions during stateless tenant swaps.
* **Zombie Interval Eradication:** Consolidated rogue `setInterval` polling loops into the centralized `ExtensionRegistry.registerTick` frontend metronome to prevent memory leaks across workspace transitions.
