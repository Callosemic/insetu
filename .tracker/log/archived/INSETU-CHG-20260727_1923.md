## Description
* **Toast Container Web Component (`ui_primitives.js`)**: Created `<insetu-toast-container>` extending `InSetuElement` (`static get extensionName() { return 'toast'; }`). Subscribes to `ToastStore` and renders `<yenvui-toast-container>` with automated `#insetu-toast-root` DOM mounting.
* **File Card Selection State Reconciliation (`ui_file_tree.js`)**: Implemented `updated(changedProperties)` lifecycle hook in `<insetu-card>` to synchronize visual selection state against `SelectionStore.selectedItems` whenever Lit reuses DOM nodes during list filtering.
* **App Shell Missing Config Banner (`ui_app_shell.js`)**: Added `configMissing` reactive property to `<insetu-app-shell>`, subscribing to `AppStore.configMissing`. Renders a non-disruptive warning banner with dismiss action when operating in empty fallback state.
