## Description
* **Version Control Settings Scoping (`engine_git.py`)**: Migrated repository pull strategy configurations from dynamic functions to static `GIT_SETTINGS_SCHEMA` with explicit `scope: "repo"`, updating `_background_git_pull` setting lookups to pass target repositories.
* **Tailscale Network Settings Scoping (`engine_tailscale.py`)**: Explicitly declared `scope: "daemon"` across daemon-level auto-bind and port configuration settings in `TAILSCALE_SETTINGS_SCHEMA`.
* **Terminal PTY Stream Decoding (`engine_term.py`)**: Hardened `_run_term_stream` WebSocket output by decoding raw PTY bytes to UTF-8 strings before sending (`safe_send(data.decode('utf-8', errors='replace'))`).
* **Semantic Update Release Previews & Build Command Configuration (`engine_update.py`, `ext_update.js`)**:
  * Added `scope: "repo"` and `scope: "workspace"` annotations to `UPDATE_SETTINGS_SCHEMA`.
  * Implemented `preview_publish` background worker and endpoint to allow dry-run package release previews prior to distribution.
  * Added `pyproject.toml` build command parsing and `update_toml_config` worker/endpoint to dynamically update build commands.
  * Added `previewPublish` action, preview tab switcher, and Build Command management UI in `ext_update.js`.
  * Hardened status polling against cross-tenant state leaks during active workspace switches.
