## Description
* **VFS Commit Pipeline Drain Safeguard (`insetu/routes_fs.py`)**: Refactored `_vfs_commit_worker()` shutdown condition to forcefully drain all pending write tasks from `_VFS_WRITE_QUEUE` before honoring the shutdown signal, preventing data loss during system termination or workspace swaps.
* **SDK V2 Extension Context Expansion (`insetu/sdk/extension.py`)**:
  - Expanded `ExtensionContext` with `expand_selection(items)` to provide SSOT polymorphic expansion and deduplication of selection items (files, folders, system chunks).
  - Added `ctx.get_manifest_files()`, `ctx.emit()`, and `ctx.emit_background()` for tenant-scoped event broadcasting.
  - Expanded `DatabaseWrapper` with `.update()` and `.get_by_id()` CRUD helpers.
  - Added `JobManager.update_meta()` for updating job metadata dictionaries off-thread.
  - Removed generator `yield` progress handling in worker tasks to enforce explicit `ctx.jobs.update_progress()` calls.
* **Frontend SDK & Shadow DOM Piercing (`insetu/static/js/sdk.js`)**:
  - Upgraded `InSetuElement.extName` getter to support Shadow DOM boundary piercing and layout slot mapping via `ExtensionRegistry`.
  - Exposed `window.inSetu.utils.parseFrontmatter` and `window.inSetu.utils.extractManifestFiles`.
* **Global Stores & UDF Alignment (`insetu/static/js/store.js`, `insetu/static/js/app.js`)**:
  - Added `StatusStore` and `ToastStore` Zustand stores.
  - Simplified `window.alert` hijacking to route directly to `ToastStore`.
  - Excised legacy imperative missing-config banner DOM creation logic in `app.js` (delegating to declarative `<insetu-app-shell>`).
* **Cartographer & VFS Cartography Parity (`insetu/utils_core.py`, `insetu/vfs.py`)**:
  - Centralized manifest chunk flattening via `extract_manifest_files()`.
  - Refactored `VFSTransaction.walk()` to delegate file inclusion and ignore rules directly to `get_valid_workspace_files()` SSOT.
* **Immediate Jobs Metadata Ledger (`insetu/workers.py`)**:
  - Added `meta_json TEXT` column migration to `immediate_jobs` SQLite schema and added `update_immediate_job_meta()` worker utility.
* **Python Architectural Fitness Rules (`tests/fitness/rules_python.py`)**:
  - Refactored Python linter rules into explicit test functions (`test_selection_expansion_mandate`, `test_backend_extension_event_emit_mandate`) enforcing `ctx.expand_selection()` and `ctx.emit()` across extension modules.
