* **Citations URI Canonicalization (`engine_citations.py`)**: Standardized citation context output file paths to canonical `ctx://contexts/citations_context.txt` and `ctx://contexts/{k}_citations_context.txt` URIs.
* **Dev Telemetry Filter (`engine_dev.py`)**: Updated `log_vfs_telemetry` to ignore VFS mutations explicitly flagged with `ignore_ledger: True`.
* **Workflows Engine & UI Hardening (`engine_flow.py`, `ext_flow.js`)**:
  * Adopted `get_domain_artifact_path` and `reconcile_and_vacuum_domain` for domain artifact resolution and vacuuming.
  * Integrated `ctx.expand_selection()` for centralized selection expansion across files, folders, and `ctx://` URIs.
  * Added incremental compilation skipping based on `touched_buckets`, `touched_diffs`, and event ledger activity.
  * Added UI auto-canonicalization of include URIs (`ctx://diffs/`, `ctx://workflows/`, `ctx://prompts/`, `ctx://contexts/`, `vfs://`) and candidate healing search ("✨ Fix → ...") for missing mapped contexts.
  * Added `onViewActivated()` lifecycle hooks and wrapped Lit element rendering in `try...catch` blocks to prevent render crashes.
* **Version Control Engine & UI Optimization (`engine_git.py`, `ext_git.js`)**:
  * Adopted `get_domain_artifact_path` and `reconcile_and_vacuum_domain`.
  * Updated background diff compilation to return `next_kwargs` (`touched_diffs`) for worker step chaining into `engine_flow`.
  * Canonicalized diff URIs to `ctx://diffs/` and updated pre-warming of sweep status tasks on `topology_boot_complete`.
  * Updated frontend `generateDiffs()` and rendering to read diff outputs directly from `AppStore.getState().manifest?.ctx` and subscribe to active module compilation status.
* **Prompt Library Resolution (`engine_prompts.py`, `ext_prompts.js`)**:
  * Extended `resolve_prompt_artifacts` (`vfs_resolve_file` and `vfs_resolve_path` hooks) to handle `.insetu/prompts/`, `prompts/`, and `ctx://prompts/` while preserving subdirectories.
  * Added `onViewActivated()` lifecycle hooks and store update comparison guards to prevent unnecessary re-renders and queue warming loops.
* **Issue Tracker Date Normalization & Offline Guardrails (`engine_tracker.py`, `ext_tracker.js`)**:
  * Updated `handle_tracker_vfs_mutations` to support `mutation_type` and full event operation sets (`save`, `added`, `modified`, `create`, `created`, `delete`, `deleted`, `remove`, `removed`).
  * Implemented `_safe_date_cmp()` to handle `T` vs space ISO date formatting differences cleanly, preventing unnecessary YAML rewrites and ghost duplicate deletions.
  * Added guardrails (`isOffline && touchedTracker.length <= 3`) in `vfs-mutated` listener to prevent N+1 fetch storms during bulk boot syncs or multi-file mutations.
