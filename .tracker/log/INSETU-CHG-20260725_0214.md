## Description
This release completes the migration of extension entity actions to the declarative `emitEvent` schema, centralizes custom event broadcasts through the SDK event bus, unifies prompt file browsing with the global browse path state, and resolves folder un-favoriting in the Favorites extension.

### Core Enhancements & Refinements
* **Declarative Entity Action Schema Migration (`ext_citations.js`, `ext_flow.js`, `ext_freshdesk.js`, `ext_git.js`, `ext_hooks.js`)**: Migrated custom event dispatching in `entityActions` definitions from imperative `onClick`/`asyncAction` functions calling `window.dispatchEvent` to declarative `emitEvent: (data) => ({ name, detail })` mappings.
* **SDK Event Bus Centralization (`ext_citations.js`, `ext_git.js`, `ext_ingest.js`, `ext_research.js`, `ext_term.js`, `ext_tracker.js`)**: Replaced manual `window.dispatchEvent` and `ExtensionRegistry.executeUIHook` invocations across extension modules with centralized `window.inSetu.events.emit` and `window.inSetu.events.emitHook` calls.
* **Favorites Extension Hardening (`engine_favorites.py`, `ext_favorites.js`)**: Enhanced `add_favorite` route and client store to explicitly support `folderpath` parameters alongside `filepath`. Updated `<insetu-fav-btn>` and `fave_toggle_folder` action cards to track and toggle folder favorites correctly (resolving `INS-BUG-20260720_1139`). Removed deprecated `zone:fs-dropdown-menu` hook.
* **Prompts Path State Unification (`ext_prompts.js`)**: Replaced standalone `currentPromptsPath` state in `PromptsStore` with the centralized `AppStore.globalBrowsePath`, ensuring consistent directory drill-down state across primary views.
* **UDF Tab Context Inspection (`ext_git.js`)**: Replaced imperative DOM query (`document.getElementById('sub-diffs')`) in `zone:tab-changed` hook with reactive `AppStore` state evaluation (`activeSubTabs['context'] === 'diffs'`).
