## Description
* **Core Text Blob Viewer Component (`InSetuBlobViewer`)**:
  * Implemented `InSetuBlobViewer` (`<insetu-blob-viewer>`) in `ui_primitives.js`, mounted at document body level.
  * Added `blobViewer` state (`open`, `title`, `content`, `suggestedFilename`) to `AppStore` in `store.js`.
  * Exposed `window.inSetu.ui.viewTextBlob(title, content, suggestedFilename)` accessor to display text blobs inside a `<sutram-modal>` with read-only textarea and dynamic action bar controls.
* **Polymorphic Text Blob Entity Actions (`core_text_blobs`)**:
  * Added `'core_text_blobs'` to `CORE_MODULES` in `sdk.js`.
  * Registered `core_text_blobs` extension providing entity actions for `targetEntity: 'text_blob'`:
    * `blob-copy` (`📋 Copy`): Copies text content to clipboard via `window.inSetu.utils.copyRawText`.
    * `blob-save-vfs` (`💾 Save to VFS`): Opens folder browser and writes text blob to VFS via `window.inSetu.sys.executeWorkspaceMutation('fs/save', ...)`.
    * `blob-download` (`⬇️ Download`): Generates client-side blob download.
* **Yomama Sync Bridge Syntax Error Diff Viewer (`bridge.js`)**:
  * Refactored `view-diff` console action in `InSetuExtBridge` to consume `this.ui.viewTextBlob('Syntax Error Diff', decodedDiff, ...)` instead of deprecated `this.vfs.openVirtualFile`.
* **Tracker & Semantic Update Text Blob Viewer Adoption (`ext_tracker.js`, `ext_update.js`)**:
  * Refactored historical changelog viewer in `InSetuExtTracker` to invoke `this.ui.viewTextBlob("Historical Changelog", changelog, ...)` and integrated `<sutram-entity-actions .entityType=${'text_blob'}>` into the changelog modal.
  * Added `<sutram-entity-actions .entityType=${'text_blob'}>` into the release preview and execution log modal header in `InSetuExtUpdate` to support copying, VFS saving, and downloading release reports.
* **Fitness Function Enforcement & Architectural Mapping (`rules_javascript.py`, `CODE_INDEX.md`)**:
  * Codified `VIEW_TEXT_BLOB_MANDATE` static analysis linter rule in `rules_javascript.py` to prohibit deprecated `vfs.openVirtualFile` calls in favor of `this.ui.viewTextBlob()`.
  * Synchronized repository architectural map (`CODE_INDEX.md`).
