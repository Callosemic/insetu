## Description
* **Sutram Form Control Migration**: Migrated all native HTML `<input>`, `<select>`, and `<textarea>` elements across all 17 Tier 3 domain extensions (`citations`, `dev`, `favorites`, `flow`, `format`, `freshdesk`, `git`, `hooks`, `ingest`, `notes`, `prompts`, `publish`, `research`, `skills`, `term`, `tracker`, `update`) to vendorized Sutram primitives (`<sutram-input>`, `<sutram-select>`, `<sutram-textarea>`, `<sutram-toggle>`), enforcing the `SUTRAM_FORM_CONTROL_MANDATE`.
* **ADR 0041 UI Hooks Deprecation**: Permanently purged legacy `uiHooks` objects and `zone:*` string hook specifiers across all frontend extension modules. Replaced with declarative `customEditors` mappings, expanded `layoutSlots`, `InSetuElement` lifecycle methods (`onForceRefresh()`, `onWorkspaceChanged()`), and the Typed Event Bus (`window.inSetu.events`).
* **Semantic API Gateway Client Alignment**: Updated all client API invocations across extension components to consume semantic HTTP shorthand methods (`this.api.get()`, `this.api.post()`, `this.api.delete()`, `window.inSetu.api.get()`, `window.inSetu.api.post()`), completely deprecating raw `api.workspace` and `api.system` string calls (ADR 0016 / ADR 0024).
* **Shared Styles Vendorization**: Replaced relative `../core/shared_styles.js` import paths with vendorized `../../vendor/sutram/js/shared_styles.js` across all extension LitElement components.
* **Event Bus Event Name Standardization**: Migrated legacy `zone:*` custom events (`zone:vfs-mutated`, `zone:soft-refresh`, `zone:context-metadata`, `zone:file-fetch-url`, `zone:global-manifest-files`, `zone:global-manifest-whitelist`, `zone:post-import-url`) to the normalized `insetu:*` event bus namespace (`insetu:vfs-mutated`, `insetu:soft-refresh`, etc.).
* **Date & Artifact Formatting Consolidation**: Standardized date rendering using `this.utils.formatDate()` and `this.utils.timeAgo()`, and unified artifact size calculations using `this.utils.formatArtifactSize(meta)`.
* **Lifecycle & Teardown Hygiene**: Integrated `this.registerGlobalListener`, `this.utils.debounce`, and unmount guards (`!this._isUnmounted`) across extensions (`term`, `dev`, `research`, `tracker`) to prevent memory leaks and ghost polling during multi-tenant workspace switches.
