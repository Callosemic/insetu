## Description
* **Canonical VFS URI Resolution (`engine_flow.py`, `engine_git.py`)**: Replaced direct physical file path calls (`_resolve_physical_path`, `abs_filepath.as_posix()`) and deprecated `is_absolute_artifact` flags with canonical `vfs://` and `ctx://` scheme URIs (`vfs://{repo}/{rel_path}`) and `ctx.resolve_path()`.
* **Step-Chaining Diff Telemetry Optimization (`engine_git.py`)**: Updated `generate_diff_context` to track and return `truly_modified_diffs` (a set of diff URIs whose content actually changed), passing them to downstream step chaining via `next_kwargs` (`touched_diffs`) to prevent redundant workflow batch compilations.
* **Pure VFS Flow Pre-Save Archive Handling (`engine_flow.py`)**: Refactored `handle_flow_pre_save` to eliminate direct `os` filesystem manipulation (`os.makedirs`, `os.listdir`, physical `open`), routing archive operations entirely through `ctx.vfs.walk()`, `ctx.vfs.read()`, `ctx.vfs.save()`, and `ctx.vfs.delete()`.
* **Domain Vacuum Path Canonicalization (`engine_flow.py`, `engine_git.py`)**: Standardized `reconcile_and_vacuum_domain` invocation arguments to pass canonical domain URIs (`ctx://workflows`, `ctx://diffs`).
