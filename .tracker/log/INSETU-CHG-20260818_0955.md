## Description
* **Client SDK API Gateway Semantic Methods (`insetu/static/js/core/api.js`)**: Expanded `window.inSetu.api.workspace` and `window.inSetu.api.system` to expose explicit `.get()`, `.post()`, and `.delete()` shorthand methods. Handled automatic `FormData` header detection versus JSON content-type headers.
* **InSetuElement SDK Alignment (`insetu/static/js/core/sdk.js`)**: Refactored `InSetuElement.prototype.api` methods (`.get()`, `.post()`, `.delete()`) to delegate directly to the underlying `window.inSetu.api.workspace` semantic helpers.
* **Core API Call Site Migration**: Migrated all raw `api.workspace()` and `api.system()` call sites across core modules to use semantic methods:
  * `insetu/static/js/core/bridge.js`: Migrated `fetchHistory` to `window.inSetu.api.workspace.get()`.
  * `insetu/static/js/core/fs.js`: Migrated `fetchAndCopy`, `downloadFromModal`, `openNewFolderModal`, `viewSourceFile`, `executeDeepLinkSearch`, and job polling to semantic `.get()` and `.post()` calls.
  * `insetu/static/js/core/gather.js`: Migrated `packSelectionPayload` and `clearQuickpacks` to `window.inSetu.api.workspace.post()`.
  * `insetu/static/js/core/config.js`: Migrated `_testRepoBucketing`, `openModal`, `_saveConfig`, and template fetching to `window.inSetu.api.system` and `window.inSetu.api.workspace` semantic calls.
  * `insetu/static/js/core/components/ui_editor.js`: Migrated `_loadFile` to `window.inSetu.api.workspace.get()`.
  * `insetu/static/js/core/components/ui_system_settings.js`: Migrated `_openGenericSettings`, `_openSettings`, `_saveActiveExtensions`, `_loadHostDirs`, `_loadWorkspacesManifest`, `_handleCreateWorkspace`, `_handleDeleteWorkspace`, and `sutram-settings` event handlers to semantic `.get()` and `.post()` methods.
