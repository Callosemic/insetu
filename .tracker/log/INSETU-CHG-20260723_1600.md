## Description
* **Declarative App Shell Architecture (`ui_app_shell.js` & `index.html`)**: Created the `<insetu-app-shell>` Web Component to manage top-level navigation, sub-tab routing, action tracks, and extension layout slots. Excised raw HTML layout nodes (`.top-bar`, `.tabs`, `#tab-context`, `#tab-edit`) from `index.html` to establish complete declarative DOM assembly.
* **yenVUI Component Suite Integration**: Replaced legacy UI primitives with native `yenVUI` web components (`<yenvui-card>`, `<yenvui-async-btn>`, `<yenvui-modal>`, `<yenvui-dropdown>`, `<yenvui-pill>`, `<yenvui-filter-group>`, `<yenvui-search-bar>`, `<yenvui-status-bar>`, `<yenvui-toast-container>`). Converted `window.alert` notifications to non-blocking toasts.
* **Asynchronous Cartographer Decoupling (`app.py` & `engine_gather.py`)**: Decoupled `map_repositories` execution from synchronous compile workflows, offloading repository cartography sweeps to non-blocking background worker tasks via `submit_immediate_job`.
* **SDK V2 Brokered Resource Tracking (`sdk.js`)**: Upgraded `InSetuElement` base class with managed lifecycle tracking primitives (`registerInterval`, `registerGlobalListener`, `dispatch`). Automated teardown of timers and event listeners upon component unmounting.
* **VFS Sync & Compilation Flow Alignment (`fs.js` & `bridge.js`)**: Deprecated optimistic manifest mutations (`optimisticallyAddFileToManifest`) in favor of deterministic system re-compilation triggers (`executeSystemCompile`).
* **Linter Guardrails & Fitness Functions (`fitness_functions.py`)**: Codified automated AST and regex linter rules to enforce `yenVUI` layout primitives, static `extensionName` getters, element registration checks, and ban raw layout classes or imperative DOM queries in action handlers.
