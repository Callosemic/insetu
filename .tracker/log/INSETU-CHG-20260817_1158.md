## Description
* **ADR 0041 UI Hooks Deprecation**: Fully purged `uiHooks` definitions across `dev`, `flow`, `ingest`, `notes`, `prompts`, and `tracker` frontend extensions in accordance with ADR 0041. Replaced with `customEditors` (`notes`, `tracker`), declarative `layoutSlots` (`ingest`), and event bus listeners (`dev`, `flow`, `prompts`).
* **Artifact Vacuum Centralization**: Refactored `engine_flow.py` and `engine_git.py` to route context and diff artifact cleanup through `utils_core.vacuum_manifest_artifacts()`.
* **Hierarchical Kanban Tracker Expansion**:
  * **Backend Schema & Settings (`engine_tracker.py`)**: Added `tier`, `parent_id`, `depends_on`, `priority`, and `size` properties to `TRACKER_SCHEMA`. Implemented dynamic tier resolution (`_resolve_tier`), configurable system and custom schemas (`SYSTEM_SCHEMAS`), parent tab scoping, and vocabulary harmonization worker (`harmonize_vocab_task`).
  * **Frontend Controls (`ext_tracker.js`)**: Introduced `InSetuExtTrackerSettings` component for configuring schemas, parent tabs, and global views. Added parent ticket and dependency picker modals, `customEditors` registration for `.tracker/` files, and dynamic layout slot re-compilation.
* **Styles & Component Cleanup**: Streamlined static CSS rules across `ext_citations.js`, `ext_flow.js`, `ext_git.js`, `ext_hooks.js`, `ext_notes.js`, `ext_prompts.js`, and `ext_tracker.js`, stripping custom body/tag classes in favor of Sutram primitives and shared styles.
