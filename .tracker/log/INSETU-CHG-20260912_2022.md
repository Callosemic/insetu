## Description
* **Centralized VFS Path Resolution SSOT (`vfs.py`)**: Introduced `_resolve_physical_path()` helper to consolidate physical path resolution across all VFS transaction operations (`delete`, `move`, `archive`, `save_physical`, `read`, `walk`), eliminating duplicated resolution logic and path handling drift.
* **Worker Step-Chaining Engine & Telemetry (`workers.py`, `extension.py`, `types.py`)**: Formalized background worker step chaining (ADR 0037) in `workers.py`. Added `JobChainStep` and `JobChainPayload` TypedDict definitions in `types.py`. Updated `_execute_immediate_job` to manage chain history, propagate `next_kwargs`, emit `job_baton_passed` hooks, and update job status/artifacts. Simplified `@worker` decorator in `extension.py`.
* **System Deltas Active/Pending Module Telemetry (`sync.py`, `app.js`)**: Updated `get_system_deltas` in `sync.py` to identify active and pending compilation modules from running worker jobs. Updated client `app.js` to update `AppStore` state (`activeModules`, `pendingModules`) and dynamically update module loading spinners across step transitions.
* **VFS Selection Expansion & Barrier Guardrails (`extension.py`)**: Updated `ctx.expand_selection()` to handle string URIs (`ctx://contexts/`, `ctx://diffs/`, `ctx://prompts/`, `vfs://`) and ensure canonical `vfs://` URI output formatting. Added 5.0s max timeout guard to `sync_vfs_barrier()`.
* **Event Bus Duplicate Registration Guardrail (`hooks.py`)**: Added guardrail in `HookRegistry.on` checking function file path and name to prevent duplicate hook callback registrations caused by double module imports.
* **URI Scheme Parsing Correction (`utils.py`)**: Refactored `parse_uri` in `utils.py` to correctly resolve single-segment authority URIs (e.g. `vfs://my_repo`) to `(repo, "")` rather than empty repo strings.
* **Redundant VFS Transaction Emission Cleanup (`vfs.py`)**: Removed redundant `vfs_mutated` event emission from `VFSTransaction.__exit__`, eliminating double-firing of mutation events during atomic file writes.
