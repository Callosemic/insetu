## Description
This release deploys the Zero-Bundler SPA Hash Router, centralizes event and hook broadcasting via the safe `window.inSetu.events` event bus substrate, enables folder entity participation in multi-selection and context quickpacking, and hardens modal teardown boundaries against event bubbling.

### Core Enhancements & Architectural Refinements
* **Zero-Bundler SPA Hash Router (`store.js`, `app.js`, `ui_app_shell.js`):**
  - Integrated `window.location.hash` as the absolute Single Source of Truth for UI routing (`#/{workspace_id}/{tab}/{sub-tab}/{deep_path}`).
  - Added `activeTab`, `activeSubTabs`, and `setActiveRoute()` to `AppStore`.
  - Replaced fragmented `localStorage` tab tracking with reactive Zustand subscriptions and URL hash synchronization.

* **Fail-Safe Event Bus & Hook Emitter (`sdk.js`, `fs.js`, `bridge.js`, `gather.js`, `app.js`):**
  - Established `window.inSetu.events` with safe `emit(eventName, detail)` and `emitHook(zoneName, payload)` methods.
  - Excised repetitive, deeply chained `window.inSetu.extensions.Registry.executeUIHook` checks across core files.
  - Normalized `act.emitEvent` definitions in `ExtensionRegistry.registerExtension` to automatically bridge to event dispatch callbacks.

* **Folder Selection & VFS Quickpack Compilation (`InSetuFileTree`, `engine_gather.py`, `app.js`):**
  - Upgraded folder cards in `<insetu-file-tree>` to assign `entityType = 'folder'` and `entityData = { id: folderPath, folderpath: folderPath, isDir: true }`.
  - Refactored `@gather_bp.worker("pack_selection_task")` in `engine_gather.py` to recursively expand `folderpath` items into context text payloads.
  - Updated selection tray and batch action matchers to handle both `filepath` and `folderpath`.

* **Modal Teardown Event Guard (`ui_modal.js`, `ui_system_settings.js`):**
  - Injected `if (e.target !== e.currentTarget) return;` checks inside modal close handlers to prevent event bubbling from child components from closing parent modal overlays.

* **UI Layout Clean-up (`gather.js`, `ui_system_settings.js`):**
  - Relocated "Clear Quickpacks" trigger from `InSetuExtGatherActions` dropdown into the "Quickpacks" category header in `InSetuExtGather`.
  - Hardened workspace deletion in `InSetuWorkspaceEditor` to explicitly reset `sessionStorage` and `localStorage` to `'default'`.
