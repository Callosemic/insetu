## Description
* Extracted `SettingsManager` into `insetu/sdk/extension.py` to provide a normalized API for registering and accessing extension configuration schemas.
* Implemented generic settings form generation via `InSetuGenericSettingsModal`, automatically rendering input panels based on dynamically declared schema layouts.
* Consolidated the RAG text chunking pipeline (`compile_context_payload`) into `engine_gather.py` to allow uniform chunking for all contexts, mapped to a new `max_context_size_kb` setting.
* Refactored `engine_bridge.py` to externalize `is_effectively_identical()` and use it to skip strict No-Op blocks and prevent false-positive duplicate patch bugs natively on the backend.
* Fixed Base64 text-decoding in the Yomama Diff Viewer (`ext_bridge.js`) to prevent UTF-8 characters from corrupting UI output.
