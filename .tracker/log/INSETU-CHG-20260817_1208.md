## Description
* **API Gateway Job Polling Offloading (`insetu/static/js/core/api.js`)**: Removed automatic, implicit `pollJob` invocation from `window.inSetu.api.workspace` when receiving `data.job_id`, preventing dual-polling race conditions and delegating background job tracking to explicit orchestrators like `bindJobAction`.
* **Parts Browser Chunk Inspection (`insetu/static/js/core/fs.js`)**: Added an `👁️ View` action button to individual chunk items in the Parts modal (`m.browser.isParts`), allowing direct text inspection of multi-part context chunks.
* **Parts Modal View State Preservation (`insetu/static/js/core/fs.js`)**: Updated `viewAndCopy` to evaluate `browserConfig.isParts` and preserve the Parts browser modal open state when launching an individual chunk view.
* **Modal Re-Center Lifecycle Fix (`insetu/static/js/core/fs.js`)**: Updated `InSetuFileModal.updated` handler to re-open/re-center `<dialog>` when `fileModal` state updates while already open.
