## Description
This release introduces priority-based lifecycle hook subscriptions, adds native toggle controls for inSetu OS directory tracking (`.insetu`), sanitizes layout slot namespace prefixes, and refines VFS context compilation and verification mechanics.

### Key Enhancements & Architectural Refinements
* **Priority-Based Hook Execution (`insetu/hooks.py`)**: Enhanced `@hooks.on(event_name, priority=50)` to accept an integer priority level. Callback subscriptions are stored as ordered tuples and sorted deterministically during execution.
* **OS Directory Tracking Control (`insetu/utils_core.py` & `insetu/static/js/config.js`)**: Integrated a native `track_os` configuration flag and settings UI checkbox, enabling developers to dynamically include or suppress auto-mapping of the `.insetu` directory.
* **Layout Slot Prefix Tolerance (`insetu/static/js/store.js`)**: Updated `ExtensionRegistry.compileLayout()` and `registerExtension()` to automatically strip redundant `slots:` prefixes from layout slot definitions (`primary-navigation`, `sub-navigation`, etc.).
* **Surgical Context Compilation (`insetu/engine_gather.py`)**: Modified `generate_context_file()` to preserve existing manifest entries when compiling specific targeted repositories rather than wiping the global manifest.
* **Macro Slew Limiter Optimization (`insetu/engine_gather.py` & `insetu/workers.py`)**: Tuned the VFS ledger processing silence window down to 0.5 seconds and reduced the VFS ledger daemon check interval to 1000ms for tighter UI responsiveness.
* **Force File Verification in Sync Bridge (`insetu/static/js/bridge.js`)**: Added a `force` parameter to `_verifyFiles` in `InSetuExtBridge`, allowing JIT cache invalidation when re-targeting patch files in the UI.
* **Editor Settings Registration Alignment (`insetu/static/js/components/ui_editor.js`)**: Replaced raw `registerSettingsAction` invocation with formal declarative extension schema registration under `ExtensionRegistry.registerExtension('editor', ...)`.
* **Fitness Function Extension Mandate (`tests/fitness_functions.py`)**: Codified `EXTENSION_NAME_GETTER_MANDATE` rule to enforce static `extensionName` getters on components inheriting from `InSetuElement`.
* **yenVUI Core Component Addition (`insetu/static/vendor/yenvui/`)**: Added vendor UI token definitions and core Lit components (`async-btn.js`, `card.js`, `modal.js`, `tabs.js`).
