## Description
* **Terminal Backend Status Endpoint (`engine_term.py`)**: Added `status` GET endpoint (`/api/<workspace_id>/term/status`) returning `has_sock` and `support_pty` availability flags to the client.
* **Missing Dependency UI Banner (`ext_term.js`)**: Updated `InSetuExtTerm` to query `/status` on mount and render a warning banner with installation instructions when `flask-sock` is missing from the host environment.
* **PS1 Prompt Capture & Environmental Warning Silence (`engine_term.py`)**: Refined PTY initialization `PROMPT_COMMAND` to capture the original OS `PS1` variable once (`_INSETU_ORIG_PS1`) while setting the prompt to `\w ❯ `, preserving dynamic prompt additions (.venv, git branch, conda environment) added later by active shells. Added `BASH_SILENCE_DEPRECATION_WARNING="1"` to the PTY execution environment.
