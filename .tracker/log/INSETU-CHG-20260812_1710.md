## Description
* **Bucket Naming Standardization (`engine_gather.py`, `engine_topology.py`)**: Standardized default catch-all bucket identifiers from `"default_catch_all"` to `"main"` across context compilation and topology ledger indexing.
* **Context Exclusion Support (`engine_gather.py`)**: Added evaluation of `exclude_from_context` in `provide_base_workspaces` to support omitting specific target repositories or sub-buckets from RAG context compilations.
* **Repo-Level Configuration Overrides (`engine_topology.py`, `utils_core.py`)**: Refactored ignore rule resolution (`repo_ignore_dirs`, `repo_ignore_files`, `repo_ignore_patterns`) and file extension filters (`exts`) to allow explicit repository-level configurations to override global defaults rather than forcing union/concatenation.
* **Bucketing Diagnostic Endpoint (`routes_system.py`)**: Added `/api/system/config/test_bucketing` and `/api/<workspace_id>/system/config/test_bucketing` REST endpoints to allow JIT previewing and validation of file-to-bucket mapping rules.
* **Config Sanitization (`utils_core.py`)**: Updated `sanitize_workspace_config` to strip legacy `is_catch_all` flags during sub-bucket sanitization.
