## Description

* **SDK V2 Context Migration across Backend Extensions**: Refactored backend extension engines (`engine_citations`, `engine_flow`, `engine_format`, `engine_git`, `engine_hooks`, `engine_ingest`, `engine_prompts`, `engine_research`, `engine_skills`, `engine_term`, `engine_tracker`) to strictly consume `ExtensionContext` (`ctx.db`, `ctx.vfs`, `ctx.jobs`, `ctx.config`, `ctx.resolve_path`).
* **Banned Import Elimination**: Removed legacy `get_connection`, `execute_vfs_save`, `execute_vfs_delete`, `submit_immediate_job`, and `update_immediate_job_status` imports from extension modules in compliance with SDK V2 contracts.
* **Worker Decorator Standardization**: Upgraded async background worker tasks in `citations` (`search_task`) and `ingest` (`ingest_task`) to use the native `@bp.worker` decorator.
* **Frontend Topology Store Decoupling**: Updated JS extension components (`ext_citations`, `ext_flow`, `ext_git`, `ext_hooks`, `ext_prompts`, `ext_tracker`) to subscribe to `window.inSetu.stores.Gather` for `allRepos` and `gatherOptions` rather than reading from `AppStore`.
* **Git Operations & Safety Hardening**: Moved Git diff/push state tracking into `GitStore`. Added explicit 30-second timeout circuit breakers to background `git pull` and `git fetch` operations.
* **Sensitive Credentials Masking**: Updated settings schemas in `freshdesk` and `research` to mask API keys using `type: "password"` and `secure: True`.
* **Automation Hooks & VFS Triggers**: Offloaded `hooks` execution off-thread via `@hooks_bp.worker("execute_rule_task")` reacting to `vfs_mutated` events.
* **Fitness Functions Validator Enhancements**: Expanded static analysis rules in `insetu/tests/fitness/` to enforce SDK context bounds, subprocess whitelists, empty route selection bans, and pull timeout circuit breakers.
