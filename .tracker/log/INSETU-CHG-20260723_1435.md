## Description
* **Modal Fullscreen Standardization (`ext_flow.js`, `ext_freshdesk.js`, `ext_research.js`, `ext_tracker.js`)**: Replaced deprecated string-based `maxWidth="100vw"` / `maxWidth="95vw"` modal attributes with declarative boolean `?fullscreen=${true}` properties on `<insetu-modal>` instances across extension components.
* **yenVUI Tracker Filter Component Integration (`ext_tracker.js`)**: Updated Issue Tracker filter pills and filter groups to consume `<yenvui-pill>` and `<yenvui-filter-group>` web components, binding to normalized `@yenvui-pill-toggled` and `@yenvui-filter-changed` custom events.
* **Narrow Viewport Layout Hardening (`ext_tracker.js`)**: Refactored `@container (max-width: 800px)` style rules to enforce column gaps, header borders, and clean vertical stacking when constrained in narrow container slots.
* **Shadow DOM Resolution for Automation Hooks (`ext_hooks.js`)**: Upgraded element resolution in action triggers and toolbar buttons to check `insetu-app-shell` shadow DOM boundaries prior to falling back to global `document.querySelector`, ensuring actions execute reliably under shadow root encapsulation.
