## Description
* **Editor Preferences Backend API Migration (`ui_editor.js`)**: Migrated editor configuration (`insetu_md_links`) off browser `localStorage` to backend workspace API endpoint (`editor/settings`), ensuring multi-tenant persistence and alignment with ADR 0017.
* **Settings Hub Modernization (`ui_system_settings.js`)**: Redesigned OS Settings Hub with a 3-tab layout (`System`, `Core`, `Extensions`), dynamically rendering settings actions for active core/domain extensions via `_openGenericSettings()` and `sutram-generic-settings`.
* **Workspace Extension Management Modal (`ui_system_settings.js`)**: Relocated workspace extension toggles from `InSetuExtConfig` to a dedicated modal in `InSetuSystemSettings` (`_saveActiveExtensions`), supporting server-driven reboot/soft-refresh flows.
* **Unified Settings Save Event Listener (`ui_system_settings.js`)**: Standardized `sutram-settings-save` event handling to post configuration payloads directly to `window.inSetu.api.workspace(`${extName}/settings`)`, removing legacy `localStorage` branching.
* **Config View Streamlining (`config.js`)**: Purged redundant workspace metadata and extension toggles from `InSetuExtConfig`, refocusing the view purely on global ignore rules and target repository mappings.
