## Description
* **Sutram Vendorization & UI Component Harmonization**: Replaced legacy `<yenvui-*>` component tags and `@yenvui-*` event listeners in `ext_citations.js`, `ext_tracker.js`, `ext_research.js`, and `ext_flow.js` with standard `<sutram-*>` equivalents.
* **Gather Store Decoupling**: Refactored `ext_citations.js`, `ext_flow.js`, `ext_git.js`, and `ext_tracker.js` to subscribe directly to `window.inSetu.stores.Gather` for `pinnedRepos` and `allRepos` topology state.
* **SDK ExtensionContext Alignment**: Standardized `engine_dev.py`, `engine_git.py`, `engine_skills.py`, and `engine_tracker.py` to strictly use `ExtensionContext` (`ctx.db`, `ctx.paths`, `ctx.config`, `ctx.get_repo_path()`).
* **Notes Extension Addition (`notes`)**: Introduced the `notes` extension (`engine_notes.py`, `ext_notes.js`) supporting workspace-level Markdown note indexing in `notes_ledger` SQLite cache, RAG context compilation, and frontmatter drawer editing.
* **VFS Non-Blocking I/O & Terminal Safety**: Converted file output in `engine_research.py` to `ctx.vfs.save` transactions and added timer race condition guards during terminal component re-initialization in `ext_term.js`.
