## Description
* **JobManager Background Coalescing & Deduplication (`insetu/kernel/extension.py`, `insetu/kernel/workers.py`)**: Enhanced `submit_immediate_job` and `JobManager.submit` with a `coalesce=False` parameter to deduplicate queued or active background tasks. Added `JobManager.is_in_flight(task_name)` to allow extensions to inspect whether a background task is actively processing in SQLite `immediate_jobs`. Updated `submit_immediate_job` return value to return the job ID string.
* **Frontend System Manifest Refresh Exporter (`insetu/static/js/app.js`)**: Implemented `refreshManifest()` to fetch system manifest state asynchronously and rehydrate `AppStore`. Exposed `refreshManifest` on `window.inSetu.sys`.
