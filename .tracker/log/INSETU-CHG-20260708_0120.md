## Description
This changelog records the comprehensive stabilization and graduation of optional extension views over to native LitElement Web Components, cementing strict Unidirectional Data Flow (UDF) compliance across the frontend layer.

### Core Enhancements
* **Research Inbox Graduation (`ext_research.js`):** Extracted manual element clearing routines and string literal injections into the encapsulated `<insetu-ext-research>` component. Bound all internal variables (`jobs`, `inbox`, `selectedJobId`) straight to the Zustand `ResearchStore` and converted item previews to a declarative modal structure.
* **Kanban Tracker Board Graduation (`ext_tracker.js`):** Fully refactored the sprint board matrix into the reactive `<insetu-ext-tracker>` Web Component. Unified all issue columns (`todos`, `bugs`, `queue`, `log`) under a single template track driven by active tab coordinates, utilizing global `<insetu-card>` primitives for standardized card rendering.
* **Declarative Workspace Configuration (`ext_config.js`):** Migrated transient container overlays to a native `<insetu-modal>` declaration inside the element's template, monitoring configuration states reactively via the central `AppStore`.
* **Context Action Slot Unification (`ext_flow.js`, `ext_git.js`, `ext_prompts.js`):** Isolated view action menus into standalone dropdown components (`InSetuExtFlowActions`, `InSetuExtGitActions`, `InSetuExtPromptsActions`) registered programmatically to the layout engine's actions slot (`slots:sub-navigation-actions`).
