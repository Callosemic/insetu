## Description
* **GatherStore Topology Decoupling (`ui_app_shell.js`, `ui_editor.js`)**: Decoupled primary tab ordering and target repository configuration lookups from `AppStore`, subscribing directly to `GatherStore` (`window.inSetu.stores.Gather`) to align with Three-Tier Architecture state isolation standards (ADR 0029).
* **Polymorphic Async Button Integration (`ui_file_tree.js`)**: Refactored `InSetuCard` dynamic entity card actions (`_renderDynamicActions`) to render actions using `<insetu-async-btn>`, providing status feedback for both async routines and event-driven actions.
* **Brokered Listener Lifecycle Migration (`ui_system_settings.js`)**: Replaced raw `document` and `window` event listeners in `InSetuSystemSettings` with managed SDK registrations (`this.registerGlobalListener`), eliminating manual listener teardown boilerplate on element unmount (ADR 0025).
* **Password Field Type Support (`ui_system_settings.js`)**: Updated `InSetuGenericSettingsModal` to support `field.type === 'password'`, rendering secure password inputs for sensitive extension configurations.
* **Debounce Fitness Guardrail Compliance (`ui_primitives.js`)**: Annotated the status bar timeout handler with the `utils.debounce` whitelist comment to clear static analysis checks.
