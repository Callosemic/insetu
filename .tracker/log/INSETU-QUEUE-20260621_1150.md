## Description
Investigate intercepting global keyboard events within the inSetu UI.
Specific goals:
1. Allow using the `Tab` key to output 4 spaces inside `<textarea>` elements without shifting DOM focus.
2. Intercept `Cmd/Ctrl + S` to override the browser's native save dialog and funnel it to `saveModalFile()`.
3. Allow the `Esc` key to close any active overlay modal contextually.
