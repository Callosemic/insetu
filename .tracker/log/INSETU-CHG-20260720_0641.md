## Description
* **Interactive Editor Link Widgets (`ui_editor.js`)**: Integrated `@codemirror/view` decorator widgets into `<insetu-markdown-editor>` to render clickable `🔗` link icons next to Markdown links (`[label](url)`). Registered `editor_settings` schema (`insetu_md_links`) with `ExtensionRegistry` allowing interactive links to be toggled on demand via settings.
* **Standard Toolbar Abstraction (`ui_primitives.js`, `fs.js`, `gather.js`)**: Abstracted sticky header search and filter bar logic into a reusable `<insetu-standard-toolbar>` Web Component. Migrated `<insetu-vfs-explorer>` and `<insetu-ext-gather>` to consume the standard primitive.
* **Filter Dropdown System Action Transformation (`ui_filter_pills.js`)**: Transformed `<insetu-filter-dropdown>` into a full-width header dropdown triggered by a `.system-action-btn` icon (`🔻` when filters are active, `▽` when neutral).
* **Viewport-Aware Card Overlay Positioning (`ui_file_tree.js`)**: Refactored `<insetu-card>` action drawer positioning to dynamically calculate viewport bounding rects on open, toggling `.position-top` and `.overlay-top` classes to prevent off-screen clipping.
* **System Settings Component Re-organization (`ui_system_settings.js`, `config.js`)**: Extracted `InSetuWorkspaceEditor` and `InSetuGenericSettingsModal` out of `config.js` into `ui_system_settings.js`. Updated settings menu rendering to group actions under "System Settings" and "Extension Settings", prioritizing system configurations first.
* **Global Status Bar Telemetry (`app.js`)**: Implemented `updateDefaultStatus()` to dynamically append pinned repository tags (` | [repo1, repo2]`) to the status bar baseline title, subscribing directly to `AppStore.getState().pinnedRepos`.
* **Yomama Sync Bridge Regex Anchoring & Click Interception (`bridge.js`)**: Refined chunk-matching regex to `/^<<<<<<< SEARCH[\s\S]*?^>>>>>>> REPLACE\s*$/gm` to enforce multiline line-boundary constraints on patch tags (closing `INS-BUG-20260719_0805`). Hardened document click handlers to ignore clicks originating inside modal containers.
* **Full-Bleed Chassis & CSS Polishing (`style.css`, `shared_styles.js`)**: Polished `.bottom-bar` typography/truncation styles and extended CSS container query lookahead selectors (`.screen:has(...)`) to zero out layout padding and scrollbars across all active extension sub-tabs (`tracker`, `gather`, `git`, `flow`, `prompts`, `files`).
