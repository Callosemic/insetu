## Description
* **Context URI Scheme Migration (`insetu/kernel/vfs.py`, `insetu/kernel/extension.py`)**: Migrated virtual URI resolution from legacy `system://` to `ctx://` (and added `vfs://` prefix handling in `VFSTransaction.read()`), ensuring backward-compatible fallback conversion from `system://` to `ctx://`.
* **Dual-Partition Manifest Delta Synchronization (`insetu/static/js/app.js`)**: Updated `checkManifestVersion`, `performSoftRefresh`, and `initializeWorkspaceTopology` to support dual-root manifest structures (`vfs` and `ctx` partitions) when applying deltas and checking manifest emptiness.
* **Architecture Mapping (`CODE_INDEX.md`)**: Updated `CODE_INDEX.md` to map `insetu/core/topology/engine_topology.py`.
* **Fitness Function Enforcement (`tests/fitness/rules_javascript.py`, `tests/fitness/rules_python.py`)**: Codified `LEGACY_SYSTEM_URI_BAN` across JS/Python linter rules to prohibit legacy `system://` strings and added `get_valid_workspace_files`, `get_omniscient_workspace_files`, and `resolve_file_bucket` to `DECOUPLED_UTIL_BAN`.
