## Description
* **Workspace State Synchronization:** Hardened tenant initialization inside `app.js` (`loadWorkspaces`) by updating the centralized `AppStore` state (`activeWorkspace`) immediately upon layout boot and soft-swapping, ensuring headers and fetch interceptors attach perfectly synchronized workspace tokens.
* **Context Tab State Retention:** Refactored `switchTab` logic for the core context panel to preserve active sub-tab layouts safely instead of resetting state blindly to standard bundles.
* **State Performance Optimization:** Optimized layout execution inside `generateDiffs` by lifting the destructuring of `categoryOrder`, `targetConfigs`, `hiddenOutputs`, and `virtualContexts` to the top level of the method block, preventing redundant store lookups during rapid array-filtering loops.
* **Decoupled View Hydration:** Cleaned up `performSoftRefresh` to evict stale payload buffers via `BridgeStore.getState().clearPayload()` and execute native tab state routing through `switchTab`, fully removing hardcoded sub-view rendering invocations.
* **Citations Extension State Hardening:** Developed and integrated a modular, vanilla Zustand store (`CitationStore`) within `ext_citations.js` to manage citation state patterns (`localLibrary`, `pinnedRepos`, `pinnedBuckets`, etc.), decoupling core runtime logic from local closures and manual DOM evaluation.
