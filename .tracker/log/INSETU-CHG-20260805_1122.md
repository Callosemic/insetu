## Description
* **Active Extensions Guarding & Workspace Isolation**: Added strict `window.ACTIVE_EXTENSIONS` checks across all 13 extension modules (`citations`, `dev`, `favorites`, `flow`, `freshdesk`, `git`, `hooks`, `notes`, `prompts`, `research`, `skills`, `term`, `tracker`) to halt polling, telemetry, and background data fetches on unmounted or disabled workspace tenant extensions.
* **Compilation Step Pipeline Registration (`engine_flow.py`, `engine_git.py`)**: Migrated Flow and Git extensions from synchronous `compile_contexts` / `vfs_mutated` hooks to the `@hooks.on('register_compilation_steps')` system worker pipeline (`compile_workflows_task` and `compile_diffs_task`), enabling off-thread multi-worker parallel context compilation.
* **System Route Navigation Standardization (`ext_favorites.js`, `ext_tracker.js`)**: Standardized cross-tab routing and deep navigation across `favorites` and `tracker` extensions to consume `AppStore.getState().setActiveRoute()`.
* **Multi-Chunk Context & System URI Resolution (`engine_format.py`, `engine_git.py`)**: Integrated `resolve_payload_chunks` event bus resolution in Document Formatting and Git Diff engines to resolve `system://` URIs and multi-part context payloads statelessly.
* **WebSocket & Terminal Cleanup Resilience (`engine_term.py`, `ext_term.js`)**: Hardened WebSocket error handling against `ConnectionClosed` / `BrokenPipeError` frame exceptions on client disconnects and sanitized terminal element initialization timers against workspace hot-swap race conditions.
* **Store State Fixes & Async UI Upgrades (`ext_skills.js`, `ext_citations.js`, `ext_dev.js`, `ext_freshdesk.js`)**: Fixed `SkillsStore.clearPayload` reference scope, updated citation modal controls to `<sutram-async-btn>`, and unified extension `uiHooks` around `zone:force-refresh`.
