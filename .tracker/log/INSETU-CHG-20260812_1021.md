## Description
* **Yomama Sync Bridge Genesis Overwrite Telemetry (`bridge_vfs.py`)**: Populated explicit `error_message` and structured `candidates` list (`[{"filepath": resolved_path, "score": 1.0, "match_type": "overwrite"}]`) when a genesis patch targets an existing file requiring user overwrite confirmation.
* **Soft-Deleted Manifest Entry Response (`engine_gather.py`)**: Updated `api_gather_manifest_entry` endpoint to return HTTP 200 with `{"path": path, "entry": None, "status": "deleted"}` when a context entry is missing or tombstoned, preventing spurious HTTP 404 console errors during JIT client manifest delta rehydration.
* **Exact Filename Topology Scanning (`engine_topology.py`)**: Enhanced `get_valid_workspace_files` to match exact file names (`fname in allowed_exts`) alongside extension suffixes (`ext in allowed_exts`), allowing extensionless or custom-named files (e.g., `Dockerfile`, `LICENSE`, `.gitignore`) to be tracked when explicitly listed in repository configuration.
