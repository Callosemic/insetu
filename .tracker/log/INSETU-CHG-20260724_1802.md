## Description
This release introduces centralized security token authentication for REST and WebSocket traffic, deploys a bucket ratio circuit breaker to optimize RAG context compilation, hardens VFS file mutation event tracking, and enhances App Shell view caching.

### Key Enhancements & Refinements
* **Unified Security Token Gatehouse (`insetu/auth.py`, `insetu/app.py`, `app.js`, `store.js`)**:
  * Deployed `insetu/auth.py` providing `/auth/bootstrap` for runtime token handshakes.
  * Configured multi-stage client verification: Localhost bypass (`127.0.0.1`), Tailscale Unix socket WHOIS profile lookups with Trust-On-First-Use (TOFU) whitelisting, and static `auth_token` fallback.
  * Enforced global REST and WebSocket token verification via `enforce_token_gate()` in `app.py`, checking `X-InSetu-Token` headers and query string parameters against the environment-anchored `BOOT_TOKEN`.
  * Integrated `executeSecurityHandshake()` into `app.js` bootloader and tracked `authToken` in `AppStore`.

* **Context Compilation Circuit Breaker & Macro Slew Limiter (`insetu/engine_gather.py`)**:
  * Integrated a Bucket Ratio Circuit Breaker inside `_surgically_update_manifest()`. If `touched_buckets / total_known_buckets > 0.5`, the compiler automatically escalates from localized surgical updates to a full workspace sweep.
  * Restored the Macro Slew Limiter silence window to `5.0` seconds to prevent thrashing during rapid batch saves.

* **VFS Event Log Move Synchronization (`insetu/routes_fs.py`)**:
  * Updated `_vfs_commit_worker()` for move operations to atomically emit both `deleted` (for source) and `added` (for destination) records to `vfs_event_log`, guaranteeing accurate differential context updates.

* **Decoupled Gather Entity Actions (`insetu/static/js/gather.js`)**:
  * Replaced imperative `document.querySelector('insetu-app-shell')` queries in `context-view-parts` entity action with custom event dispatches (`insetu:gather:view-parts`) and SDK brokered global listeners (`this.registerGlobalListener`).

* **App Shell Sub-Tab View Caching & Layout Clean-up (`ui_app_shell.js`, `fs.js`, `style.css`)**:
  * Added `?cacheViews=${true}` to nested sub-navigation `<yenvui-tabs>` instances to preserve active DOM elements and socket connections across sub-tab switches.
  * Removed duplicate `<div class="nested-tab-container">` blocks in `<insetu-app-shell>` render loop.
  * Deprecated obsolete `zIndex="3100"` parameters on `<insetu-modal>` declarations in `fs.js` and cleaned up `.fullscreen-modal` CSS rules.
