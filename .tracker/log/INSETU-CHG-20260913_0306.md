## Description
* **Dynamic Core Module Discovery (`insetu/kernel/utils.py`):** Replaced hardcoded `CORE_MODULES` set with dynamic runtime discovery (`_discover_core_modules()`) sweeping `insetu/kernel/` and `insetu/core/` subdirectories to classify core substrate modules automatically without static array maintenance.
* **Queued Event-Driven VFS Barrier Sentinel (`insetu/kernel/extension.py`, `insetu/kernel/vfs.py`):** Upgraded `ExtensionContext.sync_vfs_barrier()` to put an explicit `action: "barrier"` sentinel carrying a `threading.Event()` into `_VFS_WRITE_QUEUE`, replacing polling loops with deterministic thread signal waiting (`barrier_event.wait(timeout)`).
* **App Core Blueprint Mounting & Domain Alignment (`insetu/app.py`):** Corrected Blueprint registrations in `app.py` for system (`system_bp.bp`) and VFS (`fs_bp.bp`) core extensions. Updated `SettingsManager` domain identifier from legacy `'core_system'` to canonical `'system'`.
* **Extension Template Path Standardization (`insetu/defaults/ext_template_js.txt`):** Updated boilerplate JS extension template imports to reference absolute root-relative asset paths (`/static/extensions/system/sdk.js` and `/static/vendor/sutram/js/shared_styles.js`).
* **POSIX Pathlib Alignment (`insetu/kernel/vfs.py`):** Standardized path calculation in `execute_vfs_archive` to use `Path(new_path).relative_to(ws_root).as_posix()`.
* **Frontend Linter Regex Precision (`tests/fitness/rules_javascript.py`):** Refactored `LEGACY_DOMAIN_ACCESSOR_VIOLATION` linter regex to recognize `window.(inSetu.sys.)?executeSystemCompile` calls accurately without false-positive flags.
* **CODE_INDEX & App Shell Hydration (`CODE_INDEX.md`, `insetu/static/js/app.js`):** Synchronized repository topological tree map with current directory structures and added static entry payload `app.js`.
