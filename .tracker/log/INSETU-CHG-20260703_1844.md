## Description
This ledger item records the systemic UI and backend decoupled executed in this session:

* **Blueprint Extraction:** Decoupled formatting logic into `engine_format.py` and workflow/batch logic into `engine_flow.py`. Prompts logic isolated to `engine_prompts.py`.
* **Frontend View Decoupling:** Stripped hardcoded sub-tabs (`diffs`, `prompts`, `gather`) from `index.html`. These are now dynamically injected by their respective ES6 extension modules (`ext_git.js`, `ext_prompts.js`, `ext_flow.js`).
* **UI Factory Standardization:** Introduced `createNestedRepoFilters`, `createFilterPill`, and `createDropdown` to `UIFactory` in `ui.js`, enforcing a Single Source of Truth for shared UI primitives.
* **Event Bus Middleware (`pre_compile_document`):** Formalized the `pre_compile_document` hook allowing `engine_citations.py` to inject transient CSL-JSON bibliography artifacts and citeproc flags cleanly into the Pandoc compilation pipeline.

## Notes / Execution Log
* This completes a significant portion of the DOM logic splintering effort, moving the platform closer to a fully extension-driven UI layer.
