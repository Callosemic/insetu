## Description
* **Standardized Diff Bucket Filename Resolution (`engine_git.py`)**: Purged legacy `out_file` property overrides from diff context generation and background push tasks, standardizing diff filenames on deterministic `f"{safe_r_dir}_{b_id}_diffs.txt"` / `f"{safe_r_dir}_diffs.txt"` naming.
* **Declarative Git Exclusion Configuration Options (`ext_git.js`)**: Contributed `repoConfigOptions` (`git-repo-exclude`) and `bucketConfigOptions` (`git-exclude`) to the `git` extension registration, rendering `<sutram-toggle>` controls for repository-level and sub-bucket-level `exclude_from_diffs` options in system settings.
* **Tracker Sub-Bucket Configuration Cleanup (`engine_tracker.py`)**: Removed legacy `out_file` properties from dynamically injected tracker sub-buckets (`tracker`, `tracker_closed`, `tracker_omitted`) in `inject_tracker_config`.
