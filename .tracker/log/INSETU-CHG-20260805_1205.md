## Description
* **Client SDK API Extension Enablement Gatekeeper (`api.js`, `sdk.js`)**: Implemented client-side active extension validation across `window.inSetu.api.workspace` and `InSetuElement.prototype.api` (`get`, `post`, `delete`), returning mock HTTP 403 Forbidden responses before network request dispatch when targeting disabled workspace extensions.
* **Sutram Registry Active Extension Filter Predicate (`sdk.js`)**: Wired `SutramRegistry.setFilterPredicate()` to filter layout slots and extension registration dynamically based on `window.ACTIVE_EXTENSIONS`.
* **Yomama Sync Bridge Chunk Parsing Fixes (`bridge.js`)**: Corrected chevron delimiter checks for `>>>>>>> REPLACE` terminations with whitespace stripping and ensured unclosed SEARCH/REPLACE blocks at end-of-file streams are properly flushed into cells.
* **Core Substrate Module Expansion (`sdk.js`)**: Expanded `CORE_MODULES` set to include `'system'`, `'fs'`, `'workers'`, `'auth'`, `'security'`, and `'cartographer'`.
* **System Settings Event Propagation Fix (`ui_system_settings.js`)**: Added `e.stopPropagation()` on workspace selection buttons to prevent event bubbling during workspace transitions.
* **VFS Entity Action Chunk Parsing (`fs.js`)**: Updated `file-download` and `file-share` entity action handlers to recognize pre-parsed `chunks` on data payloads.
* **Gather Extension UI Hook Standardization (`gather.js`)**: Standardized context gatherer UI hook listener to target `zone:force-refresh`.
