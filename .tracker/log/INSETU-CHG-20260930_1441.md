## Description
* **Mounted Extension Filtering (`insetu/app.py`)**: Filtered `extensions` array passed to `index.html` template in `index()` route to `mounted_extensions`, ensuring only extensions actually mounted in `app.blueprints` (or pure frontend extensions like `"config"`) are rendered in the primary UI layout shell.
* **AST Fitness Guardrail for Path Resolution (`tests/fitness/rules_python.py`)**: Introduced `RESOLVE_PATH_MUST_EXIST_MANDATE` rule in the Python fitness validator, detecting manual `os.path.exists(ctx.resolve_path(...))` calls in domain extensions and enforcing `ctx.resolve_path(..., must_exist=True)` for SDK compliance.
