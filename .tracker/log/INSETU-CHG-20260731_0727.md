## Description
* **Presentation Layer Vendorization:** Migrated frontend components across 11 extension modules (`citations`, `flow`, `format`, `freshdesk`, `git`, `hooks`, `ingest`, `prompts`, `research`, `skills`, `tracker`) from `<yenvui-*>` to vendorized `<sutram-*>` primitives.
* **Developer Dashboard Extension (`dev`):** Created `insetu/extensions/dev/` providing real-time file thrashing monitoring and Yomama Sync Bridge error logging backed by a dedicated SQLite schema (`file_telemetry` and `bridge_errors`).
* **Non-Blocking Flow VFS Operations:** Refactored file archiving in `engine_flow.py` to route through non-blocking `ctx.vfs.save` transactions rather than synchronous `shutil` operations.
* **Git Diff Optimization:** Added `git_evaluation_complete` event emissions and optimized touched bucket diff checks in `engine_git.py` to prevent redundant compilations when diff payloads are unchanged.
