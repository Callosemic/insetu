## Description
* **Client Gateway Async Polling (`insetu/static/js/core/api.js`)**: Updated `window.inSetu.api.workspace` to evaluate `data.job_id` alongside `data.requires_refresh`, setting progress status during background job processing and conditioning soft UI refreshes strictly on `data.requires_refresh`.
* **Declarative Custom Editors Engine (`insetu/static/js/core/fs.js`)**: Integrated ADR 0041 `customEditors` schema evaluation in `viewSourceFile`, allowing extensions to intercept file view requests via declarative `.match()` rules without legacy string hooks. Added `modal:new-file:actions` layout slot mounting in the file creation modal.
* **Settings Hub Action Routing (`insetu/static/js/core/components/ui_system_settings.js`)**: Introduced `_renderExtensionActions` to dynamically render custom extension settings actions alongside base settings. Hardened settings saves to exclude hidden fields and omit empty network saves.
* **Repository Configuration UX (`insetu/static/js/core/config.js`)**: Standardized "Add Repository" vs "Edit Repository" modal titles, added path preview string, `_createDirIfNeeded` toggle, directory creation on confirm (`_handleConfirmRepo`), and `sutram-async-btn` footer integration.
* **Document Type Canonical Aliasing (`insetu/static/js/core/components/ui_editor.js`, `insetu/static/js/core/fs.js`)**: Standardized frontmatter document type extraction to evaluate `meta.doc_type` alongside `meta.doctype`.
* **Gather Template Style Cleanup (`insetu/static/js/core/gather.js`)**: Replaced deprecated `.gather-body` CSS class usage with inline flex layout styles in `InSetuExtGather`.
