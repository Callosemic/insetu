## Description
* **Process-Global Thread-Locked VFS Manifest Cache (`engine_topology.py`):** Replaced thread-local `_vfs_manifest_thread_cache` (`threading.local`) with process-global `_vfs_manifest_cache` guarded by `_vfs_manifest_cache_lock` (`threading.Lock()`). Ensures cache invalidation during `force_topology_scan` and `resolve_topology_buffer` reliably clears cached manifests across all worker and HTTP request threads.
* **Watchdog & Topology Filter `ignore_exceptions` Support (`engine_topology.py`, `utils_core.py`):** Added `ignore_exceptions` checks to `FileSystemObserver.process_event` and `resolve_topology_buffer`. Whitelisted sub-bucket exception paths bypass standard `ignore_dirs` and `ignore_patterns` exclusions.
* **Expanded Mutation Operation Aliases (`engine_topology.py`):** Updated `resolve_topology_buffer` to recognize `"deleted"`, `"remove"`, and `"removed"` mutation operation strings alongside `"delete"` when purging tombstoned records from `topology_ledger`.
* **VFS/CTX Path Normalization in Workspace Resolution (`engine_topology.py`):** Stripped `vfs://` and `ctx://` scheme prefixes before performing absolute physical path comparisons in `resolve_owning_workspaces`.
