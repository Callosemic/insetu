## Description
* **Gather Context Exclusion Decoupling (`insetu/static/js/core/gather.js`, `insetu/static/js/core/config.js`)**: Decoupled `exclude_from_context` setting controls from hardcoded UI in `config.js` into declarative `repoConfigOptions` and `bucketConfigOptions` schema options registered by the `gather` extension in `gather.js`.
* **Repository Bucketing Diagnostic Action (`insetu/static/js/core/config.js`)**: Added `_testRepoBucketing` method and "🧪 Test" action controls across bucket settings and repository settings modals, querying `/system/config/test_bucketing` and rendering dry-run file matching results in `window.inSetu.ui.viewTextBlob`.
* **Repository Override Toggles & Legacy Input Cleanup (`insetu/static/js/core/config.js`)**: Added `_renderOverrideToggle` helper in `InSetuExtConfig` to manage repository-level overrides for `exts`, `repo_ignore_dirs`, `repo_ignore_files`, and `repo_ignore_patterns`. Removed legacy `is_catch_all` and `out_file` inputs.
* **Extension Config Options Rendering (`insetu/static/js/core/config.js`)**: Dynamically rendered extension-contributed `bucketConfigOptions` and `repoConfigOptions` components within sub-bucket and repository configuration cards.
