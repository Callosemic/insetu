## Description
* **JavaScript Architectural Fitness Linter Hardening (`tests/fitness/rules_javascript.py`)**:
  * Enforced `CANONICAL_API_ROUTE_PREFIX_MANDATE` verifying that all `this.api.*` and `window.inSetu.api.*` calls specify an explicit `<module>/<endpoint>` route prefix against `known_api_modules`.
  * Enforced `TIER2_EXTENSION_NAME_LEAK_BAN` preventing Tier 2 core JavaScript modules from referencing Tier 3 extension stores (`stores.<Ext>`), context volumes (`ctx://<ext>/`), or `.insetu-data/<ext>/` paths directly.
  * Enforced `CROSS_STORE_MUTATION_BAN` ensuring extensions only invoke `.setState()` on their own declared stores.
  * Broadened `SUTRAM_FORM_CONTROL_MANDATE` to flag raw `<input type="checkbox">` and `<input type="radio">` in Lit templates, and broadened `SUTRAM_BUTTON_MANDATE` to catch any raw `<button>` tag inside Lit extension templates.
  * Added `"sutram:resolve-primary-tab-meta"` to `valid_sutram_ui_hooks` and exempted `insetu_sdk.js` in the `APPROVED_API_VERB_MANDATE` AST check.
* **Python AST Fitness Linter Hardening (`tests/fitness/rules_python.py`)**:
  * Enforced `WORKER_CTX_FIRST_PARAM_MANDATE`, `WORKER_TYPED_SIGNATURE_MANDATE`, and `WORKER_PARAMETER_OVERLOAD_BAN` across `@*.worker` functions to guarantee typed contract validation and eliminate legacy `isinstance(force_full, list)` overloading.
  * Enforced `FIND_ACTIVE_PIPELINE_JOB_PREDICATE_MANDATE` banning deprecated `force_full=` keyword arguments on `find_active_pipeline_job()` in favor of IoC `predicate=` callables.
  * Enforced `TIER2_EXTENSION_NAME_LEAK_BAN` on Python string constants in `insetu/core/` and replaced `LEGACY_SWITCHBOARD_REFERENCE_BAN` with `LEGACY_SYSTEM_JSON_BAN` (enforcing `host.json` and `workspaces.json` over legacy `system.json`).
  * Enforced `LEGACY_EXTERNAL_DUNDER_BAN`, `SUBCLASS_SIGNATURE_PARITY_MANDATE`, and `UNDECLARED_EXTERNAL_DEPENDENCY_IMPORT` across extension engines, and expanded `PATHLIB_MANDATE` to cover `splitext`, `getmtime`, `getsize`, `exists`, `relpath`, `expanduser`, `abspath`, `isdir`, and `isfile`.
* **Behavioral Unit Test Suite Expansion (`tests/unit/`)**:
  * **`test_canonical_uris.py`**: Added `test_prompts_resolve_get_and_live_post_buffer_with_nested_macros` validating recursive `{{include_prompt:...}}` expansion, `{{ macro_* }}` parameter substitution, default fallback syntax (`{{ macro_var | default }}`), and non-mutating live buffer `POST /prompts/resolve` evaluation.
  * **`test_config_cascade.py`**: Migrated daemon-scope test assertions from legacy `system.json` to `host.json` and `workspaces.json`.
  * **`test_sdk_improvements.py`**: Added `test_extension_dependency_resolution_and_whitelist_installer` testing `resolve_external_dependency_spec`, `_get_whitelisted_extension_packages`, `_background_install_extension_deps`, and declarative `post_install_commands` (Playwright Chromium installation), plus AST linter assertions for `WORKER_TYPED_SIGNATURE_MANDATE` and `WORKER_PARAMETER_OVERLOAD_BAN`.
  * **`test_sutram_compliance.py`**: Added `test_canonical_api_route_resolution_contract` and `test_dual_representation_macro_preview_contract` verifying `_resolveScopedPath`, `getJson`/`postJson`/`deleteJson`, `toggleBufferPreview`, and macro-expanded export actions.
* **Code Index Synchronization (`CODE_INDEX.md`)**:
  * Populated descriptions for ADRs 0070–0075 and updated `test_sdk_improvements.py` summary, resolving all `# [comment required]` placeholders.
