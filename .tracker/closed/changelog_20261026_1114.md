## Description
* **Flask Transport Decoupling & Unified Payload Access (`engine_cronic.py`, `engine_favorites.py`, `engine_flow.py`, `engine_hooks.py`, `engine_tracker.py`)**:
  * Eradicated all `from flask import jsonify` imports and direct `ctx.req` reads across all five Workflow Automation and Task Management engines.
  * Standardized incoming request payload reading on unified `ctx.payload` across all route handlers.
  * Route handlers return plain Python dictionaries with optional HTTP status codes, letting `AkasaExtension.route` marshal responses at the HTTP boundary.
* **Strict Typed Worker Signatures (`@*.worker`)**:
  * Purged untyped `**kwargs` and un-annotated arguments across 11 background workers in `cronic`, `flow`, `hooks`, and `tracker`, declaring explicit Python type annotations on all parameters and confirming `ctx` as the first parameter.
* **Declarative Host Binary Registration (`engine_cronic.py`)**:
  * Declared `external_binaries=["crontab"]` directly on the `InSetuExtension` constructor in `cronic`.
* **Flow Cross-Store Decoupling, Macro Preview Action Parity, and Encapsulated JIT Artifact Resolution (`engine_flow.py`, `ext_flow.js`)**:
  * Purged cross-store `GatherStore.setState` mutations from `ext_flow.js` and decoupled `availableOptions` from `GatherStore`.
  * Removed floating window-level `insetu:ensure-fresh-artifact` listener, encapsulating it strictly within `InSetuExtFlow.connectedCallback()` lifecycle management.
  * Added `supportsMacroPreview: true` and `file-copy-expanded` to prompt entity actions in `InSetuFlowViewProjection`.
  * Registered `@flow_bp.on('heal_missing_domain_volume')` to trigger targeted workflow recompilations when `workflows` cache volumes are missing or cold on disk.
* **Canonical API Route Prefix Normalization (`CANONICAL_API_ROUTE_PREFIX_MANDATE`)**:
  * Prefixed all `this.api.*` calls across `ext_cronic.js`, `ext_flow.js`, `ext_hooks.js`, and `ext_tracker.js` with explicit `<module>/<endpoint>` identifiers.
* **Sub-Navigation Menu Consolidation (`ext_hooks.js`)**:
  * Eradicated bespoke `InSetuExtHooksActions` and `slots:sub-navigation-actions` in favor of declarative `menuActions` on `slots:sub-navigation`.
* **Pathlib Compliance & InSetuURI Adoption**:
  * Replaced `os.path.splitext`, `os.listdir`, `os.path.getmtime`, `os.path.relpath`, and `os.path.expanduser` with `pathlib.Path` methods across `engine_cronic.py`, `engine_hooks.py`, and `engine_tracker.py`.
  * Replaced deprecated `parseURI()` invocations with `new this.utils.InSetuURI()` across `ext_favorites.js`, `ext_flow.js`, and `ext_tracker.js`.
  * Centered automation rule cryptographic approvals around `.insetu/host.json` (`get_daemon_host_config_path()`).
