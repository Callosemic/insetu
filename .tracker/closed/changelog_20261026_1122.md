## Description
* **App Shell Debug Mode Gating (`insetu/app.py`)**:
  * Gated `app.run(debug=...)` behind `use_debug = os.environ.get("INSETU_DEBUG", "0") == "1" or use_reloader`, eliminating default unauthenticated debugger pin interfaces during standard daemon execution.
* **Resilient Profile Scaffolding (`insetu/cli.py`)**:
  * Protected `shutil.copy` with `try...except OSError` in `scaffold_profiles(cwd)`. If default template file reads fail, the scaffolder automatically falls back to generating in-memory JSON fallback payloads (`host.json`, `workspaces.json`).
* **Extension Starter Template Flask Decoupling (`insetu/defaults/engine_template_py.txt`)**:
  * Eradicated `from flask import jsonify` from the extension starter template.
  * Injected `docstring="[sync] Lists all stored items for this extension."` and Python docstring into the scaffolded `@route` handler, returning a plain dictionary (`{"items": items}`) to guarantee immediate compliance with `FLASK_TRANSPORT_LEAK_BAN` and `API_DOCSTRING_MANDATE`.
* **Service Worker Route Cleanup & Cache Version Invalidation (`insetu/static/sw.js`)**:
  * Purged the obsolete `/download/` path pattern from `HOST_BYPASS_PATTERNS`, aligning with the canonical `/api/<ws>/fs/fetch?download=1` route.
  * Bumped `self.OS_CACHE_VERSION` from `'v5'` to `'v6'` to enforce client Service Worker cache invalidation across client browsers.
