## Description
* **Explicit API Client Migration:** Eradicated raw `fetch()` calls across all extension UI modules (`ext_citations.js`, `ext_flow.js`, `ext_format.js`, `ext_git.js`, `ext_ingest.js`, `ext_research.js`, `ext_tracker.js`, `ext_term.js`). Replaced them with the intent-driven `window.inSetu.api.workspace` and `window.inSetu.api.system` clients, resolving the leaky tenant header abstraction (ADR 0016).
* **SDK V2 Frontend Integration:** Migrated the `favorites` and `prompts` UI extensions to the native `InSetuElement` base class and `createExtensionStore` factory, automating tenant lifecycle teardowns and simplifying internal state mechanics.
* **SDK V2 Backend Integration:** Extracted `engine_prompts.py` from raw Flask Blueprints into the `InSetuExtension` object wrapper. Replaced explicit `workspace_id` parameters and localized utility imports with the managed `ctx.vfs`, `ctx.config`, and `ctx.resolve_path` context attributes.
* **Workspace Physics Fixes:** Remedied the hardcoded global directory references inside `engine_skills.py` (`_get_user_skills_dir`), routing the path evaluation properly through `get_workspace_physics(workspace_id)`.
* **Download Pipeline Cleanup:** Abstracted the raw BLOB retrieval logic inside `ext_git.js` into the centralized `window.fetchAndDownloadState` utility, matching the behavior unified in `INS-QUEUE-20260701_1030_DOWNLOAD_PIPELINE_UNIFICATION`.
