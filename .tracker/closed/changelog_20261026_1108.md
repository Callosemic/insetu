## Description
* **Flask Transport Shell Decoupling (`FLASK_TRANSPORT_LEAK_BAN`)**:
  * Eradicated `from flask import jsonify` and `from flask import request` across all seven Knowledge, Authoring, and Support extensions (`citations`, `freshdesk`, `ingest`, `notes`, `publish`, `research`, `skills`).
  * Route handlers return plain Python dictionaries and optional integer HTTP status codes, delegating response marshaling to `AkasaExtension.route` at the HTTP boundary.
  * Standardized incoming request payload reading on unified `ctx.payload` across all route handlers, replacing direct access to `ctx.req.json`, `ctx.req.args`, and `ctx.req.get_json()`.
* **Strict Typed Background Worker Contracts (`WORKER_TYPED_SIGNATURE_MANDATE`)**:
  * Purged generic `**kwargs` and un-annotated arguments across 11 asynchronous workers in `citations`, `freshdesk`, `ingest`, `publish`, and `research`, declaring explicit Python type annotations on all parameters as the SSOT for synchronous contract validation.
* **Declarative Extension Dependency Contracts & In-App Installation**:
  * Declared PyPI dependencies, system binaries, and setup commands directly on `InSetuExtension(...)` constructors:
    * `freshdesk`: `external_dependencies=["mistune"]` (purged legacy `__external_depends__`).
    * `ingest`: `external_dependencies=["beautifulsoup4", "markdownify"]`.
    * `publish`: `external_binaries=["pandoc", "pdflatex"]`.
    * `research`: `external_dependencies=["beautifulsoup4", "playwright"]` and `post_install_commands=[["$PYTHON", "-m", "playwright", "install", "chromium"]]`.
  * Wired in-app dependency verification (`this.getMissingDependencies()`) and one-click background package installation (`this.installExtensionDependencies()`) in `<insetu-ext-ingest-modals>`, `<insetu-ext-publish-modals>`, and `<insetu-ext-research>`.
* **Cross-Extension Capability Dispatch (`CROSS_MODULE_PRIVATE_IMPORT_BAN`)**:
  * In `engine_research.py`, eradicated direct cross-module private import of `extract_markdown_from_url`, delegating web extraction strictly to `ctx.call("ingest.url", url=target_url, method=parser_type, wait=True)`.
* **Canonical API Route Prefix Normalization (`CANONICAL_API_ROUTE_PREFIX_MANDATE`)**:
  * Prefixed all `this.api.*` and `window.inSetu.api.*` calls with explicit `<module>/<endpoint>` identifiers across `ext_citations.js`, `ext_freshdesk.js`, `ext_ingest.js`, `ext_publish.js`, `ext_research.js`, and `ext_skills.js`.
* **Sutram Presentation Purity & Structural Cleanup**:
  * Replaced raw `<input type="radio">` with `<sutram-select>` and raw `<button>` with `<sutram-btn>` in `ext_citations.js`.
  * Replaced raw `<form>` with `@submit` and `<button type="submit">` with `<sutram-async-btn>` in `ext_skills.js`; removed duplicate/orphaned session logging methods from `InSetuExtSkills`.
  * Replaced `InSetuExtResearchActions` and `slots:sub-navigation-actions` with an in-place "Back to Jobs" `<sutram-btn>` and declarative `menuActions` on `slots:sub-navigation` ("New Research Job") in `ext_research.js`; removed orphaned `syncResearchState()`.
  * Purged illegal cross-store mutation against `OfflineStore.setState()` in `ext_notes.js` (`CROSS_STORE_MUTATION_BAN`).
* **Pathlib Compliance & Canonical Fetch Routing**:
  * Migrated all file existence checks to `Path.exists()` in `engine_notes.py` and `engine_publish.py`.
  * Replaced `os.makedirs()` with `Path.mkdir(parents=True, exist_ok=True)` in `engine_research.py`.
  * Migrated publish and research download URLs from legacy `/download/{name}` to canonical `/api/{ctx.workspace_id}/fs/fetch?file={name}&download=1`.
  * Registered `@research_bp.on('vfs_resolve_file')` handler for artifact resolution.
