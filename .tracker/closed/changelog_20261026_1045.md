## Description
* **Hierarchical Path-Scoped Comment Preservation & Signature Caching (`insetu/core/cartographer/cartographer.py`)**:
  * Upgraded `extract_existing_comments` with an indentation-depth-aware path stack (`path_stack`), resolving comments to fully-qualified relative paths (`rel_path` and `f"{rel_path}/"`) alongside basename fallbacks. Prevents comment collisions between identically named files (e.g., `__init__.py`, `core.py`) across disparate directories.
  * Added `_is_path_managed(current_path, managed_dirs)` supporting exact segment matches, directory boundary checks, and nested subpath definitions.
  * Upgraded `render_ascii_tree` with a 4-tier comment lookup sequence (`rel_lookup_key` -> `next_path` -> `lookup_key` -> `key`).
  * Replaced physical `index_path.stat().st_mtime_ns` checks in `map_repositories` with in-memory VFS index reading (`ctx.vfs.read`) and content hashing (`pre_sig = (tuple(filtered_files), hash(live_vfs_index), tuple(managed_dirs))`), skipping AST parsing and disk writes when trees are unchanged.
  * Replaced `get_workspace_physics` and manual path concatenations with `get_repo_path(repo_dir, workspace_id)`.
  * Enforced explicit parameter typing on `_background_map` (`target_repos: Optional[List[str]] = None`, `ledger_events: Optional[List[Dict[str, Any]]] = None`).

* **Universal Default Chunking, Decoupled Volume Self-Healing & Flask Decoupling (`insetu/core/gather/engine_gather.py`)**:
  * Formalized default context chunking in `compile_context_payload`: when `max_context_size_kb` is 0 or omitted, context files cleanly default to a 400 KB ceiling (`effective_max_kb = max_kb if (max_kb and max_kb > 0) else 400`).
  * Added un-suffixed base URI cleanup in `compile_context_payload`: when a context payload splits into multiple bins (`total_bins > 1`), any obsolete unsplit `base_uri` is unlinked from disk via VFS.
  * Replaced `os.path.getsize(f_path)` with `Path(f_path).stat().st_size` in `generate_context_file`, fulfilling the `PATHLIB_MANDATE`.
  * Fully eradicated `from flask import jsonify` across all route handlers (`api_clear_quickpacks`, `api_gather_pack_selection`, `api_repo_template`, `api_manifest_version`, `api_gather_manifest_entry`) in favor of returning plain Python dictionaries.
  * Replaced direct `ctx.req.args` and `ctx.req.json` accesses with unified `ctx.payload`.
  * Decoupled JIT context self-healing in `_resolve_or_heal_compiled_ctx_artifact`: purged the direct cross-module import `from insetu.extensions.flow.engine_flow import _background_compile_workflows`, delegating non-contexts volume healing to `hooks.emit('heal_missing_domain_volume', volume=parsed.volume, workspace_id=wid)`.
  * Enforced explicit parameter typing across all worker tasks (`_execute_delayed_compile`, `_pack_selection_worker`, `_background_compile`), satisfying `WORKER_TYPED_SIGNATURE_MANDATE` and `WORKER_PARAMETER_OVERLOAD_BAN`.

* **Dual-Representation Prompt Buffer Resolution & Macro Expansion (`insetu/core/prompts/engine_prompts.py`, `insetu/core/prompts/prompts.js`)**:
  * Expanded `api_prompts_resolve` to support both `GET` and `POST` methods with typed `PromptResolveQuery`. Evaluates live, unsaved in-memory buffer content without writing to disk, strips YAML frontmatter via `parse_frontmatter(content)`, and recursively resolves `{{include_prompt: ...}}` macros within prompt bodies.
  * Fixed macro migration regex in `migrate_legacy_prompt_macros_on_boot` to match `(\{\{\s*include_prompt\s*:\s*)([^\s{};,\'"]+)`, preserving trailing parameter definitions `{ key: "val" }`.
  * Eradicated `from flask import jsonify` in `engine_prompts.py`.
  * In `prompts.js`, purged the `insetu:file-fetch-url` listener that previously intercepted buffer reads and loaded macro-expanded text into editable tabs. Editable prompt buffers now fetch raw source text (`{{include_prompt:...}}`) from `/fs/fetch`, guaranteeing non-destructive saves.
  * Subscribed `prompts.js` to `insetu:can-preview-file` and `insetu:resolve-buffer-preview`, delegating on-demand preview evaluation to `POST prompts/resolve` when buffers are dirty and `GET prompts/resolve` when clean.
  * Replaced legacy `parseURI` in `prompt-fork-template` with `new window.inSetu.utils.InSetuURI(destUri).relativePath`.

* **Typed Topology Workers & SettingsManager Centralization (`insetu/core/topology/engine_topology.py`)**:
  * Hoisted `SettingsManager` import from function scope in `broadcast_cross_workspace_mutations` to top-level module scope.
  * Enforced explicit typed parameter signatures across all worker tasks (`_background_scan_topology`, `_background_boot_scan`, `_background_resolve_topology`).
  * Eradicated `from flask import jsonify` and `ctx.req.args` in `api_topology_vfs_repo` in favor of `ctx.payload` and plain dictionary returns.
