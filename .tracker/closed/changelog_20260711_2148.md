## Description
* **Async API Migrations**: Refactored the File System deep search (`/api/<workspace_id>/fs/search`) from a blocking `GET` route to a non-blocking `POST` route. Search operations now leverage the background `immediate_jobs` ledger, eliminating HTTP event loop thread starvation.
* **CQRS Event Bus Parity**: Updated the Gather engine (`engine_gather.py`) to listen to `post_file_save` and `post_file_delete` hooks in addition to `vfs_transaction_committed`. This ensures RAG payloads dynamically regenerate for individual UI file mutations, not just bulk VFS transactions.
* **Zustand UDF Compliance**: Enforced strict state immutability across `fs.js` (ADR 0021 compliance). Replaced mutative reference assignments with pristine clones (e.g., `{ ...manifest }` and `[...files]`) to guarantee reactivity and prevent cross-tenant memory ghosting.
* **API Client Enforcement**: Migrated lingering raw `fetch` calls and legacy endpoint routes in `fs.js` to utilize the explicit `window.inSetu.api.workspace` and `window.inSetu.api.system` clients, fulfilling ADR 0016.
* **Bridge UI Auto-Hydration**: The Yomama Sync Bridge (`bridge.js`) now proactively hydrates the `AppStore` manifest and triggers `zone:post-file-save` UI hooks upon successful atomic VFS commits, synchronizing the client UI instantly.
* **PWA & Auth Hardening**: Added robust `try/catch` wrappers around `sessionStorage` in `api.js` and `app.js` to gracefully handle iOS PWA suspension quirks and strictly enforced tenant scope boundaries.
* **Static Analysis**: Expanded `fitness_functions.py` to programmatically ban Zustand reference mutations (`ZUSTAND_REFERENCE_MUTATION`) and mandate CQRS hook parity (`CQRS_EVENT_PARITY`).
