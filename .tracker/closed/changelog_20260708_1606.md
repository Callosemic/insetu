## Description
* **CodeMirror 6 Migration:** Replaced the legacy EasyMDE (CM5) dependency with a modular CodeMirror 6 integration utilizing native ES imports via `esm.sh`. This eliminates render-blocking `<script>` tags from the HTML skeleton.
* **GUI-Driven Workspace Management:** Successfully shipped the `<insetu-workspace-editor>` LitElement, providing a native visual interface for creating, deleting, and hot-swapping workspaces without manual JSON manipulation.
* **UDF Settings Segmentation:** Abstracted the settings menu rendering logic into `ExtensionRegistry.registerSettingsAction`, organizing links into semantic categories (Workspace, Tracker, Practice, Extensions).
* **VFS Emitted Deletions:** Upgraded `routes_fs.py` to correctly emit background `post_file_delete` hooks upon successful physical file removal.
* **Tenant Sniffing Consolidation:** Swept `app.py` and `routes_system.py` to enforce the use of `sniff_tenant_id()` over raw header extraction.
