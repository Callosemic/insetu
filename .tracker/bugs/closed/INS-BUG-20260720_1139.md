## Description
In the Favorites extension, favorited folders could not be removed or correctly evaluated due to payload ambiguity between file paths and folder paths in the backend API and frontend component bindings.

## Notes / Execution Log
* **Resolution (2026-07-25):** 
    - Updated `add_favorite` in `engine_favorites.py` to accept explicit `folderpath` and `filepath` attributes alongside legacy `path` strings, explicitly setting `type = 'folder'` when `folderpath` is supplied.
    - Updated `InSetuFavBtn` and `fave_toggle_folder` in `ext_favorites.js` to accept `.folderpath` properties and pass explicit path types to `FavoritesStore.addFavorite`.
    - Removed deprecated `zone:fs-dropdown-menu` UI hook.
