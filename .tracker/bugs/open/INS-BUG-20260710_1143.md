## Description
The `ext_citations.js` extension currently violates the DOM Read Ban (Unidirectional Data Flow constraint) by explicitly scraping values from the active document tree.

**Offending Code (`_insertCitationToEditor`):**
`const litEditor = document.getElementById('global-os-editor');`
`const text = isCM6 ? litEditor.value : (textArea ? textArea.value : '');`

This bypasses the Zustand state tree to imperatively read the DOM, which risks desynchronization and violates the Phase 1 Component Graduation criteria.

**Required Action:**
Abstract the active editor's string buffer into the `AppStore` (or a new `EditorStore`) via continuous `@content-changed` emissions. Refactor the citations extension to statelessly query `AppStore.getState().activeEditorContent`.
